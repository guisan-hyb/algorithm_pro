# 随机快速排序（经典版 + 荷兰国旗优化版）

> 来源笔记：`1126随机快速排序.cpp`｜核心程度：必背｜分类：01 基础与排序

## 一句话

把"选谁做划分值"从**固定位置**改成**随机位置**，就把快排从 O(n²) 的最坏情况收敛到了概率意义下的 O(n log n)。

## 解决什么问题

- 通用快速排序，常数比归并小、原地排（额外空间 O(log n) 只有递归栈）；
- 荷兰国旗版（三分区）还能一次把**所有等于 x 的元素**都钉死，而不是每次只钉死一个位置，适合有大量重复值的数组。

## 核心思想

### 经典版（二分划分）

1. 在当前范围 `[l, r]` 上**随机**取一个数做划分值 `x`；
2. `partition1`：`<= x` 的放左边、`> x` 的放右边，并保证 `<= x` 区间的**最后一个是 x**，返回它的下标 `m`；
3. 递归 `[l, m-1]` 和 `[m+1, r]`。

### 荷兰国旗版（三分划分）

游标 `i` 从左往右扫，维护三个区：`< x` 在左、`== x` 在中、`> x` 在右，用全局变量 `first / last` 带回等于区的左右边界：

- `a[i] < x`：与 `first` 交换，`first++`，`i++`（换过来的是已看过的）；
- `a[i] > x`：与 `last` 交换，`last--`，**`i` 不动**（换过来的是没看过的）；
- `a[i] == x`：`i++`。

递归时只需处理 `[l, first-1]` 和 `[last+1, r]`，等于区整段跳过。

## 适用特征（看到这些信号就选它）

- 需要原地排序、常数小、不要求稳定；
- 数组里重复元素很多（选荷兰国旗版，效率显著更好）；
- 需要"第 K 大/小"→ 直接改成随机选择算法（见 `1127随机选择算法`）。

## 复杂度

| 版本 | 时间 | 额外空间 |
| --- | --- | --- |
| 普通快排（固定位置选划分值） | O(n²) | O(n)（压 n 层栈） |
| 随机快排 | O(n log n)（概率意义） | O(log n) |
| 荷兰国旗版 | O(n log n)（概率意义） | O(log n) |

## 易错点

1. 随机只在**选划分值**那一下：`a[l + rand() % (r - l + 1)]`，写成 `rand() % n` 就错了（不是当前区间内的随机）；
2. 荷兰国旗版用全局 `first / last` 带回两个返回值，**递归前必须先存到临时变量**，否则深层递归会把全局变量覆盖掉（笔记原文特别强调了这一点）；
3. 三分区里 `> x` 分支 `i` 不能自增，这是最容易写错的地方；
4. 递归边界用 `l >= r` 而不是 `l == r`，因为三分区可能出现 `first == l`、`last == r` 导致越界递归；
5. 证明不用背（算法导论 7.4.2），记住结论即可。

## 模板（可直接编译运行）

```cpp
// 随机快速排序模板：荷兰国旗三分区版（推荐）
// 期望时间 O(n log n)，额外空间 O(log n)（递归栈），不稳定
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <cstdlib>
#include <ctime>
#include <iostream>
#include <vector>
using namespace std;

int firstIdx, lastIdx;          // 等于 x 的区间 [firstIdx, lastIdx]

// -------- 荷兰国旗划分：< x | == x | > x --------
void partition(vector<int>& a, int l, int r, int x) {
    firstIdx = l;
    lastIdx = r;
    int i = l;
    while (i <= lastIdx) {
        if (a[i] < x) {
            swap(a[firstIdx++], a[i++]);   // 换过来的是已看过的，i++
        } else if (a[i] > x) {
            swap(a[lastIdx--], a[i]);      // 换过来的是没看过的，i 不动
        } else {
            i++;                           // 等于区，直接跳过
        }
    }
}

void quickSort(vector<int>& a, int l, int r) {
    if (l >= r) return;
    int x = a[l + rand() % (r - l + 1)];   // 随机选取划分值
    partition(a, l, r, x);
    int left = firstIdx, right = lastIdx;  // 先存住，递归会覆盖全局变量
    quickSort(a, l, left - 1);
    quickSort(a, right + 1, r);
}

int main() {
    srand((unsigned)time(nullptr));
    int n;
    if (!(std::cin >> n) || n <= 0) return 0;
    vector<int> a(n);
    for (int& x : a) (std::cin >> x);
    quickSort(a, 0, n - 1);
    for (int i = 0; i < n; i++) std::cout << a[i] << " \n"[i == n - 1];
    return 0;
}
```

## 专题深化：为什么成立

三路划分保证 `< pivot` 在左、`== pivot` 居中、`> pivot` 在右。中间段一次就位，递归左右严格更短区间；随机 pivot 使任何固定输入都不能稳定构造最坏划分。

## 专题深化：手算与边界

对 `[3,5,3,1,4]` 选 pivot=3，可得到 `[1]`、`[3,3]` 和 `[5,4]`，重复的 3 不进入递归。

### 对照与取舍

随机化消除输入对抗性，但单次仍可能 O(n²)；期望递推由随机划分的期望比例给出 O(n log n)。三路划分在大量重复值上明显更稳。

### 易错点与反例

1. 随机下标必须包含 right
2. 两路划分在等值很多时可能退化
3. 递归只走较小侧、循环处理较大侧可限制栈深度
4. 小数组插入排序可降低常数
