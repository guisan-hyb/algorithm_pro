# 归并分治（小和问题 / 翻转对）

> 来源笔记：`1126归并分治.cpp`｜核心程度：高频考点｜分类：01 基础与排序

## 一句话

把统计任务装进归并排序的 merge 里：**大范围答案 = 左边答案 + 右边答案 + 跨左右答案**，而"左右各自有序"让跨越部分能用不回头滑窗 O(n) 算完。

## 解决什么问题

一类"数对计数/求和"题，暴力 O(n²)，归并分治 O(n log n)：

1. **小和问题**：每个数左边比它小的数累加起来求和；
2. **翻转对**：`i < j` 且 `nums[i] > 2 * nums[j]` 的数对个数（LeetCode 493）；
3. 逆序对、右侧比它小的个数、区间和类计数题。

## 核心思想

**判别三步法**（笔记原文）：

1. 大范围上的答案，是否等于 左部分答案 + 右部分答案 + 跨越左右产生的答案？
2. 计算"跨越左右"时，如果加上**左、右各自有序**这个设定，能否获得计算便利（形成滑窗、不走回头路）？
3. 两条都成立 → 该问题大概率能用归并分治，求解过程中顺带把归并排序做完即可。

为什么"已经算完了才排序"不影响答案：跨越左右用的是**下标关系**（左半的小标一定小于右半），排序只改变同侧内部顺序，不会改变"这个左元素配那个右元素"的配对关系。

**小和**：对右半的每个 `j`，左半中所有 `<= a[j]` 的元素都要累加。因为左半有序，指针 `i` 只向右走，用一个 `sum` 边加边用：

```cpp
for (int i = l, j = m + 1, sum = 0; j <= r; j++) {
    while (i <= m && arr[i] <= arr[j]) sum += arr[i++];
    ans += sum;
}
```

**翻转对**：对左半每个 `i`，右半中满足 `a[i] > 2 * a[j]` 的 `j` 只增不减：

```cpp
for (int i = l, j = m + 1; i <= m; i++) {
    while (j <= r && (long)arr[i] > (long)arr[j] * 2) j++;
    ans += j - m - 1;      // j 是"第一个不满足"的位置
}
```

**关键顺序**：先统计跨越贡献，**再**做 merge 排序。统计必须在排序之前完成（此时左右各自有序但仍保持原相对位置语义）。

## 适用特征（看到这些信号就选它）

- 要数"满足某不等式/大小关系的下标对 (i, j)"的个数或贡献和；
- 朴素枚举每个位置都要往回/往前看一遍，是 O(n²)；
- 题目的关系只跟元素**值的大小**有关、跟下标前后有关，且合并两个有序区间时容易双指针扫描；
- 数据量 n ≤ 10^5 ~ 10^6，O(n log n) 才过。

## 复杂度

- 时间 O(n log n)（每层 O(n) 统计 + O(n) merge，共 log n 层）；
- 额外空间 O(n)（辅助数组）。

## 易错点

1. **统计和排序的顺序不能颠倒**：先 merge 排序再统计虽然有时也正确（因为大小关系与顺序无关），但很多题会被破坏，稳妥做法是**先统计、后 merge**；
2. 溢出：小和、翻转对结果可能很大，累加用 `long long`；`arr[j] * 2` 要强转 `(long long)` 再乘，防止 `int` 溢出（笔记里有明确写法 `(long)arr[i] > (long)arr[j] * 2`）；
3. 翻转对里 `ans += j - m - 1` 的 `-1` 别丢：循环结束时 `j` 是**第一个不满足**的位置；
4. 指针 `j` 在外层循环外初始化（`j = m + 1`），不能放进 for 的初始化里，否则退化成 O(n²)；
5. 多组数据时全局 `help` 不用清空（每次都会覆盖用到的区间），但数组大小要开够。

## 模板（可直接编译运行）

```cpp
// 归并分治模板：小和 + 翻转对
// 时间 O(n log n)，额外空间 O(n)
// 判别三步法：① 大范围 = 左 + 右 + 跨左右？ ② 左右有序后跨越部分能否滑窗？ ③ 都成立即可用
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <vector>
using namespace std;

vector<int> a, help;

// -------- 小和：每个数左边比它小的数之和 --------
long long mergeSmall(int l, int m, int r) {
    long long ans = 0;
    for (int i = l, j = m + 1, sum = 0; j <= r; j++) {
        while (i <= m && a[i] <= a[j]) sum += a[i++];   // 左半有序，i 不回头
        ans += sum;
    }
    int i = l, p = l, q = m + 1;                        // 先统计，后排序
    while (p <= m && q <= r) help[i++] = a[p] <= a[q] ? a[p++] : a[q++];
    while (p <= m) help[i++] = a[p++];
    while (q <= r)   help[i++] = a[q++];
    for (int k = l; k <= r; k++) a[k] = help[k];
    return ans;
}
long long smallSum(int l, int r) {
    if (l == r) return 0;
    int m = (l + r) >> 1;
    return smallSum(l, m) + smallSum(m + 1, r) + mergeSmall(l, m, r);
}

// -------- 翻转对：i < j 且 a[i] > 2 * a[j] --------
long long mergeReverse(int l, int m, int r) {
    long long ans = 0;
    int j = m + 1;                                      // 必须在循环外初始化
    for (int i = l; i <= m; i++) {
        while (j <= r && (long long)a[i] > (long long)a[j] * 2) j++;
        ans += j - m - 1;                               // j 是第一个不满足的位置
    }
    int i = l, p = l, q = m + 1;
    while (p <= m && q <= r) help[i++] = a[p] <= a[q] ? a[p++] : a[q++];
    while (p <= m) help[i++] = a[p++];
    while (q <= r)   help[i++] = a[q++];
    for (int k = l; k <= r; k++) a[k] = help[k];
    return ans;
}
long long reversePairs(int l, int r) {
    if (l == r) return 0;
    int m = (l + r) >> 1;
    return reversePairs(l, m) + reversePairs(m + 1, r) + mergeReverse(l, m, r);
}

int main() {
    int n;
    if (!(std::cin >> n)) return 0;
    a.resize(n);
    help.resize(n);
    for (int& x : a) (std::cin >> x);

    vector<int> origin = a;                 // 两个函数都会打乱数组，各跑一份
    std::cout << "smallSum = " << smallSum(0, n - 1) << "\n";
    a = origin;
    std::cout << "reversePairs = " << reversePairs(0, n - 1) << "\n";
    return 0;
}
```

## 笔记里的题目

- **小和问题**：`[1,3,4,2,5]` 的小和 = 16（笔记给了完整手算过程）；
- **翻转对数量**（LeetCode 493）`i < j && nums[i] > 2 * nums[j]`。

## 延伸

- 同类题也能用线段树 / 树状数组做，复杂度同为最优；
- 归并分治能解决的题不止简单计数，后续还有"整块分治"；
- 与之对照：`对比 子序列DP 和 子数组DP.md` 讲的是 DP 视角，归并分治是"分治 + 有序"视角。

## 专题深化：为什么成立

分治答案总能拆成左区、右区、跨中点三类且互斥。递归解决前两类，合并阶段处理第三类，因此不会重算或漏算。

## 专题深化：手算与边界

`[2,1,3]` 分成 `[2]` 与 `[1,3]`。合并时 1 小于 2，一次贡献逆序对 1；区间内没有额外逆序，总数为 1。

### 对照与取舍

| 方法 | 复杂度 | 优点 | 局限 |
| --- | --- | --- | --- |
| 归并分治 | O(n log n) | 稳定、可离线 | 需要临时数组 |
| 树状数组 | O(n log n) | 支持动态更新 | 值域大要先离散化 |

### 易错点与反例

1. 小和/逆序对必须用 long long
2. 相等元素不能计入严格逆序
3. 跨区贡献可能一次累加一整段
4. 排序改变下标后题目若要求原下标需提前保存

## 专题深化：进阶拓展

典型扩展是多维偏序、最近点对、离线动态贡献。识别信号是“跨中点两侧的关系可以批量结算”。
