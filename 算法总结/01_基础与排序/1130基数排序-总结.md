# 基数排序（不基于比较的排序）

> 来源笔记：`1130基数排序.cpp`｜核心程度：了解 + 能默写｜分类：01 基础与排序

## 一句话

按"个位 → 十位 → 百位"逐位做**稳定计数排序**，排完最高位，整个数组就整体有序了。

## 解决什么问题

- 对整数（尤其是范围大但**位数少**的整数）做到 O(n) 排序；
- 是"不基于比较的排序"的代表（另一个是计数排序）；
- 需要 O(n) 排序且数据是整数、非负（或可整体平移到非负）时用。

## 核心思想

1. 先算出最大值在 BASE 进制下有几位 `bits`；
2. `offset = 1, BASE, BASE², ...` 逐位循环，每轮：
   - **计数**：统计当前这一位每个数字出现的次数到 `cnt[BASE]`；
   - **前缀和**：把 `cnt` 变成前缀累加形式（得到每个数字的"结束位置"）；
   - **前缀分区（关键：从右往左扫）**：`help[--cnt[digit]] = arr[i]`，从右往左扫是**保证稳定性**的关键；
   - 回写到 `arr`。

正确性来源：每一轮都要**稳定**，否则低位排好的相对顺序会被高位打乱。

## 适用特征（看到这些信号就选它）

- 数据是整数（非负；有负数则整体减去最小值再移位）；
- 位数少（例如 ≤ 10 位）、数据量大（n ≥ 10^5）；
- 不能用比较器（对象结构复杂）→ **不要用基数排序**，改写代价高，不通用。

## 复杂度

- 时间 O(n)（每轮 O(n)，共 bits 轮，bits 是常数量级）；
- 额外空间 O(m)（`cnt` 桶 + `help` 辅助数组，m 与 BASE 和 n 有关）；
- **稳定性：稳定**。

## 易错点

1. 有负数必须先整体减去最小值、排完再加回来（笔记的 `sortArray` 就是这一套）；
2. 分区回写必须**从右往左**遍历原数组，否则稳定性丢失；
3. `cnt` 每轮结束后要清零/重置，否则累计到下一轮就全错；
4. `(arr[i] / offset) % BASE` 的取位写法，`offset *= BASE` 与 `bits--` 必须同轮推进；
5. BASE 调大：轮数变少、速度变快，但 `cnt` 占用空间变大，要按题权衡；
6. 基数排序不通用：一旦要排序的对象不再是常规整数，改写成本陡增。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int BASE = 10;              // 十进制

int bitsOf(long long x) {         // 最大值有几位
    int ans = 0;
    while (x) { x /= 10; ans++; }
    return ans;
}

// arr 内必须全为非负数
void radixSort(vector<int>& arr, int bits) {
    int n = (int)arr.size();
    vector<int> cnt(BASE), help(n);
    for (long long offset = 1; bits > 0; offset *= BASE, bits--) {
        fill(cnt.begin(), cnt.end(), 0);
        for (int i = 0; i < n; i++) cnt[(arr[i] / offset) % BASE]++;
        for (int i = 1; i < BASE; i++) cnt[i] += cnt[i - 1];        // 前缀次数
        for (int i = n - 1; i >= 0; i--)                            // 从右往左，保证稳定
            help[--cnt[(arr[i] / offset) % BASE]] = arr[i];
        for (int i = 0; i < n; i++) arr[i] = help[i];
    }
}

// 处理负数版本：整体平移到非负再还原
void sortWithNegative(vector<int>& a) {
    if (a.size() < 2) return;
    int mins = *min_element(a.begin(), a.end());
    int maxs = 0;
    for (int& x : a) { x -= mins; maxs = max(maxs, x); }
    radixSort(a, bitsOf(maxs));
    for (int& x : a) x += mins;
}
```

- 笔记为纯模板；额外给了"计数排序"的说明（数组元素都在 `[0, 60]`、数据量 10^6 时，统计频次后直接从小到大输出）作为"不基于比较的排序"的引入。

## 延伸

- 不基于比较的排序只有计数/基数这类，代价是**不通用**；
- 与 `1201重要排序算法的总结.md` 的稳定性表格一起看：计数排序、基数排序都是稳定的；
- 基数是"低位优先 + 稳定排序"的思想，LSD 之外还有 MSD 基数排序，笔记未涉及。
