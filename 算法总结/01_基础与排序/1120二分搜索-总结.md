# 二分搜索（含二分精髓：找峰值）

> 来源笔记：`1120二分搜索.cpp`｜核心程度：必背（一切 log 级算法的地基）｜分类：01 基础与排序

## 一句话

二分不是"数组有序才能用"，而是"只要你能确定答案**必定在某一侧**，就可以每次砍掉一半"。

## 解决什么问题

1. 有序数组中找 `>= num` 的最左位置（`lower_bound` 的地基）；
2. 有序数组中找 `<= num` 的最右位置（`upper_bound` 的地基）；
3. 在**无序**数组上二分：寻找峰值元素（相邻元素互不相等，返回任一峰值下标）。

## 核心思想

- 维护一个"一定有答案"的闭区间 `[l, r]`，每次取 `mid`，根据比较结果砍掉一半；
- **找边界型**：用一个 `pos` 记录"目前见过的最优答案"，不满足时收缩到另一侧；
- **折线型（峰值型）**：把数组看成折线图，`arr[mid-1] > arr[mid]` 说明左边一定存在峰值，`arr[mid] < arr[mid+1]` 说明右边一定存在峰值，两侧都不可能才说明 `mid` 自己是峰值；
- 精髓原句：**"即使整体是无序的，你只要确定哪侧必有、哪侧必没有，就可以去二分。"**

## 适用特征（看到这些信号就选它）

- 题目要求 `O(log n)`；
- 有明显的"单调性"、"可行性随参数单调变化"、"峰/谷"；
- 要找一个位置的左右边界（第一个满足条件的位置、最后一个满足条件的位置）；
- 数据量到 `10^9` 以上，线性遍历必死（结合"根据数据量猜解法"）。

## 复杂度

- 时间 O(log n)，额外空间 O(1)。
- 循环写法用 `while (low <= high)` 闭区间，或 `while (low < high)` 半开区间，**两种只能选一种，不能混用**。

## 易错点

1. `mid` 的写法：`mid = low + ((high - low) >> 1)`，防止 `low + high` 溢出（C++ 里 `int` 也要养成习惯）；
2. `>>` 对负数不是向下取整，涉及负数时别用移位代替 `/2`；
3. 找边界时 `pos` 初值必须是"没找到"的语义（例如 `-1`），返回前不要漏掉它；
4. 峰值题要**先单独检查 0 位置和 n-1 位置**，这两个位置不可能靠"两侧都有邻居"的判据得到；
5. 求"左边第一个大于等于 x"和"右边最后一个小于等于 x"时方向容易写反，建议背定式而不是临场推。

## 模板（可直接编译运行）

```cpp
// 二分搜索模板：找最左/最右边界 + 无序数组找峰值
// 时间 O(log n)，额外空间 O(1)
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <vector>
using namespace std;

// ---------- 1. 有序数组中 >= value 的最左位置 ----------
int findLeft(const vector<int>& a, int value) {
    int lo = 0, hi = (int)a.size() - 1, pos = -1;
    while (lo <= hi) {
        int mid = lo + ((hi - lo) >> 1);
        if (a[mid] >= value) { pos = mid; hi = mid - 1; }   // 记录后继续往左找
        else lo = mid + 1;
    }
    return pos;                                              // 不存在返回 -1
}

// ---------- 2. 有序数组中 <= value 的最右位置 ----------
int findRight(const vector<int>& a, int value) {
    int lo = 0, hi = (int)a.size() - 1, pos = -1;
    while (lo <= hi) {
        int mid = lo + ((hi - lo) >> 1);
        if (a[mid] <= value) { pos = mid; lo = mid + 1; }   // 记录后继续往右找
        else hi = mid - 1;
    }
    return pos;
}

// ---------- 3. 无序数组找任一峰值下标（相邻元素互不相等） ----------
int findPeak(const vector<int>& a) {
    int n = (int)a.size();
    if (n == 1) return 0;
    if (a[0] > a[1]) return 0;                 // 先单独判两端
    if (a[n - 1] > a[n - 2]) return n - 1;
    int l = 1, r = n - 2;                      // 中间区间必定存在峰值
    while (l <= r) {
        int mid = l + ((r - l) >> 1);
        if (a[mid - 1] > a[mid]) r = mid - 1;      // 上坡向左，峰在左
        else if (a[mid] < a[mid + 1]) l = mid + 1; // 上坡向右，峰在右
        else return mid;
    }
    return -1;
}

// ---------- 自测：读入 n 个升序数 + 查询值 ----------
int main() {
    int n, q;
    if (!(std::cin >> n >> q)) return 0;
    vector<int> a(n);
    for (int& x : a) (std::cin >> x);
    while (q--) {
        int x;
        (std::cin >> x);
        std::cout << ">=(" << x << ") left=" << findLeft(a, x) << "  <=(" << x << ") right=" << findRight(a, x) << "\n";
    }
    return 0;
}
```

## 笔记里的题目

- 有序数组中找 `>= num` 的最左位置（`findleft`）；
- 有序数组中找 `<= num` 的最右位置（`findright`），笔记额外强调"找 `<= num` 的最左位置没有意义，直接看第一个元素即可"；
- 寻找峰值（LeetCode 162 型），要求 O(log n)，`findPeakElement`。

## 延伸

- 这套写法就是 C++ `lower_bound / upper_bound` 的手写版；
- 二分搜索的三大变体（值二分 / 位置二分 / 答案二分）见 `0105二分答案法`；
- 旋转数组上的二分见 `旋转数组二分查找总结.md`。

## 专题深化：为什么成立

二分的正确性来自每次删去不可能包含答案的区间。以找第一个 `>= target` 为例，若 `a[mid] >= target`，答案不可能是 mid 右侧；否则只可能在右侧。只有先固定区间含义，更新规则才唯一。

## 专题深化：手算与边界

在 `[1,2,2,2,5]` 找第一个 `>=2`：依次收缩到 `left=1`。若改找第一个 `>2`，命中相等时也向右，最终得到下标 4。

### 对照与取舍

| 写法 | 区间含义 | 结束状态 |
| --- | --- | --- |
| 闭区间 | 答案可能在 `[l,r]` | l>r |
| 左闭右开 | 答案在 `[l,r)` | l==r |
| 找最小可行 | 维护单调谓词 | l=首个 true |

### 易错点与反例

1. `mid=(l+r)/2` 可能溢出
2. 重复元素中命中后立即返回并非左边界
3. `while(l<=r)` 配闭区间，`while(l<r)` 常用于半开候选
4. 旋转数组每步必须先识别有序半边

## 专题深化：进阶拓展

二分答案把可行性判定当作单调谓词；三分适用于严格单峰函数。还可对答案空间而非数组二分，例如最小速度、最大容量。
