# 递归 & master 公式

> 来源笔记：`1124递归与master公式.cpp`｜核心程度：必背（分析递归复杂度的唯一通用工具）｜分类：01 基础与排序

## 一句话

一切递归都能画**递归调用图**来理解；一切"子问题规模相同"的递归都能用 master 公式一步写出复杂度。

## 解决什么问题

1. 把递归过程可视化，判断递归深度（会不会爆栈）和调用次数；
2. 快速写出分治型递归的时间复杂度，不用每次都画递归树求和；
3. 决定"这个递归要不要改成非递归"。

## 核心思想

### master 公式

成立前提：**所有子问题的规模相同**，形如

```
T(n) = a * T(n / b) + O(n^c)
```

- `a`：一次递归调用几次子过程；
- `b`：每次调用把问题规模缩小到 1/b；
- `c`：除子过程以外，本层代码的时间复杂度指数。

只看**一层**，比较 `log_b(a)` 与 `c`：

| 情况 | 复杂度 |
| --- | --- |
| `log_b(a) < c` | O(n^c) |
| `log_b(a) > c` | O(n^(log_b a)) |
| `log_b(a) == c` | O(n^c · log n) |

例：`T(n) = 2T(n/2) + O(1)`，a=2,b=2,c=0，`log_2 2 = 1 > 0`，故 O(n)。

补充结论：`T(n) = 2T(n/2) + O(n log n)` 的复杂度是 O(n · log²n)。

### 递归改非递归

- 任何递归都能自己开栈改成非递归；
- 工程上几乎必须改，除非能确定递归深度安全（归并排序、快排、线段树、各种平衡树天然就深，属于例外）；
- **笔试/比赛里能过就不改**，别给自己找麻烦。

## 适用特征（看到这些信号就选它）

- 要把一个问题分成规模相同的小问题（归并、二分、随机选择、快排）；
- 递归式形如 `T(n) = aT(n/b) + ...`，直接套公式；
- 想预估递归深度是否安全（深度 ~ log n 就安全，深度 ~ n 就要考虑爆栈）。

## 易错点

1. **"子问题规模不相同"时不能用 master 公式**。笔记里的反例：左 1/3 区域求最大值、右 2/3 区域求最大值，规模不同，套公式是错的；
2. `b` 是"规模缩小的比例"不是"子问题个数"；`a` 是子问题个数。两者写反是最高频错误；
3. `log_b(a)` 的底是真数在下、底数在上，写公式时注意别把 `log_b a` 写成 `log_a b`；
4. 公式里 `O(n^c)` 只算"本层除了递归调用之外的代价"，merge 的 O(n) 要算进去，`int mid = (l+r)/2` 这种 O(1) 不算。

## 模板（可直接编译运行）

```cpp
// 递归与 master 公式：模板 + 自测
// 记住结论，别每次现场画递归树
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;

// T(n) = 2T(n/2) + O(1) -> O(n)：区间求最大值
int maxValue(const vector<int>& a, int l, int r) {
    if (l == r) return a[l];
    int mid = l + ((r - l) >> 1);
    return max(maxValue(a, l, mid), maxValue(a, mid + 1, r));
}

// T(n) = 2T(n/2) + O(n) -> O(n log n)：归并排序的复杂度来源（见 1125 归并排序）
// T(n) = T(n/2) + O(1)  -> O(log n)：二分（见 1120 二分搜索）

// 递归改非递归的两个方向（此处只示范区间求最大值的显式栈写法）
int maxValueIterative(const vector<int>& a) {
    if (a.empty()) return INT_MIN;
    // 自底向上合并：把相邻区间两两合并，直到只剩一个区间
    vector<int> cur = a;
    while (cur.size() > 1) {
        vector<int> nxt;
        for (size_t i = 0; i < cur.size(); i += 2) {
            if (i + 1 < cur.size()) nxt.push_back(max(cur[i], cur[i + 1]));
            else nxt.push_back(cur[i]);
        }
        cur.swap(nxt);
    }
    return cur[0];
}

int main() {
    int n;
    if (!(std::cin >> n) || n <= 0) return 0;
    vector<int> a(n);
    for (int& x : a) (std::cin >> x);
    std::cout << maxValue(a, 0, n - 1) << " " << maxValueIterative(a) << "\n";
    return 0;
}
```

## 笔记里的题目

- 区间求最大值 `maxValue(arr, l, r)`：master 公式 a=2, b=2, c=0 → O(n)；
- 反例：左 1/3 + 右 2/3 求最大值，用来展示"子问题规模不同则 master 失效"。

## 延伸

- 递归到非递归的两种手段：自己开显式栈、改成迭代（如归并/快排的循环版本）；
- 二叉树遍历的非递归实现见 `1124二叉树遍历的非递归实现和复杂度分析`。

## 专题深化：为什么成立

Master 公式由递归树推导：`T(n)=aT(n/b)+f(n)`，叶子层总代价约 `n^(log_b a)`，合并层总代价由 `f(n)` 决定，比较两者量级得到三种情况。

## 专题深化：手算与边界

`T(n)=2T(n/2)+n` 每层总代价都是 n，共 log n 层，所以 O(n log n)；`T(n)=T(n/2)+1` 只有一个节点逐层缩小，所以 O(log n)。

### 对照与取舍

递归树适合直观求和，代入法适合验证猜想，Master 适合标准分治形式。像 `T(n)=T(n-1)+T(n-2)` 不符合等比例缩小，不能硬套。

### 易错点与反例

1. b 必须大于 1
2. 子问题规模应近似相等
3. 只分析递归而不计入合并常数会导致错误直觉
4. 深递归在工程上还要检查栈空间

## 专题深化：进阶拓展

Akra–Bazzi 可处理不规则分治；主定理的扩展还允许乘对数因子。实际编程中应按迭代实现成本决定是否值得递归。
