# 随机选择算法（第 K 大 / 第 K 小，O(n)）

> 来源笔记：`1127随机选择算法.cpp`｜核心程度：高频考点｜分类：01 基础与排序

## 一句话

随机快排的"单边版"：划分完之后只往**答案所在的那一侧**继续找，所以是 O(n) 而不是 O(n log n)。

## 解决什么问题

- 无序数组中找第 K 大的元素（返回值，不是下标）；
- 无序数组中找第 K 小的元素（等价变形）；
- 任何"只需要一个分位数、不需要全序"的场景（Top-K 的单点版本、中位数）。

要求：**时间复杂度 O(n)**、额外空间 O(1)（不算递归/迭代的自有空间）。

## 核心思想

1. 用荷兰国旗划分把区间分成 `< x | == x | > x`，得到等于区 `[first, last]`；
2. 看目标下标 `i` 落在哪：
   - `first > i` → 答案在左边，`r = first - 1`；
   - `last < i` → 答案在右边，`l = last + 1`；
   - 否则 `i` 落在等于区，`a[i]` 就是答案。
3. **每轮只留一侧**，期望规模按 1/2 递减：`n + n/2 + n/4 + ... = O(n)`。

第 K 大 ↔ 下标换算：数组按升序排好后，第 K 大位于下标 `n - k`（笔记里 `findKthLargest` 就是这么转的）。

## 适用特征（看到这些信号就选它）

- 题目只要"第 K 大/第 K 小/中位数"，且允许 O(n)；
- 用堆做是 O(n log k)，当 k 接近 n/2 时随机选择更优；
- 数据是**可变数组**（算法会打乱原数组顺序）。

## 复杂度

- 期望时间 **O(n)**，最坏 O(n²)（概率极低）；
- 额外空间 **O(1)**（迭代写法，无递归栈）。

## 易错点

1. 下标换算别搞反：升序数组里第 k 大 = 下标 `n - k`；
2. `partition` 的游标条件与三分区一致：`< x` 时 `i++`，`> x` 时 `i` 不动，`== x` 时 `i++`；
3. 循环写法 `for (int l = 0, r = n - 1; l <= r; )` 里**不要**自增，`l / r` 由分支决定；
4. 划分值必须是**当前区间内**的随机元素：`arr[l + rand() % (r - l + 1)]`；
5. 算法会破坏数组有序性，若后续还要用原数组，先备份。

## 模板（可直接编译运行）

```cpp
// 随机选择算法模板：O(n) 求第 K 大 / 第 K 小
// 期望时间 O(n)，最坏 O(n^2)（概率极低）；额外空间 O(1)
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <cstdlib>
#include <ctime>
#include <iostream>
#include <vector>
using namespace std;

int firstIdx, lastIdx;

// 荷兰国旗划分：< x | == x | > x，带回等于区 [firstIdx, lastIdx]
void partition(vector<int>& a, int l, int r, int x) {
    firstIdx = l; lastIdx = r;
    int i = l;
    while (i <= lastIdx) {
        if (a[i] < x)      swap(a[firstIdx++], a[i++]);
        else if (a[i] > x) swap(a[lastIdx--], a[i]);
        else               i++;
    }
}

// 返回升序后下标为 i 的元素值（0-based）
int randomizedSelect(vector<int>& a, int i) {
    int n = (int)a.size();
    for (int l = 0, r = n - 1; l <= r; ) {           // 注意：循环里不自增
        partition(a, l, r, a[l + rand() % (r - l + 1)]);
        if (firstIdx > i)     r = firstIdx - 1;      // 目标在左侧
        else if (lastIdx < i) l = lastIdx + 1;       // 目标在右侧
        else                  return a[i];           // 落在等于区，直接命中
    }
    return -1;
}

int findKthLargest(vector<int>& a, int k) {          // 第 k 大 = 升序下标 n-k
    return randomizedSelect(a, (int)a.size() - k);
}
int findKthSmallest(vector<int>& a, int k) {         // 第 k 小 = 升序下标 k-1
    return randomizedSelect(a, k - 1);
}

int main() {
    srand((unsigned)time(nullptr));
    int n, k;
    if (!(std::cin >> n >> k)) return 0;
    vector<int> a(n), backup;
    for (int& x : a) (std::cin >> x);
    backup = a;
    std::cout << "第 " << k << " 大 = " << findKthLargest(a, k) << "\n";
    a = backup;
    std::cout << "第 " << k << " 小 = " << findKthSmallest(a, k) << "\n";
    return 0;
}
```

## 笔记里的题目

- 无序数组中第 K 大的元素（LeetCode 215 型），笔记明确要求 O(n) 并用随机选择实现；
- 补充提到《算法导论》第 9 章的 **BFPRT 算法**：不随机选取、靠"中位数的中位数"也能做到 O(n) 时间、O(log n) 空间，但不要求掌握。

## 延伸

- 与堆解法对照（见 `1130堆结构常见题目`）：堆是 O(n log k)、稳定可扩展；随机选择是 O(n) 但会打乱数组、且只要一个分位点；
- 时间复杂度证明见《算法导论》9.2，记住结论即可。

## 专题深化：为什么成立

划分后 pivot 的最终名次已确定；目标在左就删除右，目标在右就删除左。只递归一边，随机化后期望规模按常数比例下降。

## 专题深化：手算与边界

`[7,1,5,3,9]` 找第 2 小，选 pivot=5 后左区 `[1,3]`，目标在左边，右侧 `[7,9]` 整体不再处理。

### 对照与取舍

| 方法 | 时间 | 空间 | 适用 |
| --- | --- | --- | --- |
| 全排序 | O(n log n) | O(log n)~O(n) | 需要完整顺序 |
| 快速选择 | 期望 O(n) | O(1) | 静态第 k |
| 堆 | O(n log k) | O(k) | 流式数据 |

### 易错点与反例

1. 第 k 大与数组下标要正确转换
2. k 越界必须先检查
3. 最坏 pivot 仍可导致 O(n²)
4. 重复值最好使用三路划分

## 专题深化：进阶拓展

median-of-medians 提供确定性 O(n)，但常数较大；动态数据应选平衡树或双堆。
