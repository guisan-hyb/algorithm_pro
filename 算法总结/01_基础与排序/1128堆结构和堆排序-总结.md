# 堆结构 & 堆排序（heapInsert / heapify / 两种建堆）

> 来源笔记：`1128堆结构和堆排序.cpp`｜核心程度：必背（堆结构比堆排序有用得多）｜分类：01 基础与排序

## 一句话

堆 = 用数组前缀表示的完全二叉树；两个核心动作是"新元素往上浮（heapInsert）"和"变小的元素往下沉（heapify）"，各自 O(log n)。

## 解决什么问题

1. 维护动态极值：随时插入一个数、随时弹出最大值（大根堆）/ 最小值（小根堆）；
2. 堆排序；
3. 一切"动态第 K 大 / 动态中位数 / 合并 K 个有序序列"的地基（见 `1130堆结构常见题目`）。

## 核心思想

### 下标关系（完全二叉树 ↔ 数组）

对下标 `i`（0 开始）：

| 关系 | 公式 |
| --- | --- |
| 父结点 | `(i - 1) / 2` |
| 左孩子 | `2 * i + 1` |
| 右孩子 | `2 * i + 2` |

孩子下标 `>= size` 视为不存在（所以堆的有效范围由**单独的变量 size** 控制，而不是数组长度）。

### 两个基本动作

- **heapInsert（向上调整）**：`arr[i]` 是新来的，与父结点比较，比父大就交换并继续往上，直到不比父大或到达根。O(log n)。
- **heapify（向下调整）**：`arr[i]` 变小了（或被换成了小值），找出左右孩子中较大的那个，若比自己大就交换并继续往下，直到两个孩子都不比自己大或到达叶子。O(log n)。

### 建堆的两种方式（差别就在这一步）

| 方法 | 过程 | 建堆复杂度 |
| --- | --- | --- |
| 从顶到底（法一） | 依次 `heapInsert(arr, i)` | O(n log n)（log1+log2+...+log n） |
| 从底到顶（法二） | 从最后一个非叶结点往上 `heapify` | **O(n)** |

堆排序的第二步（依次弹出堆顶）过程相同：`swap(arr[0], arr[--size])` 把最大值换到未排序区末尾并断开，再对根 `heapify`，重复到 `size == 1`。整体仍是 O(n log n)。

## 适用特征（看到这些信号就选它）

- 数据**动态变化**（边插边问极值），且询问次数多；
- 要 O(1) 取极值 + O(log n) 增删；
- 题目要"第 K 大/小"但数据是**流式**的（不能随机选择那种离线打乱）；
- 需要一个 O(1) 额外空间的 O(n log n) 排序 → 堆排序（但真正比赛更常用 `priority_queue`）。

## 复杂度

| 操作 | 时间 |
| --- | --- |
| heapInsert | O(log n) |
| heapify | O(log n) |
| 从底到顶建堆 | O(n) |
| 堆排序整体 | O(n log n)，额外空间 **O(1)** |

## 易错点

1. **size 与数组长度必须分开**：堆排序里 `heapify` 的边界是 `size`，不是 `length`；
2. `heapInsert` 第一个元素（i=0）时 `(0-1)/2 == 0`，会自己和自己比，虽然不死循环但要注意语义，标准写法用 `while (arr[i] > arr[(i-1)/2])` 时到达根会自动停下；
3. `heapify` 里"较大孩子"要先判断右孩子存在（`r < size`）再比；
4. 笔记里 `heapSort2` 的循环初值写成了 `for (int i = i - 1; ...)`（应为 `length / 2 - 1`），实战要写成 `for (int i = n / 2 - 1; i >= 0; i--)`；
5. 小根堆只需把比较方向整体反转；
6. **记住结论：堆结构本身比堆排序更有价值**，和比较器结合后才是主战场。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 大根堆：i 位置新来的数往上浮，O(log n)
void heapInsert(vector<int>& h, int i) {
    while (h[i] > h[(i - 1) / 2]) {
        swap(h[i], h[(i - 1) / 2]);
        i = (i - 1) / 2;
    }
}

// 大根堆：i 位置的数往下沉，堆大小为 size，O(log n)
void heapify(vector<int>& h, int i, int size) {
    int l = 2 * i + 1;
    while (l < size) {                              // 有左孩子
        int r = l + 1;
        int best = (r < size && h[r] > h[l]) ? r : l; // 较大孩子
        best = h[best] > h[i] ? best : i;
        if (best == i) break;
        swap(h[i], h[best]);
        i = best;
        l = 2 * i + 1;
    }
}

// 堆排序：从底到顶建堆 O(n) + 逐个弹出 O(n log n)
void heapSort(vector<int>& h) {
    int n = (int)h.size();
    for (int i = n / 2 - 1; i >= 0; i--) heapify(h, i, n);   // 法二建堆
    int size = n;
    while (size > 1) {
        swap(h[0], h[--size]);      // 最大值放到未排序区末尾并断开
        heapify(h, 0, size);
    }
}
```
