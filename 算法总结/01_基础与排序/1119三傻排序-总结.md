# 三傻排序（选择排序 / 冒泡排序 / 插入排序）

> 来源笔记：`1119三傻排序.cpp`｜核心程度：必背｜分类：01 基础与排序

## 一句话

三个 O(n²) 的"上手排序"，价值不在效率，而在于它们是后面所有高级排序（归并、快排、堆排、二分、分治）的对照物和垫脚石。

## 解决什么问题

把数组排成升序（或按比较器定义的顺序）。真实比赛里不会用它排序大数据，但：

- 数据量很小（n ≤ 100 左右）时代码最短、常数最小，插入排序尤其快；
- 是**对数器**里"暴力但正确的方法 b"的标准人选；
- 插入排序是理解"局部有序 → 整体有序"和希尔排序的前置。

## 核心思想

| 算法 | 做法 | 一句话记忆 |
| --- | --- | --- |
| 选择排序 | 每轮在 `[i, n-1]` 里找最小值，换到 `i` | 选一个最小值放到已排序区的末尾 |
| 冒泡排序 | 相邻两两比较，大的往后漂，每轮把最大值送到尾部 | 大的往上冒 |
| 插入排序 | 把 `arr[i]` 按大小插入到前面已排好序的区间中 | 摸牌插牌 |

## 适用特征（看到这些信号就选它）

- n 很小（≤ 1000）且要求写起来快、不易错；
- 需要"稳定排序"但只会写简单排序时（冒泡、插入稳定，选择排序不稳定）；
- 作为对数器的暴力解；
- 排序对象本身几乎有序（插入排序退化成 O(n)）。

## 复杂度

| 算法 | 最好 | 平均/最坏 | 额外空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 |
| 冒泡排序 | O(n)（有序时） | O(n²) | O(1) | 稳定 |
| 插入排序 | O(n)（有序时） | O(n²) | O(1) | 稳定 |

## 易错点

1. 选择排序第 `i` 轮只需交换一次（先记下标 `index`，循环结束后再 `swap`），边找边换是错的写法变形；
2. 冒泡内层边界是 `j < n - i - 1`，写成 `n - i` 会越界；
3. 插入排序的正确内层是"如果 `arr[j] > arr[j+1]` 就交换并继续左移"，注意循环条件里同时判断 `j >= 0`，否则越界；
4. 三者都要处理 `sz < 2` 的边界（数组长度为 0 或 1 直接返回）。

## 模板（可直接编译运行）

`cpp
// 三傻排序模板：选择 / 冒泡 / 插入
// 用途：小数据量排序、对数器暴力解、手写热身
// 复杂度：时间 O(n^2)，额外空间 O(1)
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

// ---------- 选择排序：不稳定 ----------
void selectionSort(vector<int>& values) {
    int length = static_cast<int>(values.size());
    for (int start = 0; start < length - 1; start++) {
        int minimumIndex = start;
        for (int index = start + 1; index < length; index++) {
            if (values[index] < values[minimumIndex]) {
                minimumIndex = index;
            }
        }
        swap(values[start], values[minimumIndex]);
    }
}

// ---------- 冒泡排序：稳定 ----------
void bubbleSort(vector<int>& values) {
    int length = static_cast<int>(values.size());
    for (int end = length - 1; end > 0; end--) {
        bool isSorted = true;
        for (int index = 0; index < end; index++) {
            if (values[index] > values[index + 1]) {
                swap(values[index], values[index + 1]);
                isSorted = false;
            }
        }
        if (isSorted) {
            break;
        }
    }
}

// ---------- 插入排序：稳定，近乎有序时接近 O(n) ----------
void insertionSort(vector<int>& values) {
    int length = static_cast<int>(values.size());
    for (int index = 1; index < length; index++) {
        for (int position = index;
             position > 0 && values[position - 1] > values[position];
             position--) {
            swap(values[position - 1], values[position]);
        }
    }
}

// ---------- 自测 ----------
int main() {
    int length;
    if (!(cin >> length)) {
        return 0;
    }
    vector<int> selectionValues(length);
    for (int& value : selectionValues) {
        cin >> value;
    }
    vector<int> bubbleValues = selectionValues;
    vector<int> insertionValues = selectionValues;
    selectionSort(selectionValues);
    bubbleSort(bubbleValues);
    insertionSort(insertionValues);
    for (int index = 0; index < length; index++) {
        cout << selectionValues[index]
             << (index + 1 == length ? "\n" : " ");
    }
    return 0;
}
`

## 笔记里的题目

- 笔记本身只有三个排序的实现 + 用同一组 `{2,1,4,5,7,8,3,9}` 做演示，没有配套题目。真正的用途是给 `1125归并排序`、`1126随机快速排序`、`1128堆结构和堆排序` 当对照，以及给 `1119对数器` 当暴力方法。

## 容易混淆

- 选择排序"一趟只换一次"vs 冒泡"一趟可能换很多次"；
- 插入排序不是"每次把整个前缀重排"，而是把当前元素插到正确位置，前缀始终保持有序。

## 专题深化：为什么成立

选择排序维护“前缀已是最小 i 个”；冒泡每轮把最大值推到右端；插入排序维护“前缀升序”，再把新元素放回正确位置。三者都可用循环不变式证明。

## 专题深化：手算与边界

对 `[3,1,2]`：选择排序先换 1、3，再得到 `[1,2,3]`；冒泡排序第一轮先把 3 推到末尾；插入排序依次把 1、2 插入前缀的正确位置。

### 对照与取舍

| 算法 | 稳定 | 最好 | 最坏 | 特点 |
| --- | --- | --- | --- | --- |
| 选择 | 否 | O(n²) | O(n²) | 每轮至多一次交换 |
| 冒泡 | 是 | O(n) | O(n²) | 可提前退出 |
| 插入 | 是 | O(n) | O(n²) | 近似有序时移动少 |

### 易错点与反例

1. 选择排序不稳定：`[2a,2b,1]` 首轮交换后 2a 到末尾
2. 冒泡若每轮边界不递减，会重复处理已排序区
3. 插入排序内层必须从后往前移动，越界后插入位置是 0
4. 比较相等元素时用严格大于才能保持稳定

## 专题深化：进阶拓展

插入排序常用于归并/快排的小区间优化；二分插入可减少比较，但移动仍是 O(n²)。工程排序通常组合多种策略，而不是孤立使用三傻排序。

## 专题深化：面试追问

2. 为什么选择排序不稳定？
3. 怎样通过提前退出把冒泡最好情况降为 O(n)？
