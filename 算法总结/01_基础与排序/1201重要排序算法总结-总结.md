# 重要排序算法总结（时间 / 空间 / 稳定性对照）

> 来源笔记：`1201重要排序算法的总结.md`｜性质：横向对照表（无代码）｜分类：01 基础与排序

## 一、稳定性是什么

**稳定性**：同样大小的样本在排序之后**不会改变原始的相对次序**。

- 对**基础类型**（int、double）来说，稳定性毫无意义——两个 3 谁在前谁在后看不出来；
- 对**非基础类型对象**才有意义：例如按"分数"排序学生，稳定排序能保留同分学生原来的名单顺序。

判断稳定性的口径：合并时相等元素是否会被"后来者插到前面"。冒泡、插入、归并、计数、基数稳定；选择排序（远程交换）、快排（远程交换）、堆排序不稳定。

## 二、时间 / 空间 / 稳定性总表

| 名称 | 时间 | 空间 | 稳定性 |
| --- | --- | --- | --- |
| SelectionSort 选择排序 | O(n^2) | O(1) | 无 |
| BubbleSort 冒泡排序 | O(n^2) | O(1) | 有 |
| InsertionSort 插入排序 | O(n^2) | O(1) | 有 |
| MergeSort 归并排序 | O(n log n) | O(n) | 有 |
| QuickSort 快速排序（随机） | O(n log n) | O(log n) | 无 |
| HeapSort 堆排序 | O(n log n) | O(1) | 无 |
| CountSort 计数排序 | O(n) | O(m) | 有 |
| RadixSort 基数排序 | O(n) | O(m) | 有 |

> 表中 QuickSort 的时间/空间是**随机快排**的期望值；固定位置选划分值的普通快排是 O(n^2) / O(n)。

## 三、关键结论

1. **基于比较的排序**，目前**没有**同时做到：时间 O(n log n)、空间低于 O(n)、且稳定。三者不可兼得（归并稳定但费 O(n) 空间；堆/快排省空间但不稳定）。
2. 选型速记：
   - 数据量非常小 → **插入排序**（常数最小，近乎有序时接近 O(n)）；
   - 性能优异、实现简单、可针对业务换划分策略、不在乎稳定性 → **随机快排**；
   - 性能优异、不在乎额外空间、要稳定性 → **归并排序**；
   - 性能优异、要 O(1) 额外空间、不在乎稳定性 → **堆排序**；
   - 数据是整数且范围小/位数少 → 计数排序 / 基数排序（O(n)）。

## 五、易错点

1. 别把"稳定"当成效率指标：题目不要求稳定时，用快排/堆排更快更省空间；
2. 面对结构体/对象排序，务必确认题面是否需要稳定（需要就归并或 `stable_sort`）；
3. `std::sort` 不稳定、`std::stable_sort` 稳定；两者常数都比手写代码小，能直接用就用；
4. 计数/基数排序的时间和"值域 m"有关，不能只看 n。
