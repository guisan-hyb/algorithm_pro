# 二叉树前中后遍历统一版迭代写法（标记法）

> 来源笔记：`二叉树前中后遍历统一版迭代写法.md`｜性质：统一模板（含代码）｜分类：03 二叉树与递归

## 一句话

在栈里插入 `nullptr` 作为"该访问这个节点"的标记：入栈时按目标顺序摆好"孩子 + 节点 + 标记"，出栈遇到 `nullptr` 就说明它下面的节点该被收集了；三种遍历只差**几行的摆放顺序**。

## 解决什么问题

- 只记**一套**迭代骨架就能写前序、中序、后序，不用背三种循环结构；
- 面试里写得快、不易错；
- 帮助建立直觉："栈里的顺序就是访问顺序"。

## 核心思想

约定：**栈顶遇到 `nullptr` 时，它下面的那个节点就是"现在该输出"的节点。**

因此入栈顺序与访问顺序**相反**，"标记 + 节点"要成对摆放：

| 遍历 | 入栈顺序（先压 -> 后压） | 记忆 |
| --- | --- | --- |
| 前序 | 右、左、**节点、null** | 根最先访问 -> 节点离栈顶最近 |
| 中序 | 右、**节点、null**、左 | 左最后压 -> 最先出栈 |
| 后序 | **节点、null**、右、左 | 根最后访问 -> 节点先压（离栈顶最远） |

```cpp
// 前序
while (!stk.empty()) {
    TreeNode* node = stk.top(); stk.pop();
    if (node) {
        if (node->right) stk.push(node->right);
        if (node->left)  stk.push(node->left);
        stk.push(node);
        stk.push(nullptr);           // 标记：下一次遇到它下面的节点就输出
    } else {
        result.push_back(stk.top()->val);
        stk.pop();
    }
}
```

中序把 `节点 / null` 插到"右"和"左"之间；后序把 `节点 / null` 放在最前面。其余代码完全一样。

## 适用特征（看到这些信号就选它）

- 面试要求写非递归遍历，且你不想记三套写法；
- 想在统一框架下做变形（访问顺序反过来、只输出第 k 个）；
- 只需输出值序列，不需要原地改树。

## 复杂度

- 时间 O(n)（每个节点进出栈常数次）；
- 额外空间 O(h)（栈里最多是"路径 + 标记"），最坏 O(n)。

## 易错点

1. `nullptr` 标记必须**紧贴在节点下方**（先压 node、再压 nullptr），顺序反了会提前输出；
2. `stk.push(node); stk.push(nullptr);` 这两句**必须无条件执行**，不能写进 `if (child)` 里；
3. 遇到 `nullptr` 分支时，输出的是 `stk.top()`（nullptr 下面那个节点），输出后再 `pop` 掉它；
4. 中序最容易写错：是 `右 -> 节点/null -> 左`，不是 `右 -> 左 -> 节点/null`；
5. 这种写法常数比"两个栈 / prev 指针"版略大，纯追性能请用 `1124二叉树遍历的非递归实现和复杂度分析` 里的写法。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v = 0, TreeNode* l = nullptr, TreeNode* r = nullptr) : val(v), left(l), right(r) {}
};

// order: 0 前序, 1 中序, 2 后序
vector<int> traverse(TreeNode* root, int order) {
    vector<int> res;
    if (!root) return res;
    stack<TreeNode*> stk;
    stk.push(root);
    while (!stk.empty()) {
        TreeNode* node = stk.top(); stk.pop();
        if (node) {
            if (order == 0) {                       // 前序：右 左 节点 null
                if (node->right) stk.push(node->right);
                if (node->left)  stk.push(node->left);
            } else if (order == 1) {                // 中序：右 [节点 null] 左
                if (node->right) stk.push(node->right);
            } else {                                // 后序：节点 null 右 左
                // 先不动，下面统一压 node/null
            }
            stk.push(node);
            stk.push(nullptr);                      // 标记
            if (order == 1) {
                if (node->left) stk.push(node->left);   // 中序：左最后压
            } else if (order == 2) {
                if (node->right) stk.push(node->right);
                if (node->left)  stk.push(node->left);
            }
        } else {
            res.push_back(stk.top()->val);
            stk.pop();
        }
    }
    return res;
}
```
