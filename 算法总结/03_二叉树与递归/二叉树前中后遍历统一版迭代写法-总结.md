# 二叉树前中后遍历统一版迭代写法（标记法）

> 来源笔记：`二叉树前中后遍历统一版迭代写法.md`｜性质：统一模板（含代码）｜分类：03 二叉树与递归

## 一句话

在栈里插入 `nullptr` 作为"该访问这个节点"的标记：入栈时按目标顺序摆好"孩子 + 节点 + 标记"，出栈遇到 `nullptr` 就说明它下面的节点该被收集了；三种遍历只差**几行的摆放顺序**。

## 解决什么问题

- 只记**一套**迭代骨架就能写前序、中序、后序，不用背三种循环结构；
- 面试里写得快、不易错；
- 帮助建立直觉："栈里的顺序就是访问顺序"。

## 核心思想

约定：**栈顶遇到 `nullptr` 时，它下面的那个节点就是"现在该输出"的节点。**

因此入栈顺序与访问顺序**相反**，"标记 + 节点"要成对摆放：

| 遍历 | 入栈顺序（先压 -> 后压） | 记忆 |
| --- | --- | --- |
| 前序 | 右、左、**节点、null** | 根最先访问 -> 节点离栈顶最近 |
| 中序 | 右、**节点、null**、左 | 左最后压 -> 最先出栈 |
| 后序 | **节点、null**、右、左 | 根最后访问 -> 节点先压（离栈顶最远） |

```cpp
// 前序
while (!stk.empty()) {
    TreeNode* node = stk.top(); stk.pop();
    if (node) {
        if (node->right) stk.push(node->right);
        if (node->left)  stk.push(node->left);
        stk.push(node);
        stk.push(nullptr);           // 标记：下一次遇到它下面的节点就输出
    } else {
        result.push_back(stk.top()->val);
        stk.pop();
    }
}
```

中序把 `节点 / null` 插到"右"和"左"之间；后序把 `节点 / null` 放在最前面。其余代码完全一样。

## 适用特征（看到这些信号就选它）

- 面试要求写非递归遍历，且你不想记三套写法；
- 想在统一框架下做变形（访问顺序反过来、只输出第 k 个）；
- 只需输出值序列，不需要原地改树。

## 复杂度

- 时间 O(n)（每个节点进出栈常数次）；
- 额外空间 O(h)（栈里最多是"路径 + 标记"），最坏 O(n)。

## 易错点

1. `nullptr` 标记必须**紧贴在节点下方**（先压 node、再压 nullptr），顺序反了会提前输出；
2. `stk.push(node); stk.push(nullptr);` 这两句**必须无条件执行**，不能写进 `if (child)` 里；
3. 遇到 `nullptr` 分支时，输出的是 `stk.top()`（nullptr 下面那个节点），输出后再 `pop` 掉它；
4. 中序最容易写错：是 `右 -> 节点/null -> 左`，不是 `右 -> 左 -> 节点/null`；
5. 这种写法常数比"两个栈 / prev 指针"版略大，纯追性能请用 `1124二叉树遍历的非递归实现和复杂度分析` 里的写法。

## 模板（可直接编译运行）

```cpp
// 前序、中序、后序的统一迭代模板：节点后压入访问标记
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <stack>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;

    explicit TreeNode(int value = 0, TreeNode* leftChild = nullptr,
                      TreeNode* rightChild = nullptr)
        : val(value), left(leftChild), right(rightChild) {}
};

enum class TraversalOrder {
    PREORDER,
    INORDER,
    POSTORDER,
};

vector<int> traverse(TreeNode* root, TraversalOrder order) {
    vector<int> result;
    if (root == nullptr) {
        return result;
    }

    stack<TreeNode*> nodes;
    stack<bool> visited;
    nodes.push(root);
    visited.push(false);

    while (!nodes.empty()) {
        TreeNode* current = nodes.top();
        bool hasVisited = visited.top();
        nodes.pop();
        visited.pop();

        if (hasVisited) {
            result.push_back(current->val);
            continue;
        }

        // 入栈顺序与访问顺序相反。
        if (order == TraversalOrder::PREORDER) {
            if (current->right != nullptr) {
                nodes.push(current->right);
                visited.push(false);
            }
            if (current->left != nullptr) {
                nodes.push(current->left);
                visited.push(false);
            }
            nodes.push(current);
            visited.push(true);
        } else if (order == TraversalOrder::INORDER) {
            if (current->right != nullptr) {
                nodes.push(current->right);
                visited.push(false);
            }
            nodes.push(current);
            visited.push(true);
            if (current->left != nullptr) {
                nodes.push(current->left);
                visited.push(false);
            }
        } else {
            nodes.push(current);
            visited.push(true);
            if (current->right != nullptr) {
                nodes.push(current->right);
                visited.push(false);
            }
            if (current->left != nullptr) {
                nodes.push(current->left);
                visited.push(false);
            }
        }
    }
    return result;
}

void printValues(const vector<int>& values) {
    for (int value : values) {
        cout << value << " ";
    }
    cout << "\n";
}

int main() {
    TreeNode* root = new TreeNode(
        1,
        new TreeNode(2, new TreeNode(4), new TreeNode(5)),
        new TreeNode(3));

    printValues(traverse(root, TraversalOrder::PREORDER));
    printValues(traverse(root, TraversalOrder::INORDER));
    printValues(traverse(root, TraversalOrder::POSTORDER));
    return 0;
}
```

## 专题深化：为什么成立

统一写法给节点加“是否已访问”标记：第一次弹出时按目标顺序压回子节点，第二次弹出才输出。栈中的顺序决定遍历结果，标记保证节点不会被再次展开。

## 专题深化：手算与边界

前序希望根先访问，可压入 `[右,左,根]` 后逆序弹出；中序压 `[右,根(标记),左]`；后序压 `[根(标记),右,左]`。

### 对照与取舍

统一模板易读但每个节点可能入栈两次；经典写法更省空间，Morris 则 O(1) 空间但实现复杂。

### 易错点与反例

1. 标记不能和真实节点混淆
2. 空节点不入栈
3. 输出顺序由栈逆序决定
4. 大树上双入栈会增加常数

## 专题深化：进阶拓展

统一模板适合遍历顺序多变的题；若只固定一种遍历，专用迭代法通常更高效。
