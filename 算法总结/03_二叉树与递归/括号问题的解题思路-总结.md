# 括号问题的解题思路（全景图）

> 来源笔记：`括号问题的解题思路.md`｜性质：分类地图 + 手段工具箱｜分类：03 二叉树与递归

## 一句话

所有括号题都围绕同一个量展开：**`balance` = 当前未匹配的左括号数量**；合法串 ⇔ 全程 `balance >= 0` 且最终 `balance == 0`。计数、栈、DP、贪心、Catalan 都只是它的不同包装。

## 一、核心抽象

```
遇 '('  -> balance += 1
遇 ')'  -> balance -= 1
遇 '*'、'?' 等可变字符 -> balance 分叉（不是一个数，而是一个集合）
```

## 二、按"题目问什么"分类

| 类别 | 典型问题 | 主流手段 |
| --- | --- | --- |
| 验证 | 判断串是否合法 | 计数 / 栈 / 贪心区间 |
| 计数 | 有多少合法串 / 合法子序列 | Catalan / 区间 DP / 前缀 DP |
| 生成 | 列举所有合法串 | 回溯（剪枝 = balance） |
| 最长 | 最长合法子串 / 子序列 | 栈存下标 / DP |
| 最少编辑 | 最少添加 / 删除 / 交换 | 贪心 balance / DP |
| 结构 | 分数、嵌套深度、消去 | 栈 / 递归下降 |
| 还原 | 删除最少括号使合法 | BFS / DFS 剪枝 |

## 三、七种手段

### 1. 计数法（单变量 cnt）

适用单种括号、纯验证。O(n) 时间、O(1) 空间。

```cpp
int cnt = 0;
for (char c : s) {
    if (c == '(') cnt++;
    else { cnt--; if (cnt < 0) return false; }
}
return cnt == 0;
```

局限：多种括号并存时不够（不知道是哪种没匹配）。

### 2. 栈法

适用：多种括号（LeetCode 20）、需要"位置"信息（32 最长合法子串）、嵌套结构（856 分数、1190 翻转）、消去相邻匹配对（1003、1021）。

```cpp
stack<int> st;
for (int i = 0; i < n; i++) {
    if (s[i] == '(') st.push(i);
    else if (!st.empty()) st.pop();
    else { /* 多余的 ')'，处理 */ }
}
```

**变体技巧**：

- 栈底先压一个 `-1` 哨兵 → 求"最长合法子串长度"；
- 栈里存**深度** → 算嵌套层数 / 分数；
- 栈里存**字符** → 多类型括号匹配。

### 3. 贪心区间法 [lo, hi]

适用含通配符 `*` / `?` 的合法性判断（LeetCode 678、2116）。`balance` 不再是一个值，而是可能值的集合；由于每步 ±1 或不变，集合恒为**连续区间**：

```cpp
int lo = 0, hi = 0;
for (char c : s) {
    if (c == '(')      { lo++; hi++; }
    else if (c == ')') { lo--; hi--; }
    else               { lo--; hi++; }   // '*' 可当 (、) 或空
    if (hi < 0) return false;
    if (lo < 0) lo = 0;                  // 下界夹住 0
}
return lo == 0;
```

**与 DP 的关系**：DP 枚举所有可能的 balance；区间法把它们压缩成两个端点。

### 4. 区间 DP `dp[i][j]`

适用判断/计数子串合法性、求最少插入。O(n³)，适合 n ≤ 100。

- 状态：`dp[i][j]` = 子串 `s[i..j]` 是否合法（或最小代价）；
- 转移：**包裹**（`s[i]` 与 `s[j]` 配对 且 `dp[i+1][j-1]`）+ **拼接**（存在 k 使 `dp[i][k] && dp[k+1][j]`）。

### 5. 前缀 DP `dp[i][balance]`

适用含通配符的计数/验证，比区间 DP 快。O(n²)。

- 状态：从前 i 个字符出发，能否到达（或有多少种方式到达）某个 balance；
- 转移：`(` 让 balance+1，`)` 让 balance-1（且要求 b>0），`*` 三个方向都可达。

### 6. 组合数学：Catalan 数

```
C_n = (1 / (n+1)) * C(2n, n)
```

- 无约束的 n 对括号合法排列数 = 第 n 个 Catalan 数；
- 带约束 → 前缀 DP；"禁止越过某条线" → 反射原理（总路径 - 越界路径）。

### 7. 回溯 / DFS 与 BFS 剪枝

**生成所有合法串**（LeetCode 22）：

```cpp
void gen(int open, int close, int n, string& cur) {
    if ((int)cur.size() == 2 * n) { ans.push_back(cur); return; }
    if (open < n)      { cur += '('; gen(open + 1, close, n, cur); cur.pop_back(); }
    if (close < open)  { cur += ')'; gen(open, close + 1, n, cur); cur.pop_back(); }
}
```

剪枝条件 `close <= open` 就是 `balance >= 0`。

**删除最少括号并列出所有方案**（LeetCode 301）：先用计数法算出至少删几个 `(` 和 `)`，再 DFS 按位置枚举删哪个，用集合去重；关键剪枝是"只在必须删时才删"。

## 四、拿到新题的四问流程

```
Q1：单种括号还是多种？
    多种 -> 栈（类型匹配必须用栈）
    单种 -> 继续
Q2：有没有通配符 / 可变字符？
    有 -> 贪心区间（仅判断）或前缀 DP（要计数）
    无 -> 继续
Q3：要的是判断、计数、生成，还是编辑？
    判断 -> 计数法 O(n)
    计数 -> Catalan / 前缀 DP dp[i][bal]
    生成 -> 回溯，剪枝用 balance
    编辑 -> 贪心 balance（921/1249/1541）或区间 DP（带通配）
    带语义求值 -> 递归下降（见 括号问题与嵌套递归）
Q4：需要"位置 / 嵌套深度 / 子串"信息吗？
    需要 -> 栈存下标 / 区间 DP
```

例子：

- 678（有 `*`，判断）→ 贪心区间；
- 32（最长合法子串）→ 栈存下标；
- 921（最少添加）→ 贪心 balance；
- 301（删除最少 + 列方案）→ BFS/DFS 剪枝。

## 五、两条心法

1. **永远盯住 `balance`**：先问"这一步让 balance 怎么变？合法需要 balance 满足什么？"单值 → 计数法；多值 → 集合 → 区间 / DP / 枚举。
2. **栈 = 计数 + 位置信息**：光有 balance 不够、还需要知道"是哪个 `(` 在等"或"在哪一层嵌套"时，就升级到栈（存字符 / 存下标 / 存深度）。

## 专题深化：为什么成立

括号首先用计数检查合法性：任意前缀左括号不少于右括号，最终数量相等。进一步求最长合法子串可用栈存未匹配位置，或动态规划按结尾状态转移。

## 专题深化：手算与边界

`(()` 的左计数为 2、右计数为 1，结尾不相等，因此不合法；`())` 在第三个字符出现右多于左，立即不合法。

### 对照与取舍

计数法 O(1) 空间只判整体是否合法；栈法可定位匹配关系；DP 可求最长合法子串或方案数。

### 易错点与反例

1. 空串通常合法
2. 前缀计数不能为负
3. 不同括号类型需要栈而不是单个计数
4. 求最长子串时未匹配位置要初始化

## 专题深化：进阶拓展

括号序列可映射到字典序、树结构和 Dyck path；多类型括号可直接栈匹配。
