# 二叉树遍历的非递归实现与复杂度分析

> 来源笔记：`1124二叉树遍历的非递归实现和复杂度分析.cpp`｜核心程度：必背｜分类：03 二叉树与递归

## 一句话

递归遍历是"系统帮我们压栈"，非递归遍历就是"自己用栈模拟这套压栈顺序"；三种序遍历的差别只在**打印（处理）根节点的时机**。

## 解决什么问题

1. 手写前序 / 中序 / 后序的非递归版本（面试常考）；
2. 理解"递归 = 栈"的等价关系（`1124递归与master公式` 里说"任何递归都能改成非递归"）；
3. 分析遍历的复杂度，认识 Morris 遍历。

## 核心思想

### 先序遍历（根 左 右）

压栈时**先压右孩子、再压左孩子**，这样出栈顺序就是"根 → 左 → 右"：

```cpp
stack<BiTree> s; s.push(T);
while (!s.empty()) {
    BiTree cur = s.top(); s.pop();
    cout << cur->data;
    if (cur->rchild) s.push(cur->rchild);   // 先压右
    if (cur->lchild) s.push(cur->lchild);   // 后压左
}
```

### 中序遍历（左 根 右）

一路向左压栈；左边走不动了才弹栈处理，然后转向右孩子：

```cpp
while (!s.empty() || T) {
    if (T) { s.push(T); T = T->lchild; }
    else   { T = s.top(); s.pop(); cout << T->data; T = T->rchild; }
}
```

### 后序遍历（左 右 根）——两种写法

**法一（两个栈，最巧妙）**：

- 先序' = 根 → 右 → 左（把先序里压栈的左右顺序对调即可）；
- **后序 = 先序' 的结果反转**（笔记原话："先序' 的结果反转得到"）；
- 所以用一个栈做变体先序、把结果压进另一个栈，最后整体弹出即后序。

**法二（一个栈 + prev 指针）**：

用 `prev` 记录**上一个被打印的节点**，判断当前节点的左右子树是否处理过：

```
左孩子存在 且 左孩子 != prev 且 右孩子 != prev  → 压左孩子
右孩子存在 且 右孩子 != prev                    → 压右孩子
否则（左右都处理完或都为空）                      → 打印、prev = 当前、弹栈
```

> 笔记提醒：多个 `if` 同时成立时只执行**第一个**满足的，所以这三个分支的判定顺序不能乱。

## 复杂度分析（笔记直接给了结论）

- **时间复杂度 O(n)**：递归和非递归都是每个节点被有限次操作；
- **额外空间复杂度 O(h)**：都需要高度 h 的空间保存"回来的路"（递归是系统栈，非递归是自己开的栈）；
- **存在 O(n) 时间 + O(1) 额外空间的遍历：Morris 遍历**（利用叶子节点的空指针做线索，笔记只提到名字）。

## 适用特征（看到这些信号就选它）

- 面试明确要求"用非递归 / 迭代实现"；
- 递归深度可能达到 n（链式树）怕爆栈；
- 需要在中途"暂停遍历"（迭代器式遍历，如 BST 迭代器 LeetCode 173）。

## 易错点

1. 先序压栈顺序：**先右后左**（写反了就变成"根右左"）；
2. 中序的循环条件是 `!s.empty() || T != nullptr`，两个条件缺一不可；
3. 后序法二的 `prev` 初值应为根节点（"如果没有，就是根结点"），否则第一次判断会出错；
4. 后序法二的分支顺序必须是"先看左、再看右、最后处理自己"，因为这三种情况可能同时成立；
5. 遍历前要判断树是否为空（`if (T != NULL)`）。

## 模板（可直接编译运行）

```cpp
// 二叉树非递归遍历模板：前序 / 中序 / 后序
// 时间 O(n)，额外空间 O(h)（h 为树高）
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <iostream>
#include <stack>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v = 0, TreeNode* l = nullptr, TreeNode* r = nullptr)
        : val(v), left(l), right(r) {}
};

// ---------- 前序：根 左 右（先压右、再压左） ----------
vector<int> preorder(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* cur = st.top(); st.pop();
        res.push_back(cur->val);
        if (cur->right) st.push(cur->right);
        if (cur->left)  st.push(cur->left);
    }
    return res;
}

// ---------- 中序：左 根 右 ----------
vector<int> inorder(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    TreeNode* cur = root;
    while (!st.empty() || cur) {
        if (cur) { st.push(cur); cur = cur->left; }
        else {
            cur = st.top(); st.pop();
            res.push_back(cur->val);
            cur = cur->right;
        }
    }
    return res;
}

// ---------- 后序：左 右 根（变体先序 + 反转） ----------
vector<int> postorder(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* cur = st.top(); st.pop();
        res.push_back(cur->val);          // 得到 根 右 左
        if (cur->left)  st.push(cur->left);
        if (cur->right) st.push(cur->right);
    }
    reverse(res.begin(), res.end());      // 反转为 左 右 根
    return res;
}

// ---------- 后序：单栈 + prev 指针写法（不修改结果数组） ----------
vector<int> postorderOneStack(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    stack<TreeNode*> st;
    st.push(root);
    TreeNode* prev = root;                 // 上一个被打印的节点
    while (!st.empty()) {
        TreeNode* cur = st.top();
        if (cur->left && cur->left != prev && cur->right != prev) {
            st.push(cur->left);
        } else if (cur->right && cur->right != prev) {
            st.push(cur->right);
        } else {
            res.push_back(cur->val);
            prev = cur;
            st.pop();
        }
    }
    return res;
}

// ---------- 简单自测：建一棵小树 ----------
int main() {
    //        1
    //      /   \
    //     2     3
    //    /
    //   4
    TreeNode* root = new TreeNode(1,
        new TreeNode(2, new TreeNode(4), nullptr),
        new TreeNode(3));
    auto print = [](const vector<int>& v) {
        for (int x : v) std::cout << x << " ";
        std::cout << "\n";
    };
    print(preorder(root));            // 1 2 4 3
    print(inorder(root));             // 4 2 1 3
    print(postorder(root));           // 4 2 3 1
    print(postorderOneStack(root));   // 4 2 3 1
    return 0;
}
```

## 专题深化：为什么成立

递归遍历的调用栈保存了“当前节点与下一步”；迭代写法用显式栈模拟这份状态。前序是根—左—右，入栈时应先右后左；中序沿左链压栈再回退；后序可用 reversed 前序或访问标记。

## 专题深化：手算与边界

树 `1(2(4),3(5,6))` 的前序为 1,2,4,3,5,6；显式栈先压 3 再压 2，弹出 1 后依次访问。后序为 4,2,5,6,3,1。

### 对照与取舍

Morris 遍历用临时线索实现 O(1) 空间但会修改并恢复树；递归和非递归栈空间 O(h)。完全树 h=log n，偏斜树 h=n。

### 易错点与反例

1. 空树直接返回
2. 栈的压入顺序决定左右次序
3. 后序标记版不能重复入栈
4. Morris 必须恢复被修改的右指针

## 专题深化：进阶拓展

层序使用队列，分层可通过 size 快照；迭代器化遍历适合处理超大或流式树结构。
