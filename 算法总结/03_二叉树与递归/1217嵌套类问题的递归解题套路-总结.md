# 嵌套类问题的递归解题套路（where 游标 / 递归下降）

> 来源笔记：`1217嵌套类问题的递归解题套路.cpp`｜核心程度：高频套路｜分类：03 二叉树与递归

## 一句话

遇到"括号里还有括号"的求值题，就用**递归下降**：每层函数解析自己那一段，遇到嵌套触发符就调下级递归，靠 `where` 游标把"解析到哪了"传回给上级。

## 解决什么问题

带语义的嵌套求值：

1. **表达式求值**（含括号、加减乘除，LeetCode 224 / 772）；
2. **字符串解码**（`3[a2[c]]`，LeetCode 394）；
3. **分子式原子计数**（`K4(ON(SO3)2)2`，LeetCode 726）。

## 解题套路（笔记原文五步）

1.定义全局变量 `int where`；
2.递归函数 `f(i)`：解析 `s[i..]`，遇到**字符串终止**或**嵌套条件终止**就返回；
3.返回值是 `f(i)` 负责这一段的结果；
4.`f(i)` 在返回前更新 `where`，让上级通过 `where` 知道解析到了什么位置；
5.执行细节：
   - 遇到**嵌套条件开始**（`(`、`[`）就调下级递归处理嵌套，下级负责算出嵌套部分的结果；
   - 下级返回后，`f(i)` 根据 `where` 继续从 `where + 1` 解析。

**两条铁律**：① 返回前 `where = i`；② 递归返回后 `i = where + 1`（跳过终止符）。

> 更现代的写法是把 `where` 换成**引用参数 `int& i`**，让函数自己吃掉终止符，从而消掉这两条铁律（详见 `括号问题与嵌套递归` 的 V2/V3 版本）。

## 三道题的实现要点

### 题一：表达式求值（O(n)）

- 用 `vector<int> nums` + `vector<char> ops` 双栈式模拟；
- `push(nums, ops, cur, op)`：**遇到 `*` `/` 立即结算**（弹出栈顶运算符与数字，算出结果再入栈），`+` `-` 直接入栈；
- 遇到 `(`：`cur = calculate(s, index + 1); index = where + 1;`（把括号里的值当成一个数）；
- 循环结束（遇到 `)` 或串尾）后：**补一个 `push(nums, ops, cur, '+')`**，把最后一个数结算进去；
- `where = index` 后返回 `compute(nums, ops)`（顺序处理 `+` `-`）。

### 题二：字符串解码（O(n)）

```cpp
string f(string s, int i) {
    int curTimes = 0; string path;
    while (i < s.size() && s[i] != ']') {
        if (isdigit(s[i]))      curTimes = curTimes * 10 + s[i++] - '0';
        else if (s[i] == '[') { string tmp = f(s, i + 1);
                                for (int k = 0; k < curTimes; k++) path += tmp;
                                i = where + 1; curTimes = 0; }
        else                    path += s[i++];
    }
    where = i;
    return path;
}
```

### 题三：分子式原子计数（O(n)）

- 核心触发点：**遇到大写字母或 `(` 就结算上一个单元**；
- 用 `path`（元素名）、`prev`（子括号的结果 map）、`cnt`（倍数）三个局部变量；
- `fill(curLevelAns, path, prev, cnt)` 把暂存内容提交到本层结果里：
  - `cnt == 0` 时视为 1；
  - `path` 非空就 `ans[path] += cnt`；
  - `prev` 非空就把每个原子数乘 `cnt` 后加入；
- 遇到 `(`：`prev = f(s, i + 1); i = where + 1;`
- 用 `map<string,int>` 保证输出按字典序。

## 适用特征（看到这些信号就选它）

- 字符串里有**配对的定界符**（`()`、`[]`、`<tag>`）；
- 括号里还有"内容"，必须**真正进去解析**（不是只数括号）；
- 每层行为相同：算本层 → 遇嵌套 → 递归下级 → 拿结果回来继续算本层；
- 复杂度要求 O(n)（从左到右一趟扫完）。

## 复杂度

三道题都是 **O(n)**（每个字符被常数次访问），空间 O(嵌套深度)。

## 易错点

1. **返回前忘写 `where = i`** → 上级读到错位置（最常见 bug）；
2. **递归返回后忘写 `i = where + 1`** → 死循环或重复扫终止符；
3. 循环结束后**忘补最后一次结算**（表达式题的末尾 `push`、分子式的末尾 `fill`）——最后一个数/元素没有被统计；
4. `path` / `prev` / `cnt` 在新单元开始时**必须清空/重置**，否则会污染后面的单元；
5. 递归调用**前**要先 flush 当前缓冲（否则嵌套前面的数字/原子被吞）；
6. `string s` 要按**引用**传递（`string& s`），按值传每次递归都会复制整个字符串；
7. 表达式题的 `* /` 必须在 `push` 时立即结算，`+ -` 留到 compute 阶段。

## 模板（可直接编译运行）

```cpp
// 嵌套类问题模板：递归下降（where 游标版）
// 三道经典题：字符串解码 / 表达式求值 / 分子式原子计数
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <map>
#include <string>
#include <vector>
using namespace std;

// ================= 1. 字符串解码（LeetCode 394） =================
class DecodeString {
    int where = 0;
    string f(const string& s, int i) {
        int curTimes = 0;
        string path;
        while (i < (int)s.size() && s[i] != ']') {
            if (isdigit(s[i])) {
                curTimes = curTimes * 10 + (s[i++] - '0');
            } else if (s[i] == '[') {
                string tmp = f(s, i + 1);              // 递归处理嵌套
                for (int k = 0; k < curTimes; k++) path += tmp;
                i = where + 1;                         // ★跳过 ']'
                curTimes = 0;
            } else {
                path += s[i++];
            }
        }
        where = i;                                     // ★返回前更新
        return path;
    }
public:
    string decode(const string& s) { where = 0; return s.empty() ? s : f(s, 0); }
};

// ================= 2. 表达式求值（含括号、+ - * /） =================
class Calc {
    int where = 0;

    // 遇到 * 或 / 立即结算栈顶，否则直接入栈
    void push(vector<int>& nums, vector<char>& ops, int cur, char op) {
        if (!ops.empty()) {
            char top = ops.back();
            if (top == '*') { ops.pop_back(); int a = nums.back(); nums.pop_back();
                              nums.push_back(a * cur); ops.push_back(op); return; }
            if (top == '/') { ops.pop_back(); int a = nums.back(); nums.pop_back();
                              nums.push_back(a / cur); ops.push_back(op); return; }
        }
        nums.push_back(cur);
        ops.push_back(op);
    }
    int compute(vector<int>& nums, vector<char>& ops) {
        if (!ops.empty() && ops.back() == '+') ops.pop_back();   // 去掉末尾补的 '+'
        int ans = nums[0];
        for (size_t i = 1; i < nums.size(); i++)
            ans = (ops[i - 1] == '+') ? ans + nums[i] : ans - nums[i];
        return ans;
    }
    int f(const string& s, int i) {
        vector<int> nums; vector<char> ops;
        int cur = 0;
        while (i < (int)s.size() && s[i] != ')') {
            char c = s[i];
            if (isdigit(c)) {
                cur = cur * 10 + (c - '0'); i++;
            } else if (c == '(') {
                cur = f(s, i + 1);                     // 括号里的值 = 一个数
                i = where + 1;
            } else {
                push(nums, ops, cur, c); i++;
                cur = 0;
            }
        }
        push(nums, ops, cur, '+');                     // ★末尾补结算
        where = i;
        return compute(nums, ops);
    }
public:
    int calculate(const string& s) { where = 0; return f(s, 0); }
};

// ================= 3. 分子式原子计数（LeetCode 726） =================
class CountAtoms {
    int where = 0;
    void flush(map<string,int>& acc, string& path, map<string,int>& prev, int cnt) {
        cnt = (cnt == 0 ? 1 : cnt);
        if (!path.empty()) acc[path] += cnt;
        for (auto& e : prev) acc[e.first] += e.second * cnt;
    }
    map<string,int> f(const string& s, int i) {
        map<string,int> acc, prev;
        string path;
        int cnt = 0;
        while (i < (int)s.size() && s[i] != ')') {
            char c = s[i];
            if (isupper(c) || c == '(') {
                flush(acc, path, prev, cnt);           // 结算上一个单元
                path.clear(); prev.clear(); cnt = 0;
                if (isupper(c)) { path += c; i++; }
                else { prev = f(s, i + 1); i = where + 1; }
            } else if (islower(c)) {
                path += c; i++;
            } else {                                   // 数字
                cnt = cnt * 10 + (c - '0'); i++;
            }
        }
        flush(acc, path, prev, cnt);                   // ★末尾补结算
        where = i;
        return acc;
    }
public:
    string count(const string& formula) {
        where = 0;
        map<string,int> mp = f(formula, 0);
        string ans;
        for (auto& e : mp) {
            ans += e.first;
            if (e.second > 1) ans += to_string(e.second);
        }
        return ans;
    }
};

int main() {
    DecodeString ds;
    std::cout << ds.decode("3[a2[c]]") << "\n";     // accaccacc
    Calc c;
    std::cout << c.calculate("2*(3+4)-5") << "\n";          // 9
    CountAtoms ca;
    std::cout << ca.count("K4(ON(SO3)2)2") << "\n"; // K4N2O14S4
    return 0;
}
```

## 专题深化：为什么成立

嵌套表达式天然对应递归：遇到左括号进入下一层，遇到闭括号把当前层结构返回给父层。每个递归函数只负责解析自己这一层，直到分隔符或字符串结束。

## 专题深化：手算与边界

解析 `3[a2[c]]`：外层读到 3 和 `[` 后递归解析 `a2[c]`；内层得到 `cc`，拼成 `acc`，外层重复三次得到 `accaccacc`。

### 对照与取舍

递归写法状态清晰；显式栈写法适合极深嵌套；正则/语法分析器则处理更一般文法。

### 易错点与反例

1. 多位数要完整读取
2. 空括号与嵌套边界
3. 闭括号不能无条件 pop
4. 递归返回位置要精确更新

## 专题深化：进阶拓展

把解析结果定义成 AST，可自然扩展到变量、函数和运算优先级；逆波兰表达式适合栈求值。
