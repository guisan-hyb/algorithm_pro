# 常见经典递归过程解析（7 类模板）

> 来源笔记：`1215常见经典递归过程解析.cpp`｜核心程度：必背（递归题的通用弹药库）｜分类：03 二叉树与递归

## 一句话

一切递归都是 DFS；写递归只需要两件事——**找到 base case** 和**找到规模最小的子过程**（更复杂的情况都由它推广而来）。

## 笔记开篇的递归观

- 任何递归都是 DFS，且非常灵活；
- 分"带路径的递归"与"不带路径的递归"（大部分 DP、状压 DP 可以看作路径被简化了结构）；
- **"回溯"这个术语并不重要**：本质就是"选完要恢复现场"；
- 写递归的两步法：
  1. 找到 **base case**（获得一次答案的条件）；
  2. 找到**规模最小的子过程**（完成本问题的最小单元），复杂情况都由它推广。

## 七个模板

### 一、全部子序列（去重）

每个字符"选 / 不选"两条分支，到末尾收集。`path` 用 push/pop 做选择与恢复。

复杂度 O(2^n · n)，去重用 `unordered_set<string>`。

### 二、全部组合（无视顺序、去重）

两种写法：

1. **上题思路 + 排序后 `set<vector<int>>` 去重**：每个元素选/不选，收集时把 path 排序再插入 set；
2. **排序 + 相同元素分组**（推荐，效率高）：
   - 先 `sort`，把相等的元素划成一组；
   - 每组可以取 0 个、1 个、…、全部，**按组递归**（而不是按元素），天然去重；
   - 循环内 `pth.push_back(nums[index]); dfs(nextGroupIndex);`，回溯时把这一组加进去的全部 `pop_back`。

### 三、无重复数组的全排列

1. **交换法**：`for (i = index; i < n; i++) { swap(nums[index], nums[i]); dfs(index+1); swap(...); }`——每个元素都可能出现在任意位置；
2. **visited 法**：path 的每个位置枚举 nums 的每个元素，用 `visited` 标记用过没，选完恢复。

复杂度 O(n! · n)。

### 四、有重复数组的全排列（去重）

在交换法上剪枝：**同一层里，如果要交换的元素值已经试过，就跳过**：

```cpp
unordered_set<int> used;                  // 每一层新建，只对本层去重
for (int i = index; i < n; i++) {
    if (used.count(nums[i])) continue;    // 这一层这个值已经试过
    used.insert(nums[i]);
    swap(nums[index], nums[i]);
    dfs(index + 1);
    swap(nums[index], nums[i]);
}
```

### 五、递归逆序一个栈（空间 O(1) 思路，时间 O(n²)）

两个函数配合：

1. `bottomOut(s)`：**弹出栈底元素**并保持其余元素次序不变（递归到只剩一个时返回它，回归时把上层元素压回去）；
2. `reverse(s)`：每次取栈底放到"递归结果之上"——`int tmp = bottomOut(s); reverse(s); s.push(tmp);`。

### 六、递归排序一个栈

按"找到最大值 → 把它沉到底/放到该在的位置 → 缩小规模"的思路：

- `findDepth(s)`：求栈深；
- `findMax(s, depth)`：在指定深度内求最大值；
- `findTimes(s, maxs, depth)`：统计最大值出现次数；
- `down(s, maxs, times, depth)`：先把非最大值的元素暂存（递归向下），到底后把 `times` 个最大值压入，回归时把非最大值压回；
- `sort(s)`：`while (depth) { 找 max、次数；down；depth -= times; }`。

> 笔记里一个细节坑：`int times = restTimes + (nums == maxs ? 1 : 0);` 必须先算 `restTimes` 再相加，写成三目里 `times + 1` 会因为 `times` 还未定义/未初始化而报错。

### 七、汉诺塔（打印最优移动轨迹）

```cpp
void hanoi(int n, from, to, other) {
    if (n == 1) { 移动圆盘 1: from -> to; return; }
    hanoi(n - 1, from, other, to);   // 先把上面 n-1 个挪到中转
    移动圆盘 n: from -> to;           // 移动最大的那个
    hanoi(n - 1, other, to, from);   // 再把 n-1 个挪到目标
}
```

n 层汉诺塔最少步数 = **2^n - 1**，时间复杂度 O(2^n)。

## 适用特征（看到这些信号就选它）

| 题目要求 | 用哪个模板 |
| --- | --- |
| 所有子序列 / 子集 | 模板一（选/不选），集合去重 |
| 组合（顺序无关、去重） | 模板二（排序 + 分组递归） |
| 全排列（无重复） | 模板三（交换法 / visited 法） |
| 全排列（有重复、去重） | 模板四（本层 set 剪枝） |
| 只允许用递归操作栈 | 模板五、六 |
| 递归轨迹/最少步数 | 模板七 |

## 复杂度速查

| 题目 | 时间 |
| --- | --- |
| 子序列 / 组合 | O(2^n · n) |
| 全排列 | O(n! · n) |
| 递归逆序栈 / 排序栈 | O(n²) |
| 汉诺塔 | O(2^n)（步数 2^n - 1） |

## 易错点

1. 选择/不选择类递归里，`path.pop_back()` 的位置要对（选了之后 push，回来先 pop 再走"不选"分支）；
2. 组合去重的"分组递归"写法里，**回溯循环的边界是 `nextGroupIndex`**，容易写错；
3. 全排列交换法里递归参数是 `index + 1`（不是 `i + 1`）；
4. 有重复排列的 `used` 集合必须**每层新建**（放在 dfs 函数体内），放外面就成了全局去重，答案会变少；
5. 递归操作栈时，恢复现场的顺序与压回顺序必须严格对称；
6. 汉诺塔的 `other` 参数在两次递归里要交换位置（第一次 `from, other, to`，第二次 `other, to, from`）。

## 模板（可直接编译运行）

```cpp
// 经典递归模板合集：子集 / 组合 / 全排列 / 栈递归 / 汉诺塔
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <iostream>
#include <stack>
#include <unordered_set>
#include <vector>
using namespace std;

vector<vector<int>> ans;
vector<int> path;

// ================= 1. 全部子集（选 / 不选） =================
void subsets(vector<int>& a, int idx) {
    if (idx == (int)a.size()) { ans.push_back(path); return; }
    path.push_back(a[idx]);                 // 选
    subsets(a, idx + 1);
    path.pop_back();                        // 不选（恢复现场）
    subsets(a, idx + 1);
}

// ================= 2. 组合去重（排序 + 分组递归） =================
void combinations(vector<int>& a, int idx) {
    if (idx == (int)a.size()) { ans.push_back(path); return; }
    int next = idx;
    while (next + 1 < (int)a.size() && a[next] == a[next + 1]) next++;
    next++;
    combinations(a, next);                  // 本组取 0 个
    int back = idx;
    for (; idx < next; idx++) {
        path.push_back(a[idx]);             // 本组取若干个
        combinations(a, next);
    }
    for (; back < next; back++) path.pop_back();
}

// ================= 3. 全排列（无重复，交换法） =================
void permute(vector<int>& a, int idx) {
    if (idx == (int)a.size()) { ans.push_back(a); return; }
    for (int i = idx; i < (int)a.size(); i++) {
        swap(a[idx], a[i]);
        permute(a, idx + 1);
        swap(a[idx], a[i]);
    }
}

// ================= 4. 全排列（有重复，本层去重） =================
void permuteUnique(vector<int>& a, int idx) {
    if (idx == (int)a.size()) { ans.push_back(a); return; }
    unordered_set<int> used;                // 关键：每层新建
    for (int i = idx; i < (int)a.size(); i++) {
        if (used.count(a[i])) continue;
        used.insert(a[i]);
        swap(a[idx], a[i]);
        permuteUnique(a, idx + 1);
        swap(a[idx], a[i]);
    }
}

// ================= 5. 递归逆序一个栈（O(n^2) 时间，O(h) 栈空间） =================
int bottomOut(stack<int>& s) {              // 弹出栈底元素，其余保持原序
    int top = s.top(); s.pop();
    if (s.empty()) return top;
    int last = bottomOut(s);
    s.push(top);
    return last;
}
void reverseStack(stack<int>& s) {
    if (s.empty()) return;
    int bt = bottomOut(s);
    reverseStack(s);
    s.push(bt);
}

// ================= 6. 汉诺塔（2^n - 1 步） =================
void hanoi(int n, char from, char to, char other) {
    if (n == 1) { std::cout << "盘 1: " << from << " -> " << to << "\n"; return; }
    hanoi(n - 1, from, other, to);
    std::cout << "盘 " << n << ": " << from << " -> " << to << "\n";
    hanoi(n - 1, other, to, from);
}

int main() {
    vector<int> a = {1, 2, 2, 3};
    sort(a.begin(), a.end());
    ans.clear(); path.clear();
    combinations(a, 0);
    std::cout << "组合(去重)共 " << (int)ans.size() << " 个\n";

    vector<int> b = {1, 1, 2};
    ans.clear();
    permuteUnique(b, 0);
    std::cout << "排列(去重)共 " << (int)ans.size() << " 个\n";

    stack<int> s;
    for (int x : {1, 2, 3, 4}) s.push(x);
    reverseStack(s);
    std::cout << "逆序后的栈顶 = " << s.top() << "\n";

    hanoi(3, 'A', 'C', 'B');
    return 0;
}
```

## 专题深化：为什么成立

递归过程由参数、终止条件和分支组成。子集是每个位置选/不选，组合是无序枚举，排列是有序枚举，回溯是进入分支修改状态、返回后恢复状态。汉诺塔证明大问题依赖三个小问题。

## 专题深化：手算与边界

从 `[1,2,3]` 枚举 2 个元素的组合，可固定起点避免重复：选 1 后只能从 2、3 选；选 2 后只能从 3 选。

### 对照与取舍

| 模型 | 分支 | 去重关键 |
| --- | --- | --- |
| 子集 | 选/不选 | 通常无重复 |
| 组合 | 从 start 往后 | 有序枚举避免排列重复 |
| 排列 | 选未用元素 | used 或交换 |
| 回溯 | 收集所有状态 | 进入修改、退出恢复 |

### 易错点与反例

1. 组合不能每次从 0 开始
2. 排列要处理重复值
3. 回溯必须成对修改与撤销
4. 递归深度过大会栈溢出

## 专题深化：进阶拓展

迭代加深控制深度；剪枝按剩余和/最小值提前返回；位掩码、交换法可降低排列标记开销。
