# 二叉树高频题目（不含树形 DP，16 题）

> 来源笔记：`1210二叉树高频题目-不含树型dp.cpp`｜核心程度：面试主力题库｜分类：03 二叉树与递归

## 一句话

二叉树题只有三件事：**怎么遍历（层序/前中后序）**、**信息往哪个方向流（向下传参还是向上返值）**、**要不要带位置编号**。

## 关键实现要点

### 层序遍历的三种写法

1. **哈希记层**：`unordered_map<TreeNode*, int>` 记录每个节点的层号，慢但直观；
2. **按层切分（推荐）**：每次先取 `int size = q.size()`，这一轮只处理 size 个节点，天然分层；
3. **数组模拟队列**：`vector<TreeNode*> que` + 两个下标 `l / r`。注意 **`r` 不能在 for 循环里更新**（笔记强调：否则整棵树会被输出在同一层），要在 for 之后 `r = que.size()`；若用定长数组则需**预先确定容量**。

### 锯齿形层序

**不能通过改变入队顺序来翻转**（笔记原话：一旦某处入队顺序改变，会影响接下来所有节点的入队）。正确做法是照常入队，只把值写到 `curLevel[flag ? i : size-1-i]`，每层翻转 `flag`。

### 最大特殊宽度

把树看成完全二叉树编号：根为 1，左孩子 `2i`、右孩子 `2i+1`（用 `unsigned long long` 防溢出）。每层宽度 = `本层最右编号 - 最左编号 + 1`（队列天然保持层内有序）。

### 最小深度

**空节点会干扰最小值**：如果直接 `min(left, right) + 1`，一个只有左子树的节点会从右空孩子那里得到深度 1。必须分别判断左右是否存在，叶子节点直接返回 1（笔记特别提醒）。

### 序列化 / 反序列化

- **只有前序、后序、层序可以唯一序列化，中序不行**（笔记明确：中序序列化结果不唯一）；
- 前序版：空节点写 `"null,"`，反序列化用 `list<string>` 从头逐个吃、递归建树；
- 层序版：**空节点也要入队**，反序列化时按层配对消费 `lst`。

### 前序 + 中序构造二叉树（O(n)）

1. 用 `unordered_map<int,int>` 预存中序的"值 → 下标"；
2. 先序第一个是根，`k = 根在中序中的下标`，左子树大小 `k - l2`；
3. 递归区间：左子树先序 `[l1+1, l1+size]`、中序 `[l2, k-1]`；右子树先序 `[l1+size+1, r1]`、中序 `[k+1, r2]`。

（如果不想推下标，`前序、中序、后序 三选二构造二叉树 O(n^2)轮椅解法` 里有"每次复制子数组"的 O(n²) 写法，更好记。）

### 验证完全二叉树的两条判据

1. **有右孩子但没左孩子** → 不是完全二叉树；
2. **一旦遇到"孩子不全"的节点，之后必须全是叶节点**（用 `leafFlag` 记录）。

### 完全二叉树节点个数（O(log²n)）

思路：求整棵树最左深度 `maxDepth`；对当前节点看**右子树的最左深度**是否等于 `maxDepth`：

- 等于 → 左子树是满二叉树，直接加 `2^(maxDepth-level)` 再递归右子树；
- 不等于 → 右子树是满二叉树（少一层），加 `2^(maxDepth-level-1)` 再递归左子树。

每层只走一条路，但每层要算一次深度（O(log n)），总 O(log²n)，优于 O(n)。

### LCA（两个版本）

**普通二叉树**（后序）：

```cpp
if (!root || root == p || root == q) return root;
TreeNode* l = lca(root->left, p, q);
TreeNode* r = lca(root->right, p, q);
if (l && r) return root;              // 左右各找到一只 -> 自己是 LCA
return l ? l : r;                     // 只找到一只就往上传递
```

**搜索二叉树**：利用大小关系——`root->val` 同时大于两者就走左，小于两者就走右，落在两者之间（或命中某个目标）就是答案；迭代版一个 while 循环即可。

### 验证搜索二叉树

1. **中序遍历升序**（笔记给的迭代实现：栈 + `prev` 比较）；
2. 递归带上下界：子树返回自己范围内的 `min / max`，父节点要求 `左max < root->val < 右min`（笔记用全局 `mins / maxs`，注意空节点时重置为 `LONG_MAX / LONG_MIN`）。

### 路径和（带回溯的收集）

前序传 `preSum`，到叶子判断 `preSum + val == target`；`path` 在进入时 push、退出时 pop（恢复现场）；只有叶子节点才收集答案。

### 打家劫舍（树的版本，树形 DP 入门）

后序返回两个值：**选当前节点**的最大收益与**不选当前节点**的最大收益。

- 选自己 → 加上两个孩子的"不选"值；
- 不选自己 → 加上两个孩子"选/不选"的较大值。

笔记用两个全局变量 `Yes / No` 承载返回值（每处理完一棵子树就更新它们）。

## 适用特征（看到这些信号就选它）

- 题目要求"按层"处理 → BFS / 数组模拟队列；
- 要求"根到叶的路径" → 前序 + 回溯；
- 要求"子树的信息"（高度、是否平衡、是否 BST、最大收益） → 后序 / 树形 DP；
- 要求"位置 / 宽度 / 编号" → BFS + 下标编号；
- 题目给两种遍历序列 → 构造题（先序+中序，或中序+后序）。

## 易错点

1. 数组模拟队列时 `r` 更新位置（在 for 之后）与容量预分配；
2. 锯齿遍历不要靠入队顺序翻转；
3. 最小深度必须排除空孩子；
4. 序列化只有前序/后序/层序唯一，中序不唯一；
5. 构造二叉树时左子树大小的计算（`k - l2`）与四个区间端点；
6. 完全二叉树判据两条都要写；
7. LCA 的 base case 必须包含 `root == p || root == q`；
8. 验证 BST 用中序时别忘了 `prev` 是"中序前一个节点"，不是父节点；
9. 路径和题只有叶子才收集结果（非叶子即使和相等也不算）；
10. 打家劫舍的两个状态要**同时向上返回**，用一个全局变量会互相覆盖。

## 模板（可直接编译运行）

```cpp
// 二叉树高频题模板：层序 / 锯齿 / 宽度 / 深度 / 完全二叉树 / 序列化 / 构造 / LCA / BST / 打家劫舍
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <iostream>
#include <list>
#include <queue>
#include <stack>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v = 0, TreeNode* l = nullptr, TreeNode* r = nullptr)
        : val(v), left(l), right(r) {}
};

// ---------- 1. 层序遍历（按层切分，推荐写法） ----------
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> ans;
    if (!root) return ans;
    queue<TreeNode*> q; q.push(root);
    while (!q.empty()) {
        int sz = q.size();
        vector<int> cur;
        while (sz--) {
            TreeNode* t = q.front(); q.pop();
            cur.push_back(t->val);
            if (t->left)  q.push(t->left);
            if (t->right) q.push(t->right);
        }
        ans.push_back(cur);
    }
    return ans;
}

// ---------- 2. 锯齿形层序（改写下标，不改入队顺序） ----------
vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
    vector<vector<int>> ans;
    if (!root) return ans;
    queue<TreeNode*> q; q.push(root);
    bool leftToRight = true;
    while (!q.empty()) {
        int sz = q.size();
        vector<int> cur(sz);
        for (int i = 0; i < sz; i++) {
            TreeNode* t = q.front(); q.pop();
            cur[leftToRight ? i : sz - 1 - i] = t->val;
            if (t->left)  q.push(t->left);
            if (t->right) q.push(t->right);
        }
        leftToRight = !leftToRight;
        ans.push_back(cur);
    }
    return ans;
}

// ---------- 3. 最大特殊宽度（完全二叉树编号） ----------
int widthOfBinaryTree(TreeNode* root) {
    if (!root) return 0;
    int ans = 0;
    queue<pair<TreeNode*, unsigned long long>> q;
    q.push({root, 1});
    while (!q.empty()) {
        unsigned long long l = q.front().second, r = q.back().second;
        ans = max(ans, (int)(r - l + 1));
        int sz = q.size();
        while (sz--) {
            auto pr = q.front(); q.pop();
            TreeNode* t = pr.first;
            unsigned long long code = pr.second;
            if (t->left)  q.push({t->left,  code * 2});
            if (t->right) q.push({t->right, code * 2 + 1});
        }
    }
    return ans;
}

// ---------- 4. 最大 / 最小深度 ----------
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    return max(maxDepth(root->left), maxDepth(root->right)) + 1;
}
int minDepth(TreeNode* root) {
    if (!root) return 0;
    if (!root->left && !root->right) return 1;          // 叶子
    int ld = INT_MAX, rd = INT_MAX;
    if (root->left)  ld = minDepth(root->left);         // 防空孩子干扰
    if (root->right) rd = minDepth(root->right);
    return min(ld, rd) + 1;
}

// ---------- 5. 验证完全二叉树 ----------
bool isCompleteTree(TreeNode* root) {
    if (!root) return true;
    queue<TreeNode*> q; q.push(root);
    bool leafFlag = false;
    while (!q.empty()) {
        TreeNode* cur = q.front(); q.pop();
        if ((cur->right && !cur->left) ||
            (leafFlag && (cur->left || cur->right))) return false;
        if (cur->left)  q.push(cur->left);
        if (cur->right) q.push(cur->right);
        if (!cur->left || !cur->right) leafFlag = true;
    }
    return true;
}

// ---------- 6. 完全二叉树节点个数（O(log^2 n)） ----------
int leftDepthOf(TreeNode* node) {
    int d = 0;
    while (node) { d++; node = node->left; }
    return d;
}
int countNodes(TreeNode* root) {
    if (!root) return 0;
    int ld = leftDepthOf(root->left), rd = leftDepthOf(root->right);
    if (ld == rd) return (1 << ld) + countNodes(root->right);   // 左子树满
    return (1 << rd) + countNodes(root->left);                  // 右子树满（矮一层）
}

// ---------- 7. 前序序列化 / 反序列化 ----------
class Codec {
    void ser(TreeNode* root, string& s) {
        if (!root) { s += "null,"; return; }
        s += to_string(root->val) + ",";
        ser(root->left, s);
        ser(root->right, s);
    }
    TreeNode* des(list<string>& lst) {
        if (lst.front() == "null") { lst.pop_front(); return nullptr; }
        TreeNode* node = new TreeNode(stoi(lst.front()));
        lst.pop_front();
        node->left  = des(lst);
        node->right = des(lst);
        return node;
    }
public:
    string serialize(TreeNode* root) { string s; ser(root, s); return s; }
    TreeNode* deserialize(const string& data) {
        list<string> lst;
        string tmp;
        for (char c : data) {
            if (c == ',') { lst.push_back(tmp); tmp.clear(); }
            else tmp += c;
        }
        if (!tmp.empty()) lst.push_back(tmp);
        return lst.empty() ? nullptr : des(lst);
    }
};

// ---------- 8. 前序 + 中序构造二叉树 ----------
TreeNode* buildFrom(vector<int>& pre, int l1, int r1, vector<int>& in, int l2, int r2,
                    unordered_map<int,int>& pos) {
    if (l1 > r1) return nullptr;
    TreeNode* root = new TreeNode(pre[l1]);
    int k = pos[pre[l1]];
    int leftSize = k - l2;
    root->left  = buildFrom(pre, l1 + 1, l1 + leftSize, in, l2, k - 1, pos);
    root->right = buildFrom(pre, l1 + leftSize + 1, r1, in, k + 1, r2, pos);
    return root;
}
TreeNode* buildTree(vector<int>& pre, vector<int>& in) {
    unordered_map<int,int> pos;
    for (int i = 0; i < (int)in.size(); i++) pos[in[i]] = i;
    return buildFrom(pre, 0, (int)pre.size() - 1, in, 0, (int)in.size() - 1, pos);
}

// ---------- 9. LCA：普通二叉树 / 搜索二叉树 ----------
TreeNode* lcaBinaryTree(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    TreeNode* l = lcaBinaryTree(root->left, p, q);
    TreeNode* r = lcaBinaryTree(root->right, p, q);
    if (l && r) return root;                 // 左右各找到一个 -> 当前即 LCA
    return l ? l : r;
}
TreeNode* lcaBST(TreeNode* root, TreeNode* p, TreeNode* q) {
    int lo = min(p->val, q->val), hi = max(p->val, q->val);
    while (root) {
        if (root->val > hi)      root = root->left;
        else if (root->val < lo) root = root->right;
        else return root;
    }
    return nullptr;
}

// ---------- 10. 验证 BST（中序迭代） ----------
bool isValidBST(TreeNode* root) {
    stack<TreeNode*> st;
    TreeNode *cur = root, *prev = nullptr;
    while (cur || !st.empty()) {
        while (cur) { st.push(cur); cur = cur->left; }
        cur = st.top(); st.pop();
        if (prev && prev->val >= cur->val) return false;
        prev = cur;
        cur = cur->right;
    }
    return true;
}

// ---------- 11. 路径和等于 aim 的所有路径 ----------
vector<vector<int>> pathAns;
vector<int> pathBuf;
void pathDfs(TreeNode* cur, int preSum, int target) {
    if (!cur->left && !cur->right) {                       // 只在叶子判断
        if (preSum + cur->val == target) {
            pathBuf.push_back(cur->val);
            pathAns.push_back(pathBuf);
            pathBuf.pop_back();
        }
        return;
    }
    pathBuf.push_back(cur->val);
    if (cur->left)  pathDfs(cur->left,  preSum + cur->val, target);
    if (cur->right) pathDfs(cur->right, preSum + cur->val, target);
    pathBuf.pop_back();                                    // 恢复现场
}

// ---------- 12. 打家劫舍 III（树形 DP 入门） ----------
pair<int,int> robDp(TreeNode* root) {                      // {选, 不选}
    if (!root) return {0, 0};
    pair<int,int> L = robDp(root->left), R = robDp(root->right);
    int pick = root->val + L.second + R.second;
    int skip = max(L.first, L.second) + max(R.first, R.second);
    return {pick, skip};
}
int rob(TreeNode* root) { pair<int,int> r = robDp(root); return max(r.first, r.second); }

int main() {
    //        1
    //      /   \
    //     2     3
    //    / \
    //   4   5
    TreeNode* root = new TreeNode(1,
        new TreeNode(2, new TreeNode(4), new TreeNode(5)),
        new TreeNode(3));
    std::cout << "maxDepth=" << maxDepth(root) << " minDepth=" << minDepth(root) << " width=" << widthOfBinaryTree(root) << " complete=" << (int)isCompleteTree(root) << "\n";
    std::cout << "countNodes=" << countNodes(root) << " rob=" << rob(root) << "\n";
    Codec codec;
    string data = codec.serialize(root);
    std::cout << "serialize: " << data << "\n";
    return 0;
}
```

## 专题深化：为什么成立

大多数二叉树题可归为“后序收集子树信息再合并”或“层序按层处理”。最大深度是左右最大加一；对称树比较左右镜像；完全二叉树可借编号性质计数。

## 专题深化：手算与边界

深度题中空节点高度 0，叶子返回 1；直径题对每个节点尝试左高加右高，同时向上只返回单边最大高度。

### 对照与取舍

递归适合自底向上信息；队列适合最短层数、右视图、逐层平均值；哈希表适合路径和、节点映射。

### 易错点与反例

1. 叶子与空指针语义不同
2. 直径边数/节点数定义差一
3. 完全二叉树编号可能溢出
4. 序列化需要处理空节点分隔符

## 专题深化：进阶拓展

Morris 可 O(1) 空间遍历；序列化可支持反序列化；LCA 可倍增或 Tarjan 离线。
