# 括号问题与嵌套递归（终极总结 · 递归下降 V1/V2/V3）

> 来源笔记：`括号问题与嵌套递归.md`｜性质：嵌套类问题查阅手册｜分类：03 二叉树与递归

## 一句话

**判断/计数/最长**类括号题：`balance` 是充分统计量，单值用计数、集合用区间；**结构/分数/消去**类：栈 = 计数 + 位置信息；**带语义的嵌套求值**：递归下降 V3（`&i` + `if...break` + 末尾 flush）。

## 一、什么是嵌套类问题

满足任一特征即是：

1. 字符串中有**配对的定界符**（`()`、`[]`、`{}`、`<tag>`、自定义规则）；
2. 同构结构**在自身内部重复出现**（括号套括号、`3[a2[c]]`、`(OH)2`）；
3. 每层行为相同：算本层 → 遇嵌套触发符 → 递归下级 → 拿结果继续算本层。

**一句话识别**：从左到右扫，扫到特殊字符就"派下级去处理里面那段"，处理完回来继续。

## 二、七种手段速览（详见 `括号问题的解题思路`）

计数法（单变量）、栈法（多类型/位置/嵌套）、贪心区间 `[lo, hi]`（通配符判断）、区间 DP（O(n³)）、前缀 DP `dp[i][bal]`（O(n²)）、Catalan 数（计数）、回溯/BFS（生成/还原）。

## 三、递归下降：三种版本

核心思想：每个递归函数对应一条文法非终结符，负责解析"一段平衡子串"。

| 版本 | 写法 | 优劣 |
| --- | --- | --- |
| V1（原始） | 全局 `where` + `f(string& s, int i)` | 显式，但易忘 `where = i` / `i = where + 1` |
| V2（升级） | 引用 `&i` + `f(string& s, int& i)` | 少两个易错点 |
| V3（派发，推荐） | V2 + 循环首行 `if (c == TERM) { i++; break; }` | 多分支更清晰，多终止符易扩展 |

### V1：`where` 全局游标

两条铁律：① 函数返回前必须 `where = i`；② 递归返回后必须 `i = where + 1`。

### V2：`&i` 引用

函数自己边走边推进 `i`，返回时 `i` 指向**本层终止符之后**；循环条件里判断终止符，循环外补吃一次 TERM。

### V3：`if...break` 派发（默认推荐）

把终止符识别放在**循环首行**，识别与消费合并到一处：

```cpp
Result f(string& s, int& i) {
    Result acc; LocalBuf buf; int times = 0;
    while (i < (int)s.size()) {
        char c = s[i];
        if (c == TERM) { i++; break; }        // ★终止符自检自吃
        if (c == BEGIN) {
            flush(buf, acc, times);           // 先结算当前缓冲
            buf.clear(); times = 0;
            i++;                              // 跳过 BEGIN
            Result sub = f(s, i);             // 递归吃完自己的范围
            merge(acc, sub, times);           // 按语义合并
            times = 0;
            continue;
        }
        if (isdigit(c)) { times = times * 10 + (c - '0'); i++; continue; }
        buf.append(c); i++;
    }
    flush(buf, acc, times);                   // ★末尾补 flush
    return acc;
}
```

## 四、三个固定组件 + 三个填空钩子

**固定组件**：

1. 循环 `while (i < n)`，首行判终止符并 `break`；
2. 嵌套触发：`if (c == BEGIN) { i++; 递归; 合并; continue; }`；
3. 循环外补一次 flush。

**填空钩子**（不同题不同）：

| 钩子 | 作用 | 三种题的填法 |
| --- | --- | --- |
| `Result` | 返回类型 | `int` / `string` / `map<string,int>` |
| `flush(buf, acc, times)` | 把缓冲提交到累积结果 | push 进栈 / append 到 path / 写入 map |
| `merge(acc, sub, times)` | 子结果按倍数合并 | 当数参与运算 / 重复 times 次拼接 / 每个原子 ×times |

## 六、坑点清单（照着检查）

| 坑 | 现象 | 解决 |
| --- | --- | --- |
| V1 忘 `where = i` | 上级读到错位置 | 用 V2/V3 消除 |
| V1 忘 `i = where + 1` | 死循环 / 重复扫终止符 | 用 V2/V3 消除 |
| V2 忘循环外补吃 TERM | 上级位置错 | 用 V3 消除 |
| 末尾忘 flush | 最后一个缓冲没结算 | 循环外必补一次 |
| 缓冲没在新单元开始时清空 | `Mg` 变成 `MgH` 类污染 | flush 后立刻 clear |
| 倍数 `cnt` 没重置 | 后续单元继承前一个倍数 | 用完立刻置 0 |
| 递归前没 flush 当前缓冲 | 嵌套前的数/原子被吞 | 调 `f` 之前先 flush |
| V2 误传右值 `f(s, 0)` | 编译失败 | 入口先 `int i = 0; f(s, i);` |
| V2 递归后重复 `i++` | 多走一步 | 递归已吃完 TERM，别再 ++ |
| `string s` 按值传递 | 每次递归复制串 | 改 `string& s` |

## 七、拿题判断流程（第四问升级版）

```
Q1 单种还是多种括号？  多种 -> 栈
Q2 有没有通配符？      有 -> 贪心区间（判断）/ 前缀 DP（计数）
Q3 要判断/计数/生成/编辑/带语义求值？
    判断 -> 计数法；计数 -> Catalan / 前缀 DP
    生成 -> 回溯；编辑 -> 贪心 balance 或区间 DP
    带语义求值 -> ★递归下降 V3★
Q4 需要位置 / 嵌套深度 / 子串信息吗？ 需要 -> 栈存下标 / 区间 DP / 递归下降
```

## 九、两套心法

1. **永远盯住 balance**：单值 → 计数法；多值集合 → 区间 / DP / 枚举。
2. **递归下降 = 文法非终结符 + 自吃终止符**：每个 `f(s, i)` 是一条非终结符，`BEGIN`/`TERM` 是它的定界符，`i` 是给调用者回传的"读到这里"。返回值 = 业务结果，`i` = 解析位置，两件事分清后，剩下就是把语义填进 `flush` 与 `merge`。
