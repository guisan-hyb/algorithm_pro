# N 皇后问题（数组版 + 位运算版）

> 来源笔记：`1219N皇后问题.cpp`｜核心程度：经典暴力/剪枝题｜分类：03 二叉树与递归

## 一句话

按行放皇后，每行逐列尝试；用**列 + 两条对角线**三个约束剪枝。位运算版把这三个约束压进三个整数的位里，常数最小。

## 解决什么问题

在 n×n 棋盘上放 n 个皇后，使它们互不攻击（不同行、不同列、不同对角线），求**方案数**（LeetCode 52）或列举所有方案（LeetCode 51）。

复杂度本质是 O(n!)——好的方法只能"大量剪枝、优化常数"，**改变不了量级**（笔记原话）。

## 核心思想

### 法一：路径数组（经典、好懂、常数慢）

- `path[i] = j` 表示第 i 行的皇后放在第 j 列；
- 来到第 i 行，枚举第 0~n-1 列，用 `check` 判断是否与 0~i-1 行冲突：

```
同列      : j == path[k]
同对角线  : abs(i - k) == abs(j - path[k])
```

（笔记注释里把对角线的 `abs(i-k) == abs(j-path[k])` 解释为曼哈顿距离相等。）

- 能放就 `path[i] = j`、递归下一行、返回后回溯 `path[i] = -1`。

### 法二：位运算（巧妙、常数快、推荐）

用三个整数表示"哪些列被禁"：

| 变量 | 含义 |
| --- | --- |
| `col` | 已有皇后所在列（正下方延伸方向） |
| `left` | 左下方向的影响（每往下一行要 `>> 1`） |
| `right` | 右下方向的影响（每往下一行要 `<< 1`） |

```cpp
int limit     = (1 << n) - 1;
int ban       = col | left | right;
int candidate = limit & ~ban;          // 1 表示这一列可放
while (candidate) {
    int place = candidate & (-candidate);      // Brian Kernighan：取最右边的 1
    candidate ^= place;                        // 用掉这一位
    dfs(limit, col | place, (left | place) >> 1, (right | place) << 1);
}
```

- 终止条件：`col == limit`（所有列都占满）→ 计数 +1；
- **注意**：位运算版**不回退**三个整数——因为每层用参数传值，天然就是"恢复现场"（笔记原话："因为之前放的皇后有持续影响，不回溯"）；
- `int limit = (1 << n) - 1;` 记得**加括号**（笔记特意提醒，否则优先级出错）。

## 适用特征（看到这些信号就选它）

- 第 i 行的决策只跟前面已放的位置有关（行天然互斥）；
- 约束是"列 + 两条对角线"这类可位压缩的条件；
- 另一类典型场景：数独、棋盘染色、约束搜索——**"按行/按层决策 + 位压缩约束"**是通用套路。

## 复杂度

- 时间：O(n!)（剪枝后远小于 n!，但量级不变）；
- 空间：O(n)（路径数组版）/ O(n)（递归栈）；
- 位运算版常数明显更小，n=12~15 时优势明显。

## 易错点

1. 对角线判据是 `abs(i-k) == abs(j-path[k])`，漏掉 `abs` 或写成行列和差都会错；
2. `path[i] = -1` 的回溯不能省（数组版）；
3. 位运算版的左移右移方向：`left` 是 `>> 1`、`right` 是 `<< 1`，写反了结果错但通常不崩，很难 debug；
4. `(1 << n) - 1` 的括号；n ≥ 31 时要换 `long long`（本题不会）；
5. `candidate & (-candidate)` 依赖补码（有符号负数），用 `unsigned` 更稳；
6. `col == limit` 是成功标志（等价于"n 行都放完了"）。

## 模板（可直接编译运行）

```cpp
// N 皇后模板：路径数组法 + 位运算法（位运算版常数更小）
#define _CRT_SECURE_NO_WARNINGS
#include <cstdlib>
#include <iomanip>
#include <iostream>
#include <vector>
using namespace std;

// ================= 法一：路径数组（好懂） =================
class SolutionArray {
    int n, ans = 0;
    vector<int> path;                              // path[i] = 第 i 行皇后所在列
    bool check(int i, int j) {
        for (int k = 0; k < i; k++)
            if (j == path[k] || abs(i - k) == abs(j - path[k]))
                return false;                      // 同列 或 同对角线
        return true;
    }
    void dfs(int i) {
        if (i == n) { ++ans; return; }
        for (int j = 0; j < n; j++) {
            if (check(i, j)) {
                path[i] = j;
                dfs(i + 1);
                path[i] = -1;                      // 回溯
            }
        }
    }
public:
    int totalNQueens(int n_) {
        n = n_; path.assign(n, -1); ans = 0;
        dfs(0);
        return ans;
    }
};

// ================= 法二：位运算（推荐） =================
class SolutionBit {
    int dfs(int limit, int col, int left, int right) {
        if (col == limit) return 1;
        int ans = 0;
        int candidate = limit & ~(col | left | right);
        while (candidate) {
            int place = candidate & (-candidate);   // 取出最低位的 1
            candidate ^= place;                     // 该位置已使用
            ans += dfs(limit, col | place,
                       (left  | place) >> 1,
                       (right | place) << 1);
        }
        return ans;
    }
public:
    int totalNQueens(int n) {
        return n < 1 ? 0 : dfs((1 << n) - 1, 0, 0, 0);
    }
};

int main() {
    for (int n = 1; n <= 10; n++)
        std::cout << "n=" << std::setw(2) << n << "  数组法=" << SolutionArray().totalNQueens(n) << "  位运算法=" << SolutionBit().totalNQueens(n) << "\n";
    return 0;
}
```

## 专题深化：为什么成立

逐行放皇后，状态只需记录已占用列、两条对角线。主对角线可用 `row-col+offset`，副对角线 `row+col`；位运算版用三个整数的 1 位表示这些禁用位置。

## 专题深化：手算与边界

n=4 第一行放 0 列后，列 0、两条对角线被禁用；第二行可选列 2，再继续搜索，最终得到两种布局。

### 对照与取舍

数组标记版直观、适合解释；位运算版快速枚举可用列。若要求最小冲突而非全解，可转成搜索/模拟退火问题。

### 易错点与反例

1. 对角线下标需要加偏移避免负数
2. 回溯时每层必须撤销标记
3. 只记录列不够，还要两条对角线
4. 位掩码宽度要与 n 一致

## 专题深化：进阶拓展

n 皇后计数可用位运算和对称性剪枝；冲突搜索可用最小冲突启发式。
