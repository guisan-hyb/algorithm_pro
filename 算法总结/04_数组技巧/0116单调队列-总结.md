# 单调队列（窗口最值 + 维持可能性）

> 来源笔记：`0116单调队列.cpp`｜核心程度：必背｜分类：04 数组技巧

## 一句话

单调队列 = **双端队列** + 单调性：队头维持"最值优势"，队尾维持"新旧优势"；新元素又新又更优时，可以把队尾那些又旧又差的直接淘汰，从而在窗口滑动时均摊 O(1) 取到最值。

## 一、经典用法：滑动窗口最值

场景：`r++` 表示右侧数字进窗口，`l++` 表示左侧数字出窗口，过程中随时要当前窗口的**最大值/最小值**。总代价 O(n)，单次均摊 O(1)。

**模板（滑动窗口最大值，LeetCode 239）**：

```cpp
// deque 里存下标，保持从队头到队尾单调递减 -> 队头就是窗口最大值
for (int i = 0; i < k - 1; i++) {                 // 先形成长度 k-1 的窗口
    while (head < tail && nums[i] >= nums[deque[tail - 1]]) tail--;
    deque[tail++] = i;
}
for (int l = 0, r = k - 1; r < n; l++, r++) {
    while (head < tail && nums[r] >= nums[deque[tail - 1]]) tail--;
    deque[tail++] = r;
    ans.push_back(nums[deque[head]]);             // 队头即最大值
    if (l == deque[head]) head++;                 // 队头过期出队
}
```

要点：入队时**从队尾淘汰比新元素差的**；出队时只有"队头下标正好过期"才 `head++`。

### 用法二：绝对差不超过限制的最长子数组（LeetCode 1438）

同时维护**两个单调队列**（一个求最大、一个求最小）：

- `maxs = maxDeque` 队头、`mins = minDeque` 队头；
- 能否加入新元素由 `maxs - mins <= limit` 决定；
- 窗口左端移动时，若 `l` 正好是两个队列的队头就弹出。

笔记把它们总结成一句话：**题二与题三是一体两面**——题二求"最大长度"，用 `max - min <= limit`；落水题求"最小宽度"，用 `max - min >= D`。

笔记还特别比较了两种写法：**先操作后检查**（标准写法）vs **先检查后操作**（本题笔记用的写法），并给出了"先操作后检查"的对照实现，建议统一成前者。

## 二、进阶用法（维持答案的可能性）

与单调栈同理的四条：

1. 队列按规定的单调性组织；
2. 新元素从**队头或队尾**淘汰"对后续没有帮助"的对象；
3. 对象被弹出时结算它参与的答案，之后不再参与；
4. 先分析题目发现单调性，再用单调队列实现。

### 进阶题一：和至少为 K 的最短子数组（LeetCode 862）

- **前缀和 + 二分失败**的原因（笔记点明）：数组含负数时，"子数组长度"与"和"之间没有单调性；
- **单调队列 O(n)**：维护**递增的前缀和下标队列**；
  - 若 `preSum[i] - preSum[deque[head]] >= k`，就 `ans = min(ans, i - deque[head])` 并弹出队头（后面再用它只会更长）；
  - 若 `preSum[i] <= preSum[deque[tail-1]]`，则队尾"又旧又不优"，弹出。

### 进阶题二：满足不等式的最大值（LeetCode 1499）

要求 `yi + yj + |xi - xj|` 最大（`|xi - xj| <= k`，x 已升序）：

- 拆成"后面点的 `y + x`" + "前面点的 `y - x`"；
- 队列存 `[x, y-x]`，按 `y-x` **从大到小**；
- **操作顺序（笔记提醒）**：先移除过期队头 → 再计算当前点与队头的值 → 最后入队并维护单调性。

### 进阶题三：最多能安排的任务数目（LeetCode 2071）

二分答案（完成 `aim` 个任务）× 单调队列（在这里更像一个"双端队列窗口"）：

- 任务与工人分别排序；取"最小的 `aim` 个任务"和"最大的 `aim` 个工人"；
- 每个工人先解锁"不吃药就能完成的任务"入队；能不吃药完成就取队头（最小的）；
- 否则吃药后再解锁"吃药能完成的任务"，**取队尾（最难的）**完成，为后面的工人减轻负担；
- 用过药数超过 `pills` 就失败。

## 适用特征（看到这些信号就选它）

- 滑动窗口里要**随时取最值**（滑窗 + 最值 = 单调队列）；
- 数组含负数导致"和"不单调，但"前缀和"本身单调（递增队列）；
- 需要按"某个量的单调性"淘汰旧元素，且淘汰是永久性的；
- 需要"双向都能进出"的窗口（队头过期、队尾被新元素挤掉）。

## 复杂度

- 时间 O(n)（每个元素至多进出队一次）；
- 空间 O(n)（队列最多存 n 个下标）。

## 易错点

1. 队列里存**下标**而不是值（要靠下标判断过期）；
2. 入队的比较符号：求最大值用 `>=` 淘汰队尾（相等也淘汰，保留新的更有利）；求最小值反过来；
3. 只有"队头下标 == 出窗口的下标"时才 `head++`（不要无脑弹队头）；
4. 和至少为 K 的题：前缀和队列是**递增**的，且队头弹出条件是 `>= k`；这里不能对含负数数组用二分；
5. 不等式最大值题的操作顺序（先出队、再计算、最后入队）不能颠倒；
6. 用数组模拟双端队列时 `[head, tail)` 是左闭右开，`tail - 1` 是队尾；
7. 多组数据/多次调用要重置 `head = tail = 0`。

## 模板（可直接编译运行）

```cpp
// 单调队列模板：滑动窗口最值 / 和至少为 K 的最短子数组 / 绝对差不超过限制的最长子数组
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <deque>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

// ================= 1. 滑动窗口最大值（数组模拟双端队列） =================
vector<int> maxSlidingWindow(const vector<int>& nums, int k) {
    int n = (int)nums.size();
    vector<int> dq(n), ans;
    int head = 0, tail = 0;                       // [head, tail)
    for (int i = 0; i < n; i++) {
        while (head < tail && nums[dq[tail - 1]] <= nums[i]) tail--;
        dq[tail++] = i;
        if (i >= k - 1) {
            ans.push_back(nums[dq[head]]);        // 队头即窗口最大值
            if (dq[head] == i - k + 1) head++;    // 队头过期
        }
    }
    return ans;
}

// ================= 2. 和至少为 K 的最短子数组（前缀和递增队列） =================
int shortestSubarray(const vector<int>& nums, int k) {
    int n = (int)nums.size();
    vector<long long> pre(n + 1, 0);
    for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + nums[i - 1];
    vector<int> dq(n + 1);
    int head = 0, tail = 0, ans = INT_MAX;
    for (int i = 0; i <= n; i++) {
        while (head < tail && pre[i] - pre[dq[head]] >= k) {
            ans = min(ans, i - dq[head]);
            head++;                               // 队头以后只会得到更长的答案
        }
        while (head < tail && pre[i] <= pre[dq[tail - 1]]) tail--;   // 队尾又旧又不优
        dq[tail++] = i;
    }
    return ans == INT_MAX ? -1 : ans;
}

// ================= 3. 绝对差不超过 limit 的最长子数组（双队列） =================
int longestSubarray(vector<int>& nums, int limit) {
    int n = (int)nums.size();
    vector<int> maxDq(n), minDq(n);
    int mh = 0, mt = 0, nh = 0, nt = 0, ans = 0;
    for (int l = 0, r = 0; r < n; r++) {
        while (mt > mh && nums[maxDq[mt - 1]] <= nums[r]) mt--;      // 最大值队列
        maxDq[mt++] = r;
        while (nt > nh && nums[minDq[nt - 1]] >= nums[r]) nt--;      // 最小值队列
        minDq[nt++] = r;
        while (nums[maxDq[mh]] - nums[minDq[nh]] > limit) {          // 超限则收左边界
            if (maxDq[mh] == l) mh++;
            if (minDq[nh] == l) nh++;
            l++;
        }
        ans = max(ans, r - l + 1);
    }
    return ans;
}

// ================= 4. 满足不等式的最大值（y_i + y_j + |x_i - x_j|） =================
int findMaxValueOfEquation(vector<vector<int>>& points, int k) {
    deque<pair<int,int>> dq;                      // {x, y - x}，按 y-x 从大到小
    int ans = INT_MIN;
    for (auto& p : points) {
        int x = p[0], y = p[1];
        while (!dq.empty() && x - dq.front().first > k) dq.pop_front();   // 1) 出过期队头
        if (!dq.empty()) ans = max(ans, dq.front().second + x + y);       // 2) 计算答案
        while (!dq.empty() && y - x >= dq.back().second) dq.pop_back();   // 3) 维护单调性
        dq.push_back({x, y - x});
    }
    return ans;
}

int main() {
    vector<int> a = {1, 3, -1, -3, 5, 3, 6, 7};
    for (int x : maxSlidingWindow(a, 3)) std::cout << x << " ";   // 3 3 5 5 6 7
    std::cout << "\n";
    vector<int> b = {2, -1, 2};
    std::cout << "和至少为 3 的最短子数组 = " << shortestSubarray(b, 3) << "\n";   // 3
    vector<int> c = {8, 2, 4, 7};
    std::cout << "绝对差 <=4 的最长子数组 = " << longestSubarray(c, 4) << "\n";    // 2
    return 0;
}
```

## 专题深化：为什么成立

滑动窗口最值要求 O(1) 取队头最大值，同时删除过期下标。维护值递减的双端队列：新值进入前弹掉更小值，因为它们不可能在未来比新值更优；队头下标过期就弹出。

## 专题深化：手算与边界

窗口 `[1,3,-1]` 的队列存 3 和 -1；右移加入 -3 后队列 `3,-1,-3`；当 3 过期时弹出，新队头为 -1。

### 对照与取舍

单调栈不看窗口过期；优先队列支持任意插入但 O(log n) 取极值；单调队列用于连续窗口且每个元素只进出一次。

### 易错点与反例

1. 队头过期判断用 `index <= i-k`
2. 先保证窗口形成再记录答案
3. 相等值弹或不弹要对应不同最优候选
4. 队列为空时不能访问队头
