# 一维差分与等差数列差分

> 来源笔记：`1229一维差分与等差数列差分.cpp`｜核心程度：必背｜分类：04 数组技巧

## 一句话

差分是**前缀和的逆运算**：在区间左端点"开状态"、在右端点后一位"关状态"，最后做前缀和即可把批量区间修改还原；等差数列差分就是"把这一步做两遍"。

## 解决什么问题

- 查询少、**区间修改多**的场景（笔记原话：对"查询少而区间修改多"的数组的一种优化）；
- 一次性处理 m 个区间加操作，最后统一求出每个位置的值；
- 升级版：每次加的不是常数，而是一段**等差数列**。

## 核心思想

### 一维差分

区间 `[L, R]` 每个数 `+V`：

```
diff[L]     += V;
diff[R + 1] -= V;
// 所有操作做完后，对 diff 做一遍前缀和，得到每个位置的最终值
```

**注意：不支持边修改边查询**，必须先做完所有修改再 `build`。

### 等差数列差分

在 `[l, r]` 上依次加上首项 `s`、末项 `e`、公差 `d` 的等差数列：

```
set:   arr[l] += s;  arr[l+1] += d - s;  arr[r+1] -= d + e;  arr[r+2] += e;
build: 做两遍前缀和
```

记忆方式：**`set` 写 4 个端点，`build` 做 2 遍前缀和**。

### 大偏移量技巧（笔记的"神来之笔"）

当操作下标可能为负（例如以某个点为中心向左右扩散的抛物线影响）：

- 数组开成 `OFFSET + MAXN + OFFSET`；
- 所有 `set` 的下标统一 `+OFFSET`；
- 输出时从 `1 + OFFSET` 开始数 m 个。

这样**省掉大量边界讨论**（笔记原话："为了防止出现负数下标，进而有很多很烦的边界讨论，所以任何位置都加上一个较大的数字"）。

洛谷 P5026 的四段（笔记原文）：

```
set(x - 3v + 1, x - 2v,      1,    v,  1)
set(x - 2v + 1, x,           v-1, -v, -1)
set(x + 1,      x + 2v,     -v+1,  v,  1)
set(x + 2v + 1, x + 3v - 1,  v-1,  1, -1)
```

## 适用特征（看到这些信号就选它）

- "对区间整体加减"的操作有 m 次（m 很大），查询在最后；
- 操作是等差数列形式（首项、末项、公差）；
- 下标可能越界到负数 → 用 OFFSET 平移；
- 本质是"前缀和的逆问题"。

## 复杂度

- 每次区间操作 **O(1)**；
- 全部完成后 `build` 一遍 O(n)；
- 空间 O(n)（带 OFFSET 则是 O(n + 2·OFFSET)）。

## 易错点

1. 差分数组要开到 `n + 2` 以上（`r + 1`、`r + 2` 会越界）；
2. **先做完全部修改再 build**，边改边查必然错；
3. 等差数列差分的 4 个端点符号：`+s`、`+(d-s)`、`-(d+e)`、`+e`，容易记混；
4. 公差 `d = (e - s) / (r - l)`，注意整除与负数；
5. 带 OFFSET 时 `build` 的上界要到 `m + OFFSET`，输出从 `1 + OFFSET` 开始；
6. 数组有初始值时，可把初始值当作"单点差分"处理（`add(i, j, i, j, a)`）；
7. 差分与前缀和互为逆运算，两者不能同时用错下标基准（1-based 与 0-based 要统一）。

## 模板（可直接编译运行）

```cpp
// 一维差分模板：区间加常数 / 区间加等差数列 / 带 OFFSET 的负下标处理
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <iostream>
using namespace std;

const int MAXN = 1000005;
std::array<long long, MAXN + 5> diffArr = {};
std::array<long long, MAXN + 5> arithArr = {};
int n;

// ---------- 1. 区间加常数：O(1) 修改 + O(n) 还原 ----------
void rangeAdd(int l, int r, long long v) {
    diffArr[l] += v;                       // 左端点开状态
    diffArr[r + 1] -= v;                   // 右端点后一位关状态
}
void buildConst() {
    for (int i = 1; i <= n; i++) diffArr[i] += diffArr[i - 1];
}

// ---------- 2. 区间加等差数列 [s, s+d, ..., e] ----------
void rangeAddArith(int l, int r, long long s, long long e, long long d) {
    arithArr[l]     += s;
    arithArr[l + 1] += d - s;
    arithArr[r + 1] -= d + e;
    arithArr[r + 2] += e;
}
void buildArith() {                        // 两遍前缀和
    for (int i = 1; i <= n; i++) arithArr[i] += arithArr[i - 1];
    for (int i = 1; i <= n; i++) arithArr[i] += arithArr[i - 1];
}

int main() {
    // ---- 示例 1：区间加常数 ----
    n = 5;
    rangeAdd(1, 3, 2);
    rangeAdd(2, 4, 1);
    buildConst();
    std::cout << "区间加：";
    for (int i = 1; i <= n; i++) std::cout << diffArr[i] << " ";   // 2 3 3 1 0
    std::cout << "\n";

    // ---- 示例 2：区间加等差数列 ----
    // 在 [1,5] 上依次加 1,3,5,7,9（首项 1、末项 9、公差 2）
    rangeAddArith(1, 5, 1, 9, 2);
    buildArith();
    std::cout << "等差加：";
    for (int i = 1; i <= n; i++) std::cout << arithArr[i] << " ";  // 1 3 5 7 9
    std::cout << "\n";

    // ---- 示例 3：洛谷 P4231 题型（每行输入 l r s e，公差自动算） ----
```

## 专题深化：为什么成立

给区间加常数 c，只需在 `diff[l]+=c`、`diff[r+1]-=c`，最后前缀和还原。区间加等差数列需要同时维护常数差分和“斜率”差分，使前缀和恢复出线性增长。

## 专题深化：手算与边界

n=5，给 `[1,5]` 加 `1,3,5,7,9`，首项 1、公差 2。构建差分后两次前缀累加得到目标序列。

### 对照与取舍

普通差分适合区间常数；算术差分适合一次函数；多次查询与修改交替时应使用树状数组/线段树。

### 易错点与反例

1. 右端加一必须检查是否越界
2. 等差公差为负仍成立
3. 多次修改后统一恢复
4. 累加和可能超出 int

## 专题深化：进阶拓展

二阶差分可处理区间加二次函数；差分数组结合懒标记可处理区间历史最值。
