# 寻找两个正序数组的中位数（二分分割线）

> 来源笔记：`寻找两个正序数组的中位数.md`｜核心程度：Hard 经典（二分的高级用法）｜分类：04 数组技巧

## 一句话

不要找"中位数那个数"，要找**一条分割线**：它把两个数组的左半部分凑成长度 `half = (m+n+1)/2`，且满足"左半最大值 ≤ 右半最小值"；在较短的数组上二分分割线位置即可。

## 核心推导

设 `nums1` 长度 m、`nums2` 长度 n，在 `nums1` 的索引 `i` 处切一刀、`nums2` 的索引 `j` 处切一刀：

1. 左半总元素数固定：`i + j = half = (m + n + 1) / 2`（+1 是为了奇数时左半多一个）；
2. 一旦确定 `i`，`j = half - i` 就确定了；
3. 完美分割线满足两个不等式：
   - `nums1[i-1] <= nums2[j]`（nums1 左最大 ≤ nums2 右最小）
   - `nums2[j-1] <= nums1[i]`（nums2 左最大 ≤ nums1 右最小）

**二分的单调性**：`i` 越大，`nums1[i-1]` 越大、`nums2[j-1]` 越小；条件随之单调变化。

## 二分过程

在 **较短的数组**（设 `nums1`）上二分 `i ∈ [0, m]`：

1. `i = left + (right - left) / 2`，`j = half - i`；
2. 若 `nums2[j-1] > nums1[i]` → `i` 切得太靠左，`left = i + 1`；
3. 否则（可能切得太靠右，也可能就是答案）→ `right = i`（**不是 `i - 1`**，因为要找"最左的可行位置"）。

循环结束 `i = left`，再算四个边界值与答案。

## 边界处理

切在数组边缘时"左边最大"或"右边最小"不存在，用极值代替：

```cpp
int nums1_left_max  = (i == 0) ? INT_MIN : nums1[i - 1];
int nums2_left_max  = (j == 0) ? INT_MIN : nums2[j - 1];
int nums1_right_min = (i == m) ? INT_MAX : nums1[i];
int nums2_right_min = (j == n) ? INT_MAX : nums2[j];
int left_max  = max(nums1_left_max, nums2_left_max);
int right_min = min(nums1_right_min, nums2_right_min);
return (m + n) % 2 ? (double)left_max : (left_max + right_min) / 2.0;
```

## 两个关键问题（笔记原文的解析）

1. **为什么一定要让 `nums1` 是较短的那个？**
   - 时间复杂度变成 `O(log min(m,n))`，比要求的 `O(log(m+n))` 更好；
   - 更重要的：防止 `j = half - i` 越界。若 `m <= n`，`i` 取到 `m` 时 `j = (m+n+1)/2 - m = (n-m+1)/2 >= 0`，不会为负。
2. **`left = i + 1` 与 `right = i` 的区别？**
   - `nums2[j-1] > nums1[i]` 说明 `i` 太小，必须往右找 → `left = i + 1`；
   - 否则说明 `i` 可能太大、也可能刚好，由于要找**第一个满足条件**的位置，把右边界缩到 `i`。

## 适用特征（看到这些信号就选它）

- 两个有序序列、要求 O(log) 找中位数/第 k 小；
- 需要把"找元素"转化为"找划分位置"；
- 更一般地，凡是要"在两条有序序列上切一刀使左右满足不等式"的题都能套。

## 复杂度

- 时间 O(log min(m, n))；
- 空间 O(1)（递归版是 O(log) 栈，可改迭代）。

## 易错点

1. `half = (m + n + 1) / 2` 的 **+1**（奇数时保证左半多一个）；
2. 交换 `nums1 / nums2` 让短的在前面，递归写法靠 `return findMedianSortedArrays(nums2, nums1);`；
3. `j - 1`、`i - 1` 的越界用 `INT_MIN / INT_MAX` 兜住；
4. `right = i` 不是 `i - 1`（否则会漏掉可行解，甚至死循环）；
5. 偶数时返回 `(left_max + right_min) / 2.0`，注意**浮点除法**；
6. 笔记里作者的另一种写法用 `i, j` 表示"划分的个数"，注意与"下标"的区别（累加 1 的时机）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
    if (nums1.size() > nums2.size())                  // 保证 nums1 更短
        return findMedianSortedArrays(nums2, nums1);

    int m = (int)nums1.size(), n = (int)nums2.size();
    int half = (m + n + 1) / 2;                       // 左半部分元素个数
    int left = 0, right = m;                          // 在 nums1 上二分切分点
    while (left < right) {
        int i = left + (right - left) / 2;
        int j = half - i;
        if (nums2[j - 1] > nums1[i]) left = i + 1;    // i 切得太靠左
        else                         right = i;       // 可能是答案，保留
    }
    int i = left, j = half - i;

    int l1 = (i == 0) ? INT_MIN : nums1[i - 1];
    int l2 = (j == 0) ? INT_MIN : nums2[j - 1];
    int r1 = (i == m) ? INT_MAX : nums1[i];
    int r2 = (j == n) ? INT_MAX : nums2[j];

    int leftMax  = max(l1, l2);
    int rightMin = min(r1, r2);
    if ((m + n) % 2 == 1) return (double)leftMax;
    return (leftMax + rightMin) / 2.0;
}
```
