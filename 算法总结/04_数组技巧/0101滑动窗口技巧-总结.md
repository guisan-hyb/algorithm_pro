# 滑动窗口技巧

> 来源笔记：`0101滑动窗口技巧与相关题目.cpp`｜核心程度：必背｜分类：04 数组技巧

## 一句话

维持左、右边界**都不回退**的一段范围，用"范围变大/变小 → 答案指标单调变化"这条性质，把 O(n²) 的子数组枚举压成 O(n)。

## 核心思想

1. **关键：找单调性**。笔记原话："滑动窗口的关键是找到 范围 和 答案指标 之间的单调性关系（类似贪心）"——`[l, r)` 越大，答案指标是否单调？
2. **维护信息**：窗口内信息用简单变量（sum、count）或结构（数组、哈希表、单调队列）维护；
3. **求解大流程**：求"以每个位置开头"或"以每个位置结尾"的答案（选哪种看题目习惯）；
4. 两个边界都不回退，所以总调整次数 O(n)。

> 需要维护窗口**最大/最小值**时，必须配合单调队列，见 `0116单调队列`。

## 七道题的套路

### 题一：和 >= target 的最短子数组（LeetCode 209）

右边界扩张累加 `sum`；一旦 `sum - nums[l] >= target` 就一路右移左边界（贪心扔掉多余元素），再更新答案。

### 题二：无重复字符的最长子串（LeetCode 3）

关键一步：`l = max(l, last_index[s[r]] + 1)`——左边界**只能往右**，可以一次跳到不冲突的位置（这正是"窗口不回退"的体现）。

### 题三：最小覆盖子串（LeetCode 76）

**负债表**技巧（笔记核心）：

1. `for (char c : t) debtMap[c]--;` 把 t 的需求记成负数；
2. `debt = -t.size()` 是总负债；
3. 右扩时 `if (debtMap[s[r]]++ < 0) debt++;`——用掉一个欠款，负债减少；
4. 负债还清（`debt == 0`）时收左边界，直到再收就会欠债：`while (debtMap[s[l]] > 0) debtMap[s[l++]]--;`

### 题四：加油站（LeetCode 134）

`[l, r)` 是"能从 l 出发走到的区间"；`sum + gas[r] - cost[r] >= 0` 就右扩，转满一圈返回 `l`；一旦走不动就 `l = r + 1, r = l` 重新开始（不回退）。

### 题五：替换子串得到平衡字符串（LeetCode 1234）

**转化问题 + 负债表**：

1. 统计各字符出现次数，超过 `n/4` 的部分记成负债（负数）；
2. 题目变成"找最短子串，把它换成任意字符后能还清负债"；
3. 右扩补库存，左收直到不能再收（`while (map[s[l]] > 0) map[s[l++]]--`）。

### 题六：K 个不同整数的子数组（LeetCode 992）

**"恰好 k"没有单调性 → 容斥成两个"至多 k"**：

```
ans = numsOfMostKinds(nums, k) - numsOfMostKinds(nums, k - 1)
```

`numsOfMostKinds` 是标准滑窗：种类超过 k 就收左边界；每轮 `ans += r - l + 1`（以 r 结尾的所有合法子数组）。

### 题七：至少有 K 个重复字符的最长子串（LeetCode 395）

**外层枚举"窗口内的字符种类数" require（1~26）**，内层滑窗：

- `collect_kind`：窗口内出现的字符种类数；
- `aim`：窗口内"出现次数已达到 k"的字符种类数；
- 种类超过 require 就收左边界；
- `require == aim`（所有种类都达标）时更新答案。

把"不确定的种类数"变成枚举维度，是滑窗处理复杂约束的常用手段。

## 适用特征（看到这些信号就选它）

- 问**连续子数组/子串**的"最长/最短/个数"；
- 求和的题里元素**非负**；或指标随范围单调；
- 可以"贪心扔掉左端多余部分"（扔掉后不会变差）；
- 需要窗口最值时搭配单调队列。

> 反例：数组有负数时"和"不再随窗口长度单调，滑窗失效 → 改用前缀和 + 哈希表（见 `1226构建前缀信息的技巧`）。

## 复杂度

- O(n) 时间（左右边界各最多走 n 步）；
- O(1) 或 O(字符集大小) 空间。

## 易错点

1. **先判断单调性**：有负数、指标非单调时滑窗必然错；
2. 收左边界用 `while` 而不是 `if`（一次可能要收很多步）；
3. 负债表 `if (map[s[r]]++ < 0)` 的后置 ++ 与判断顺序很微妙，理解"先判断再自增"；
4. 结算答案的时机（右扩后结算还是左收后结算）要和更新逻辑自洽；
5. 题六容斥是 `f(k) - f(k-1)`，别把 `<=k` 写成 `<k`；
6. 题七只在 `require == aim` 时更新答案。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 1) 和 >= target 的最短子数组（元素为正）
int minSubArrayLen(int target, vector<int>& nums) {
    int ans = INT_MAX;
    for (int l = 0, r = 0, sum = 0; r < (int)nums.size(); r++) {
        sum += nums[r];
        while (sum - nums[l] >= target) sum -= nums[l++];
        if (sum >= target) ans = min(ans, r - l + 1);
    }
    return ans == INT_MAX ? 0 : ans;
}

// 2) 无重复字符的最长子串
int lengthOfLongestSubstring(const string& s) {
    vector<int> last(256, -1);
    int ans = 0;
    for (int l = 0, r = 0; r < (int)s.size(); r++) {
        l = max(l, last[(unsigned char)s[r]] + 1);
        ans = max(ans, r - l + 1);
        last[(unsigned char)s[r]] = r;
    }
    return ans;
}

// 3) 最小覆盖子串（负债表）
string minWindow(const string& s, const string& t) {
    unordered_map<char,int> debt;
    for (char c : t) debt[c]--;
    int total = -(int)t.size(), cnt = INT_MAX;
    string ans;
    for (int l = 0, r = 0; r < (int)s.size(); r++) {
        if (debt[s[r]]++ < 0) total++;
        if (total == 0) {
            while (debt[s[l]] > 0) debt[s[l++]]--;
            if (r - l + 1 < cnt) { cnt = r - l + 1; ans = s.substr(l, cnt); }
        }
    }
    return ans;
}

// 4) 至多 k 种不同整数的子数组个数（容斥的基础）
int numsOfMostKinds(const vector<int>& a, int k) {
    unordered_map<int,int> mp;
    int ans = 0;
    for (int l = 0, r = 0, kinds = 0; r < (int)a.size(); r++) {
        if (++mp[a[r]] == 1) kinds++;
        while (kinds > k) if (--mp[a[l++]] == 0) kinds--;
        ans += r - l + 1;
    }
    return ans;
}
```
