# 双指针技巧

> 来源笔记：`0103双指针技巧与相关题目.cpp`｜核心程度：必会｜分类：04 数组技巧

## 一句话

"双指针"只是一层皮：真正决定能不能用的是**题目里的单调性/贪心取舍**；代码写成双指针，是因为你先想清楚了"哪一步可以安全地丢掉"。

## 笔记开篇的四种类型

1. **同向双指针**（左、右都往右走，例如滑窗）
2. **快慢双指针**（一快一慢，找中点/判环/去重）
3. **两头往中间的双指针**（排序后从两端夹）
4. 其他

笔记的态度很明确：不要纠结"双指针"这个名号，要练的是**分析单调性与舍弃的合理性**。

## 七道题的套路

### 题一：按奇偶排序数组 II（LeetCode 922）

用 `even`（指向偶数位）、`odd`（指向奇数位）两个指针，配一个从后往前的 `look` 读指针：值为偶数就与 `even` 换、`even += 2`；为奇数就与 `odd` 换、`odd += 2`。三个指针，一次遍历。

### 题二：寻找重复数（LeetCode 287）

**把数组当链表**：下标 `i -> nums[i]` 是一条边；有重复数 ⇔ 链表有环，重复数就是**环的入口**。于是问题变成 Floyd 判圈（见 `1203链表高频题目和必备技巧`）：快慢指针相遇后，一个回到起点，同速前进再相遇即答案。

要求：不修改数组 + O(1) 空间 → 正是 Floyd 判圈的适用场景。

### 题三：接雨水（LeetCode 42）

- **辅助数组版**（O(n) 空间）：预处理每个位置的左侧最大值 `left_max`、右侧最大值 `right_max`，累加 `max(0, min(left_max[i-1], right_max[i+1]) - height[i])`；
- **双指针版**（O(1) 空间，最优）：`lmax <= rmax` 时结算左边（左边是真的探明了），否则结算右边。笔记的问答把"为什么只结算较小的一侧"讲得很透：**较大一侧的"对面最大值"还只是虚拟值，不能提前结算**。

### 题四：救生艇（LeetCode 881）

排序后 `l` 指向最轻、`r` 指向最重：`people[l] + people[r] > limit` → 最重的人只能独占一船，`r--`；否则两人一船，`l++, r--`。**贪心：让最轻的和最重的配对，不会亏。**

扩展（大厂真考过）：如果要求两人同船时体重和必须为偶数 → 按奇偶拆成两个数组分别做，再求和。

### 题五：盛最多水的容器（LeetCode 11）

`l, r` 从两端向中间收：`ans = max(ans, min(h[l], h[r]) * (r - l))`；每次把**较矮的一侧**向内移动（因为移动高的一侧不可能更好）。

### 题六：供暖器（LeetCode 475）

两个数组都排序，`heater_index` 只前进不后退（同向双指针）：对每个房子，走到"离它最近的供暖器"，取所有房子距离的最大值。注意 `>=` 的取舍（两距离相等时选下标更大的那个，便于后续推进）。

### 题七：缺失的第一个正数（LeetCode 41）

O(n) 时间 + O(1) 空间。用 `[l, r)` 划分：

- `[0, l)`：已经做到"位置 i 上放着 i+1"的区域；
- `[r, n)`：垃圾区；
- 永远盯着 `l` 位置的数看：符合 `nums[l] == l+1` 就 `l++`；是垃圾（`<= l`、`> r`、目标位置已有相同值）就与 `--r` 交换扔进垃圾区；否则换到它"应该在的位置"。

**笔记重点提醒**：三个条件的判断顺序很关键，原实现因为判断顺序错误会导致越界（如 `nums[l] == 0`）；正确写法是先判 `== l+1`，再判垃圾，最后交换。

## 适用特征（看到这些信号就选它）

| 信号 | 类型 |
| --- | --- |
| 两数之和 / 三数之和 / 容器水量 | 排序 + 两头往中间 |
| 环形/重复数/找中点 | 快慢指针 |
| 需要 O(1) 空间做 on-line 扫描 | 同向双指针 |
| 排序后"最大配最小"最优 | 两头贪心 |

## 复杂度

除"接雨水辅助数组版"是 O(n) 空间外，其余都是 **O(n) 时间、O(1) 额外空间**（排序题另有 O(n log n) 排序开销）。

## 易错点

1. 两头向中间时"移动哪一侧"的依据必须来自单调性论证（盛水题移动矮的一侧）；
2. Floyd 判圈的第一步是"快指针先走两步"，注意出发点的初始化；
3. 接雨水题不能结算"尚未探明"的一侧；
4. 救生艇题的贪心结论需要排序作为前提；
5. 供暖器同向指针的 `>=` 方向会影响后续推进，写反了正确性仍在但效率/边界会出问题；
6. 缺失第一个正数的判断顺序（先"符合"再"垃圾"再"交换"），顺序错会越界。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 接雨水：双指针 O(1) 空间 ----------
int trap(vector<int>& h) {
    int n = (int)h.size();
    if (n == 0) return 0;
    int lmax = h[0], rmax = h[n - 1], sum = 0;
    for (int l = 1, r = n - 2; l <= r; ) {
        if (lmax <= rmax) {
            sum += max(0, lmax - h[l]);
            lmax = max(lmax, h[l++]);
        } else {
            sum += max(0, rmax - h[r]);
            rmax = max(rmax, h[r--]);
        }
    }
    return sum;
}

// ---------- 2. 盛最多水的容器 ----------
int maxArea(vector<int>& h) {
    int ans = 0;
    for (int l = 0, r = (int)h.size() - 1; l < r; ) {
        ans = max(ans, min(h[l], h[r]) * (r - l));
        if (h[l] <= h[r]) l++; else r--;      // 移动较矮的一侧
    }
    return ans;
}

// ---------- 3. 救生艇 ----------
int numRescueBoats(vector<int>& people, int limit) {
    sort(people.begin(), people.end());
    int boats = 0;
    for (int l = 0, r = (int)people.size() - 1; l <= r; ) {
        if (people[l] + people[r] > limit) { r--; boats++; }   // 最重的独占
        else { l++; r--; boats++; }                            // 最轻 + 最重
    }
    return boats;
}

// ---------- 4. 寻找重复数（数组当链表 + Floyd） ----------
int findDuplicate(vector<int>& nums) {
    int slow = nums[0], fast = nums[nums[0]];
    while (slow != fast) { slow = nums[slow]; fast = nums[nums[fast]]; }
    for (fast = 0; fast != slow; ) { fast = nums[fast]; slow = nums[slow]; }
    return slow;
}
```
