# 构建前缀信息的技巧（子数组问题通用解法）

> 来源笔记：`1226构建前缀信息的技巧-解决子数组相关问题.cpp`｜核心程度：必背（子数组题第一反应）｜分类：04 数组技巧

## 一句话

子数组必须连续 ⇒ "以 i 结尾的子数组"的信息 = **前缀信息之差**；把"需要的前缀信息"装进哈希表（最早/最晚出现的位置、出现次数），就能把 O(n²) 的枚举压成 O(n)。

## 核心思想

固定右端点 `i`，令 `sum = a[0..i]` 的前缀信息。要判断"以 i 结尾、满足某条件的子数组"，都等价于在哈希表里找某个"历史前缀信息"：

| 题目要求 | 需要构建的前缀信息 | 哈希表存什么 |
| --- | --- | --- |
| 区间和 | 前缀和 S | 直接用数组 |
| 累加和 = aim 的**最长**子数组 | 前缀和 | **前缀和第一次出现的位置** |
| 累加和 = aim 的**子数组个数** | 前缀和 | **前缀和出现的次数** |
| 正负数个数相等 | 前缀和（正数变 1，负数变 -1） | 前缀和第一次出现的位置 |
| 表现良好时间段 | 前缀和（>8 变 1，否则 -1） | 前缀和第一次出现的位置 |
| 移除最短子数组使和被 p 整除 | 前缀和**余数** | 余数**最晚**出现的位置 |
| 每个元音出现偶数次 | 前缀**奇偶状态**（5 位 bitmask） | 状态第一次出现的位置 |

**必须处理前缀为空的情况**：`ump[0] = -1`（求长度）或 `mp[0] = 1`（求个数）。笔记原文特意强调："一定要记得处理前缀为空时哈希表的状态！！！"

## 逐题要点

**题一：区间和（前缀和数组）**

`sum[i+1] = sum[i] + nums[i]`，`sumRange(l, r) = sum[r+1] - sum[l]`。笔记同时提醒：前缀和数组有两种下标约定（`sum[i]` 表示"前 i 个数之和"或"0~i 之和"），写题时统一即可。

**题二：累加和为 aim 的最长子数组（牛客）**

- `ump[0] = -1`；
- `sum += arr[i]`，`aim = sum - k`，若 `aim` 出现过则 `ans = max(ans, i - ump[aim])`；
- **只记录每个前缀和第一次出现的位置**：`if (ump.find(sum) == ump.end()) ump[sum] = i;`

**题三：子数组和等于 k 的个数（LeetCode 560）**

- `mp[0] = 1`；答案累加 `mp[aim]`（次数），然后 `mp[sum]++`。

**题四：正负数个数相等的最长子数组**

把正数变成 1、负数变成 -1、0 不变，问题变成"累加和为 0 的最长子数组"。

**题五：表现良好的最长时间段（LeetCode 1126）**

- 转成 ±1 的数组，求"和 > 0 的最长区间"；
- 暴力版：拿当前 `sum` 与哈希表里所有历史前缀和比较（O(n²)）；
- **优化版 O(n)**：转化后数组只有 ±1，所以只需要查 `prefix - 1`：
  - `prefix > 0` → `ans = max(ans, i + 1)`；
  - 否则查 `ump[prefix - 1]`。

**题六：移除最短子数组使剩余和能被 p 整除（LeetCode 1590）**

- 记整体余数 `mod_all`；若为 0 直接返回 0；
- 要找的子数组余数 = `mod_all`，即"历史前缀余数 = (当前余数 - mod_all + p) % p"；
- 哈希表存**最晚**出现的位置，`ans = min(ans, i - ump[findAim])`；
- 最后 `ans == n` 说明只能删掉整个数组（题目不允许），返回 -1。

**题七：每个元音包含偶数次的最长子串（LeetCode 1371）**

- 用 5 位状态表示 a/e/i/o/u 的奇偶性，遇元音就 `status ^= (1 << m)`；
- 相同的状态两次出现之间的子串，所有元音都是偶数次；
- `ump[0] = -1`（全偶状态在空前就已存在），哈希表存**最早**出现的位置。

## 适用特征（看到这些信号就选它）

- 题目在**子数组/子串**上问"最长/最短/个数"，且数组**有负数或 0**（不能用滑动窗口）；
- 问"和等于 / 整除 / 奇偶 / 正负个数"，本质都是"前缀信息之差"；
- n 到 10^5，需要 O(n)。

## 复杂度

全部是 **O(n) 时间、O(n) 空间**（哈希表）。

## 易错点

1. **忘记 `ump[0] = -1` / `mp[0] = 1`**：最高频错误，会让"从头开始的子数组"被漏掉；
2. 求**最长**要记录第一次出现的位置（`if not exists`）；求**最短**要记录最晚出现的位置（每次覆盖）；
3. 求个数要 `ans += mp[aim]` 再 `mp[sum]++`，顺序反了会把当前自己算进去；
4. 取模类题目注意负数取模：`(cur - mod + p) % p`；
5. 位状态类题目状态数很小（2^5 = 32），用数组比哈希表更快；
6. 前缀和会溢出，用 `long long`（尤其与 p 取模的题）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 1) 前缀和：区间和 O(1)
struct PrefixSum {
    vector<long long> s;                      // s[i] = a[0..i-1] 之和
    explicit PrefixSum(const vector<int>& a) : s(a.size() + 1, 0) {
        for (size_t i = 0; i < a.size(); i++) s[i + 1] = s[i] + a[i];
    }
    long long range(int l, int r) const { return s[r + 1] - s[l]; }
};

// 2) 和等于 k 的最长子数组
int longestSubarraySumK(const vector<int>& a, int k) {
    unordered_map<long long, int> firstPos;
    firstPos[0] = -1;                         // ★空前缀
    long long sum = 0;
    int ans = 0;
    for (int i = 0; i < (int)a.size(); i++) {
        sum += a[i];
        auto it = firstPos.find(sum - k);
        if (it != firstPos.end()) ans = max(ans, i - it->second);
        if (!firstPos.count(sum)) firstPos[sum] = i;   // 只记第一次
    }
    return ans;
}

// 3) 和等于 k 的子数组个数
int countSubarraySumK(const vector<int>& a, int k) {
    unordered_map<long long, int> cnt;
    cnt[0] = 1;                               // ★空前缀
    long long sum = 0;
    int ans = 0;
    for (int x : a) {
        sum += x;
        ans += cnt[sum - k];
        cnt[sum]++;
    }
    return ans;
}
```
