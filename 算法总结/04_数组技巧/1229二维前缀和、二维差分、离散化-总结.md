# 二维前缀和、二维差分、离散化

> 来源笔记：`1229二维前缀和、二维差分、离散化技巧.cpp`｜核心程度：二维题必背｜分类：04 数组技巧

## 一句话

把一维的两件事各加一个维度：**前缀和**用容斥求任意子矩阵和，**差分**用 4 个端点做子矩阵加减；**离散化**是在坐标巨大且稀疏时，把真实坐标换成排名下标，从而把数组大小压到 O(n)。

## 一、二维前缀和

定义 `sum[i][j]` 为左上角 `(0,0)` 到右下角 `(i,j)` 的累加和。

构建（左 + 上 - 左上 + 自己）：

```
sum[i][j] += sum[i][j-1] + sum[i-1][j] - sum[i-1][j-1];
```

查询 `(a,b)` 到 `(c,d)` 的子矩阵和（容斥）：

```
sum[c][d] - sum[c][b-1] - sum[a-1][d] + sum[a-1][b-1];
```

两种写法：

1. 不补第 0 行/列：每次查询要判 `a>0`、`b>0`，笔记用 `get()` 辅助函数兜住越界；
2. **补第 0 行/列（推荐）**：`sum` 开成 `(n+1) x (m+1)`，公式统一、不用特判：

```
sum[i+1][j+1] = matrix[i][j] + sum[i][j+1] + sum[i+1][j] - sum[i][j];
sumRegion(r1,c1,r2,c2) = sum[r2+1][c2+1] - sum[r1][c2+1] - sum[r2+1][c1] + sum[r1][c1];
```

## 二、二维差分

子矩阵 `(a,b)` 到 `(c,d)` 每个数 `+v`，只动 4 个端点：

```
diff[a][b]         += v;
diff[c + 1][b]     -= v;
diff[a][d + 1]     -= v;
diff[c + 1][d + 1] += v;
```

还原（build）与二维前缀和的构建同形：

```
diff[i][j] += diff[i][j-1] + diff[i-1][j] - diff[i-1][j-1];
```

三个要点：

1. **先做完所有修改再 build**，不能边改边查；
2. **用一圈 0 把真实数据包起来**（多开一行一列），可以避免端点越界和一堆边界讨论；
3. 矩阵有初始值时，把初始值当"单点差分"处理：`add(i, j, i, j, a)`。

## 三、离散化

动机：真实坐标可能到 10^9（例如"最强祝福力场"），但实际用到的关键坐标只有 O(n) 个。

做法：

1. 收集所有**关键坐标**（矩形四角）到 `px / py`；
2. `sort` + `unique` 去重；
3. 用 `lower_bound` 把真实坐标映射成排名下标；
4. 在"下标空间"上做二维差分，数组大小只跟元素个数有关；
5. 在离散化后的关键点集合上统计答案。

笔记里的细节：**把坐标乘 2 再处理**——力场以"中心 + 边长"给出，边界是 `x ± side/2`，乘 2 后全部变成整数，避免小数。

## 适用特征（看到这些信号就选它）

| 需求 | 手段 |
| --- | --- |
| 静态、多次查询子矩阵和 | 二维前缀和 |
| 多次子矩阵整体加减，最后统一查询 | 二维差分 |
| 判断"能否被若干矩形完全覆盖" | 前缀和查空白 + 差分贴覆盖 |
| 坐标巨大/稀疏，只有 O(n) 个关键点 | 离散化 + 二维差分 |

## 复杂度

| 操作 | 复杂度 |
| --- | --- |
| 二维前缀和构建 | O(n·m) |
| 子矩阵查询 | O(1) |
| 子矩阵差分修改 | O(1) |
| 二维差分 build | O(n·m) |
| 离散化排序 | O(n log n) |

## 易错点

1. 容斥四个符号的顺序：**正、负、负、正**；
2. 不补 0 行列时，`a-1`、`b-1` 要用 `get()` 兜住（越界返回 0）；
3. 二维差分数组要开到 `(n+2) x (m+2)`，给 `c+1`、`d+1` 留空间；
4. 贴邮票类题目：**在差分矩阵里贴，在原矩阵里查**，不要混着改；
5. 离散化时原始坐标要用 `long long`（乘 2 后可能超 int）；
6. 离散化后的下标代表一个"关键点"，统计最大值时要在关键点集合上取。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 1) 二维前缀和（补 0 行列版）
struct MatSum {
    vector<vector<long long>> s;
    explicit MatSum(const vector<vector<int>>& a) {
        int n = (int)a.size(), m = n ? (int)a[0].size() : 0;
        s.assign(n + 1, vector<long long>(m + 1, 0));
        for (int i = 0; i < n; i++)
            for (int j = 0; j < m; j++)
                s[i + 1][j + 1] = a[i][j] + s[i][j + 1] + s[i + 1][j] - s[i][j];
    }
    long long query(int r1, int c1, int r2, int c2) const {   // 0-based 闭区间
        return s[r2 + 1][c2 + 1] - s[r1][c2 + 1] - s[r2 + 1][c1] + s[r1][c1];
    }
};

// 2) 二维差分：diff 开 (n+2) x (m+2)，下标从 1 开始
vector<vector<long long>> diff;
void diffAdd(int a, int b, int c, int d, long long v) {
    diff[a][b]         += v;
    diff[c + 1][b]     -= v;
    diff[a][d + 1]     -= v;
    diff[c + 1][d + 1] += v;
}
void diffBuild(int n, int m) {
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            diff[i][j] += diff[i][j - 1] + diff[i - 1][j] - diff[i - 1][j - 1];
}
```
