# 二分答案法

> 来源笔记：`0105二分答案法与相关题目.cpp`｜核心程度：必背（笔记称"非常重要、非常精妙"）｜分类：04 数组技巧

## 一句话

正着求不好求时，改成"**假设答案是 m，我能不能判断条件是否达标**"——只要"答案越大（越小）越容易满足"这条单调性成立，就能在答案空间上二分，把"构造最优解"变成"O(一次判断) × O(log 值域)"。

## 四步流程（笔记原文）

1. **估计最终答案的可能范围**（可以估得粗略，反正二分不了几次）；
2. **分析答案与条件之间的单调性**（大部分时候用"自然智慧"就够）；
3. **建立 f 函数**：固定答案 m 时，判断给定条件是否达标；
4. **在答案范围上二分**，每次用 f 判断，直到收敛。

核心点只有两个：**分析单调性、建立 f 函数**。

## 七道题

### 题一：爱吃香蕉的珂珂（LeetCode 875）

- 答案 = 速度 k，范围 `[1, max(piles)]`；
- 单调性：k 越大，耗时越短；
- `f(k)`: `sum = Σ ceil(pile / k)`，判断 `sum <= h`。

### 题二：分割数组的最大值 / 画匠问题（LeetCode 410）

- 答案 = 子数组和的最大值，范围 `[max(nums), sum(nums)]`；
- 单调性：允许的最大和越小 → 需要的段数越多；
- `f(m)`：贪心分组（`sum + num > m` 就开新组），返回组数，判断 `组数 <= k`；
- 复杂度 O(n log sum)。

笔记还给了两个答疑，值得记住：

1. **为什么结果一定对应"恰好 k 段"**：`f(m) <= k` 时，可以把某段再切开得到 k 段（切出的每段和更小，仍满足）；
2. **为什么至少有一段的和恰好等于 ans**：反证——若全部 ≤ ans-1，则 `f(ans-1)` 会成立，与二分结束时 `f(ans-1)` 不成立矛盾。

### 题三：机器人跳跃问题（牛客）

- 答案 = 初始能量，范围 `[0, max(高度)]`；
- `f(E)`：按题意模拟能量变化（`H > E` 失去差值，否则得到差值），中途 `< 0` 返回 false；
- **关键剪枝**：一旦 `E >= max`，后面必然通关，直接返回 true（否则能量指数增长会溢出）。

### 题四：第 K 小的数对距离（LeetCode 719）

**第 k 小/大的通用转化（笔记强调"非常重要"）**：

- 第 k 小 ⇔ 求最小的 x，使得"某指标 ≤ x 的个数 ≥ k"；
- 第 k 大 ⇔ 求最大的 x，使得"某指标 ≥ x 的个数 ≥ k"。

本题：二分距离 m，用**排序 + 双指针**数出"距离 ≤ m 的数对个数"，判断 `>= k`。

### 题五：同时运行 N 台电脑的最长时间（LeetCode 2141）

- 答案 = 运行时间，二分；`f(t)`: 电量 ≥ t 的电池直接供一台电脑，其余电池当作"碎片时间"累加，判断碎片总和 ≥ `剩余电脑数 × t`；
- 优化：若 `sum >= max * n`，答案直接是 `sum / n`（全靠碎片拼接），否则二分范围缩到 `[0, max]`。

### 题六：计算等位时间（谷歌面试题）

- 朴素解法：最小堆模拟 m 次服务（m 很大时超时）；
- **二分答案**：二分时间 t，`f(t) = Σ (t / arr[i] + 1)` 表示"到时刻 t 为止(含正在服务的)已经能服务多少人"，判断 `>= m + 1`；
- 相关题：LeetCode 2187 完成旅途的最少时间（`f(t) = Σ t / time[i]`，不需要 +1）。

### 题七：刀砍毒杀怪兽（大厂真题）

- 答案 = 回合数，范围 `[1, hp + 1]`；
- `f(回合数)`：逐回合贪心——如果本回合下毒在剩余回合造成的总伤害大于刀砍，就下毒，否则砍；
- 笔记补充了"纯枚举法"作为对数器验证。

## 适用特征（看到这些信号就选它）

- "最小的最大值 / 最大的最小值 / 最少需要多少 / 最多能到多少"；
- 答案是一个**数值**，且"答案更大（更小）时条件更容易满足"；
- 给定答案后，判断是否符合条件比求解本身容易得多；
- 数据范围提示：答案值域大（10^9）但判断是 O(n) → `O(n log 值域)`。

## 复杂度

一般为 **O(n log(答案范围))**，空间 O(1) 或 O(n)（f 函数需要辅助结构时）。

## 易错点

1. **单调性方向搞反**：导致二分的方向反了（答案始终不对）；
2. **答案范围估错**：左端应取"一定不满足"或"最小可能值"，右端取"一定满足"；宁可粗一点也不要越界；
3. `mid` 用 `l + (r - l) / 2` 防溢出；`(r - l) >> 1` 建议转 `unsigned`；
4. **向上取整**：`ceil(a / b)` 写作 `(a + b - 1) / b`，在 `f` 里最容易漏；
5. **溢出**：模拟类的 `f`（如机器人能量增长）要提前剪枝返回；
6. 机器人题里 `int maxs = (1 << n) - 1` 之类的括号与类型（见 `1219N皇后问题` 的同类提醒）；
7. 注意 `f` 里用 `long long`：`m * n`、`Σ` 都可能爆 int。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 通用骨架：找最小的满足条件的 x ----------
// long long lo = 最小可能值, hi = 最大可能值, ans = -1;
// while (lo <= hi) {
//     long long mid = lo + (hi - lo) / 2;
//     if (check(mid)) { ans = mid; hi = mid - 1; }   // mid 可行，试更小
//     else            { lo = mid + 1; }              // mid 不可行，试更大
// }

// ---------- 1. 爱吃香蕉的珂珂 ----------
bool canEat(const vector<int>& piles, int h, int k) {
    long long time = 0;
    for (int p : piles) time += (p + k - 1) / k;    // 向上取整
    return time <= h;
}
int minEatingSpeed(vector<int>& piles, int h) {
    int lo = 1, hi = *max_element(piles.begin(), piles.end()), ans = 0;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (canEat(piles, h, mid)) { ans = mid; hi = mid - 1; }
        else lo = mid + 1;
    }
    return ans;
}

// ---------- 2. 分割数组的最大值（画匠问题） ----------
int groupsNeeded(const vector<int>& a, long long cap) {
    int groups = 1;
    long long sum = 0;
    for (int x : a) {
        if (x > cap) return INT_MAX;               // 单个元素就超过上限
        if (sum + x > cap) { groups++; sum = x; }
        else sum += x;
    }
    return groups;
}
int splitArray(vector<int>& a, int k) {
    long long lo = *max_element(a.begin(), a.end());
    long long hi = accumulate(a.begin(), a.end(), 0LL);
    long long ans = 0;
    while (lo <= hi) {
        long long mid = lo + (hi - lo) / 2;
        if (groupsNeeded(a, mid) <= k) { ans = mid; hi = mid - 1; }
        else lo = mid + 1;
    }
    return (int)ans;
}

// ---------- 3. 第 k 小的数对距离 ----------
int countPairsLE(const vector<int>& a, int x) {    // 距离 <= x 的数对个数
    int ans = 0;
    for (int l = 0, r = 1; l < (int)a.size(); l++) {
        while (r < (int)a.size() && a[r] - a[l] <= x) r++;
        ans += r - l - 1;                          // r 是第一个不满足的位置
    }
    return ans;
}
int smallestDistancePair(vector<int>& a, int k) {
    sort(a.begin(), a.end());
    int lo = 0, hi = a.back() - a.front(), ans = 0;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (countPairsLE(a, mid) >= k) { ans = mid; hi = mid - 1; }
        else lo = mid + 1;
    }
    return ans;
}
```
