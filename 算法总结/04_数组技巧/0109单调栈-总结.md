# 单调栈（经典用法 + 维持可能性）

> 来源笔记：`0109单调栈.cpp`｜核心程度：必背｜分类：04 数组技巧

## 一句话

单调栈有两大类用法：**经典用法**求"每个位置左/右最近且更小（更大）的位置"；**进阶用法**用"淘汰对未来没有帮助的元素"来维持答案的可能性，每个元素进出栈一次，均摊 O(1)。

## 一、经典用法（笔记原文）

每个位置都求：

- **左右两侧最近且严格更小**的位置 → 维护"大压小"（栈底小、栈顶大）的单调栈；
- 或**左右两侧最近且严格更大**的位置 → 维护"小压大"的单调栈。

两条要点：

1. 所有调整的**总代价 O(n)**，单次操作均摊 O(1)；
2. **新元素与栈顶相等时要不要弹栈，是关键的取舍**（笔记原文："根据具体情况决定是否将栈顶元素弹出（挺关键的取舍）"）。

### 模板题（牛客）要点

求"每个位置左边/右边最近的、值严格小于它的位置"：

```cpp
while (!stk.empty() && arr[stk.back()] >= arr[i]) {   // 弹出并结算
    int idx = stk.pop_back();
    ans[idx][0] = stk.empty() ? -1 : stk.back();      // 左边最近更小
    ans[idx][1] = i;                                  // 右边最近更小
}
```

**处理相等元素的修正阶段**：如果 `ans[i][1]` 指向的值与 `arr[i]` 相等，就继续往右找 `ans[ans[i][1]][1]`（从右往左一遍扫描修正）。

## 二、经典用法的五道题

### 题二：每日温度（LeetCode 739）

求右边最近且**严格大于**的位置，答案是距离 `i - idx`。用"小压大"栈，当前温度大于栈顶时才结算；**最后不用清算**（栈内剩余元素的右侧都没有更大的）。

### 题三：子数组的最小值之和（LeetCode 907）

以每个元素为最小值，数它**能辐射到多少个子数组**：`(cur - pre) * (i - cur)`（左边可选起点数 × 右边可选终点数）。

**同余运算细节（笔记强调"重要"）**：不要写 `ans += ... % MOD`（`+=` 不会对 `ans` 取模，会溢出），要写 `ans = (ans + ...) % MOD`。

### 题四：柱状图中最大的矩形（LeetCode 84）

以每根柱子为高，向左右扩展到"第一个比它矮的柱子"：面积 = `height[cur] * (i - pre - 1)`。

### 题五：最大矩形（LeetCode 85）

**题目四 + 数组压缩**：逐行把"该列向上连续 1 的个数"累加成 `heights[j]`，对每一行调用一次"柱状图最大矩形"。

## 三、进阶用法（维持答案的可能性）

四条特征（笔记原文）：

1. 栈内元素按规定好的单调性组织；
2. 新元素进栈时，从栈顶依次淘汰"对后续求解答案没有帮助"的对象；
3. 每个对象从栈顶弹出时结算它参与的答案，之后不再参与；
4. **先有对题目的分析，才发现单调性**，然后才用单调栈实现。

### 进阶题一：最大宽度坡（LeetCode 962）

- 单调性：新数据 ≥ 栈顶时，即使能得答案也不如栈顶更优；新数据 < 栈顶时才可能是最优答案；
- 做法：第一遍把"可能成为左端"的位置（严格递减的序列）入栈；第二遍从右往左扫，`nums[stk.back()] <= nums[i]` 就结算 `i - stk.back()` 并弹栈；
- 笔记还给了"二分答案 + 构造最小值数组"的另一种解法（`lmin[j] <= nums[i]`）。

### 进阶题二：去除重复字母使字典序最小（LeetCode 316）

**大压小的单调栈 + 剩余次数表**：新字符字典序更小、且栈顶字符后面还会再出现，就弹掉栈顶；再用 `existInStack` 保证每个字符只进一次。

### 进阶题三：大鱼吃小鱼（LeetCode 2289）

从右往左扫，栈里存 `[下标, 该位置需要多少轮被吃完]`：

```cpp
int times = 0;
while (!stk.empty() && nums[i] > nums[stk.back()[0]]) {
    times = max(times + 1, stk.back()[1]);   // 奖池累加
    stk.pop_back();
}
stk.push_back({i, times});
ans = max(ans, times);
```

### 进阶题四：统计全 1 子矩形（LeetCode 1504）

单调栈 + 层数计算：`cur` 弹出时贡献

```
(height[cur] - max(height[pre], height[i])) * (length * (length + 1) / 2)
```

其中 `length = i - pre - 1`。含义是"以 `cur` 的位置为最右端、高度在 `(max(左,右), height[cur]]` 之间的子矩形个数"。

## 适用特征（看到这些信号就选它）

- 求"每个位置左右最近的更大/更小的位置"；
- 直方图/矩形面积类（柱状图、最大矩形、统计全 1 子矩形）；
- 要"删掉某些元素使结果字典序最小（大）"；
- 需要"每个元素作为最值能辐射多远"的贡献统计。

## 复杂度

- 时间 O(n)（每元素进出栈一次）；
- 空间 O(n)。

## 易错点

1. **相等元素怎么处理**（`>=` 还是 `>`）必须按题目语义决定，写错会出现重复统计或漏统计；
2. 弹栈时的 `pre` 取 `stk.empty() ? -1 : stk.back()`，边界别写成 0；
3. 柱子面积公式是 `(i - pre - 1)`，不是 `(i - pre)`；
4. 子数组最小值之和要写成 `ans = (ans + ...) % MOD`，不要用 `+=`；
5. 每日温度最后**不需要**清算栈（剩余的右侧都没有更大的）；
6. 去重字母题里"栈顶字符后面还会出现"的判断依赖 `umap`，注意递减时机；
7. 进阶题结算顺序：先弹栈结算，再把当前元素入栈。

## 模板（可直接编译运行）

```cpp
// 单调栈模板：左右最近更小 / 柱状图最大矩形 / 每日温度 / 最大宽度坡 / 去重字母
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= 1. 经典：每个位置左右最近的严格更小位置 =================
void nearestSmaller(const vector<int>& a, vector<int>& L, vector<int>& R) {
    int n = (int)a.size();
    L.assign(n, -1);
    R.assign(n, -1);
    vector<int> stk;
    for (int i = 0; i < n; i++) {
        while (!stk.empty() && a[stk.back()] >= a[i]) {   // 相等也要弹（配合修正阶段）
            int idx = stk.back(); stk.pop_back();
            L[idx] = stk.empty() ? -1 : stk.back();
            R[idx] = i;
        }
        stk.push_back(i);
    }
    while (!stk.empty()) {
        int idx = stk.back(); stk.pop_back();
        L[idx] = stk.empty() ? -1 : stk.back();
        R[idx] = -1;
    }
    // 修正：右边第一个"更小"其实相等时要继续往右找
    for (int i = n - 2; i >= 0; i--)
        if (R[i] != -1 && a[R[i]] == a[i]) R[i] = R[R[i]];
}

// ================= 2. 柱状图中最大的矩形 =================
int largestRectangleArea(const vector<int>& h) {
    long long ans = 0;
    vector<int> stk;
    int n = (int)h.size();
    for (int i = 0; i <= n; i++) {
        int cur = (i == n) ? -1 : h[i];                   // 末尾虚拟高度 -1，强制清算
        while (!stk.empty() && h[stk.back()] >= cur) {
            int idx = stk.back(); stk.pop_back();
            int pre = stk.empty() ? -1 : stk.back();
            ans = max(ans, (long long)h[idx] * (i - pre - 1));
        }
        if (i < n) stk.push_back(i);
    }
    return (int)ans;
}

// ================= 3. 每日温度 =================
vector<int> dailyTemperatures(const vector<int>& t) {
    int n = (int)t.size();
    vector<int> ans(n, 0), stk;
    for (int i = 0; i < n; i++) {
        while (!stk.empty() && t[i] > t[stk.back()]) {
            int idx = stk.back(); stk.pop_back();
            ans[idx] = i - idx;
        }
        stk.push_back(i);
    }
    return ans;
}

// ================= 4. 最大宽度坡 =================
int maxWidthRamp(const vector<int>& a) {
    int n = (int)a.size(), ans = 0;
    vector<int> stk;
    for (int i = 0; i < n; i++)                          // 只把"可能是左端"的入栈
        if (stk.empty() || a[i] < a[stk.back()]) stk.push_back(i);
    for (int i = n - 1; i >= 0; i--)                     // 从右往左找答案
        while (!stk.empty() && a[stk.back()] <= a[i]) {
            ans = max(ans, i - stk.back());
            stk.pop_back();
        }
    return ans;
}

// ================= 5. 去除重复字母，字典序最小 =================
string removeDuplicateLetters(const string& s) {
    std::array<int, 26> cnt= {0};
    std::array<bool, 26> inStack= {false};
    for (char c : s) cnt[c - 'a']++;
    string stk;
    for (char c : s) {
        if (!inStack[c - 'a']) {
            while (!stk.empty() && c < stk.back() && cnt[stk.back() - 'a'] > 0) {
                inStack[stk.back() - 'a'] = false;
                stk.pop_back();
            }
            inStack[c - 'a'] = true;
            stk.push_back(c);
        }
        cnt[c - 'a']--;
    }
    return stk;
}

int main() {
    vector<int> a = {2, 1, 5, 6, 2, 3};
    std::cout << "柱状图最大矩形 = " << largestRectangleArea(a) << "\n";   // 10
    vector<int> t = {73, 74, 75, 71, 69, 72, 76, 73};
    for (int x : dailyTemperatures(t)) std::cout << x << " ";        // 1 1 4 2 1 1 0 0
    std::cout << "\n";
    vector<int> r = {6, 0, 8, 2, 1, 5};
    std::cout << "最大宽度坡 = " << maxWidthRamp(r) << "\n";               // 4
    std::cout << "去重字母 = " << removeDuplicateLetters("bcabc") << "\n";  // abc
    return 0;
}
```

## 专题深化：为什么成立

以“下一个更小”为例，栈中保留尚未找到右侧更小值的下标且值单调递增。当前元素更大时先无法结算；一旦更小，所有被弹出的栈顶同时找到答案。每个下标进出一次，故 O(n)。

## 专题深化：手算与边界

高度 `[2,1,5,6,2,3]`，到末尾的虚拟 0 时依次弹出 3、2，可计算宽度并得到最大矩形 10。

### 对照与取舍

单调栈求元素两侧边界和矩形面积；单调队列求滑动窗口极值并会从队头删除过期元素；前缀和适合可减去的区间和。

### 易错点与反例

1. 相等元素选择 `>` 或 `>=` 会影响边界归属
2. 虚拟哨兵可统一末尾清算
3. 计算宽度时 pre 为空用 -1
4. 面积用 long long 防乘溢出
