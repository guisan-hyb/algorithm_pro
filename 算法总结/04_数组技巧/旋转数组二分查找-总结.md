# 旋转数组二分查找

> 来源笔记：`旋转数组二分查找总结.md`｜性质：二分变体专项｜分类：04 数组技巧

## 一句话

旋转数组不再是整体有序，但**一定存在一个完全有序的半边**；判断"中点在哪个有序半边、目标是否落在该半边内"，就能决定丢哪一半。

## 一、题目一：搜索旋转排序数组（LeetCode 33）

```cpp
int search(vector<int>& nums, int target) {
    int ans = -1;
    for (int l = 0, r = nums.size() - 1; l <= r;) {
        int m = l + (r - l) / 2;
        if (nums[m] == target) { ans = m; break; }
        if (nums[0] <= nums[m]) {                    // 左半边 [l..m] 有序
            if (target >= nums[0] && target < nums[m]) r = m - 1;
            else l = m + 1;
        } else {                                     // 右半边 [m..r] 有序
            if (target > nums[m] && target <= nums[n - 1]) l = m + 1;
            else r = m - 1;
        }
    }
    return ans;
}
```

要点：**先判断哪半边有序，再判断 target 是否在该半边内**。

## 二、题目二：寻找旋转数组中的最小值（LeetCode 153）

```cpp
int findMin(vector<int>& nums) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int m = l + (r - l) / 2;
        if (nums[m] < nums[r]) r = m;      // [m..r] 有序，最小值在 m 或左侧
        else l = m + 1;                    // 发生"断崖"，最小值在 m 右侧
    }
    return nums[l];
}
```

- **为什么跟 `nums[r]` 比**：`nums[r]` 是当前区间的右端点；`nums[m] < nums[r]` 说明 `[m, r]` 段完全升序，最小值只可能在 `m` 及其左侧；
- **为什么 `l < r` 且 `r = m`**：`m` 本身可能就是最小值，不能写成 `r = m - 1`（会漏掉答案）；
- 用 `nums[r]` 做基准**天然兼容未旋转的情况**，不需要额外特判。

## 三、两道题的对比

| 维度 | 找最小值 | 搜 target |
| --- | --- | --- |
| 目标 | 断崖处（旋转点） | 等于 target 的元素 |
| 比较基准 | 常与 `nums[r]` 比 | 常与 `nums[0]`（或 `nums[r]`）比 |
| 循环条件 | `while (l < r)` | `while (l <= r)` |
| 边界更新 | `r = m` 或 `l = m + 1`（**不排除 m**） | `r = m - 1` 或 `l = m + 1`（**严格排除 m**） |
| 未旋转时 | 不需要特判 | 逻辑天然兼容 |

## 四、共同的坑

1. **死循环**：找最小值时必须 `r = m`（`m` 可能是答案），所以循环条件必须是 `l < r`；
2. **相等的退化情况**：两题都保证元素**互不相同**，所以不需要处理 `nums[m] == nums[r]`；如果允许重复（LeetCode 154），需要额外处理相等（例如 `r--` 缩小区间）；
3. **溢出**：中点统一写 `l + (r - l) / 2`；
4. **target 的区间判断用开闭区间要一致**：`nums[0] <= target < nums[m]` 与 `nums[m] < target <= nums[n-1]` 这两个式子的开闭是配合好的，改动要谨慎。

## 五、通用一句话

**"判断有序半边 → 看目标是否落在该半边 → 决定丢弃哪一半。"** 掌握这句，一切旋转数组的二分变体都能推出来。

## 适用特征（看到这些信号就选它）

- 数组是"两段各自升序"的旋转形态；
- 题目要求 O(log n)；
- 需要在部分有序结构里定位元素或极值（山脉数组、峰值、旋转点等都属于同一族）。

## 复杂度

全部 O(log n) 时间、O(1) 空间。

## 专题深化：为什么成立

旋转数组至少一半有序。每轮比较 `nums[mid]` 与右端或左端，判断哪一半有序，再判断 target 是否落在该有序区间内，从而排除一半。

## 专题深化：手算与边界

`[4,5,6,7,0,1,2]` 查 0：mid=3 值 7，左半 `[4..7]` 有序且 0 不在其中，于是搜索右半 `[0,1,2]`。

### 对照与取舍

无重复时 O(log n)；有重复时 `nums[l]==nums[mid]==nums[r]` 无法判断，只能收缩端点，最坏 O(n)。

### 易错点与反例

1. 先判有序半区再判 target 范围
2. 有重复必须处理三者相等
3. 目标不存在时循环结束返回 -1
4. 整数中点溢出

## 专题深化：进阶拓展

旋转多次或允许重复时可先找最小点；二维旋转矩阵可先定位行/列有序性。
