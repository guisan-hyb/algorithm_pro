# 从递归入手一维动态规划

> 来源笔记：`0225从递归入手一维动态规划.cpp`｜核心程度：必背（DP 总纲）｜分类：06 动态规划

## 一句话

**任何动态规划都一定对应一个"有重复调用行为"的递归**；所以从尝试（递归）入手 → 记忆化搜索 → 严格位置依赖的 DP → 空间压缩 → 枚举优化，是一条稳、通用、改错代价低的路。

## 核心心法（笔记原文）

- DP = **用空间换重复计算**；
- 「知道怎么算的算法」vs「知道怎么试的算法」——DP 学的是**怎么试**；
- **尝试策略就是转移方程**，完全一回事；推荐从尝试入手，因为代码好写，发现尝试错了重新想的代价也轻；
- DP 表 = **装递归返回值的容器**；
- 演进路线：`递归 -> dp递归(记忆化搜索) -> dp迭代(严格位置依赖) -> dp状态压缩迭代 -> 优化枚举`；
- 记忆化搜索是**自顶向下**，迭代 DP 是**自底向上**；
- 什么时候没必要改 DP：每次展开都是不同的解、或重复调用现象很少时。

## 四道题（每题都从递归一路改到空间压缩）

### 题一：斐波那契数（LeetCode 509）

暴力递归 O(2^n) → 记忆化 O(n)（`dp[i] != -1` 直接返回）→ 迭代 O(n) → **滚动变量 O(1) 空间**。

> 笔记提示：最优解其实是**矩阵快速幂 O(log n)**，后续课程会讲。

### 题二：最低票价（LeetCode 983）

- 递归定义：`f(i)` = 从第 i 个出行日往后，最少花多少钱；
- 三种票（1/7/30 天）各算一次覆盖到哪个下标 `j`，再 `costs[k] + f(j)` 取最小；
- 记忆化 → 迭代（`dp[n] = 0`，从后往前）→ 空间已是 O(n)，无需再压。

### 题三：解码方法（LeetCode 91）

- `f(i)`：从 i 开始有多少种解码；
- `s[i] == '0'` → 返回 0（前面决策失误）；
- 单个数字必能成一组 → `f(i+1)`；两位数字 ≤ 26 → `+ f(i+2)`；
- 空间压缩：`last` 表示 `dp[i+1]`、`lastlast` 表示 `dp[i+2]`，从后往前滚。

### 题四：解码方法 II（LeetCode 639，带 `*`）

在题三基础上分情况讨论 `*`（可表示 1~9）：

- 单个：`'*'` 时 ×9；
- 两位：`s[i]` 是数字且 `s[i+1]=='*'` 时，`s[i]=='1'` 加 9 种、`'2'` 加 6 种；
- `s[i]=='*'` 且 `s[i+1]` 是数字时，`≤6` 加 2 种否则 1 种；两个 `*` 加 **15** 种；
- 全程对 `1e9+7` 取模。

## 适用特征（看到这些信号就选它）

- 递归展开时**反复求解同一个子问题**；
- 只有**一个可变参数**能决定返回值 → 一维 DP；
- 求"最少 / 最多 / 方案数"，且当前决策只依赖"后面的某几个状态"。

## 复杂度

暴力递归指数级 → 记忆化/迭代 = **状态数 × 单个状态的枚举代价**；能滚动的话空间能压到 O(1)。

## 易错点

1. `dp` 数组初始化成 `-1` 表示"没算过"（若答案可能是 -1 要用别的哨兵）；
2. base case（`i == n` 返回什么）必须先想清楚；
3. 空间压缩时**滚动变量的更新顺序**不能反（先算 `cur`、再 `lastlast = last; last = cur;`）；
4. 从后往前填还是从前往后填，取决于"当前格子依赖谁"；
5. 取模题要在**每一步**取模，不要只在最后取；
6. 用**长度**定义递归（`len` 从 0 开始）往往能省掉一堆下标边界讨论。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 通用流程：递归 -> 记忆化 -> 迭代 -> 空间压缩 ----------

// 1) 暴力递归（会超时，仅用于想清楚尝试）
int f1(int i) {
    if (i == 0) return 0;
    if (i == 1) return 1;
    return f1(i - 1) + f1(i - 2);
}

// 2) 记忆化搜索（自顶向下）
int f2(int i, vector<int>& dp) {
    if (i == 0) return 0;
    if (i == 1) return 1;
    if (dp[i] != -1) return dp[i];          // 算过就直接用
    return dp[i] = f2(i - 1, dp) + f2(i - 2, dp);
}

// 3) 严格位置依赖的迭代（自底向上）
int f3(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    vector<int> dp(n + 1);
    dp[1] = 1;
    for (int i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}

// 4) 空间压缩（滚动变量）
int f4(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    int lastlast = 0, last = 1;
    for (int i = 2; i <= n; i++) {
        int cur = lastlast + last;
        lastlast = last;                     // ★顺序不能反
        last = cur;
    }
    return last;
}

// ---------- 例题：解码方法（LeetCode 91，空间压缩版） ----------
int numDecodings(const string& s) {
    int n = (int)s.size();
    int last = 1;            // dp[n]
    int lastlast = 0;        // dp[n + 1]（不存在，视为 0）
    for (int i = n - 1; i >= 0; i--) {
        int cur = 0;
        if (s[i] != '0') {
            cur = last;
            if (i + 1 < n && ((s[i] - '0') * 10 + (s[i + 1] - '0')) <= 26)
                cur += lastlast;
        }
        lastlast = last;
        last = cur;
    }
    return last;
}
```
