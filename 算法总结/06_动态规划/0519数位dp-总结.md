# 数位 DP

> 来源笔记：`0519数位dp.cpp`｜核心程度：必背模板｜分类：06 动态规划

## 一句话

数位 DP 不特殊，它只是**在数字的每一位上做"从左往右"的线性尝试**；核心在于整理可能性与排列组合。**推荐直接用记忆化搜索**，不必刻意改成迭代。

## 通用模板（笔记原文的结构，务必背下来）

```cpp
// f(i, ...) 表示：构造从左往右第 i 位及其之后数位的合法方案数
int f(string& num, int i, bool isLimit, bool isNum /*, 其他约束参数 */) {
    if (i == num.size()) return isNum;          // 走完整个数位，isNum 表示是否填过数字

    // ★关键：只有"不受限 isLimit=false 且已经填过数字 isNum=true"才是通用子问题，才能记忆化
    if (!isLimit && isNum && dp[i][...] != -1) return dp[i][...];

    int ans = 0;
    if (!isNum) ans += f(num, i + 1, false, false, ...);   // 这一位继续不填（处理前导零）

    int up    = isLimit ? (num[i] - '0') : 9;              // 受限于 num 时最多填到当前位
    int start = isNum ? 0 : 1;                             // 还没填过数字时不能填 0（除 0 本身）
    for (int pick = start; pick <= up; pick++) {
        // 按题目约束过滤 pick
        bool nextLimit = isLimit && (pick == up);
        ans += f(num, i + 1, nextLimit, true, ...);
    }

    if (!isLimit && isNum) dp[i][...] = ans;               // 只存通用子问题的解
    return ans;
}
```

两个布尔量：

- **`isLimit`**：当前是否仍受 `num` 的约束（true → 这一位最多填 `num[i]`）；
- **`isNum`**：之前是否已经填过数字（false → 还在处理前导零，最后返回时要返回 `isNum` 而不是 1，避免把 0 之外的"空数"算进去）。

## 上篇：四道题

### 题一：统计各位数字都不同的数字个数（LeetCode 357）

纯排列组合：`f(0)=1`、`f(1)=10`、`f(n) = 9*9*8*... + f(n-1)`（首位不能是 0，其余位依次少一种选择）。

### 题二：最大为 N 的数字组合（LeetCode 902）

数位 DP 的"标准形状"：`digits` 是允许使用的数字集合（无 0），求 ≤ n 的正整数个数。

按模板走，用二分在 `digits` 里数"严格小于当前位的个数"。

> ⚠️ 笔记里的一个坑：`to_string(char)` 会把 char 转成 ASCII 码的字符串（`'1'` → `"49"`），要用 `to_string(num[i] - '0')` 或 `string(1, num[i])`。

### 题三：统计整数数目（LeetCode 2719）

求 `[num1, num2]` 内数位和在 `[min_sum, max_sum]` 的整数个数：

- 转化：`ans = f(num2) - f(num1)`，再**单独判断 num1 本身**是否合法（`+1`）——这样避免高精度减法；
- 状态：`dp[i][sum][isLimit]`；
- **两个剪枝**：
  - `sum > maxs` → 直接返回 0；
  - `sum + (剩余位数) * 9 < mins` → 直接返回 0（笔记称"神之一剪"）。

### 题四：完全没有重复的数字（LeetCode 1012）／变种"至少有 1 位重复"

用 `status` 位集记录已用过的数字，`dp[i][status]`；

- 变种答案 = `n - 无重复的个数`。

**笔记的小结（重要）**：记忆化只能存**通用子问题**的解；`isLimit == true`（与 num 前缀相同）或 `isNum == false`（还在前导零）的状态是**路径特殊的**，不能复用，所以只在 `!isLimit && isNum` 时才写入 memo。

## 下篇：四道题

### 题一：windy 数（洛谷 P2657）

不含前导零、且相邻两位差 ≥ 2。状态带 `prev`（上一位数字），转移时判 `pick <= prev-2 || pick >= prev+2`；答案 = `f(b) - f(a-1)`。

### 题二：萌数（洛谷 P3413）

**正难则反**：含长度 ≥ 2 的回文子串 ⟺ 存在 i 使 `s[i] == s[i-1]` 或 `s[i] == s[i-2]`。

所以先数"不是萌数"的：状态带 `prepre`、`pre`，转移要求 `pick != prepre && pick != pre`；最后 `答案 = 总数 - 非萌数个数`（再单独补判左边界 `l` 本身）。

### 题三：不含连续 1 的非负整数（LeetCode 600）

把 n 转成**二进制字符串**，状态带"上一位是否是 1"：

```
if (isPre && pick) continue;      // 不能出现连续 1
```

### 题四：范围内的数字计数（LeetCode 1067 / 洛谷 P2602 / LeetCode 233）

统计某个数码 d 在 `[a,b]` 中出现的次数：状态带"到目前为止 d 出现了几次"，走到末尾时返回这个计数（`cnt`）；区间用 `f(b) - f(a-1)`。

## 适用特征（看到这些信号就选它）

- 题目问"在 [L, R] 范围内有多少个数满足某种**逐位**性质"；
- 约束与"数字的每一位"有关（数位和、相邻差、是否重复、是否含某个数码）；
- 范围大到 10^18，必须按位枚举；
- 例题特征词："范围内计数""第 N 个满足条件的数""不含/含有某种数位模式"。

## 易错点

1. **只在 `!isLimit && isNum` 时记忆化**（最核心的一条）；
2. `isNum == false`（前导零）时，递归终点要返回 `isNum` 而不是 1；
3. `up = isLimit ? num[i]-'0' : 9`，`start = isNum ? 0 : 1`；
4. 区间计数用 `f(R) - f(L-1)`；**大数用字符串、避免减 1 的高精度麻烦**时改为 `f(R) - f(L)` 再单独判 L；
5. `check()` 单独验证边界数（如 num1 本身）不能漏；
6. dp 表的维度和状态参数一一对应（笔记强调："DP 状态的维度必须和递归函数的可变参数保持一致"）；
7. 数位 DP 的 dp 表要在多次调用之间**重建**（或用 `build()` 重置）。

## 模板（可直接编译运行）

```cpp
// 数位 DP 模板：不含连续1 / 数位和区间计数 / 无重复数字 / windy数 / 位数码计数
#define _CRT_SECURE_NO_WARNINGS
#include <bitset>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= 通用要点 =================
// f(i, isLimit, isNum, ...) ：构造从左往右第 i 位及之后的方案数
// up    = isLimit ? num[i]-'0' : 9
// start = isNum ? 0 : 1
// 只有 (!isLimit && isNum) 的状态才能写进 dp（通用子问题）

// ================= 1. 不含连续 1 的非负整数 =================
class NoConsecutiveOnes {
    vector<vector<int>> dp;
    string num;
    int f(int i, bool isPre, bool isLimit) {
        if (i == (int)num.size()) return 1;
        if (!isLimit && dp[i][isPre] != -1) return dp[i][isPre];
        int ans = 0, cur = num[i] - '0', up = isLimit ? cur : 1;
        for (int pick = 0; pick <= up; pick++) {
            if (isPre && pick) continue;                       // 不能连续两个 1
            ans += f(i + 1, pick == 1, isLimit && pick == up);
        }
        if (!isLimit) dp[i][isPre] = ans;
        return ans;
    }
public:
    int findIntegers(int n) {
        num = bitset<32>(n).to_string();
        dp.assign(num.size(), vector<int>(2, -1));
        return f(0, false, true);
    }
};

// ================= 2. 数位和在 [mins, maxs] 的整数个数（两个剪枝） =================
class CountOfIntegers {
    vector<vector<vector<int>>> dp;
    int mins = 0, maxs = 0;
    static const int MOD = 1000000007;
    int f(const string& num, int i, int sum, bool isLimit) {
        if (sum > maxs) return 0;
        if (sum + (int)(num.size() - i) * 9 < mins) return 0;  // ★神之一剪
        if (i == (int)num.size()) return 1;
        if (dp[i][sum][isLimit] != -1) return dp[i][sum][isLimit];
        long long ans = 0;
        int cur = num[i] - '0';
        if (isLimit) {
            ans += f(num, i + 1, sum + cur, true);
            for (int pick = 0; pick < cur; pick++) ans += f(num, i + 1, sum + pick, false);
        } else {
            for (int pick = 0; pick <= 9; pick++) ans += f(num, i + 1, sum + pick, false);
        }
        return dp[i][sum][isLimit] = (int)(ans % MOD);
    }
    bool check(const string& s) {
        int sum = 0;
        for (char c : s) sum += c - '0';
        return sum >= mins && sum <= maxs;
    }
    void reset() { dp.assign(23, vector<vector<int>>(401, vector<int>(2, -1))); }
public:
    int count(const string& num1, const string& num2, int min_sum, int max_sum) {
        mins = min_sum; maxs = max_sum;
        reset();
        long long ans = f(num2, 0, 0, true);
        reset();
        ans -= f(num1, 0, 0, true);
        if (check(num1)) ans++;                                // 补回左端点
        return (int)((ans % MOD + MOD) % MOD);
    }
};

// ================= 3. 完全没有重复的数字（status 位集） =================
class SpecialNumbers {
    vector<vector<int>> dp;
    string num;
    int f(int i, bool isLimit, bool isNum, int status) {
        if (i == (int)num.size()) return isNum ? 1 : 0;
        if (!isLimit && isNum && dp[i][status] != -1) return dp[i][status];
        int ans = 0;
        if (!isNum) ans += f(i + 1, false, false, status);
        int up = isLimit ? num[i] - '0' : 9;
        int start = isNum ? 0 : 1;
        for (int pick = start; pick <= up; pick++)
            if (!(status & (1 << pick)))
                ans += f(i + 1, isLimit && pick == up, true, status ^ (1 << pick));
        if (!isLimit && isNum) dp[i][status] = ans;
        return ans;
    }
public:
    int countSpecialNumbers(int n) {
        num = to_string(n);
        dp.assign(num.size(), vector<int>(1 << 10, -1));
        return f(0, true, false, 0);
    }
    int numDupDigitsAtMostN(int n) { return n - countSpecialNumbers(n); }  // 至少有 1 位重复
};

// ================= 4. windy 数（相邻差 ≥ 2） =================
class WindyNumbers {
    vector<vector<int>> dp;
    int f(const string& num, int i, bool isLimit, bool isNum, int prev) {
        if (i == (int)num.size()) return isNum ? 1 : 0;
        if (!isLimit && isNum && dp[i][prev] != -1) return dp[i][prev];
        int ans = 0;
        if (!isNum) ans += f(num, i + 1, false, false, 0);
        int up = isLimit ? num[i] - '0' : 9;
        int start = isNum ? 0 : 1;
        for (int pick = start; pick <= up; pick++) {
            if (!isNum || pick <= prev - 2 || pick >= prev + 2)   // 首位不判
                ans += f(num, i + 1, isLimit && pick == up, true, pick);
        }
        if (!isLimit && isNum) dp[i][prev] = ans;
        return ans;
    }
public:
    int countUpTo(int x) {
        if (x < 0) return 0;
        string s = to_string(x);
        dp.assign(11, vector<int>(10, -1));
        return f(s, 0, true, false, 0);
    }
    int inRange(int a, int b) { return countUpTo(b) - countUpTo(a - 1); }
};

// ================= 5. 数字 1 的个数（状态带计数） =================
class DigitOne {
    vector<vector<long long>> dp;
    string num;
    long long f(int i, int cnt, bool isLimit) {
        if (i == (int)num.size()) return cnt;
        if (!isLimit && dp[i][cnt] != -1) return dp[i][cnt];
        long long ans = 0;
        int up = isLimit ? num[i] - '0' : 9;
        for (int pick = 0; pick <= up; pick++)
            ans += f(i + 1, cnt + (pick == 1), isLimit && pick == up);
        if (!isLimit) dp[i][cnt] = ans;
        return ans;
    }
public:
    long long countDigitOne(long long n) {
        num = to_string(n);
        dp.assign(num.size(), vector<long long>(num.size() + 1, -1));
        return f(0, 0, true);
    }
};

int main() {
    NoConsecutiveOnes a;
    std::cout << "不含连续1(5) = " << a.findIntegers(5) << "\n";          // 5
    CountOfIntegers b;
    std::cout << "数位和[1,8]内的数(1..20) = " << b.count("1", "20", 1, 8) << "\n";  // 18
    SpecialNumbers c;
    std::cout << "无重复数字(20) = " << c.countSpecialNumbers(20) << "\n";  // 19
    WindyNumbers d;
    std::cout << "windy数[1,10] = " << d.inRange(1, 10) << "\n";            // 9
    DigitOne e;
    std::cout << "数字1的个数(13) = " << e.countDigitOne(13) << "\n";     // 6
    return 0;
}
```

## 为什么数位 DP 从高位开始

比较一个数和上界 `limit` 时，必须先决定高位。若高位已经小于上界，低位就完全自由；若高位仍相等，后续才继续受上界约束。`isLimit` 正是把这两种情况分开。

| 状态 | 当前位的可选范围 | 能否与普通状态复用 |
| --- | --- | --- |
| `isLimit=true` | `0..num[i]`，且选等号继续受限 | 只能对应一条前缀，通常不缓存 |
| `isLimit=false` | `0..9` 完整 | 可以缓存 |

前导零用 `isNum` 单独管理：尚未填写数字时，当前位可以继续不填；一旦填过非零数字，后面的 0 才是真正数位。

## 手算演练：数位和不超过 5 的数到 23

从最高位开始：

1. 选 0：处理 0..9，数位和为 `0..9`，保留 `0..5`，共 6 个；
2. 选 1：剩余一位可 `0..9` 且总数位和 `1+d<=5`，有 5 个；
3. 选 2：第二位只能 `0..3`，且 `2+d<=5`，有 4 个；
4. 合计 `[0,23]` 内 15 个。

若直接按大小枚举会漏掉“前导零与真正 0”的区别，数位 DP 的边界表把这种差异显式化。

## 区间差分的三种安全写法

1. 普通整数：`answer(R) - answer(L-1)`；
2. 大数字字符串：`answer(R) - answer(L) + valid(L)`；
3. 需要报告模数的方案数：先做差再 `((x % MOD) + MOD) % MOD`。

模板中的 `check(L)` 是在做第 2 种。

## 常见约束转状态

| 题面约束 | 额外状态 |
| --- | --- |
| 数位和 | 当前和 `sum` |
| 不能有相邻 1 | 上一位 `previousDigit` |
| 相邻差 ≥ 2 | 上一位 `previousDigit` |
| 不能有重复数字 | 已用数字集合 `digitMask` |
| 是否出现两个连续相同后缀 | 前两位 `prePrevious, previous` |
| 统计某个数字出现次数 | 当前计数 `count` |
