# 树型 DP

> 来源笔记：`0330树型dp.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

树形 DP 的套路只有四步：**① 分析父树要答案需要子树的哪些信息 → ② 把子树信息的全集定义成返回值 → ③ 递归让子树返回全集 → ④ 整合出父树的信息**。难点不在依赖关系（父依赖子，很简单），而在"信息怎么设计"。

## 上篇：七道题

### 题一：最大 BST 子树（LeetCode 333）

返回信息 `Info{ maxBSTSize, isBST, max, min }`：

```
isBST = 左isBST && 右isBST && 左max < x < 右min
maxBSTSize = isBST ? 1 + 左size + 右size : max(左size, 右size)
```

空节点返回 `{0, true, LLONG_MIN, LLONG_MAX}`。

### 题二：二叉搜索子树的最大键值和（LeetCode 1373）

**节点值可能为负，所以要同时记录"子树总和"与"子树内部最大 BST 和"**：

```
Info{ isBST, max, min, sum, maxBstSum }
maxBstSum = max(左maxBstSum, 右maxBstSum, isBST ? sum : 0)
```

### 题三：二叉树直径（LeetCode 543）

`Info{ diameter, height }`：

```
height = max(左height, 右height) + 1
diameter = max(左diameter, 右diameter, 左height + 右height)
```

### 题四：在二叉树中分配硬币（LeetCode 979）

**贡献法**：跨越"节点 x 与它父节点"的那条边，至少要走 `|子树节点数 - 子树硬币数|` 次：

```
step = 左step + 右step + |左cnt - 左sum| + |右cnt - 右sum|
```

### 题五：没有上司的舞会（洛谷 P1352 / LeetCode 337 打家劫舍 III）

`Info{ yes, no }`：

```
yes = happy[x] + 左no + 右no
no  = max(左yes, 左no) + max(右yes, 右no)
```

笔记还给了**多叉树版**：链式前向星建图，先用 `boss[]` 找根（谁的入度为 0），再递归。

### 题六：监控二叉树（LeetCode 968）

**三状态设计**（笔记的经典）：

| 返回值 | 含义 |
| --- | --- |
| 0 | x 无覆盖，x 下方都已覆盖 |
| 1 | x 已覆盖，x 上没摄像头 |
| 2 | x 已覆盖，x 上有摄像头 |

```
左右有一个 0 -> 必须在 x 装摄像头，ans++，返回 2
左右都是 1   -> x 无覆盖，返回 0
否则         -> x 已覆盖无摄像头，返回 1
```

空节点返回 1（视为已覆盖）；**最后若根返回 0，还要再 +1**。

### 题七：路径总和 III（LeetCode 437）

树上的"和为 K 的子数组"：递归时维护**根到当前节点的前缀和**，用哈希表数 `sum - target` 出现过几次，**返回时回溯**（`cnt[sum]--`）。

## 下篇：dfn 序 + 六道题

### dfn 序是什么

DFS 给每个节点按访问顺序编号；**祖先的 dfn 一定小于子孙**。配合"子树大小 size"就能定位子树：

> 若节点 dfn 为 x、子树大小为 y，则 dfn 在 `[x, x+y-1]` 的节点恰好是它的子树。

这是后面很多算法（树链剖分等）的基础。

### 题一：到达首都的最少油耗（LeetCode 2477）

`Info{ cnt, cost }`，对每个孩子：

```
cnt  += 孩子的 cnt
cost += 孩子的 cost + ceil(孩子的 cnt / seats)    // 这一层过路要开的车数
```

建图技巧：**无向图 + 递归时带 `father` 参数**，避免"不知道谁是父节点"。

### 题二：相邻字符不同的最长路径（LeetCode 2246）

`Info{ maxPath, maxPathFromHead }`：对孩子取"从根出发的最大与次大路径"（仅在字符不同时），`maxPath` 还要用 `max1 + max2 + 1` 更新。

### 题三：移除子树后的二叉树高度（LeetCode 2458）

dfn 预处理：

- `dfn[节点值]`、`size[dfn]`、`deep[dfn]`；
- `lmax[i]`：dfn 前缀最大深度；`rmax[i]`：dfn 后缀最大深度；
- 删除某节点子树后，答案是 `max(lmax[dfn-1], rmax[dfn+size])`。

### 题四：从树中删除边的最小分数（LeetCode 2322）

dfn + 子树异或和：删两条边得到三个连通块，利用 `dfn` 判断两个被删节点是否互为祖先：

- 若 `b <= a + size[a] - 1`（b 在 a 的子树内）→ 三段异或分别为 `xOr[1]^xOr[a]`、`xOr[a]^xOr[b]`、`xOr[b]`；
- 否则 → `xOr[1]^xOr[a]^xOr[b]`、`xOr[a]`、`xOr[b]`。

### 题五：选课（洛谷 P2014）——树上 01 背包 · 普通解法

`dp[i][j][k]`：以 i 为根、在前 j 棵子树里选 k 门课且连成一片：

```
不选第 j 棵：dp[i][j-1][k]
选第 j 棵  ：max over s ( dp[x][全部子树][s] + dp[i][j-1][k-s] )   // s < k（要给 i 留位置）
```

建一个**虚拟节点 0** 当所有无先修课课程的父节点，最后求 `f(0, 孩子数, m+1)`。

### 题六：选课 · 最优解（O(n·m)）

用 dfn 序 + 巧妙定义：

> **有效结构**：来到 dfn 为 i 的节点，若后面出现一个"总头部"，能把它选出的节点连成一整片、不断开。

```
dp[i][j] = max( 不选 i：dp[i + size[i]][j],
                选 i  ：dp[i + 1][j - 1] + dfnScore[i] )
```

从 dfn 大到小填表，答案是 `dp[1][m+1]`。笔记明确推荐掌握这个 O(n·m) 的写法。

## 适用特征（看到这些信号就选它）

- 题目在**树**上求最优/计数，且"父节点的答案依赖子树"；
- 树上"选或不选"（舞会、打家劫舍、监控）；
- 需要"某棵子树"的信息 → 用 dfn + size 把子树变成 dfn 上的连续区间；
- 树上背包（选课）。

## 易错点

1. 空节点返回什么信息，直接影响合并公式（BST 题返回极值哨兵）；
2. 节点值有负数时，"最大和"要单独一维（不能只用总和）；
3. 监控二叉树"根返回 0 还要 +1"；
4. 树是无向图时，递归必须带 `father` 参数防回头；
5. dfn 序里 `size` 要在**回溯时累加**；
6. 树上背包的 `s < k`（要给根留一个位置）；
7. 多叉树的走法：链式前向星时注意边编号从 1 开始。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v = 0, TreeNode* l = nullptr, TreeNode* r = nullptr) : val(v), left(l), right(r) {}
};

// ---------- 1. 最大 BST 子树 ----------
struct BstInfo { int maxSize; bool isBst; long long mx, mn; };
BstInfo largestBst(TreeNode* node) {
    if (!node) return {0, true, LLONG_MIN, LLONG_MAX};
    BstInfo L = largestBst(node->left), R = largestBst(node->right);
    long long mx = max((long long)node->val, max(L.mx, R.mx));
    long long mn = min((long long)node->val, min(L.mn, R.mn));
    bool isBst = L.isBst && R.isBst && L.mx < node->val && node->val < R.mn;
    int sz = isBst ? 1 + L.maxSize + R.maxSize : max(L.maxSize, R.maxSize);
    return {sz, isBst, mx, mn};
}

// ---------- 2. 二叉树直径 ----------
pair<int,int> diameter(TreeNode* node) {          // {diameter, height}
    if (!node) return {0, 0};
    auto L = diameter(node->left), R = diameter(node->right);
    int h = max(L.second, R.second) + 1;
    int d = max(max(L.first, R.first), L.second + R.second);
    return {d, h};
}

// ---------- 3. 打家劫舍 III / 没有上司的舞会 ----------
pair<int,int> robTree(TreeNode* node) {           // {选, 不选}
    if (!node) return {0, 0};
    auto L = robTree(node->left), R = robTree(node->right);
    int yes = node->val + L.second + R.second;
    int no  = max(L.first, L.second) + max(R.first, R.second);
    return {yes, no};
}

// ---------- 4. 监控二叉树（三状态） ----------
int cameraAns = 0;
int cameraDp(TreeNode* node) {
    if (!node) return 1;                          // 空节点视为已覆盖
    int l = cameraDp(node->left), r = cameraDp(node->right);
    if (l == 0 || r == 0) { cameraAns++; return 2; }   // 孩子无覆盖 → 必须装
    if (l == 1 && r == 1) return 0;                    // 都被覆盖但自己没被覆盖
    return 1;
}
int minCameraCover(TreeNode* root) {
    cameraAns = 0;
    if (cameraDp(root) == 0) cameraAns++;         // 根无覆盖还要补一个
    return cameraAns;
}

// ---------- 5. dfn 序预处理（子树变区间） ----------
vector<int> dfn, sz, deep;
int dfnCnt = 0;
void buildDfn(TreeNode* node, int h) {
    dfn[node->val] = ++dfnCnt;                     // 假设节点值就是编号
    deep[dfn[node->val]] = h;
    sz[dfn[node->val]] = 1;
    if (node->left)  { buildDfn(node->left, h + 1);  sz[dfn[node->val]] += sz[dfn[node->left->val]]; }
    if (node->right) { buildDfn(node->right, h + 1); sz[dfn[node->val]] += sz[dfn[node->right->val]]; }
}
```
