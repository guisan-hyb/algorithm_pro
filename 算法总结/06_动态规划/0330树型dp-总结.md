# 树型 DP

> 来源笔记：`0330树型dp.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

树形 DP 的套路只有四步：**① 分析父树要答案需要子树的哪些信息 → ② 把子树信息的全集定义成返回值 → ③ 递归让子树返回全集 → ④ 整合出父树的信息**。难点不在依赖关系（父依赖子，很简单），而在"信息怎么设计"。

## 上篇：七道题

### 题一：最大 BST 子树（LeetCode 333）

返回信息 `Info{ maxBSTSize, isBST, max, min }`：

```
isBST = 左isBST && 右isBST && 左max < x < 右min
maxBSTSize = isBST ? 1 + 左size + 右size : max(左size, 右size)
```

空节点返回 `{0, true, LLONG_MIN, LLONG_MAX}`。

### 题二：二叉搜索子树的最大键值和（LeetCode 1373）

**节点值可能为负，所以要同时记录"子树总和"与"子树内部最大 BST 和"**：

```
Info{ isBST, max, min, sum, maxBstSum }
maxBstSum = max(左maxBstSum, 右maxBstSum, isBST ? sum : 0)
```

### 题三：二叉树直径（LeetCode 543）

`Info{ diameter, height }`：

```
height = max(左height, 右height) + 1
diameter = max(左diameter, 右diameter, 左height + 右height)
```

### 题四：在二叉树中分配硬币（LeetCode 979）

**贡献法**：跨越"节点 x 与它父节点"的那条边，至少要走 `|子树节点数 - 子树硬币数|` 次：

```
step = 左step + 右step + |左cnt - 左sum| + |右cnt - 右sum|
```

### 题五：没有上司的舞会（洛谷 P1352 / LeetCode 337 打家劫舍 III）

`Info{ yes, no }`：

```
yes = happy[x] + 左no + 右no
no  = max(左yes, 左no) + max(右yes, 右no)
```

笔记还给了**多叉树版**：链式前向星建图，先用 `boss[]` 找根（谁的入度为 0），再递归。

### 题六：监控二叉树（LeetCode 968）

**三状态设计**（笔记的经典）：

| 返回值 | 含义 |
| --- | --- |
| 0 | x 无覆盖，x 下方都已覆盖 |
| 1 | x 已覆盖，x 上没摄像头 |
| 2 | x 已覆盖，x 上有摄像头 |

```
左右有一个 0 -> 必须在 x 装摄像头，ans++，返回 2
左右都是 1   -> x 无覆盖，返回 0
否则         -> x 已覆盖无摄像头，返回 1
```

空节点返回 1（视为已覆盖）；**最后若根返回 0，还要再 +1**。

### 题七：路径总和 III（LeetCode 437）

树上的"和为 K 的子数组"：递归时维护**根到当前节点的前缀和**，用哈希表数 `sum - target` 出现过几次，**返回时回溯**（`cnt[sum]--`）。

## 下篇：dfn 序 + 六道题

### dfn 序是什么

DFS 给每个节点按访问顺序编号；**祖先的 dfn 一定小于子孙**。配合"子树大小 size"就能定位子树：

> 若节点 dfn 为 x、子树大小为 y，则 dfn 在 `[x, x+y-1]` 的节点恰好是它的子树。

这是后面很多算法（树链剖分等）的基础。

### 题一：到达首都的最少油耗（LeetCode 2477）

`Info{ cnt, cost }`，对每个孩子：

```
cnt  += 孩子的 cnt
cost += 孩子的 cost + ceil(孩子的 cnt / seats)    // 这一层过路要开的车数
```

建图技巧：**无向图 + 递归时带 `father` 参数**，避免"不知道谁是父节点"。

### 题二：相邻字符不同的最长路径（LeetCode 2246）

`Info{ maxPath, maxPathFromHead }`：对孩子取"从根出发的最大与次大路径"（仅在字符不同时），`maxPath` 还要用 `max1 + max2 + 1` 更新。

### 题三：移除子树后的二叉树高度（LeetCode 2458）

dfn 预处理：

- `dfn[节点值]`、`size[dfn]`、`deep[dfn]`；
- `lmax[i]`：dfn 前缀最大深度；`rmax[i]`：dfn 后缀最大深度；
- 删除某节点子树后，答案是 `max(lmax[dfn-1], rmax[dfn+size])`。

### 题四：从树中删除边的最小分数（LeetCode 2322）

dfn + 子树异或和：删两条边得到三个连通块，利用 `dfn` 判断两个被删节点是否互为祖先：

- 若 `b <= a + size[a] - 1`（b 在 a 的子树内）→ 三段异或分别为 `xOr[1]^xOr[a]`、`xOr[a]^xOr[b]`、`xOr[b]`；
- 否则 → `xOr[1]^xOr[a]^xOr[b]`、`xOr[a]`、`xOr[b]`。

### 题五：选课（洛谷 P2014）——树上 01 背包 · 普通解法

`dp[i][j][k]`：以 i 为根、在前 j 棵子树里选 k 门课且连成一片：

```
不选第 j 棵：dp[i][j-1][k]
选第 j 棵  ：max over s ( dp[x][全部子树][s] + dp[i][j-1][k-s] )   // s < k（要给 i 留位置）
```

建一个**虚拟节点 0** 当所有无先修课课程的父节点，最后求 `f(0, 孩子数, m+1)`。

### 题六：选课 · 最优解（O(n·m)）

用 dfn 序 + 巧妙定义：

> **有效结构**：来到 dfn 为 i 的节点，若后面出现一个"总头部"，能把它选出的节点连成一整片、不断开。

```
dp[i][j] = max( 不选 i：dp[i + size[i]][j],
                选 i  ：dp[i + 1][j - 1] + dfnScore[i] )
```

从 dfn 大到小填表，答案是 `dp[1][m+1]`。笔记明确推荐掌握这个 O(n·m) 的写法。

## 适用特征（看到这些信号就选它）

- 题目在**树**上求最优/计数，且"父节点的答案依赖子树"；
- 树上"选或不选"（舞会、打家劫舍、监控）；
- 需要"某棵子树"的信息 → 用 dfn + size 把子树变成 dfn 上的连续区间；
- 树上背包（选课）。

## 易错点

1. 空节点返回什么信息，直接影响合并公式（BST 题返回极值哨兵）；
2. 节点值有负数时，"最大和"要单独一维（不能只用总和）；
3. 监控二叉树"根返回 0 还要 +1"；
4. 树是无向图时，递归必须带 `father` 参数防回头；
5. dfn 序里 `size` 要在**回溯时累加**；
6. 树上背包的 `s < k`（要给根留一个位置）；
7. 多叉树的走法：链式前向星时注意边编号从 1 开始。

## 模板（可直接编译运行）

```cpp
// 树型 DP 模板：最大BST子树 / 直径 / 打家劫舍 / 监控 / 分配硬币 / dfn 序
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <cstdlib>
#include <functional>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v = 0, TreeNode* l = nullptr, TreeNode* r = nullptr) : val(v), left(l), right(r) {}
};

// ================= 1. 最大 BST 子树 =================
struct BstInfo { int maxSize; bool isBst; long long mx, mn; };
BstInfo largestBst(TreeNode* node) {
    if (!node) return {0, true, LLONG_MIN, LLONG_MAX};
    BstInfo L = largestBst(node->left), R = largestBst(node->right);
    long long mx = max((long long)node->val, max(L.mx, R.mx));
    long long mn = min((long long)node->val, min(L.mn, R.mn));
    bool isBst = L.isBst && R.isBst && L.mx < node->val && node->val < R.mn;
    int sz = isBst ? 1 + L.maxSize + R.maxSize : max(L.maxSize, R.maxSize);
    return {sz, isBst, mx, mn};
}
int largestBSTSubtree(TreeNode* root) { return largestBst(root).maxSize; }

// ================= 2. 二叉搜索子树的最大键值和（节点可为负） =================
struct SumBstInfo { bool isBst; int mx, mn, sum, maxBstSum; };
SumBstInfo maxSumBst(TreeNode* node) {
    if (!node) return {true, INT_MIN, INT_MAX, 0, 0};
    SumBstInfo L = maxSumBst(node->left), R = maxSumBst(node->right);
    bool isBst = L.isBst && R.isBst && L.mx < node->val && node->val < R.mn;
    int mx = max(node->val, max(L.mx, R.mx));
    int mn = min(node->val, min(L.mn, R.mn));
    int sum = L.sum + R.sum + node->val;
    int best = max(L.maxBstSum, R.maxBstSum);
    if (isBst) best = max(best, sum);
    return {isBst, mx, mn, sum, best};
}

// ================= 3. 二叉树直径 =================
pair<int,int> diameterDfs(TreeNode* node) {        // {diameter, height}
    if (!node) return {0, 0};
    pair<int,int> L = diameterDfs(node->left), R = diameterDfs(node->right);
    int h = max(L.second, R.second) + 1;
    int d = max(max(L.first, R.first), L.second + R.second);
    return {d, h};
}
int diameterOfBinaryTree(TreeNode* root) { return diameterDfs(root).first; }

// ================= 4. 打家劫舍 III / 没有上司的舞会 =================
pair<int,int> robDfs(TreeNode* node) {             // {选, 不选}
    if (!node) return {0, 0};
    pair<int,int> L = robDfs(node->left), R = robDfs(node->right);
    int yes = node->val + L.second + R.second;
    int no  = max(L.first, L.second) + max(R.first, R.second);
    return {yes, no};
}
int rob(TreeNode* root) { pair<int,int> r = robDfs(root); return max(r.first, r.second); }

// ================= 5. 在二叉树中分配硬币（贡献法） =================
struct CoinInfo { int cnt, sum, step; };
CoinInfo coinDfs(TreeNode* node) {
    if (!node) return {0, 0, 0};
    CoinInfo L = coinDfs(node->left), R = coinDfs(node->right);
    int cnt = L.cnt + R.cnt + 1;
    int sum = node->val + L.sum + R.sum;
    int step = L.step + R.step + abs(L.cnt - L.sum) + abs(R.cnt - R.sum);
    return {cnt, sum, step};
}
int distributeCoins(TreeNode* root) { return coinDfs(root).step; }

// ================= 6. 监控二叉树（三状态） =================
int cameraAns = 0;
int cameraDfs(TreeNode* node) {
    if (!node) return 1;                            // 0 无覆盖 / 1 已覆盖无摄像头 / 2 有摄像头
    int l = cameraDfs(node->left), r = cameraDfs(node->right);
    if (l == 0 || r == 0) { cameraAns++; return 2; }
    if (l == 1 && r == 1) return 0;
    return 1;
}
int minCameraCover(TreeNode* root) {
    cameraAns = 0;
    if (cameraDfs(root) == 0) cameraAns++;
    return cameraAns;
}

// ================= 7. dfn 序：子树变成连续区间 =================
vector<int> dfn, sz, deep;
int dfnCnt = 0;
void buildDfn(TreeNode* node, int h) {              // 假设 val 就是 1..n 的编号
    dfn[node->val] = ++dfnCnt;
    deep[dfn[node->val]] = h;
    sz[dfn[node->val]] = 1;
    if (node->left)  { buildDfn(node->left, h + 1);  sz[dfn[node->val]] += sz[dfn[node->left->val]]; }
    if (node->right) { buildDfn(node->right, h + 1); sz[dfn[node->val]] += sz[dfn[node->right->val]]; }
}
// 删除某节点子树后的树高：max(lmax[dfn-1], rmax[dfn+size])
vector<int> treeQueriesByDfn(TreeNode* root, const vector<int>& queries) {
    int n = 0;                                       // 节点编号最大值
    function<void(TreeNode*)> getMax = [&](TreeNode* p) { if (!p) return; n = max(n, p->val); getMax(p->left); getMax(p->right); };
    getMax(root);
    dfn.assign(n + 1, 0); sz.assign(n + 1, 0); deep.assign(n + 1, 0);
    dfnCnt = 0;
    buildDfn(root, 0);
    vector<int> lmax(dfnCnt + 2, 0), rmax(dfnCnt + 2, 0);
    for (int i = 1; i <= dfnCnt; i++) lmax[i] = max(lmax[i - 1], deep[i]);
    for (int i = dfnCnt; i >= 1; i--) rmax[i] = max(rmax[i + 1], deep[i]);
    vector<int> ans;
    for (int v : queries)
        ans.push_back(max(lmax[dfn[v] - 1], rmax[dfn[v] + sz[dfn[v]]]));
    return ans;
}

int main() {
    //        1
    //      /   \
    //     2     3
    //    / \
    //   4   5
    TreeNode* root = new TreeNode(1,
        new TreeNode(2, new TreeNode(4), new TreeNode(5)),
        new TreeNode(3));
    std::cout << "最大BST子树 = " << largestBSTSubtree(root) << "\n";       // 1
    std::cout << "直径 = " << diameterOfBinaryTree(root) << "\n";           // 3
    std::cout << "打家劫舍 = " << rob(root) << "\n";                        // 7
    std::cout << "分配硬币步数 = " << distributeCoins(root) << "\n";        // 0
    std::cout << "最少摄像头 = " << minCameraCover(root) << "\n";           // 1
    return 0;
}
```

## 为什么树形 DP 先定义“子树返回信息”

把树看作递归结构：父节点只能通过子节点返回的信息了解整棵子树。若返回信息不足，父节点就无法做出局部决策；若返回信息过多，状态数量会爆炸。因此设计过程是：

1. 假设左右子树已经处理完；
2. 列出父节点若要求最优值，必须知道哪些量；
3. 证明这些量足以合并，再删除冗余维度；
4. 用后序遍历，在返回时组装父节点信息。

这不是针对树硬套 DP，而是“后序递归 + 信息汇总”的标准化。

## 手算演练：最大 BST 子树

对节点值 `[10,5,15,1,8,null,7]`：

| 节点 | 左信息 | 右信息 | 是否 BST | 最大 BST 大小 |
| --- | --- | --- | --- | --- |
| 5 | 子树 [1] | 子树 [8] | 左最大 1 < 5 < 右最小 8，是 | 3 |
| 15 | 空 | 子树 [7] | 根 15 不大于左极大值？右最小 7 < 15 不满足 | 1 |
| 10 | 左是 BST，范围 [1,8] | 右不是 BST | 否 | max(3,1)=3 |

若空节点返回 `INT_MIN/INT_MAX`，合并极值时不会污染真实范围；若错误返回 0，节点值为负时会直接判错。

## 三种常见返回协议

| 问题类型 | 返回信息 | 合并重点 |
| --- | --- | --- |
| 选/不选 | `{take, skip}` | 父选则子不能选；父不选则子任选最优 |
| 路径类 | `{globalBest, fromRootBest}` | 全局路径可横跨两根，但向上返回只能选一根 |
| 覆盖状态机 | `{uncovered, covered, camera}` | 按子节点最危险状态决定父节点动作 |

## dfn 序为什么不破坏连通性

DFS 先访问根、再完整访问每个子树。记录进入时间 `dfn[x]` 和子树大小 `size[x]` 后，`[dfn[x], dfn[x]+size[x]-1]` 恰好覆盖节点 x 的所有后代。因此，“删除一棵子树”在 dfn 序列上是删除一个连续区间，树问题就变成前后缀查询。

使用时必须满足：

- `dfn` 从 1 连续编号；
- `size` 在后序回溯时累加；
- 查询区间包含 dfn 的末端时做空区间哨兵。

## 与树形递归的边界

1. 单节点树要能独立得到答案；
2. 负权节点不能把“空子树收益”粗暴初始化成 0，除非题目允许不选；
3. 无向树递归必须传父节点，否则会回到父节点形成死递归；
4. 统计方案数时乘法前先判空子树；
5. 节点编号不连续时不能直接拿 `val` 当 dfn 下标。
