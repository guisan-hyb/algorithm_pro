# 背包 DP（三）：多重背包与混合背包

> 来源笔记：`0325背包dp-多重背包、混合背包.cpp`｜核心程度：必背（二进制分组是重点）｜分类：06 动态规划

## 一句话

**多重背包** = 每种物品有数量上限，原本要枚举"取 0 ~ cnt 个"；用 **二进制分组**把 cnt 拆成 1、2、4、8… 的若干"新物品"，就把多重背包变成 01 背包，枚举量从 O(cnt) 降到 O(log cnt)。

## 题目一：多重背包（不优化）

`dp[i][j]` = 前 i 种货物、容量不超过 j 的最大价值：

```
dp[i][j] = max( dp[i-1][j],                                  // 取 0 个
                max_{k=1..cnt[i]} dp[i-1][j - k*w[i]] + k*v[i] );  // 取 k 个
```

复杂度 O(n × t × 平均个数)，数据一大就超时。

## 题目二：二进制分组优化（**本文件最重要的代码**）

```cpp
for (int k = 1; k <= cnt; k <<= 1) {   // 1, 2, 4, 8, ...
    v[++m] = val * k;                  // 新物品的体积与价值都乘 k
    w[m]   = weight * k;
    cnt -= k;
}
if (cnt > 0) {                         // 余数单独成一组
    v[++m] = cnt * val;
    w[m]   = cnt * weight;
}
```

原理：任何正整数都能用 `1,2,4,…` 的若干项**组合**出来（例如 `13 = 1+2+4+6`、`50 = 1+2+4+8+16+19`），所以不会漏、也不会多算任何一种"张数情况"。

拆完之后跑 01 背包（容量倒序）即可，复杂度 O(t × Σlog(cnt_i))。

> **重要限制（笔记原文）**：二进制优化可以把多重背包转成 01 背包，适用于**可行性问题**和**最优值问题**，但**不适用于计数问题**（方案数）。

## 题目三：观赏樱花（完全背包 → 多重背包 → 二进制 → 01 背包）

混合背包的典型转化链：

- `cnt == 0`（可无限买）→ **完全背包转多重背包**：`cnt = 总容量 / 该物品花费`（因为容量有限，最多也就能买这么多个）；
- `cnt > 0` → 直接二进制分组；
- 统一转成 01 背包求解（容量倒序）。

## 题目四：多重背包的单调队列优化

笔记在本节**留空**（只写了标题），属于"复杂度最好但理解稍难"的进阶做法：

- 对每个余数类 `r = j % w` 单独处理，用单调队列维护窗口内 `dp[r + k*w] - k*v` 的最大值；
- 复杂度 O(n × t)，优于二进制分组；
- 建议先掌握二进制分组，比赛够用。

## 题目五：混合背包 + 普通窗口优化（POJ 1742 找零钱种类）

题面：每种货币有面值 `val[i]` 和数量 `cnt[i]`，问 1~m 中有多少金额**能被凑出**。

**做法（可行性多重背包 + 窗口优化）**：

- `dp[j]` 表示金额 j 能否凑出；
- 对每种货币，用一个辅助数组 `used[j]` 记录"凑出 j 时用掉了本种货币多少个"，限制 `used[j] <= cnt[i]`；
- 遍历顺序：容量**正序**（因为是多重/完全背包的可重复特性）+ `used` 限制个数；
- 复杂度 O(n × m)。

```cpp
for (int i = 0; i < n; i++) {
    fill(used.begin(), used.end(), 0);
    for (int j = val[i]; j <= m; j++) {
        if (!dp[j] && dp[j - val[i]] && used[j - val[i]] < cnt[i]) {
            dp[j] = true;
            used[j] = used[j - val[i]] + 1;
        }
    }
}
```

## 四种背包的关系（速查）

| 模型 | 每种物品可选次数 | 空间压缩后的容量遍历方向 |
| --- | --- | --- |
| 01 背包 | 0 或 1 次 | **倒序** |
| 完全背包 | 无限次 | **正序** |
| 多重背包 | 有限次（≤cnt） | 二进制分组后按 01 背包（倒序） |
| 分组背包 | 每组恰好/最多 1 件 | 外层组、中层容量倒序、内层枚举组内物品 |

## 适用特征（看到这些信号就选它）

- "每种物品有数量限制" → 多重背包；
- 数量上限很大但只需要可行性/最优值 → **二进制分组**；
- 题目里同时出现"可以无限买"和"限定个数" → 混合背包，先统一转化；
- 求"能凑出多少种金额/方案" → 可行性背包 + 数量限制数组。

## 易错点

1. 二进制分组的循环写法：`k <= cnt; k <<= 1` 且**循环里要 `cnt -= k`**，最后 `if (cnt > 0)` 再补一组；
2. 拆分出的"新物品"体积和价值都要乘 k；
3. 分组后**必须用 01 背包的倒序遍历**；
4. 计数问题不能用二进制分组（会重复计数）；
5. 完全背包转多重时，上限要取 `容量 / 花费`（而不是一个很大的常数）；
6. 可行性背包的 `used` 数组要**每种货币重新清空**；
7. 数组大小要按"拆分组数"开（`n × log(最大数量)`），别按原物品数开。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 二进制分组：多重背包 -> 01 背包 ----------
// 返回最大价值；weight/val 为每种物品的单件信息，cnt 为数量上限
long long multiKnapsackBinary(int cap, const vector<int>& weight,
                              const vector<int>& val, const vector<int>& cnt) {
    vector<long long> w, v;                      // 拆分后的"新物品"
    for (size_t i = 0; i < weight.size(); i++) {
        int c = cnt[i];
        for (int k = 1; k <= c; k <<= 1) {       // 1,2,4,8,...
            w.push_back((long long)weight[i] * k);
            v.push_back((long long)val[i] * k);
            c -= k;
        }
        if (c > 0) {                             // 余数单独一组
            w.push_back((long long)weight[i] * c);
            v.push_back((long long)val[i] * c);
        }
    }
    vector<long long> dp(cap + 1, 0);
    for (size_t i = 0; i < w.size(); i++)
        for (int j = cap; j >= w[i]; j--)        // 01 背包：倒序
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[cap];
}

// ---------- 2. 混合背包：cnt == 0 视为完全背包（先转成多重） ----------
long long mixedKnapsack(int cap, const vector<int>& weight,
                        const vector<int>& val, const vector<int>& cnt) {
    vector<int> fixed = cnt;
    for (size_t i = 0; i < fixed.size(); i++)
        if (fixed[i] == 0) fixed[i] = cap / weight[i];   // 完全 -> 多重
    return multiKnapsackBinary(cap, weight, val, fixed);
}

// ---------- 3. 可行性多重背包 + used 数组（能凑出多少种金额） ----------
int countableAmounts(int m, const vector<int>& val, const vector<int>& cnt) {
    vector<char> dp(m + 1, 0);
    vector<int> used(m + 1, 0);
    dp[0] = 1;
    for (size_t i = 0; i < val.size(); i++) {
        fill(used.begin(), used.end(), 0);
        for (int j = val[i]; j <= m; j++) {
            if (!dp[j] && dp[j - val[i]] && used[j - val[i]] < cnt[i]) {
                dp[j] = 1;
                used[j] = used[j - val[i]] + 1;
            }
        }
    }
    int ans = 0;
    for (int j = 1; j <= m; j++) ans += dp[j];
    return ans;
}
```

## 笔记里的题目

洛谷 P1776 宝物筛选（多重背包：不优化版、二进制分组版）、洛谷 P1833 观赏樱花（混合背包：完全转多重再二进制分组）、POJ 1742 能成功找零的钱数种类（可行性多重背包 + used 窗口优化）。

## 延伸

- 01 背包与有依赖背包：`0320背包dp-01背包、有依赖的背包`；
- 分组背包与完全背包：`0322背包dp-分组背包、完全背包`；
- 单调队列（多重背包的单调队列优化会用到）：`0116单调队列`。
