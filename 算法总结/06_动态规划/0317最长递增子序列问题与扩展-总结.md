# 最长递增子序列（LIS）问题与扩展

> 来源笔记：`0317最长递增子序列问题与扩展.cpp`｜核心程度：必背（O(n log n) 最优解）｜分类：06 动态规划

## 一句话

LIS 的最优解 = **贪心 + 二分**：维护 `ends[len]` 表示"长度为 len+1 的递增子序列的最小结尾值"；新数 x 就用二分找到 `ends` 里第一个 `>= x` 的位置并替换它，找不到就追加——`ends` 的长度就是 LIS 长度。

## 核心原理（笔记原文）

> "依然着眼于某个上升子序列的结尾元素：已经得到的上升子序列的**结尾数越小**，那么后面接上一个数时，越有可能构成长度更长的上升子序列。"

于是 `ends` 数组保持**严格升序**，更新规则：

- 找 `ends[0..len-1]` 中第一个 `>= x` 的位置：找到就**替换**（让结尾更小）；
- 找不到（所有值都 `< x`）：**追加**到末尾，`len++`；
- 答案就是 `len`。

**严格递增 vs 不下降**：只在二分条件上差一个号——

- 严格递增：找第一个 **`>= x`** 的位置；
- 最长不下降：找第一个 **`> x`** 的位置。

```cpp
// ends[0..len-1] 严格升序，找第一个 >= x 的位置，不存在返回 -1
int bs(const vector<int>& ends, int len, int x) {
    int ans = -1;
    for (int l = 0, r = len - 1; l <= r; ) {
        int m = l + (r - l) / 2;
        if (ends[m] >= x) { ans = m; r = m - 1; }
        else l = m + 1;
    }
    return ans;
}
```

## 五道题

### 题一：LIS / 最长不下降子序列（LeetCode 300）

- 先给 O(n²) 的 DP：`dp[i] = 1 + max{dp[j] : j < i, nums[j] < nums[i]}`；
- 再给 O(n log n) 的 `ends + 二分` 最优解；
- 不下降子序列只需把二分条件换成 `> x`。

**答题心法（笔记的重要问答）**：

- **相邻无关**的子序列问题（如 0-1 背包）适合"**选或不选**"；
- **相邻相关**的子序列问题（如 LIS）适合"**枚举选哪个**"——枚举"当前必选 i，再枚举前一个必选 j"；硬用"选或不选"会额外记录"上一个选的数"，空间从 O(n) 变 O(n²)。

### 题二：俄罗斯套娃信封（LeetCode 354）

**排序 + LIS**：

- 宽度**从小到大**；宽度相同时，高度**从大到小**；
- 然后对高度数组求 LIS（宽度相同的那组因为高度降序，天然不会被同时选中）。

### 题三：使数组 K 递增的最少操作次数（LeetCode 2111）

**分组 + LIS**：按下标模 k 分成 k 组，每组内部要变成"不下降"；

```
ans += 组大小 - 该组的最长不下降子序列长度
```

因为每组的非 LIS 元素改成"合适的值"即可。

### 题四：最长数对链（LeetCode 646）

- 法一（LIS 思路）：按 left 升序排序，`ends` 里存 right；替换时取 `min(ends[find], right)`（**查询与更新分离**）；
- 法二（更优的贪心）：**按 right 升序排序**，`pre` 记录上一个选中数对的 right，`left > pre` 就选它。

### 题五：有一次修改机会的最长不下降子序列（洛谷 P8776）

思路：把要修改的连续 k 个数放在中间，即 `..., a, k个可任意修改的数, b, ...`：

1. 求出"a 左侧最长不下降子序列长度"（用 `ends` + 二分维护，`f1` 找第一个 `> x`）；
2. 加上 k（修改的这 k 个数一定都能接上）；
3. 加上"b 右侧的最长不下降子序列长度"（`right_[i]`，**从右往左**用"最长不上升子序列"的二分 `f2` 预处理）；
4. 枚举分界点 i，滚动更新答案，最后别忘了"修改区间覆盖到数组末尾"的情况 `len + k`。

## 适用特征（看到这些信号就选它）

- "最长递增/不下降/不上升子序列"；
- 二维偏序（宽度和高度都要更大）→ 先排序转一维 LIS；
- "最少修改几个数使数组单调"→ 总数减 LIS；
- 需要"某位置左侧/右侧的最长子序列"→ 预处理 `ends` 或 `right[]`（正反两遍）。

## 复杂度

- O(n log n) 时间、O(n) 空间（`ends` 数组）；
- 笔记提醒：这题也能用线段树做，复杂度相同，但需要理解线段树。

## 易错点

1. `ends` 数组里存的**不是子序列本身**，只是"每个长度的最小结尾值"，别试图还原子序列（要还原得另存前驱）；
2. 严格递增用 `>= x`、不下降用 `> x`，两者差一个等号；
3. 套娃信封的排序：宽度升序、**高度必须降序**（否则同宽度的会被误选）；
4. 替换时要取 `min`（数对链题）；
5. 反向求"以 i 开头的最长不下降"时，等价于"从右往左看的最长不上升"（二分条件反转）；
6. 二分的返回值 -1 表示"所有值都比 x 小"，要 `len++`。

## 模板（可直接编译运行）

```cpp
// LIS 模板：O(n log n) 二分 + 套娃信封 + K 递增 + 数对链 + 一次修改机会
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;

// ================= 1. LIS：ends + 二分（O(n log n)） =================
// strict = true：严格递增；false：最长不下降
int LIS(const vector<int>& a, bool strict = true) {
    int n = (int)a.size();
    vector<int> ends(n);
    int len = 0;
    for (int x : a) {
        int l = 0, r = len - 1, pos = -1;
        while (l <= r) {                       // 找第一个满足条件的位置
            int m = l + (r - l) / 2;
            bool ok = strict ? (ends[m] >= x) : (ends[m] > x);
            if (ok) { pos = m; r = m - 1; }
            else l = m + 1;
        }
        if (pos == -1) ends[len++] = x;        // 追加（所有值都 < x）
        else ends[pos] = x;                    // 替换（让结尾更小）
    }
    return len;
}

// ================= 2. 俄罗斯套娃信封 =================
int maxEnvelopes(vector<vector<int>> env) {
    sort(env.begin(), env.end(), [](const vector<int>& a, const vector<int>& b) {
        return a[0] != b[0] ? a[0] < b[0] : a[1] > b[1];   // 宽升序、高降序
    });
    vector<int> heights;
    for (auto& e : env) heights.push_back(e[1]);
    return LIS(heights, true);
}

// ================= 3. 使数组 K 递增的最少操作次数 =================
int kIncreasing(const vector<int>& arr, int k) {
    int n = (int)arr.size(), ans = 0;
    for (int i = 0; i < k; i++) {
        vector<int> group;
        for (int j = i; j < n; j += k) group.push_back(arr[j]);
        ans += (int)group.size() - LIS(group, false);      // 每组要不下降
    }
    return ans;
}

// ================= 4. 最长数对链 =================
// 法一：LIS 思路（按 left 升序，ends 存 right，替换时取 min）
int findLongestChainLIS(vector<vector<int>> pairs) {
    sort(pairs.begin(), pairs.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[0] < b[0]; });
    vector<int> ends(pairs.size());
    int len = 0;
    for (auto& p : pairs) {
        int l = 0, r = len - 1, pos = -1;
        while (l <= r) {
            int m = l + (r - l) / 2;
            if (ends[m] >= p[0]) { pos = m; r = m - 1; }
            else l = m + 1;
        }
        if (pos == -1) ends[len++] = p[1];
        else ends[pos] = min(ends[pos], p[1]);
    }
    return len;
}
// 法二：贪心（按 right 升序，更优）
int findLongestChainGreedy(vector<vector<int>> pairs) {
    sort(pairs.begin(), pairs.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
    int ans = 0, pre = INT_MIN;
    for (auto& p : pairs)
        if (p[0] > pre) { ans++; pre = p[1]; }
    return ans;
}

// ================= 5. 有一次修改机会的最长不下降子序列 =================
// 思路：把要修改的连续 k 个数放在中间，左右各接一段最长不下降子序列
int longestAfterChange(const vector<int>& nums, int k) {
    int n = (int)nums.size();
    vector<int> rightLen(n, 0);                 // 以 i 开头的最长不下降长度
    vector<int> ends(n);
    int len = 0;
    for (int i = n - 1; i >= 0; i--) {          // 等价于从右往左的最长不上升
        int l = 0, r = len - 1, pos = -1;
        while (l <= r) {
            int m = l + (r - l) / 2;
            if (ends[m] < nums[i]) { pos = m; r = m - 1; }
            else l = m + 1;
        }
        if (pos == -1) { ends[len++] = nums[i]; rightLen[i] = len; }
        else { ends[pos] = nums[i]; rightLen[i] = pos + 1; }
    }

    int ans = 0;
    len = 0;
    for (int i = 0, j = k; j < n; i++, j++) {
        int l = 0, r = len - 1, pos = -1;       // 找左侧第一个 > nums[j] 的位置
        while (l <= r) {
            int m = l + (r - l) / 2;
            if (ends[m] > nums[j]) { pos = m; r = m - 1; }
            else l = m + 1;
        }
        int lans = (pos == -1) ? len : pos;
        ans = max(ans, lans + k + rightLen[j]);

        l = 0; r = len - 1; pos = -1;           // 把 nums[i] 并入左侧
        while (l <= r) {
            int m = l + (r - l) / 2;
            if (ends[m] > nums[i]) { pos = m; r = m - 1; }
            else l = m + 1;
        }
        if (pos == -1) ends[len++] = nums[i];
        else ends[pos] = nums[i];
    }
    ans = max(ans, len + k);                    // 修改区间落到数组末尾
    return ans;
}

int main() {
    vector<int> a = {10, 9, 2, 5, 3, 7, 101, 18};
    std::cout << "LIS(严格) = " << LIS(a, true) << "\n";                    // 4
    std::cout << "LIS(不下降) = " << LIS({2,2,2}, false) << "\n";           // 3
    vector<vector<int>> env = {{5,4},{6,4},{6,7},{2,3}};
    std::cout << "套娃信封 = " << maxEnvelopes(env) << "\n";                // 3
    std::cout << "K 递增最少修改 = " << kIncreasing({5,4,3,2,1}, 1) << "\n";// 4
    vector<vector<int>> pairs = {{1,2},{2,3},{3,4}};
    std::cout << "最长数对链 = " << findLongestChainGreedy(pairs) << "\n";  // 2
    std::cout << "一次修改后最长不下降 = " << longestAfterChange({1,2,3,4,5}, 1) << "\n"; // 5
    return 0;
}
```

## 深化补充

### 为什么 ends 数组能代表 LIS

设 `ends[i]` = "所有长度为 i+1 的递增子序列中，**结尾最小值**"。它有三条性质：

1. `ends` 是**严格递增**的（长度更长的子序列，其最小结尾一定更大）；
2. 对每个新元素 x，所有"结尾 < x"的长度都能接上 x；
3. 把 x 放到"第一个 `ends >= x`"的位置，恰好让该长度的结尾更小（不会让任何长度变得不可达）。

所以 `ends` 的长度就是当前能构造出的最长长度；扫描完整个数组，它就是 LIS 长度。

### 手算演练：`[10,9,2,5,3,7,101,18]`

| 处理 | ends 变化 | 长度 |
| --- | --- | --- |
| 10 | [10] | 1 |
| 9 | [9] | 1 |
| 2 | [2] | 1 |
| 5 | [2,5] | 2 |
| 3 | [2,3] | 2 |
| 7 | [2,3,7] | 3 |
| 101 | [2,3,7,101] | 4 |
| 18 | [2,3,7,18] | 4 |

最终答案 4（例如 `2,3,7,101` 或 `2,3,7,18`）。

### 与 O(n²) DP 的对比

| 版本 | 状态 | 转移 | 复杂度 |
| --- | --- | --- | --- |
| 基础 DP | `dp[i]` 以 i 结尾 | 枚举所有 j<i | O(n²) |
| 贪心 + 二分 | `ends` 数组 | 二分第一个 ≥ x | O(n log n) |

### 进阶拓展

- **值域 LIS**：`dp[i] = 1 + max(dp[j])`，其中 `nums[j] < nums[i]`，用树状数组维护前缀最大值，O(n log V)；
- **输出方案**：存 `pre[i]` 前驱，最后从最优结尾回溯；
- **LIS 计数**：再开一个 `cnt[i]` 统计"以 i 结尾的最长长度方案数"，合并时注意去重。
