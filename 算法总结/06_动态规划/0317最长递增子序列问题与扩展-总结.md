# 最长递增子序列（LIS）问题与扩展

> 来源笔记：`0317最长递增子序列问题与扩展.cpp`｜核心程度：必背（O(n log n) 最优解）｜分类：06 动态规划

## 一句话

LIS 的最优解 = **贪心 + 二分**：维护 `ends[len]` 表示"长度为 len+1 的递增子序列的最小结尾值"；新数 x 就用二分找到 `ends` 里第一个 `>= x` 的位置并替换它，找不到就追加——`ends` 的长度就是 LIS 长度。

## 核心原理（笔记原文）

> "依然着眼于某个上升子序列的结尾元素：已经得到的上升子序列的**结尾数越小**，那么后面接上一个数时，越有可能构成长度更长的上升子序列。"

于是 `ends` 数组保持**严格升序**，更新规则：

- 找 `ends[0..len-1]` 中第一个 `>= x` 的位置：找到就**替换**（让结尾更小）；
- 找不到（所有值都 `< x`）：**追加**到末尾，`len++`；
- 答案就是 `len`。

**严格递增 vs 不下降**：只在二分条件上差一个号——

- 严格递增：找第一个 **`>= x`** 的位置；
- 最长不下降：找第一个 **`> x`** 的位置。

```cpp
// ends[0..len-1] 严格升序，找第一个 >= x 的位置，不存在返回 -1
int bs(const vector<int>& ends, int len, int x) {
    int ans = -1;
    for (int l = 0, r = len - 1; l <= r; ) {
        int m = l + (r - l) / 2;
        if (ends[m] >= x) { ans = m; r = m - 1; }
        else l = m + 1;
    }
    return ans;
}
```

## 五道题

### 题一：LIS / 最长不下降子序列（LeetCode 300）

- 先给 O(n²) 的 DP：`dp[i] = 1 + max{dp[j] : j < i, nums[j] < nums[i]}`；
- 再给 O(n log n) 的 `ends + 二分` 最优解；
- 不下降子序列只需把二分条件换成 `> x`。

**答题心法（笔记的重要问答）**：

- **相邻无关**的子序列问题（如 0-1 背包）适合"**选或不选**"；
- **相邻相关**的子序列问题（如 LIS）适合"**枚举选哪个**"——枚举"当前必选 i，再枚举前一个必选 j"；硬用"选或不选"会额外记录"上一个选的数"，空间从 O(n) 变 O(n²)。

### 题二：俄罗斯套娃信封（LeetCode 354）

**排序 + LIS**：

- 宽度**从小到大**；宽度相同时，高度**从大到小**；
- 然后对高度数组求 LIS（宽度相同的那组因为高度降序，天然不会被同时选中）。

### 题三：使数组 K 递增的最少操作次数（LeetCode 2111）

**分组 + LIS**：按下标模 k 分成 k 组，每组内部要变成"不下降"；

```
ans += 组大小 - 该组的最长不下降子序列长度
```

因为每组的非 LIS 元素改成"合适的值"即可。

### 题四：最长数对链（LeetCode 646）

- 法一（LIS 思路）：按 left 升序排序，`ends` 里存 right；替换时取 `min(ends[find], right)`（**查询与更新分离**）；
- 法二（更优的贪心）：**按 right 升序排序**，`pre` 记录上一个选中数对的 right，`left > pre` 就选它。

### 题五：有一次修改机会的最长不下降子序列（洛谷 P8776）

思路：把要修改的连续 k 个数放在中间，即 `..., a, k个可任意修改的数, b, ...`：

1. 求出"a 左侧最长不下降子序列长度"（用 `ends` + 二分维护，`f1` 找第一个 `> x`）；
2. 加上 k（修改的这 k 个数一定都能接上）；
3. 加上"b 右侧的最长不下降子序列长度"（`right_[i]`，**从右往左**用"最长不上升子序列"的二分 `f2` 预处理）；
4. 枚举分界点 i，滚动更新答案，最后别忘了"修改区间覆盖到数组末尾"的情况 `len + k`。

## 适用特征（看到这些信号就选它）

- "最长递增/不下降/不上升子序列"；
- 二维偏序（宽度和高度都要更大）→ 先排序转一维 LIS；
- "最少修改几个数使数组单调"→ 总数减 LIS；
- 需要"某位置左侧/右侧的最长子序列"→ 预处理 `ends` 或 `right[]`（正反两遍）。

## 复杂度

- O(n log n) 时间、O(n) 空间（`ends` 数组）；
- 笔记提醒：这题也能用线段树做，复杂度相同，但需要理解线段树。

## 易错点

1. `ends` 数组里存的**不是子序列本身**，只是"每个长度的最小结尾值"，别试图还原子序列（要还原得另存前驱）；
2. 严格递增用 `>= x`、不下降用 `> x`，两者差一个等号；
3. 套娃信封的排序：宽度升序、**高度必须降序**（否则同宽度的会被误选）；
4. 替换时要取 `min`（数对链题）；
5. 反向求"以 i 开头的最长不下降"时，等价于"从右往左看的最长不上升"（二分条件反转）；
6. 二分的返回值 -1 表示"所有值都比 x 小"，要 `len++`。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. LIS：O(n log n) ----------
// strict = true 求严格递增；false 求最长不下降
int LIS(const vector<int>& a, bool strict = true) {
    int n = (int)a.size();
    vector<int> ends(n);
    int len = 0;
    for (int x : a) {
        // 找第一个满足条件的位置：严格递增找 >= x，不下降找 > x
        int l = 0, r = len - 1, pos = -1;
        while (l <= r) {
            int m = l + (r - l) / 2;
            bool ok = strict ? (ends[m] >= x) : (ends[m] > x);
            if (ok) { pos = m; r = m - 1; }
            else l = m + 1;
        }
        if (pos == -1) ends[len++] = x;   // 追加
        else ends[pos] = x;               // 替换，让结尾更小
    }
    return len;
}

// ---------- 2. 俄罗斯套娃信封 ----------
int maxEnvelopes(vector<vector<int>> env) {
    sort(env.begin(), env.end(), [](const vector<int>& a, const vector<int>& b) {
        return a[0] != b[0] ? a[0] < b[0] : a[1] > b[1];   // 宽升序，高降序
    });
    vector<int> heights;
    heights.reserve(env.size());
    for (auto& e : env) heights.push_back(e[1]);
    return LIS(heights, true);
}

// ---------- 3. 使数组 K 递增的最少操作次数 ----------
int kIncreasing(const vector<int>& arr, int k) {
    int n = (int)arr.size(), ans = 0;
    for (int i = 0; i < k; i++) {
        vector<int> group;
        for (int j = i; j < n; j += k) group.push_back(arr[j]);
        ans += (int)group.size() - LIS(group, false);   // 不下降
    }
    return ans;
}

// ---------- 4. 最长数对链（贪心：按 right 升序） ----------
int findLongestChain(vector<vector<int>> pairs) {
    sort(pairs.begin(), pairs.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
    int ans = 0, pre = INT_MIN;
    for (auto& p : pairs)
        if (p[0] > pre) { ans++; pre = p[1]; }
    return ans;
}
```
