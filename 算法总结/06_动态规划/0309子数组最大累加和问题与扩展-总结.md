# 子数组最大累加和问题与扩展

> 来源笔记：`0309子数组最大累加和问题与扩展.cpp`｜核心程度：必背（笔试面试高频）｜分类：06 动态规划

## 一句话

子数组类 DP 的定义关键词是"**必须以 i 结尾，往左延伸**"（或"以 i 开头往右延伸"）；把这条线想清楚，最大和、不能相邻、环形、乘积、二维压缩这些变体都是同一套。

## 上篇：六道题

### 题一：子数组最大累加和（LeetCode 53）

```
dp[i] = max(nums[i], nums[i] + dp[i-1])        // 不延伸 或 接着左面延伸
```

空间压缩成一个变量 `cur` 即可。

**变式（重要）：要求返回最大和子数组的下标范围**

用 `pre` 记录当前段的累加和：`pre >= 0` 就吸收，否则**换开头**（`pre = nums[r]; l = r;`），同时用 `sum/left/right` 记录最优。

### 题二：不能选相邻元素的最大累加和（LeetCode 198）

```
dp[i] = max(dp[i-1], nums[i] + dp[i-2])
```

base case：`dp[0] = nums[0]`、`dp[1] = max(nums[0], nums[1])`（笔记特别标注这里是易错点）。

### 题三：环形数组的子数组最大累加和（LeetCode 918）

两种情况：

1. 子数组不跨边界 → 普通最大子数组和；
2. 子数组跨边界 → 它等价于"**总和 - 中间那段的最小子数组和**"。

答案 = `max(最大子数组和, 总和 - 最小子数组和)`；

**特判**：`总和 == 最小子数组和` 时（例如全负）不能返回 0（题目要求非空），直接返回最大子数组和。

### 题四：环形数组打家劫舍（LeetCode 213）

**拆环**：`max(不偷 nums[0] 的 [1, n-1], 偷 nums[0] 的 nums[0] + [2, n-2])`。

### 题五：打家劫舍 IV（LeetCode 2560，二分答案 + DP）

要求"至少偷 k 间且单间金额的最大值最小"：

- 二分"能力值 able"；
- `f(able)` = 在"只能偷金额 ≤ able 的房子、且不能偷相邻"条件下的**最多偷几间**（DP：`dp[i] = max(dp[i-1], (able >= nums[i] ? 1 : 0) + dp[i-2])`）；
- 判断 `f(able) >= k`；
- **小贪心优化**：因为"偷一间的收益都是 1"，所以只要 `able >= nums[i]` 就直接偷（`i++` 跳过下一间），等价于"能偷就偷"。

### 题六：子矩阵最大累加和（面试题 17.24）

**二维压缩成一维**：枚举上边界 `up`，把 `up..down` 的每一列求和压成一个一维数组，再在它上面跑"返回下标的子数组最大累加和"。复杂度 O(n²·m)。

## 下篇：六道题

### 题一：乘积最大子数组（LeetCode 152）

因为负数相乘会变号，所以要**同时维护最大和最小乘积**：

```
curmax = max(nums[i], max(premax*nums[i], premin*nums[i]))
curmin = min(nums[i], min(premax*nums[i], premin*nums[i]))
```

### 题二：子序列累加和必须被 7 整除的最大累加和

**状态里带余数**：`dp[i][j]` = 前 i 个数形成的子序列中，累加和 `%7 == j` 的最大和（-1 表示不存在）：

```
need = (j - nums[i] % 7 + 7) % 7;
dp[i][j] = max(dp[i-1][j], dp[i-1][need] == -1 ? -1 : dp[i-1][need] + nums[i]);
```

答案 `dp[n][0]`。

### 题三：魔法卷轴（2 个卷轴把连续一段变成 0）

讨论用 0 / 1 / 2 个卷轴三种情况：

- 1 个：`prefix[i]` = "0~i 上一定用 1 次卷轴"的最大累加和 = `max(nums[i] + prefix[i-1], 当前最大前缀和)`；
- 2 个：再对称地求 `suffix[i]`（i~n-1 上一定用 1 次），然后枚举分界点 `prefix[i-1] + suffix[i]`；
- **两个数组必须错开**（连上就等于只用了 1 个卷轴）。

### 题四：三个无重叠子数组的最大和（LeetCode 689）

构造三个信息数组：

1. `sum[i]`：从 i 开始长度 k 的子数组和（滑动窗口预处理）；
2. `prefix[i]`：0~i 范围内最大长度 k 子数组的**开头下标**；
3. `suffix[i]`：i~n-1 范围内最大长度 k 子数组的开头下标。

枚举中间那段的开头 `i`（`prefix[i-1] + sum[i] + suffix[i+k]` 取最大）。

### 题五：允许翻转一次的子数组最大累加和

- `preDP[i]`：以 i 结尾往左延伸的最大和；
- `sufDP[i]`：以 i 开头往右延伸的最大和；
- 翻转能把"左边某段"和"右边某段"接起来 → 枚举分界点 `sufDP[i] + maxPreSum`；
- 笔记附了对数器暴力验证代码。

### 题六：删掉 1 个数字后长度为 k 的子数组最大累加和

**每个长度 k+1 的窗口，减去窗口内的最小值**：滑动窗口求和 + **单调队列**求窗口最小值。

## 适用特征（看到这些信号就选它）

- "连续子数组"的"最大/最小和"；
- "不能选相邻元素"→ 打家劫舍模型；
- 环形 → 拆成"不跨边界"和"跨边界（总和减最小）"；
- 维度太高 → 压缩维度（二维压一维、用余数/模数压缩状态）。

## 易错点

1. 打家劫舍的 `dp[1] = max(nums[0], nums[1])` 不能写成 `nums[1]`；
2. 环形最大和必须特判"全负"（不能返回空子数组的 0）；
3. 乘积题忘了维护"最小值"；
4. 魔法卷轴的两个数组要错开一位；
5. 子矩阵压缩时，`up` 固定后要**重置压缩数组**；
6. 需要下标时用"pre >= 0 就吸收、否则换开头"的写法，别只记最大和。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 1) 子数组最大累加和（空间压缩）
int maxSubArray(const vector<int>& a) {
    int cur = a[0], ans = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        cur = max(a[i], cur + a[i]);
        ans = max(ans, cur);
    }
    return ans;
}

// 2) 最大和子数组的区间（返回 {left, right, sum}）
array<int,3> maxSubArrayRange(const vector<int>& a) {
    int n = (int)a.size();
    int left = 0, right = 0, sum = INT_MIN, pre = INT_MIN;
    for (int l = 0, r = 0; r < n; r++) {
        if (pre >= 0) pre += a[r];            // 吸收左面有利可图
        else { pre = a[r]; l = r; }           // 否则换开头
        if (pre > sum) { sum = pre; left = l; right = r; }
    }
    return {left, right, sum};
}

// 3) 环形数组最大子数组和
int maxSubarraySumCircular(const vector<int>& a) {
    int all = a[0], maxSum = a[0], minSum = a[0];
    int maxPre = a[0], minPre = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        maxPre = max(a[i], a[i] + maxPre);
        minPre = min(a[i], a[i] + minPre);
        maxSum = max(maxSum, maxPre);
        minSum = min(minSum, minPre);
        all += a[i];
    }
    return all == minSum ? maxSum : max(maxSum, all - minSum);   // 特判全负
}

// 4) 打家劫舍（不能相邻）
int rob(const vector<int>& a) {
    int prepre = 0, pre = 0;
    for (int x : a) {
        int cur = max(pre, prepre + x);
        prepre = pre; pre = cur;
    }
    return pre;
}

// 5) 乘积最大子数组
int maxProduct(const vector<int>& a) {
    int premax = a[0], premin = a[0], ans = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        int curmax = max(a[i], max(premax * a[i], premin * a[i]));
        int curmin = min(a[i], min(premax * a[i], premin * a[i]));
        premax = curmax; premin = curmin;
        ans = max(ans, premax);
    }
    return ans;
}
```
