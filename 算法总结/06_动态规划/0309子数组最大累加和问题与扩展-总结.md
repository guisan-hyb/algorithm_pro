# 子数组最大累加和问题与扩展

> 来源笔记：`0309子数组最大累加和问题与扩展.cpp`｜核心程度：必背（笔试面试高频）｜分类：06 动态规划

## 一句话

子数组类 DP 的定义关键词是"**必须以 i 结尾，往左延伸**"（或"以 i 开头往右延伸"）。把这条线想清楚，最大和、不能相邻、环形、乘积、二维压缩都是同一套骨架。

## 解决什么问题

- 连续子数组的最大 / 最小和；
- 不能选相邻元素的最大和（打家劫舍）；
- 环形数组上的最大和 / 打家劫舍；
- 乘积最大子数组；
- 子矩阵最大和（二维压缩）；
- 带额外约束的子数组（被 7 整除、删一个数、翻转一次）。

## 核心思想

### Kadane 的定义

`dp[i]` = **以 nums[i] 结尾**的子数组的最大和。

为什么是"以 i 结尾"？因为子数组必须连续：

- 要么 `nums[i]` 自己单独成段；
- 要么接在"以 i-1 结尾的最优段"后面。

```
dp[i] = max(nums[i], nums[i] + dp[i - 1])
```

全局答案是 `max(dp[i])`——注意不是 `dp[n-1]`，因为最优段可能在中间结束。

### 为什么这个定义是对的

任何以 i 结尾的子数组，去掉最后一个元素后，要么为空（只剩 nums[i]），要么是以 i-1 结尾的某个子数组。后者取最大值，就是 `dp[i-1]`。所以两种可能取 max 覆盖了全部情况。

## 手算演练

`nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`：

| i | nums[i] | 单独成段 | 接上前一段 | dp[i] |
| --- | --- | --- | --- | --- |
| 0 | -2 | -2 | — | -2 |
| 1 | 1 | 1 | -1 | 1 |
| 2 | -3 | -3 | -2 | -2 |
| 3 | 4 | 4 | 2 | 4 |
| 4 | -1 | -1 | 3 | 3 |
| 5 | 2 | 2 | 5 | 5 |
| 6 | 1 | 1 | 6 | 6 |
| 7 | -5 | -5 | 1 | 1 |
| 8 | 4 | 4 | 5 | 5 |

最大是 `dp[6] = 6`，对应子数组 `[4,-1,2,1]`。

## 上篇：六道题

### 题一：子数组最大累加和（LeetCode 53）

空间压缩成一个变量 `cur`：

```cpp
cur = max(nums[i], cur + nums[i]);
answer = max(answer, cur);
```

**变式：要求返回最大和子数组的下标范围**

用 `pre` 记录当前段的累加和：`pre >= 0` 就吸收，否则**换开头**（`pre = nums[r]; left = r;`），同时记录最优的 `left/right/sum`。

### 题二：不能选相邻元素的最大累加和（LeetCode 198）

```
dp[i] = max(dp[i-1], nums[i] + dp[i-2])
```

base：`dp[0] = nums[0]`、`dp[1] = max(nums[0], nums[1])`（第二个是易错点）。

### 题三：环形数组的子数组最大累加和（LeetCode 918）

两种情况：

1. 不跨边界 → 普通最大子数组和；
2. 跨边界 → 等价于"**总和 - 中间那段的最小子数组和**"。

答案 = `max(最大子数组和, 总和 - 最小子数组和)`。

**特判**：`总和 == 最小子数组和`（全负）时不能返回 0（题目要求非空），直接返回最大子数组和。

### 题四：环形数组打家劫舍（LeetCode 213）

拆环：`max(不偷 nums[0] 的 [1,n-1], 偷 nums[0] 的 nums[0] + [2,n-2])`。

### 题五：打家劫舍 IV（LeetCode 2560，二分答案 + DP）

要求"至少偷 k 间且单间金额的最大值最小"：

- 二分"能力值 able"；
- `f(able)` = 只能偷金额 ≤ able、且不能偷相邻时的最多偷几间；
- 判断 `f(able) >= k`；
- **小贪心优化**：偷一间的收益都是 1，所以只要 `able >= nums[i]` 就直接偷（`i++` 跳过下一间）。

### 题六：子矩阵最大累加和（面试题 17.24）

**二维压缩成一维**：枚举上边界 `up`，把 `up..down` 的每一列求和压成一维数组，再跑"返回下标的子数组最大和"。复杂度 O(n²·m)。

## 下篇：六道题

### 题一：乘积最大子数组（LeetCode 152）

负数相乘会变号，所以要**同时维护最大和最小乘积**：

```
curMax = max(nums[i], max(preMax*nums[i], preMin*nums[i]))
curMin = min(nums[i], min(preMax*nums[i], preMin*nums[i]))
```

### 题二：子序列累加和必须被 7 整除的最大累加和

状态带余数：`dp[i][j]` = 前 i 个数形成的子序列中，累加和 `%7 == j` 的最大和（-1 表示不存在）：

```
need = (j - nums[i] % 7 + 7) % 7
dp[i][j] = max(dp[i-1][j], dp[i-1][need] + nums[i])
```

答案 `dp[n][0]`。

### 题三：魔法卷轴（2 个卷轴把连续一段变成 0）

讨论用 0 / 1 / 2 个卷轴：

- 1 个：`prefix[i] = max(nums[i] + prefix[i-1], 历史最大前缀和)`；
- 2 个：对称求 `suffix[i]`，枚举分界点 `prefix[i-1] + suffix[i]`；
- **两个数组必须错开**（连上就等于只用了 1 个）。

### 题四：三个无重叠子数组的最大和（LeetCode 689）

构造三个数组：`sum[i]`（从 i 起长 k 的和）、`prefix[i]`（0~i 内最大 k 段的开头）、`suffix[i]`（i~n-1 内最大 k 段的开头），枚举中间段。

### 题五：允许翻转一次的子数组最大累加和

- `preDp[i]`：以 i 结尾往左延伸的最大和；
- `sufDp[i]`：以 i 开头往右延伸的最大和；
- 翻转能把"左边某段"和"右边某段"接起来 → 枚举分界点 `sufDp[i] + maxPreSum`。

### 题六：删掉 1 个数字后长度为 k 的子数组最大累加和

每个长度 k+1 的窗口，**减去窗口内的最小值**：滑动窗口求和 + 单调队列求最小值。

## 适用特征（看到这些信号就选它）

- "连续子数组"的"最大 / 最小和"；
- "不能选相邻元素"→ 打家劫舍模型；
- 环形 → 拆成"不跨边界"和"跨边界（总和减最小）"；
- 维度太高 → 压缩维度（二维压一维、用余数压缩状态）。

## 复杂度

| 题 | 时间 | 空间 |
| --- | --- | --- |
| 最大子数组和 | O(n) | O(1) |
| 打家劫舍 | O(n) | O(1) |
| 环形最大和 | O(n) | O(1) |
| 打家劫舍 IV | O(n log V) | O(1) |
| 子矩阵最大和 | O(n²m) | O(m) |
| 乘积最大 | O(n) | O(1) |

## 与相似算法对比

| 方法 | 适用 | 复杂度 | 备注 |
| --- | --- | --- | --- |
| Kadane DP | 连续、求和 | O(n) | 最通用 |
| 前缀和 + 哈希 | 和为定值、含负数 | O(n) | 见 `1226` |
| 滑动窗口 | 非负数、最值 | O(n) | 有负数失效 |
| 分治 | 最大子数组和 | O(n log n) | 面试可展示思路 |
| 单调队列 | 窗口最值 | O(n) | 删一个数取最小值 |

## 易错点

1. 打家劫舍的 `dp[1] = max(nums[0], nums[1])` 不能写成 `nums[1]`；
2. 环形最大和必须特判全负（不能返回空子数组的 0）；
3. 乘积题忘了维护最小值；
4. 魔法卷轴的两个数组要错开一位；
5. 子矩阵压缩时，`up` 固定后要重置压缩数组；
6. 需要下标时用"pre >= 0 就吸收、否则换开头"，别只记最大和。

## 模板（可直接编译运行）

```cpp
// 子数组最大累加和模板：最大和/区间、打家劫舍、环形、乘积、子矩阵、余数状态、卷轴、三无重叠
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <climits>
#include <iostream>
#include <vector>
using namespace std;

// ================= 1. 最大子数组和 + 区间 =================
int maxSubArray(const vector<int>& a) {
    int cur = a[0], ans = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        cur = max(a[i], cur + a[i]);
        ans = max(ans, cur);
    }
    return ans;
}
array<int,3> maxSubArrayRange(const vector<int>& a) {   // {left, right, sum}
    int n = (int)a.size();
    int left = 0, right = 0, sum = INT_MIN, pre = INT_MIN;
    for (int l = 0, r = 0; r < n; r++) {
        if (pre >= 0) pre += a[r];                       // 吸收左面有利可图
        else { pre = a[r]; l = r; }                      // 否则换开头
        if (pre > sum) { sum = pre; left = l; right = r; }
    }
    return {left, right, sum};
}

// ================= 2. 环形数组最大子数组和 =================
int maxSubarraySumCircular(const vector<int>& a) {
    int all = a[0], maxSum = a[0], minSum = a[0];
    int maxPre = a[0], minPre = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        maxPre = max(a[i], a[i] + maxPre);
        minPre = min(a[i], a[i] + minPre);
        maxSum = max(maxSum, maxPre);
        minSum = min(minSum, minPre);
        all += a[i];
    }
    return all == minSum ? maxSum : max(maxSum, all - minSum);   // 全负特判
}

// ================= 3. 打家劫舍（不能相邻） =================
int rob(const vector<int>& a) {
    int prepre = 0, pre = 0;
    for (int x : a) { int cur = max(pre, prepre + x); prepre = pre; pre = cur; }
    return pre;
}
int robCircular(const vector<int>& a) {                  // 环形版
    int n = (int)a.size();
    if (n == 1) return a[0];
    auto best = [&](int l, int r) {
        int prepre = 0, pre = 0;
        for (int i = l; i <= r; i++) { int cur = max(pre, prepre + a[i]); prepre = pre; pre = cur; }
        return pre;
    };
    return max(best(1, n - 1), a[0] + best(2, n - 2));
}

// ================= 4. 乘积最大子数组（同时维护 max/min） =================
int maxProduct(const vector<int>& a) {
    int premax = a[0], premin = a[0], ans = a[0];
    for (int i = 1; i < (int)a.size(); i++) {
        int curmax = max(a[i], max(premax * a[i], premin * a[i]));
        int curmin = min(a[i], min(premax * a[i], premin * a[i]));
        premax = curmax; premin = curmin;
        ans = max(ans, premax);
    }
    return ans;
}

// ================= 5. 子矩阵最大累加和（返回左上/右下坐标） =================
vector<int> getMaxMatrix(const vector<vector<int>>& m) {
    int rows = (int)m.size(), cols = (int)m[0].size();
    vector<int> nums(cols);
    int x1 = 0, y1 = 0, x2 = 0, y2 = 0, sum = INT_MIN;
    for (int up = 0; up < rows; up++) {
        fill(nums.begin(), nums.end(), 0);
        for (int down = up; down < rows; down++) {
            int pre = INT_MIN, l = 0;
            for (int r = 0; r < cols; r++) {
                nums[r] += m[down][r];
                if (pre >= 0) pre += nums[r];
                else { pre = nums[r]; l = r; }
                if (pre > sum) { sum = pre; x1 = up; x2 = down; y1 = l; y2 = r; }
            }
        }
    }
    return {x1, y1, x2, y2};
}

// ================= 6. 子序列和被 7 整除的最大和（余数进状态） =================
int maxSumDivisibleBy7(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<vector<int>> dp(n + 1, vector<int>(7, -1));   // -1 表示不存在
    dp[0][0] = 0;
    for (int i = 1; i <= n; i++) {
        int cur = nums[i - 1] % 7;
        for (int j = 0; j < 7; j++) {
            dp[i][j] = dp[i - 1][j];                     // 不要 nums[i-1]
            int need = (j - cur + 7) % 7;
            if (dp[i - 1][need] != -1)
                dp[i][j] = max(dp[i][j], dp[i - 1][need] + nums[i - 1]);
        }
    }
    return max(0, dp[n][0]);
}

// ================= 7. 魔法卷轴（2 个卷轴把连续一段变 0） =================
int magicScroll(const vector<int>& nums) {
    int n = (int)nums.size();
    int p1 = 0;
    for (int x : nums) p1 += x;                          // 0 个卷轴

    vector<int> prefix(n, 0);                            // 0~i 一定用 1 次
    int maxPreSum = max(0, nums[0]);
    for (int i = 1, curSum = nums[0]; i < n; i++) {
        prefix[i] = max(nums[i] + prefix[i - 1], maxPreSum);
        curSum += nums[i];
        maxPreSum = max(maxPreSum, curSum);
    }
    int p2 = prefix[n - 1];

    vector<int> suffix(n, 0);                            // i~n-1 一定用 1 次
    int maxSufSum = max(nums[n - 1], 0);
    for (int i = n - 2, curSum = nums[n - 1]; i >= 0; i--) {
        suffix[i] = max(nums[i] + suffix[i + 1], maxSufSum);
        curSum += nums[i];
        maxSufSum = max(maxSufSum, curSum);
    }
    int p3 = INT_MIN;
    for (int i = 1; i < n; i++) p3 = max(p3, prefix[i - 1] + suffix[i]);
    return max(max(p1, p2), p3);
}

// ================= 8. 三个无重叠子数组的最大和（k 固定） =================
vector<int> maxSumOfThreeSubarrays(const vector<int>& nums, int k) {
    int n = (int)nums.size();
    vector<int> sum(n, 0), prefix(n, 0), suffix(n, 0);
    for (int l = 0, r = 0, cur = 0; r < n; r++) {        // sum[i]：从 i 起长 k 的和
        cur += nums[r];
        if (r - l + 1 == k) { sum[l] = cur; cur -= nums[l]; l++; }
    }
    for (int i = k; i < n; i++)
        prefix[i] = sum[prefix[i - 1]] >= sum[i - k + 1] ? prefix[i - 1] : i - k + 1;
    suffix[n - k] = n - k;
    for (int i = n - k - 1; i >= 0; i--)
        suffix[i] = sum[i] >= sum[suffix[i + 1]] ? i : suffix[i + 1];

    int a = 0, b = 0, c = 0, best = 0;
    for (int i = k, j = 2 * k - 1; j <= n - k - 1; i++, j++) {
        int p = prefix[i - 1], s = suffix[j + 1];
        int cur = sum[p] + sum[i] + sum[s];
        if (cur > best) { best = cur; a = p; b = i; c = s; }
    }
    return {a, b, c};
}

int main() {
    vector<int> a = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    auto r = maxSubArrayRange(a);
    std::cout << "最大子数组和 = " << r[2] << " (下标 " << r[0] << "~" << r[1] << ")\n";   // 6 (3~6)
    std::cout << "环形最大和 = " << maxSubarraySumCircular({5,-3,5}) << "\n";  // 10
    std::cout << "打家劫舍 = " << rob({2,7,9,3,1}) << "\n";                    // 12
    std::cout << "乘积最大 = " << maxProduct({2,3,-2,4}) << "\n";              // 6
    std::cout << "被7整除最大和 = " << maxSumDivisibleBy7({4,3,2,1}) << "\n";  // 7
    return 0;
}
```

## 进阶拓展

1. **分治解法**：最大子数组和可以 O(n log n) 分治（左、右、跨中点），面试可讲。
2. **前缀和 + 哈希**：求和为定值的子数组（可含负数），见 `1226`。
3. **单调队列**：窗口内最小值 / 最大值，配合滑动窗口求和。
4. **状态带余数**：把"和"换成"和 mod k"，可处理整除类约束。
5. **二维压缩**：子矩阵问题都能"枚举行、压缩成列、跑一维 Kadane"。

## 面试追问

1. **Kadane 为什么只需一个变量？** `dp[i]` 只依赖 `dp[i-1]`，滚动即可。
2. **环形为什么用"总和减最小"？** 跨边界子数组的补集是中间一段连续子数组。
3. **全负时为什么不能返回 0？** 子数组要求非空，0 不是任何子数组的和。
4. **乘积为什么同时维护 min？** 负数相乘会翻转大小关系。
5. **二维子矩阵怎么降到 O(n²m)？** 枚举行边界，把列压成一维。
