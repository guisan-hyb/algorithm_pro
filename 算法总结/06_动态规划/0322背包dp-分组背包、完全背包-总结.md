# 背包 DP（二）：分组背包与完全背包

> 来源笔记：`0322背包dp-分组背包、完全背包.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

**分组背包**：每组只能取 1 件，对"不取 / 取哪一件"展开；**完全背包**：每种物品可以取无限次，转移时"用**同一层**的结果"（空间压缩后就是容量**从左往右**遍历）。

## 题目一：分组背包模板（洛谷 P1757）

`dp[i][j]` = 前 i **组**、容量不超过 j 的最大价值（注意 i 是"组号"）：

```
dp[i][j] = max( dp[i-1][j],                              // 不取这一组
                max over 组内每件 (dp[i-1][j-w] + v) );   // 取组内某一件
```

复杂度 O(物品数 × 容量)（不会升阶）。

## 题目二：从栈中取出 K 个硬币的最大面值和（LeetCode 2218）

每个栈等价于"一个组"，组内必须从顶部连续取 k 个：

- 对每个栈做**前缀和** `preSum[t]`；
- 分组背包：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-k] + preSum[k])`，`k` 从 0 枚举到 `min(栈长度, j)`。

## 题目三：完全背包模板（洛谷 P1616）

`dp[i][j]` = 前 i 种商品、每种可取任意个、容量不超过 j 的最大价值：

```
dp[i][j] = max(dp[i-1][j], dp[i][j - cost[i]] + val[i]);
                                  ^^^ 注意是"同一层 i"
```

空间压缩后变成**容量从左往右**遍历（与 01 背包正好相反）：

```cpp
for (int i = 1; i <= m; i++)
    for (int j = cost[i]; j <= t; j++)        // ★从左往右
        dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
```

## 题目四：正则表达式匹配（LeetCode 10）——`*` 就是"完全背包"

`*` 的含义：把它和**前一个字符**当作整体，可以匹配 0 次、1 次、2 次……

递归定义 `f(sIdx, pIdx)`（`p[pIdx]` 一定不是 `*`）：

- `s` 用完时：`p` 也用完 → true；否则要求 `p[pIdx+1] == '*'` 且 `f(sIdx, pIdx+2)`（把 `x*` 整个消掉）；
- `p` 用完但 `s` 没完 → false；
- `p[pIdx+1] != '*'`：`(p[pIdx] == s[sIdx] || p[pIdx] == '.') && f(sIdx+1, pIdx+1)`；
- `p[pIdx+1] == '*'`（**完全背包的两支**）：
  - 不让 `x*` 匹配当前字符：`f(sIdx, pIdx+2)`；
  - 让它匹配一个字符：`(匹配) && f(sIdx+1, pIdx)`（**pIdx 不动**，可以继续吃更多）。

改迭代时按"从后往前"填 `dp[i][j]`，初始化 `dp[m][n] = 1` 以及最后一行（`s` 用完后的可消除后缀）。

## 题目五：通配符匹配（LeetCode 44）

与正则高度相似，边界更简单：

- `?` 匹配任意单字符；`*` 匹配任意字符串（包括空串）；
- `dp[i][j] = (p[j]==s[i] || p[j]=='?') && dp[i+1][j+1]`；
- `p[j]=='*'`：`dp[i][j] = dp[i][j+1] || dp[i+1][j]`（`*` 消掉 或 吃一个字符）；
- 初始化：`dp[m][n] = 1`，最后一行 `dp[m][j] = (p[j]=='*' && dp[m][j+1])`。

## 题目六：购买足量干草的最小花费（洛谷 P2918）

完全背包的变体："**至少**买 h 数量的干草，花最少钱"。

- `dp[i][j]` = 前 i 家公司、数量**恰好**为 j 的最小花费；
- **关键：数组要扩充**（最多扩充"单份干草数量的最大值"），因为"恰好为 j"的定义有缺陷（例如只能买每份 3 单位时，7 是买不到的，但买 9 可以满足"至少 7"）；
- 答案是 `min(dp[n][h..h+m])`。

## 适用特征（看到这些信号就选它）

| 题面特征 | 模型 |
| --- | --- |
| "每组只能选一个" | 分组背包 |
| "每种物品可以取无限次" | 完全背包（容量正序遍历） |
| 模式串里的 `*`（可匹配 0..n 次） | 完全背包思想 |
| "至少满足某个量" | 完全背包 + 数组扩充 / 取后缀最小值 |

## 易错点

1. **完全背包与 01 背包的唯一区别就是容量维的遍历方向**（正序 vs 倒序），记牢；
2. 分组背包的枚举顺序：外层组、中层容量、内层组内物品；
3. 正则匹配里 `p[pIdx+1]=='*'` 分支的 `pIdx` **不动**（这才是"可以吃多个"）；
4. 通配符匹配的 `*` 与正则的 `*` 语义不同，不能互相套用；
5. "至少"类完全背包要**扩充数组**再取后缀最小；
6. 二维 DP 不空间压缩时可能超时/超内存（笔记明确说完全背包不压缩过不了全部样例）。

## 模板（可直接编译运行）

```cpp
// 分组背包 / 完全背包 / 正则匹配 / 通配符匹配 / 足量干草模板
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <iostream>
#include <string>
#include <utility>
#include <vector>
using namespace std;

// ================= 1. 分组背包（每组最多取一件） =================
int groupKnapsack(int cap, const vector<vector<pair<int,int>>>& groups) {
    vector<long long> dp(cap + 1, 0);
    for (auto& g : groups) {
        for (int j = cap; j >= 0; j--)                 // ★容量倒序
            for (auto& it : g)
                if (j >= it.first)
                    dp[j] = max(dp[j], dp[j - it.first] + (long long)it.second);
    }
    return (int)dp[cap];
}

// ================= 2. 从栈中取 K 个硬币（分组背包 + 前缀和） =================
int maxValueOfCoins(const vector<vector<int>>& piles, int k) {
    int n = (int)piles.size();
    vector<vector<int>> dp(n + 1, vector<int>(k + 1, 0));
    for (int i = 1; i <= n; i++) {
        const vector<int>& nums = piles[i - 1];
        int t = min((int)nums.size(), k);
        vector<int> pre(t + 1, 0);
        for (int j = 1; j <= t; j++) pre[j] = pre[j - 1] + nums[j - 1];
        for (int j = 0; j <= k; j++) {
            dp[i][j] = dp[i - 1][j];
            for (int c = 0; c <= t && c <= j; c++)
                dp[i][j] = max(dp[i][j], dp[i - 1][j - c] + pre[c]);
        }
    }
    return dp[n][k];
}

// ================= 3. 完全背包（容量正序） =================
long long completeKnapsack(int cap, const vector<int>& cost, const vector<int>& val) {
    vector<long long> dp(cap + 1, 0);
    for (size_t i = 0; i < cost.size(); i++)
        for (int j = cost[i]; j <= cap; j++)           // ★容量正序
            dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
    return dp[cap];
}

// ================= 4. 正则表达式匹配 =================
bool isMatchRegex(const string& s, const string& p) {
    int m = (int)s.size(), n = (int)p.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    dp[m][n] = 1;
    for (int j = n - 1; j >= 0; j--)
        dp[m][j] = (j + 1 < n && p[j + 1] == '*' && dp[m][j + 2]);
    for (int i = m - 1; i >= 0; i--) {
        for (int j = n - 1; j >= 0; j--) {
            if (j + 1 == n || p[j + 1] != '*') {
                dp[i][j] = (p[j] == s[i] || p[j] == '.') && dp[i + 1][j + 1];
            } else {
                bool p1 = dp[i][j + 2];                                    // x* 匹配 0 次
                bool p2 = (p[j] == s[i] || p[j] == '.') && dp[i + 1][j];   // 匹配 1 次且继续
                dp[i][j] = p1 || p2;
            }
        }
    }
    return dp[0][0];
}

// ================= 5. 通配符匹配 =================
bool isMatchWildcard(const string& s, const string& p) {
    int m = (int)s.size(), n = (int)p.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    dp[m][n] = 1;
    for (int j = n - 1; j >= 0; j--) dp[m][j] = (p[j] == '*' && dp[m][j + 1]);
    for (int i = m - 1; i >= 0; i--) {
        for (int j = n - 1; j >= 0; j--) {
            if (p[j] != '*') dp[i][j] = (p[j] == s[i] || p[j] == '?') && dp[i + 1][j + 1];
            else             dp[i][j] = dp[i][j + 1] || dp[i + 1][j];   // 消掉 * 或吃一个字符
        }
    }
    return dp[0][0];
}

// ================= 6. 购买足量干草的最小花费（完全背包 + 数组扩充） =================
int minHayCost(int h, const vector<int>& cost, const vector<int>& amount) {
    int n = (int)cost.size(), extra = 0;
    for (int a : amount) extra = max(extra, a);        // 最多扩充"单份最大值"
    vector<vector<int>> dp(n + 1, vector<int>(h + extra + 1, INT_MAX));
    for (int i = 0; i <= n; i++) dp[i][0] = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= h + extra; j++) {
            dp[i][j] = dp[i - 1][j];
            if (j >= amount[i - 1] && dp[i][j - amount[i - 1]] != INT_MAX)
                dp[i][j] = min(dp[i][j], dp[i][j - amount[i - 1]] + cost[i - 1]);
        }
    int ans = INT_MAX;
    for (int j = h; j <= h + extra; j++) ans = min(ans, dp[n][j]);   // 至少 h
    return ans;
}

int main() {
    vector<vector<pair<int,int>>> groups = {{{2,3},{3,5}}, {{1,4}}};
    std::cout << "分组背包 = " << groupKnapsack(4, groups) << "\n";        // 7
    vector<vector<int>> piles = {{1,100,3},{7,8,9}};
    std::cout << "取 K 个硬币 = " << maxValueOfCoins(piles, 2) << "\n";     // 101
    std::cout << "完全背包 = " << completeKnapsack(10, {5,3}, {20,12}) << "\n";  // 40
    std::cout << "正则 = " << (int)isMatchRegex("aa", "a*") << ", 通配符 = " << (int)isMatchWildcard("cb", "?a") << "\n";  // 1 0
    std::cout << "足量干草最小花费 = " << minHayCost(7, {5}, {3}) << "\n";  // 15
    return 0;
}
```

## 深化补充

### 完全背包为什么正序

完全背包的二维转移是 `dp[i][j] = max(dp[i-1][j], dp[i][j-w] + v)`，注意第二项用的是**同一层 i**。压成一维后，正序遍历 j 时 `dp[j-w]` 已经是"本层更新过"的值，正好对应"可以再选一次"。

### 分组背包为什么容量倒序

分组背包要求"每组最多选一件"。外层枚举组、中层倒序枚举容量、内层枚举组内物品：倒序保证每组只被选一次，内层枚举保证"选组内哪一件"。

### 正则表达式匹配的"完全背包"本质

`x*` 可以匹配 0 次、1 次、2 次……这正是"完全背包"的多选结构：

- 匹配 0 次：`f(i, j+2)`；
- 匹配 1 次并继续：`(匹配) && f(i+1, j)`（j 不动，可以继续吃）。

### 手算演练（完全背包）

容量 10，物品 `(w,v) = (5,20), (3,12)`：

- 只选 (5,20)：最多 2 件，价值 40；
- 只选 (3,12)：最多 3 件（9 容量），价值 36；
- 混选：5+3=8，价值 32；5+5=40；3+3+3=36。

答案 40。

### 进阶拓展

- **完全背包计数**：`dp[j] += dp[j-w]`（求方案数，不是最大价值）；
- **多重背包**：二进制分组转 01 背包（见 `0325`）；
- **二维费用**：容量维变二维（见 `0306`）；
- **单调队列优化**：完全背包本身 O(nW)，多重背包可用单调队列做到 O(nW)。
