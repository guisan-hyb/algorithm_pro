# 背包 DP（二）：分组背包与完全背包

> 来源笔记：`0322背包dp-分组背包、完全背包.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

**分组背包**：每组只能取 1 件，对"不取 / 取哪一件"展开；**完全背包**：每种物品可以取无限次，转移时"用**同一层**的结果"（空间压缩后就是容量**从左往右**遍历）。

## 题目一：分组背包模板（洛谷 P1757）

`dp[i][j]` = 前 i **组**、容量不超过 j 的最大价值（注意 i 是"组号"）：

```
dp[i][j] = max( dp[i-1][j],                              // 不取这一组
                max over 组内每件 (dp[i-1][j-w] + v) );   // 取组内某一件
```

复杂度 O(物品数 × 容量)（不会升阶）。

## 题目二：从栈中取出 K 个硬币的最大面值和（LeetCode 2218）

每个栈等价于"一个组"，组内必须从顶部连续取 k 个：

- 对每个栈做**前缀和** `preSum[t]`；
- 分组背包：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-k] + preSum[k])`，`k` 从 0 枚举到 `min(栈长度, j)`。

## 题目三：完全背包模板（洛谷 P1616）

`dp[i][j]` = 前 i 种商品、每种可取任意个、容量不超过 j 的最大价值：

```
dp[i][j] = max(dp[i-1][j], dp[i][j - cost[i]] + val[i]);
                                  ^^^ 注意是"同一层 i"
```

空间压缩后变成**容量从左往右**遍历（与 01 背包正好相反）：

```cpp
for (int i = 1; i <= m; i++)
    for (int j = cost[i]; j <= t; j++)        // ★从左往右
        dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
```

## 题目四：正则表达式匹配（LeetCode 10）——`*` 就是"完全背包"

`*` 的含义：把它和**前一个字符**当作整体，可以匹配 0 次、1 次、2 次……

递归定义 `f(sIdx, pIdx)`（`p[pIdx]` 一定不是 `*`）：

- `s` 用完时：`p` 也用完 → true；否则要求 `p[pIdx+1] == '*'` 且 `f(sIdx, pIdx+2)`（把 `x*` 整个消掉）；
- `p` 用完但 `s` 没完 → false；
- `p[pIdx+1] != '*'`：`(p[pIdx] == s[sIdx] || p[pIdx] == '.') && f(sIdx+1, pIdx+1)`；
- `p[pIdx+1] == '*'`（**完全背包的两支**）：
  - 不让 `x*` 匹配当前字符：`f(sIdx, pIdx+2)`；
  - 让它匹配一个字符：`(匹配) && f(sIdx+1, pIdx)`（**pIdx 不动**，可以继续吃更多）。

改迭代时按"从后往前"填 `dp[i][j]`，初始化 `dp[m][n] = 1` 以及最后一行（`s` 用完后的可消除后缀）。

## 题目五：通配符匹配（LeetCode 44）

与正则高度相似，边界更简单：

- `?` 匹配任意单字符；`*` 匹配任意字符串（包括空串）；
- `dp[i][j] = (p[j]==s[i] || p[j]=='?') && dp[i+1][j+1]`；
- `p[j]=='*'`：`dp[i][j] = dp[i][j+1] || dp[i+1][j]`（`*` 消掉 或 吃一个字符）；
- 初始化：`dp[m][n] = 1`，最后一行 `dp[m][j] = (p[j]=='*' && dp[m][j+1])`。

## 题目六：购买足量干草的最小花费（洛谷 P2918）

完全背包的变体："**至少**买 h 数量的干草，花最少钱"。

- `dp[i][j]` = 前 i 家公司、数量**恰好**为 j 的最小花费；
- **关键：数组要扩充**（最多扩充"单份干草数量的最大值"），因为"恰好为 j"的定义有缺陷（例如只能买每份 3 单位时，7 是买不到的，但买 9 可以满足"至少 7"）；
- 答案是 `min(dp[n][h..h+m])`。

## 适用特征（看到这些信号就选它）

| 题面特征 | 模型 |
| --- | --- |
| "每组只能选一个" | 分组背包 |
| "每种物品可以取无限次" | 完全背包（容量正序遍历） |
| 模式串里的 `*`（可匹配 0..n 次） | 完全背包思想 |
| "至少满足某个量" | 完全背包 + 数组扩充 / 取后缀最小值 |

## 易错点

1. **完全背包与 01 背包的唯一区别就是容量维的遍历方向**（正序 vs 倒序），记牢；
2. 分组背包的枚举顺序：外层组、中层容量、内层组内物品；
3. 正则匹配里 `p[pIdx+1]=='*'` 分支的 `pIdx` **不动**（这才是"可以吃多个"）；
4. 通配符匹配的 `*` 与正则的 `*` 语义不同，不能互相套用；
5. "至少"类完全背包要**扩充数组**再取后缀最小；
6. 二维 DP 不空间压缩时可能超时/超内存（笔记明确说完全背包不压缩过不了全部样例）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 分组背包 ----------
// items[group] = { {w, v}, ... }，每组最多取一件
int groupKnapsack(int cap, const vector<vector<pair<int,int>>>& items) {
    vector<int> dp(cap + 1, 0);
    for (auto& group : items) {
        for (int j = cap; j >= 0; j--) {              // ★容量倒序
            for (auto& it : group) {
                if (j >= it.first)
                    dp[j] = max(dp[j], dp[j - it.first] + it.second);
            }
        }
    }
    return dp[cap];
}

// ---------- 2. 完全背包 ----------
int completeKnapsack(int cap, const vector<int>& cost, const vector<int>& val) {
    vector<long long> dp(cap + 1, 0);
    int n = (int)cost.size();
    for (int i = 0; i < n; i++)
        for (int j = cost[i]; j <= cap; j++)          // ★容量正序
            dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
    return (int)dp[cap];
}

// ---------- 3. 正则表达式匹配 ----------
bool isMatchRegex(const string& s, const string& p) {
    int m = (int)s.size(), n = (int)p.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    dp[m][n] = 1;
    for (int j = n - 1; j >= 0; j--)                  // s 用完后可消掉的后缀
        dp[m][j] = (j + 1 < n && p[j + 1] == '*' && dp[m][j + 2]);
    for (int i = m - 1; i >= 0; i--) {
        for (int j = n - 1; j >= 0; j--) {
            if (j + 1 == n || p[j + 1] != '*') {
                dp[i][j] = (p[j] == s[i] || p[j] == '.') && dp[i + 1][j + 1];
            } else {
                bool p1 = dp[i][j + 2];                          // x* 匹配 0 次
                bool p2 = (p[j] == s[i] || p[j] == '.') && dp[i + 1][j]; // 匹配 1 次且继续
                dp[i][j] = p1 || p2;
            }
        }
    }
    return dp[0][0];
}

// ---------- 4. 通配符匹配 ----------
bool isMatchWildcard(const string& s, const string& p) {
    int m = (int)s.size(), n = (int)p.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    dp[m][n] = 1;
    for (int j = n - 1; j >= 0; j--) dp[m][j] = (p[j] == '*' && dp[m][j + 1]);
    for (int i = m - 1; i >= 0; i--) {
        for (int j = n - 1; j >= 0; j--) {
            if (p[j] != '*') dp[i][j] = (p[j] == s[i] || p[j] == '?') && dp[i + 1][j + 1];
            else             dp[i][j] = dp[i][j + 1] || dp[i + 1][j];
        }
    }
    return dp[0][0];
}
```
