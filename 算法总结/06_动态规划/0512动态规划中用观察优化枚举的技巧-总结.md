# 动态规划中用观察优化枚举的技巧

> 来源笔记：`0512动态规划中用观察优化枚举的技巧.cpp`｜核心程度：必背（DP 进阶）｜分类：06 动态规划

## 一句话

DP 的复杂度 ≈ **状态数 × 每个状态的枚举代价**；当枚举代价高时，**从记忆化改写成严格位置依赖的迭代版**（为了建立"空间感"），再通过观察把枚举压成 O(1)（前缀和、滑动窗口、单调队列、二分、查询结构）。

## 为什么要写迭代版

笔记明确回答：不只是为了空间压缩，**更关键的是通过"位置依赖"看清格子之间的关系**，从而发现可以优化的枚举。

## 上篇：买卖股票系列 + DI 序列

### 题一：只能买卖一次（LeetCode 121）

维护历史最低价 `minPrice`，`ans = max(ans, price - minPrice)`。

### 题二：不限次数（LeetCode 122）

把每一段上涨都赚到：`ans += max(0, prices[i] - prices[i-1])`。

### 题三：最多两笔（LeetCode 123）——**观察优化枚举的样板**

不优化的写法里 `dp2[i]` 要枚举 `j`：

```
dp2[i] = max over j ( dp1[j] + prices[i] - prices[j] )
```

**观察**：`dp1[j] - prices[j]` 与 `i` 无关 → 预处理 `best[i] = max(best[i-1], dp1[i] - prices[i])`，于是 `dp2[i] = best[i] + prices[i]`，枚举消失。

最后还能把三行揉成一个循环并把数组压成三个变量。

### 题四：最多 k 笔（LeetCode 188）

- 剪枝：`k >= n/2` 时退化成"不限次数"（所有上坡都能吃到）；
- 不优化版：`dp[i][j] = max(dp[i][j-1], max over p (dp[i-1][p] + prices[j] - prices[p]))`，枚举 p 是 O(n)；
- **优化**：`best` 随 j 滚动维护 `dp[i-1][p] - prices[p]` 的最大值，枚举消失，复杂度从 O(kn²) 降到 O(kn)；
- 再空间压缩成一维（注意用 `tmp` 保存旧值）。

### 题五：含手续费（LeetCode 714）

记忆化：`f(i, hold)`，持有则 `max(继续持有, 卖出+价格)`，不持有则 `max(跳过, 买入-价格-手续费)`。

### 题六：含冷冻期（LeetCode 309）

卖出的下一步要跳到 `i+2`（冷冻一天）：`f(i+2, 0) + prices[i]`。

### 题七：DI 序列的有效排列（LeetCode 903）——**"猜法很妙"的状态设计**

难点：数字是几并不重要，**只要知道"剩余数字中有几个比前一个数字小"**，状态就确定了：

- `dp[i][less]`：正在填第 i 个位置，剩余可选数字中比 `perm[i-1]` 小的有 `less` 个；
- `s[i-1] == 'D'` → 下一个数字要比当前小，枚举 `nxtless ∈ [0, less)`；
- `s[i-1] == 'I'` → 枚举 `nxtless ∈ [less, n-i)`；
- 枚举是区间求和 → **前缀和优化**：D 分支用前缀和正着累加，I 分支倒着累加。

笔记还回答了一个细节问题：记忆化是 `n × (n+1)` 个格子，而迭代版要 `(n+1) × (n+1)`——因为迭代没有 base case 兜底，要多准备一行存"越界时的返回值"。

## 下篇：观察 + 二分 / 滑动窗口

### 题一：规划兼职工作（LeetCode 1235）

- 按**结束时间**升序排序；
- `dp[i] = max(dp[i-1], 不冲突的前一份的 dp + profit[i])`；
- "找最近一份结束时间 ≤ 当前开始时间的工作"→ **二分**（因为已按结束时间有序）。

### 题二：K 个逆序对数组（LeetCode 629）——**滑动窗口优化枚举**

`dp[i][j]` = 1~i 的排列中恰有 j 个逆序对的个数；把最大数 e 插到倒数第 p 位会新增 p 个逆序对：

```
dp[i][j] = Σ dp[i-1][p]，p ∈ [max(0, j-i+1), j]
```

这是一段**滑动窗口求和** → 用 `slideWindow` 滚动维护：

```
slideWindow += dp[i-1][j];
if (j >= i) slideWindow -= dp[i-1][j-i];
dp[i][j] = slideWindow;
```

笔记还给了"记忆化 + 前缀和"的等价推导：`dp[i][j] = dp[i][j-1] + dp[i-1][j] - dp[i-1][j-i]`。

> 笔记末尾注明：下篇的题目三、四（"观察并设计高效的查询结构"）**本节留空**，后续再讲。

## 适用特征（看到这些信号就选它）

- DP 转移里出现 `max/min over j` 或 `sum over j` 的**连续区间**；
- 该区间端点随 i 单调移动 → 前缀和 / 滑动窗口 / 单调队列；
- 转移项能拆成"与 i 无关的量" → 预处理后 O(1)；
- 需要"找最近满足条件的位置"→ 排序 + 二分。

## 易错点

1. 先写出**不优化的版本**（或用记忆化），再谈优化——否则容易想漏；
2. 滑动窗口/前缀和的下标区间要精确（`max(0, j-i+1)` 这类边界）；
3. 空间压缩时旧值要先 `tmp` 备份（滚动更新顺序）；
4. 股票题 `k >= n/2` 的剪枝不能漏（否则复杂度爆炸）；
5. DI 序列题的状态设计（"还剩几个比前一个小的数"）是核心，数字本身无关；
6. 迭代版比记忆化多一行/一列（存越界返回值）。

## 模板（可直接编译运行）

```cpp
// 优化枚举模板：股票系列 / DI 序列（前缀和）/ K 个逆序对（滑窗）/ 兼职工作（二分）
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <climits>
#include <functional>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= 1. 一次交易 =================
int maxProfitOnce(const vector<int>& prices) {
    int ans = 0, minPrice = INT_MAX;
    for (int p : prices) {
        ans = max(ans, p - minPrice);
        minPrice = min(minPrice, p);
    }
    return ans;
}

// ================= 2. 无限次交易 =================
int maxProfitUnlimited(const vector<int>& prices) {
    int ans = 0;
    for (int i = 1; i < (int)prices.size(); i++)
        ans += max(0, prices[i] - prices[i - 1]);
    return ans;
}

// ================= 3. 最多两笔（预处理 best 消除枚举） =================
int maxProfitTwo(const vector<int>& prices) {
    int n = (int)prices.size();
    if (n < 2) return 0;
    int dp1 = 0, best = -prices[0], dp2 = 0, ans = 0;
    for (int i = 1, minPrice = prices[0]; i < n; i++) {
        minPrice = min(minPrice, prices[i]);
        dp1 = max(dp1, prices[i] - minPrice);
        best = max(best, dp1 - prices[i]);       // 滚动维护 max(dp1[p] - prices[p])
        dp2 = best + prices[i];
        ans = max(ans, dp2);
    }
    return ans;
}

// ================= 4. 最多 k 笔（O(kn)） =================
int maxProfitK(int k, const vector<int>& prices) {
    int n = (int)prices.size();
    if (k >= n / 2) return maxProfitUnlimited(prices);   // 剪枝
    vector<int> dp(n, 0);
    for (int t = 1; t <= k; t++) {
        int best = dp[0] - prices[0];
        for (int j = 1; j < n; j++) {
            int tmp = dp[j];
            dp[j] = max(dp[j - 1], best + prices[j]);
            best = max(best, tmp - prices[j]);
        }
    }
    return dp[n - 1];
}

// ================= 5. 含手续费 / 含冷冻期（记忆化） =================
int maxProfitWithFee(vector<int>& prices, int fee) {
    int n = (int)prices.size();
    vector<vector<int>> dp(n + 1, vector<int>(2, 0));
    for (int i = n - 1; i >= 0; i--) {
        dp[i][1] = max(dp[i + 1][1], dp[i + 1][0] + prices[i]);          // 持有
        dp[i][0] = max(dp[i + 1][0], dp[i + 1][1] - prices[i] - fee);    // 不持有
    }
    return dp[0][0];
}
int maxProfitWithCooldown(vector<int>& prices) {
    int n = (int)prices.size();
    vector<vector<int>> dp(n + 2, vector<int>(2, 0));
    for (int i = n - 1; i >= 0; i--) {
        dp[i][1] = max(dp[i + 1][1], dp[i + 2][0] + prices[i]);          // 卖完要跳过一天
        dp[i][0] = max(dp[i + 1][0], dp[i + 1][1] - prices[i]);
    }
    return dp[0][0];
}

// ================= 6. DI 序列有效排列（前缀和优化） =================
int numPermsDISequence(const string& s) {
    const long long MOD = 1000000007;
    int n = (int)s.size() + 1;
    vector<vector<long long>> dp(n + 1, vector<long long>(n + 1, 0));
    for (int less = 0; less <= n; less++) dp[n][less] = 1;
    for (int i = n - 1; i >= 0; i--) {
        if (i == 0 || s[i - 1] == 'D') {
            dp[i][1] = dp[i + 1][0];
            for (int less = 2; less <= n; less++)
                dp[i][less] = (dp[i][less - 1] + dp[i + 1][less - 1]) % MOD;
        } else {
            dp[i][n - i - 1] = dp[i + 1][n - i - 1];
            for (int less = n - i - 2; less >= 0; less--)
                dp[i][less] = (dp[i][less + 1] + dp[i + 1][less]) % MOD;
        }
    }
    return (int)dp[0][n];
}

// ================= 7. K 个逆序对（滑动窗口优化） =================
int kInversePairs(int n, int k) {
    const long long MOD = 1000000007;
    vector<vector<long long>> dp(n + 1, vector<long long>(k + 1, 0));
    for (int i = 0; i <= n; i++) dp[i][0] = 1;
    for (int i = 1; i <= n; i++) {
        long long window = 1;
        for (int j = 1; j <= k; j++) {
            window += dp[i - 1][j];
            if (j >= i) window -= dp[i - 1][j - i];
            window = (window % MOD + MOD) % MOD;
            dp[i][j] = window;
        }
    }
    return (int)dp[n][k];
}

// ================= 8. 规划兼职工作（排序 + 二分） =================
int jobScheduling(vector<int> startTime, vector<int> endTime, vector<int> profit) {
    int n = (int)startTime.size();
    vector<array<int,3>> info(n);
    for (int i = 0; i < n; i++) info[i] = {endTime[i], startTime[i], profit[i]};
    sort(info.begin(), info.end());
    vector<int> dp(n, 0), ends(n);
    for (int i = 0; i < n; i++) ends[i] = info[i][0];
    dp[0] = info[0][2];
    for (int i = 1; i < n; i++) {
        int s = info[i][1], p = info[i][2];
        int pos = (int)(lower_bound(ends.begin(), ends.begin() + i, s + 1) - ends.begin()) - 1;
        dp[i] = max(dp[i - 1], p + (pos >= 0 ? dp[pos] : 0));
    }
    return dp[n - 1];
}

int main() {
    std::cout << "一次交易 = " << maxProfitOnce({7,1,5,3,6,4}) << "\n";        // 5
    std::cout << "无限次 = " << maxProfitUnlimited({7,1,5,3,6,4}) << "\n";      // 7
    std::cout << "最多两笔 = " << maxProfitTwo({3,3,5,0,0,3,1,4}) << "\n";      // 6
    std::cout << "最多 k=2 笔 = " << maxProfitK(2, {3,3,5,0,0,3,1,4}) << "\n";   // 6
    std::cout << "DI 排列数 = " << numPermsDISequence("DID") << "\n";           // 5
    std::cout << "K 个逆序对 = " << kInversePairs(3, 1) << "\n";                // 2
    std::cout << "兼职最大报酬 = " << jobScheduling({1,2,3,3}, {3,4,5,6}, {50,10,40,70}) << "\n"; // 120
    return 0;
}
```

## 从“晚优化”谈起：“为什么先写迭代表”

枚举优化最怕“凭空猜”。先把暴力转移写成二维表，就能看见每一个格子依赖的是哪一行、哪一段连续列：

```text
单点依赖       -> 滚动变量
同列前缀依赖   -> 前缀最值 / 前缀和
同列窗口依赖   -> 滑动窗口 / 单调队列
有序位置依赖   -> 二分
值域范围依赖   -> 树状数组 / 线段树
```

因此迭代版不是“记忆化的替代品”，而是**发现依赖形状的显微镜**。

## 手算演练：最多两笔交易

价格 `[3,3,5,0,0,3,1,4]`，从左到右维护：

| 下标 | 价格 | 当前最低价 | `dp1`（一笔） | `best`（第二笔买入前最优差） | `dp2`（两笔） |
| --- | --- | --- | --- | --- | --- |
| 0 | 3 | 3 | 0 | -3 | -3→0 |
| 2 | 5 | 3 | 2 | -1 | 4 |
| 5 | 3 | 0 | 3 | 0 | 3 |
| 7 | 4 | 0 | 4 | 0 | 4 |

最终仍有 6 的最优方案（0 买、3 卖；1 买、4 卖），滚动状态只是要配合“先更新前一笔旧值再更新后一笔”避免同一天买卖重叠。

## 优化方式对照

| 转移形状 | 暴力代价 | 优化工具 | 降到的代价 |
| --- | --- | --- | --- |
| `max(dp[j] - price[j]) + price[i]` | O(n) | 滚动最值 | O(1) |
| `sum dp[i-1][j]` 的固定窗口 | O(n) | 滑动窗口 | O(1) |
| 滑动窗口最值 | O(n) | 单调队列 | O(1) |
| 最近结束时间 ≤ 开始时间 | O(n) | 排序 + 二分 | O(log n) |
| 前缀/值域最大值 | O(n) | 树状数组 | O(log n) |

## 反例：为什么不能随意交换更新顺序

最多 `k` 笔交易用一维数组压缩，若当前交易层先写 `best` 再读旧 `dp[j]`，可能把“本层刚更新过的状态”当作上一层使用，变成同一天多次买入。

正确原则：**做空间压缩前先在纸上标出每个依赖属于本层还是上一层**。如果两者混用，就先用 `backup` 保存旧值，或保留两行数组。
