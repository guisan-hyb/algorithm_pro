# 背包 DP（一）：01 背包与有依赖的背包

> 来源笔记：`0320背包dp-01背包、有依赖的背包.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

01 背包 = 每个物品"**要和不要**"两种展开；有依赖的背包 = 把主件和它的附件**打包成一个复合物品**，对"不要 / 要哪几种组合"展开。

## 题目一：01 背包模板（洛谷 P1048）

`dp[i][j]` = 前 i 个物品、容量不超过 j 的最大价值：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-cost[i]] + val[i]);
```

**空间压缩（必背）**：一维 `dp[j]`，容量**从大到小**遍历（保证用的是"上一层"的数据）：

```cpp
for (int i = 1; i <= m; i++)
    for (int j = t; j >= cost[i]; j--)       // ★从右往左
        dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
```

## 题目二：夏季特惠（LeetCode 平台题，折扣即"增加预算"）

把"优惠额 - 现价"记作 `diff`：

- `diff >= 0`（买了反而赚/不亏）→ **一定要买**，直接累加快乐值，并把这部分优惠加到预算 `x` 上；
- `diff < 0` → 变成 01 背包的一个物品（代价 = `-diff`，收益 = 快乐值）。

最后答案 = "一定要买"的快乐值 + 背包 DP 的结果。

## 题目三：目标和（LeetCode 494）——一题四解，最经典的"转化"

给每个数加 `+` 或 `-`，问凑出 target 的方案数。四种做法：

1. DFS（暴力）；
2. 记忆化搜索（`sum` 可能是负数 → 用 `map<pair<i,sum>,int>` 或嵌套哈希表当缓存）；
3. **平移技巧**的动态规划：`dp[i][j + s]`（`s` = 数组元素和，把所有和整体平移成非负下标），注意 `nums[0] == 0` 时初值为 2；
4. **转化为 01 背包（最优）**：
   - 记正数集合和为 `sumA`、负数集合为 `sumB`，则 `sumA - sumB = target`，两式相加得 **`sumA = (sum + target) / 2`**；
   - 于是问题变成"有多少个子集和为 `(sum + target)/2`"；
   - 前提判断：`target > sum` 或 `target < -sum` 或 `(target + sum)` 为奇数 → 返回 0；
   - 数组里有负数也没关系（可以整体取绝对值）。

## 题目四：最后一块石头的重量 II（LeetCode 1049）

同样转化为"**选出和尽量接近 `sum/2` 的子集**"：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-stones[i]] + stones[i]);
答案 = (sum - dp[n-1][aim]) - dp[n-1][aim];
```

## 题目五：有依赖的背包模板（洛谷 P1064 金明的预算方案）

约束：每个主件最多 **2 个附件**，买附件必须先买主件。

**做法：把每个主件展开成 4 种购买组合**：

1. 不买主件；
2. 只买主件；
3. 主件 + 附件 1；
4. 主件 + 附件 2；
5. 主件 + 附件 1 + 附件 2（"我全都要"）。

实现要点：只对**主件**转移（`if (king[i])`），附件的信息存在 `follow[主件][0..1]`；`dp[i][j]` 的上一层用 `preMain`（上一个主件的编号），而不是 `i-1`。

## 题目六：非负数组前 k 个最小的子序列和（**01 背包不可行**的例子）

- n、k 都到 10^5，值也大 → 用 01 背包枚举所有可能的和会爆时间/空间；
- **正解：排序 + 小根堆（贪心）**：
  - 堆里存"当前子序列最右侧的下标 + 累加和"，初始 `{0, nums[0]}`；
  - 每次弹出最小的和，然后推入两个后继：`不换最右`（`sum - nums[right] + nums[right+1]`）与 `加上下一个`（`sum + nums[right+1]`）；
  - 第 1 小是空集 0；
  - 复杂度 O(n log n + k log k)，**只有在所有数非负时成立**。

## 题目七：找出数组的第 K 大子序列和（LeetCode 2386）

**转化为"第 k 小子序列和"**：

1. 把所有正数相加得到 `maxSum`（第 1 大）；
2. 把每个元素取绝对值，得到非负数组 `a`；
3. `nums` 的第 k 大子序列和 = `maxSum - a 的第 k 小子序列和`；
4. 第 k 小子序列和用题目六的堆方法求（第 1 小是空集 0）。

## 适用特征（看到这些信号就选它）

- "每个物品选或不选、容量有限、求最大价值/方案数" → 01 背包；
- 题目表面与背包无关，但能推出"选出一个子集使其和等于某值"（目标和、石头）→ 先**转化**再背包；
- 物品之间有"买了 A 才能买 B"的依赖且组合数少 → 展开成复合物品；
- 数据量大到背包不可行 → 换贪心/堆的做法。

## 复杂度

- 01 背包：O(n × 容量)，空间压缩后 O(容量)；
- 目标和转化后：O(n × aim)；
- 前 k 小子序列和：O(n log n + k log k)。

## 易错点

1. 空间压缩时**容量维度必须从大到小**（否则变成"完全背包"）；
2. 目标和转化前必须判断 `sum + target` 的**奇偶**与范围；
3. `nums[0] == 0` 这类边界（目标和题）初值要写对；
4. 有依赖背包的上一层是 `preMain` 不是 `i-1`；
5. 堆做前 k 小和时，堆里要存"最右下标"，并且**只在 `right + 1 < n` 时**推入后继；
6. 第 K 大转第 K 小时，注意下标对齐（第 1 大 ↔ 第 1 小 = 空集）。

## 模板（可直接编译运行）

```cpp
// 01 背包模板：基础 / 目标和转化 / 石头 / 前 k 小子序列和 / 第 K 大子序列和
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <cstdlib>
#include <functional>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

// ================= 1. 01 背包（空间压缩） =================
int knapsack01(int cap, const vector<int>& cost, const vector<int>& val) {
    vector<int> dp(cap + 1, 0);
    for (size_t i = 0; i < cost.size(); i++)
        for (int j = cap; j >= cost[i]; j--)              // ★容量倒序
            dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
    return dp[cap];
}

// ================= 2. 目标和 -> 子集和方案数（01 背包） =================
int findTargetSumWays(const vector<int>& nums, int target) {
    int sum = 0;
    for (int x : nums) sum += abs(x);
    if (target > sum || target < -sum || ((target + sum) & 1)) return 0;
    int aim = (target + sum) / 2;
    vector<int> dp(aim + 1, 0);
    dp[0] = 1;
    for (int x : nums) {
        int w = abs(x);
        for (int j = aim; j >= w; j--) dp[j] += dp[j - w];
    }
    return dp[aim];
}

// ================= 3. 最后一块石头的重量 II =================
int lastStoneWeightII(const vector<int>& stones) {
    int sum = 0;
    for (int s : stones) sum += s;
    int aim = sum / 2;
    vector<int> dp(aim + 1, 0);
    for (int s : stones)
        for (int j = aim; j >= s; j--)
            dp[j] = max(dp[j], dp[j - s] + s);
    return sum - 2 * dp[aim];
}

// ================= 4. 有依赖的背包（主件 + 最多 2 个附件） =================
// cost[i] / val[i] 为第 i 件的花费与收益；king[i] 表示 i 是主件
// follow[i][0..1] 为主件 i 的附件下标，fans[i] 为附件个数
int dependentKnapsack(int money, const vector<int>& cost, const vector<int>& val,
                      const vector<char>& king,
                      const vector<array<int,2>>& follow,
                      const vector<int>& fans) {
    int m = (int)cost.size() - 1;                        // 商品编号 1..m
    vector<vector<int>> dp(m + 1, vector<int>(money + 1, 0));
    int preMain = 0;
    for (int i = 1; i <= m; i++) {
        if (!king[i]) continue;
        int p1 = fans[i] >= 1 ? follow[i][0] : -1;
        int p2 = fans[i] >= 2 ? follow[i][1] : -1;
        for (int j = 0; j <= money; j++) {
            dp[i][j] = dp[preMain][j];                                  // 不要主件
            if (j >= cost[i])
                dp[i][j] = max(dp[i][j], dp[preMain][j - cost[i]] + val[i]);   // 只买主件
            if (p1 != -1 && j >= cost[i] + cost[p1])
                dp[i][j] = max(dp[i][j], dp[preMain][j - cost[i] - cost[p1]] + val[i] + val[p1]);
            if (p2 != -1 && j >= cost[i] + cost[p2])
                dp[i][j] = max(dp[i][j], dp[preMain][j - cost[i] - cost[p2]] + val[i] + val[p2]);
            if (p1 != -1 && p2 != -1 && j >= cost[i] + cost[p1] + cost[p2])
                dp[i][j] = max(dp[i][j], dp[preMain][j - cost[i] - cost[p1] - cost[p2]]
                                          + val[i] + val[p1] + val[p2]);
        }
        preMain = i;                                          // ★更新上一件主件
    }
    return dp[preMain][money];
}

// ================= 5. 非负数组前 k 小子序列和（排序 + 小根堆） =================
vector<long long> topKSmallestSubseqSum(vector<int> nums, int k) {
    sort(nums.begin(), nums.end());
    vector<long long> ans(k, 0);                              // ans[0] = 0（空集）
    if (k == 1) return ans;
    using State = array<long long,2>;                         // {最右下标, 当前和}
    priority_queue<State, vector<State>, greater<State>> pq;
    pq.push({0, nums[0]});
    for (int i = 1; i < k; i++) {
        State cur = pq.top(); pq.pop();
        ans[i] = cur[1];
        long long idx = cur[0], sum = cur[1];
        if (idx + 1 < (long long)nums.size()) {
            pq.push({idx + 1, sum - nums[idx] + nums[idx + 1]});   // 不换最右，接下一个
            pq.push({idx + 1, sum + nums[idx + 1]});               // 加上下一个
        }
    }
    return ans;
}

// ================= 6. 第 K 大子序列和 =================
long long kSum(vector<int> nums, int k) {
    long long maxSum = 0;
    for (int& x : nums) {
        if (x > 0) maxSum += x;
        else x = -x;                                          // 取绝对值
    }
    sort(nums.begin(), nums.end());
    if (k == 1) return maxSum;
    using State = array<long long,2>;
    priority_queue<State, vector<State>, greater<State>> pq;
    pq.push({0, nums[0]});
    long long aim = 0;                                        // 第 k 小的绝对值和
    for (int i = 1; i < k; i++) {
        State cur = pq.top(); pq.pop();
        aim = cur[1];
        long long idx = cur[0], sum = cur[1];
        if (idx + 1 < (long long)nums.size()) {
            pq.push({idx + 1, sum - nums[idx] + nums[idx + 1]});
            pq.push({idx + 1, sum + nums[idx + 1]});
        }
    }
    return maxSum - aim;
}

int main() {
    vector<int> cost = {1, 2, 3}, val = {1, 5, 8};
    std::cout << "01 背包 = " << knapsack01(4, cost, val) << "\n";        // 9
    std::cout << "目标和方案数 = " << findTargetSumWays({1,1,1,1,1}, 3) << "\n";  // 5
    std::cout << "最后石头重量 = " << lastStoneWeightII({2,7,4,1,8,1}) << "\n";   // 1
    std::cout << "第 3 小子序列和 = " << topKSmallestSubseqSum({1,2,3}, 3)[2] << "\n";  // 3
    std::cout << "第 2 大子序列和 = " << kSum({1,2,3,4,5}, 2) << "\n";  // 14
    return 0;
}
```

## 深化补充

### 为什么一维压缩必须倒序

二维式子是 `dp[i][j] = max(dp[i-1][j], dp[i-1][j-w] + v)`。压成一维后，`dp[j-w]` 必须表示"上一层"的值。

- 倒序遍历 j：`dp[j-w]` 还没被当前物品更新过 → 是上一层，正确；
- 正序遍历 j：`dp[j-w]` 可能已经被当前物品更新过 → 同一个物品被用了多次，变成完全背包。

**一句话**：倒序 = 每件物品只能用一次；正序 = 每件物品可以用无限次。

### 手算演练

容量 4，物品 `(w,v) = (1,1), (2,5), (3,8)`：

| 物品 | dp[0] | dp[1] | dp[2] | dp[3] | dp[4] |
| --- | --- | --- | --- | --- | --- |
| 初始 | 0 | 0 | 0 | 0 | 0 |
| (1,1) | 0 | 1 | 1 | 1 | 1 |
| (2,5) | 0 | 1 | 5 | 6 | 6 |
| (3,8) | 0 | 1 | 5 | 8 | 9 |

答案 9（选 (1,1)+(3,8)，或用 (2,5)+(1,1)+(1,1) 不合法因为只有一件 (1,1)）。

### 与完全背包的区别

| 背包 | 容量遍历 | 原因 |
| --- | --- | --- |
| 01 背包 | 倒序 | 每件只能用一次 |
| 完全背包 | 正序 | 每件可用无限次 |
| 分组背包 | 倒序 | 每组只能选一件 |

### 进阶拓展

- **恰好装满**：`dp[0]=0`，其余初始化为 `-INF`；
- **方案数**：把 `max` 换成 `sum`，注意初始化 `dp[0]=1`；
- **超大容量**：用 `map` 只存可达容量，或折半搜索（n ≤ 40）；
- **bitset 优化**：可行性问题可用 `bitset` 做位运算加速。
