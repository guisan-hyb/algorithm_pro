# 背包 DP（一）：01 背包与有依赖的背包

> 来源笔记：`0320背包dp-01背包、有依赖的背包.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

01 背包 = 每个物品"**要和不要**"两种展开；有依赖的背包 = 把主件和它的附件**打包成一个复合物品**，对"不要 / 要哪几种组合"展开。

## 题目一：01 背包模板（洛谷 P1048）

`dp[i][j]` = 前 i 个物品、容量不超过 j 的最大价值：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-cost[i]] + val[i]);
```

**空间压缩（必背）**：一维 `dp[j]`，容量**从大到小**遍历（保证用的是"上一层"的数据）：

```cpp
for (int i = 1; i <= m; i++)
    for (int j = t; j >= cost[i]; j--)       // ★从右往左
        dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
```

## 题目二：夏季特惠（LeetCode 平台题，折扣即"增加预算"）

把"优惠额 - 现价"记作 `diff`：

- `diff >= 0`（买了反而赚/不亏）→ **一定要买**，直接累加快乐值，并把这部分优惠加到预算 `x` 上；
- `diff < 0` → 变成 01 背包的一个物品（代价 = `-diff`，收益 = 快乐值）。

最后答案 = "一定要买"的快乐值 + 背包 DP 的结果。

## 题目三：目标和（LeetCode 494）——一题四解，最经典的"转化"

给每个数加 `+` 或 `-`，问凑出 target 的方案数。四种做法：

1. DFS（暴力）；
2. 记忆化搜索（`sum` 可能是负数 → 用 `map<pair<i,sum>,int>` 或嵌套哈希表当缓存）；
3. **平移技巧**的动态规划：`dp[i][j + s]`（`s` = 数组元素和，把所有和整体平移成非负下标），注意 `nums[0] == 0` 时初值为 2；
4. **转化为 01 背包（最优）**：
   - 记正数集合和为 `sumA`、负数集合为 `sumB`，则 `sumA - sumB = target`，两式相加得 **`sumA = (sum + target) / 2`**；
   - 于是问题变成"有多少个子集和为 `(sum + target)/2`"；
   - 前提判断：`target > sum` 或 `target < -sum` 或 `(target + sum)` 为奇数 → 返回 0；
   - 数组里有负数也没关系（可以整体取绝对值）。

## 题目四：最后一块石头的重量 II（LeetCode 1049）

同样转化为"**选出和尽量接近 `sum/2` 的子集**"：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-stones[i]] + stones[i]);
答案 = (sum - dp[n-1][aim]) - dp[n-1][aim];
```

## 题目五：有依赖的背包模板（洛谷 P1064 金明的预算方案）

约束：每个主件最多 **2 个附件**，买附件必须先买主件。

**做法：把每个主件展开成 4 种购买组合**：

1. 不买主件；
2. 只买主件；
3. 主件 + 附件 1；
4. 主件 + 附件 2；
5. 主件 + 附件 1 + 附件 2（"我全都要"）。

实现要点：只对**主件**转移（`if (king[i])`），附件的信息存在 `follow[主件][0..1]`；`dp[i][j]` 的上一层用 `preMain`（上一个主件的编号），而不是 `i-1`。

## 题目六：非负数组前 k 个最小的子序列和（**01 背包不可行**的例子）

- n、k 都到 10^5，值也大 → 用 01 背包枚举所有可能的和会爆时间/空间；
- **正解：排序 + 小根堆（贪心）**：
  - 堆里存"当前子序列最右侧的下标 + 累加和"，初始 `{0, nums[0]}`；
  - 每次弹出最小的和，然后推入两个后继：`不换最右`（`sum - nums[right] + nums[right+1]`）与 `加上下一个`（`sum + nums[right+1]`）；
  - 第 1 小是空集 0；
  - 复杂度 O(n log n + k log k)，**只有在所有数非负时成立**。

## 题目七：找出数组的第 K 大子序列和（LeetCode 2386）

**转化为"第 k 小子序列和"**：

1. 把所有正数相加得到 `maxSum`（第 1 大）；
2. 把每个元素取绝对值，得到非负数组 `a`；
3. `nums` 的第 k 大子序列和 = `maxSum - a 的第 k 小子序列和`；
4. 第 k 小子序列和用题目六的堆方法求（第 1 小是空集 0）。

## 适用特征（看到这些信号就选它）

- "每个物品选或不选、容量有限、求最大价值/方案数" → 01 背包；
- 题目表面与背包无关，但能推出"选出一个子集使其和等于某值"（目标和、石头）→ 先**转化**再背包；
- 物品之间有"买了 A 才能买 B"的依赖且组合数少 → 展开成复合物品；
- 数据量大到背包不可行 → 换贪心/堆的做法。

## 复杂度

- 01 背包：O(n × 容量)，空间压缩后 O(容量)；
- 目标和转化后：O(n × aim)；
- 前 k 小子序列和：O(n log n + k log k)。

## 易错点

1. 空间压缩时**容量维度必须从大到小**（否则变成"完全背包"）；
2. 目标和转化前必须判断 `sum + target` 的**奇偶**与范围；
3. `nums[0] == 0` 这类边界（目标和题）初值要写对；
4. 有依赖背包的上一层是 `preMain` 不是 `i-1`；
5. 堆做前 k 小和时，堆里要存"最右下标"，并且**只在 `right + 1 < n` 时**推入后继；
6. 第 K 大转第 K 小时，注意下标对齐（第 1 大 ↔ 第 1 小 = 空集）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 01 背包（空间压缩） ----------
int knapsack01(int cap, const vector<int>& cost, const vector<int>& val) {
    int n = (int)cost.size();
    vector<int> dp(cap + 1, 0);
    for (int i = 0; i < n; i++)
        for (int j = cap; j >= cost[i]; j--)          // ★倒序
            dp[j] = max(dp[j], dp[j - cost[i]] + val[i]);
    return dp[cap];
}

// ---------- 2. 目标和 -> 子集和等于 aim 的方案数 ----------
int findTargetSumWays(const vector<int>& nums, int target) {
    int sum = 0;
    for (int x : nums) sum += abs(x);
    if (target > sum || target < -sum || ((target + sum) & 1)) return 0;
    int aim = (target + sum) / 2;
    vector<int> dp(aim + 1, 0);
    dp[0] = 1;
    for (int x : nums) {
        x = abs(x);
        for (int j = aim; j >= x; j--) dp[j] += dp[j - x];
    }
    return dp[aim];
}

// ---------- 3. 最后一块石头的重量 II ----------
int lastStoneWeightII(const vector<int>& stones) {
    int sum = accumulate(stones.begin(), stones.end(), 0);
    int aim = sum / 2;
    vector<int> dp(aim + 1, 0);
    for (int s : stones)
        for (int j = aim; j >= s; j--)
            dp[j] = max(dp[j], dp[j - s] + s);
    return sum - 2 * dp[aim];
}

// ---------- 4. 非负数组前 k 小子序列和（排序 + 小根堆） ----------
vector<long long> topKSmallestSubseqSum(vector<int> nums, int k) {
    sort(nums.begin(), nums.end());
    vector<long long> ans(k, 0);
    if (k == 1) return ans;
    using State = array<long long,2>;                 // {最右下标, 当前和}
    priority_queue<State, vector<State>, greater<State>> pq;
    pq.push({0, nums[0]});
    for (int i = 1; i < k; i++) {
        State cur = pq.top(); pq.pop();
        ans[i] = cur[1];
        long long idx = cur[0], sum = cur[1];
        if (idx + 1 < (long long)nums.size()) {
            pq.push({idx + 1, sum - nums[idx] + nums[idx + 1]});   // 不换最右
            pq.push({idx + 1, sum + nums[idx + 1]});               // 加上下一个
        }
    }
    return ans;
}
```
