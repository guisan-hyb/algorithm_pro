# 对比：子序列 DP 与子数组 DP

> 来源笔记：`对比 子序列DP 和 子数组DP.md`｜性质：对照总结（高频易混点）｜分类：06 动态规划

## 核心概念区分

- **子数组**：原数组中**连续**的一段（强调连续性）；
- **子序列**：不改变相对顺序的任意子集，**不要求连续**（强调保序性）。

## 一、子数组 DP

### 状态套路

> **以 i 结尾的、满足某条件的子数组**。

原因：连续 ⇒ 只要知道"以 i-1 结尾"的最优解，接上 `nums[i]` 就能得到"以 i 结尾"的；或者在 `nums[i]` 处重新开始。

### 经典模型

| 题目 | 状态 | 转移 |
| --- | --- | --- |
| 最大子数组和 | `dp[i]` 以 i 结尾的最大和 | `max(nums[i], dp[i-1] + nums[i])` |
| 最长连续递增 | `dp[i]` 以 i 结尾的长度 | `nums[i] > nums[i-1] ? dp[i-1]+1 : 1` |
| 最长回文子串 | `dp[i][j]` 区间是否回文 | `s[i]==s[j] && (j-i<2 || dp[i+1][j-1])` |

### 子数组题的"降维打击"（往往不用 DP）

- **前缀和 + 哈希表**：和为定值、和被 K 整除（见 `1226构建前缀信息的技巧`）；
- **滑动窗口**：有单调性时的最长/最短子数组（见 `0101滑动窗口技巧`）；
- **单调栈**：子数组的最小/最大值之和（见 `0109单调栈`）。

## 二、子序列 DP

### 状态套路（两种）

1. **一维、以 i 结尾**：`dp[i]` = 以 `nums[i]` 结尾的最优解；
2. **二维、考虑前 i 个**：`dp[i]` = 考虑前 i 个元素的最优解（**不强制包含第 i 个**）；双串问题用 `dp[i][j]`。

### 经典模型

| 题目 | 状态 | 转移 |
| --- | --- | --- |
| LIS | `dp[i]` 以 i 结尾 | `dp[i] = max(dp[j]+1)`，`j<i && nums[j]<nums[i]` |
| LCS | `dp[i][j]` 前 i / 前 j | 相等 `dp[i-1][j-1]+1`；否则 `max(dp[i-1][j], dp[i][j-1])` |
| 最长回文子序列 | `dp[i][j]` 区间 | 相等 `dp[i+1][j-1]+2`；否则 `max(dp[i+1][j], dp[i][j-1])` |
| 背包 | 本质是"子序列选取" | 见背包三讲 |

> **关键区别**：子数组只看 `i-1`（O(1) 转移），子序列要看**前面所有 j**（O(n) 转移）——这就是"连续递增 O(n)"与"LIS O(n²)"的根源。

### 子序列 DP 的优化

- **贪心 + 二分**：LIS 的 `ends` 数组 → O(n log n)（见 `0317最长递增子序列问题与扩展`）；
- **树状数组 / 线段树**：转移依赖前面的某个**值域范围**时，维护前缀最值（见 `1002树状数组`）。

## 三、核心对比表

| 对比维度 | 子数组 DP | 子序列 DP |
| --- | --- | --- |
| 连续性 | 必须连续 | 不要求连续，但保持原序 |
| 状态依赖 | 通常只依赖紧邻的 `dp[i-1]`（区间 DP 除外） | 依赖前面所有状态 `dp[j]` 或 `dp[i-1][j-1]` |
| 转移代价 | O(1) | 多为 O(n) |
| 常见复杂度 | O(n) / O(n²) | O(n²)（可优化） |
| 替代算法 | 滑窗、前缀和+哈希、单调栈 | 二分、树状数组、背包 |
| 经典题型 | 最大子数组和、和为 K 的子数组 | LIS、LCS、背包、回文子序列 |

## 四、避坑指南

1. **"和为 K" 的子数组用前缀和哈希 O(n)；"和为 K" 的子序列是 0/1 背包 O(n·K)** —— 两者绝对不能混用；
2. 初始化差异：
   - 子数组 `dp[i]`：要求非空时，不符合条件要**重置**（如重置为 `nums[i]`）；
   - 子序列 `dp[i]`：通常初始化为 1（单个元素本身就是一个子序列）；
3. 看到"连续"先想非 DP 解法（滑窗 / 前缀和），DP 是保底。

## 五、一个重要的细节问答（笔记原文）

**问：求最终答案时，子序列有时不需要遍历 0~n-1，而子数组需要遍历？**

**答：取决于状态定义是"必须以 i 结尾"还是"考虑前 i 个"**：

| DP 类型 | 状态定义 | 求最终答案 | 典型例题 |
| --- | --- | --- | --- |
| 子数组 | 以 i 结尾 | **必须遍历** `max(dp)` | 最大子数组和 |
| 子序列 | 以 i 结尾 | **必须遍历** `max(dp)` | LIS |
| 子序列 | 考虑前 i 个 | **直接取 `dp[n]`** | LCS、背包 |

口诀：**"以 i 结尾"→ 遍历取 max；"前 i 个中选"→ 直接取 dp[n]。**

## 七、手算对照：连续与非连续

数组 `[2,-1,3,-5,4]`：

| 答案 | 值 | 对应元素 |
| --- | --- | --- |
| 最大子数组和 | 4 | `[2,-1,3]` |
| 最大子序列和（可不连续） | 8 | `[2,3,4]` |
| 和为 4 的子数组数量 | 1 | `[4]` |
| 和为 4 的子序列数量 | 2 | `[4]`、`[2,-1,3]` |

连续约束通常让“切掉左端”或“接上前一状态”具有 O(1) 依据；非连续约束允许跳过元素，故经常需要遍历多个前驱。

## 八、状态定义检查表

写转移前，必须明确：

1. 当前元素是否**必须选**；
2. 当前状态是否允许空集/空子数组；
3. 答案是否可能在任意位置结束；
4. 是否保存了“最后一个元素值”这种无法省略的信息；
5. 相同状态是否只对应一个最优值。

例如“最大子数组和”的 `dp[i]` 强制以 i 结尾；“从前往后选子序列得到最大和且可跳过”的 `dp[i]` 则通常表示“前 i 个元素中的最优”，两者最终答案读取方式不同。

## 九、进阶路线

- 子数组：
  - 正数滑动窗口；
  - 前缀和 + 哈希；
  - 前后缀最大最小值；
  - 二维压一维；
  - 分治求跨中点的最优段；
- 子序列：
  - O(n²) 结尾枚举；
  - LIS 贪心 + 二分；
  - 值域树状数组；
  - 双串 LCS 压成一维；
  - 强制以 i 结尾的方案数需要额外去重。
