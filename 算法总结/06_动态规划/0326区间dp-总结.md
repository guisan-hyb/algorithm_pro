# 区间 DP

> 来源笔记：`0326区间dp.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

区间 DP = 把大区间拆成小区间；可能性展开只有两条路：**基于两侧端点讨论**，或**基于区间内的划分点讨论**。填表顺序通常是 `l` 递减、`r` 递增。

## 上篇：六道题

### 题一：让字符串成为回文串的最少插入次数（LeetCode 1312）

`f(l, r)` = 把 `s[l..r]` 变回文的最少插入数：

```
s[l] == s[r] -> f(l+1, r-1)
否则         -> min(f(l, r-1), f(l+1, r)) + 1
```

base：`l == r` → 0；`l+1 == r` → `s[l]==s[r] ? 0 : 1`。
可空间压缩成一维（用 `leftdown` 暂存左下角）。

### 题二：预测赢家（LeetCode 486）

`f(l, r)` = 先手在 `[l,r]` 上能拿到的最大分数（**双方都绝顶聪明**）：

```
p1 = nums[l] + min(f(l+2, r), f(l+1, r-1))       // 我拿左，对手会在剩下的里拿最优，给我留下较小的一支
p2 = nums[r] + min(f(l+1, r-1), f(l, r-2))       // 我拿右
```

先手 ≥ 总和的一半就赢。

### 题三：多边形三角剖分的最低得分（LeetCode 1030）

**划分点型**：固定 `(l, r)` 作为某三角形的底边，枚举顶点 `k ∈ (l, r)`：

```
dp[l][r] = min over k of values[l]*values[k]*values[r] + dp[l][k] + dp[k][r]
```

### 题四：切棍子的最小成本（LeetCode 1547）

- 把 `cuts` 排序并在首尾补上 `0` 和 `n`（**离散化**，否则 dp 表按 n 开会爆内存）；
- `dp[l][r]`：切点 `l..r` 全部切完的最小成本；
- `dp[l][r] = min over k of (nums[r+1] - nums[l-1]) + dp[l][k-1] + dp[k+1][r]`。

### 题五：戳气球（LeetCode 312）

**关键：不能按"最先打爆哪个"定义，要按"哪个最后打爆"定义**（否则边界外是否已爆无法讨论）——笔记明说这与"打砖块"的时光倒流思路类似。

- 首尾各补一个 1；
- `dp[l][r] = max over k of arr[l-1]*arr[k]*arr[r+1] + dp[l][k-1] + dp[k+1][r]`。

### 题六：布尔运算（LeetCode 面试题 08.14）

**状态里带"期望结果"这一维**：`dp[l][r][want]` = `[l,r]` 上算出 want 的方案数；

- 枚举运算符位置 k（`k` 从 `l+1` 到 `r-1`，每次 +=2）；
- 按 `&`、`|`、`^` 各自枚举左右子式取值的组合。

## 下篇：六道题

### 题一：括号配对的最少插入（牛客）

**端点 + 划分点两种可能都要试**：

- 端点配对：`s[l]` 与 `s[r]` 正好配对 → `f(l+1, r-1)`；
- 划分点：`min over k (f(l, k) + f(k+1, r))`；

⚠️ 笔记强调：划分点这一支**不能放进 else**——例如 `"()()"`，端点配对算出来是 2，而划分点算出来是 0，取 min 才正确。

### 题二：涂色 / 奇怪打印机（洛谷 P4170 / LeetCode 664）

`s[l] == s[r]` 时：

```
ans = f(l, r - 1)          // ★不是 f(l+1, r-1) + 1
```

因为首尾同色时可以"顺带刷过去"（如 `aaaaa` 答案是 1 而不是 5）；否则枚举划分点取 min。

### 题三：合唱队（洛谷 P3205）

**端点讨论 + 两维状态**：`dp[l][r][0/1]` = 区间 `[l,r]` 的形成方案数，且"最后进来的是 l 端 / r 端"；转移按 `nums[l] < nums[l+1]`、`nums[l] < nums[r]`、`nums[r] > nums[l]`、`nums[r] > nums[r-1]` 四种情况累加，取模 19650827。

### 题四：移除盒子（LeetCode 546）

**状态带"前面跟着 k 个同色盒子"**：`dp[l][r][k]`；

1. 前缀先消：`cnt*cnt + f(s+1, r, 0)`（`cnt = k + 连续同色个数`）；
2. 前缀跟着后面某个同色段一起消：枚举 `m` 满足 `boxes[m] == boxes[l] && boxes[m] != boxes[m-1]`，`f(s+1, m-1, 0) + f(m, r, cnt)`。

### 题五：合并石头的最低成本（LeetCode 1000）

- 先判 `(n - 1) % (k - 1) != 0` → 返回 -1；
- `dp[l][r]`：区间合并成一份的最小代价，**枚举划分点时 m 每次跳 `k-1`**：

```
for (int m = l; m < r; m += k - 1)
    dp[l][r] = min(dp[l][r], dp[l][m] + dp[m+1][r]);
if ((r - l) % (k - 1) == 0) dp[l][r] += preSum[r+1] - preSum[l];   // 最后合成一份的代价
```

复杂度 O(n³)。笔记的推导很值得读：`l..r` 最终合并成几份是**注定的**，所以才敢让 `m` 跳 `k-1`。

### 题六：统计不同回文子序列（LeetCode 730）

容斥 + 记录同字符的最近位置：

- `s[i] != s[j]`：`dp[i][j] = dp[i][j-1] + dp[i+1][j] - dp[i+1][j-1]`（容斥）；
- `s[i] == s[j]`：找 `l = next[i]`、`r = prev[j]`（`i` 右侧、`j` 左侧最近的同字符）：
  - 内部没有同字符（`l > r`）→ `2*dp[i+1][j-1] + 2`（多出 `a` 和 `aa`）；
  - 内部恰好一个（`l == r`）→ `2*dp[i+1][j-1] + 1`（只多 `aa`）；
  - 内部有多个 → `2*dp[i+1][j-1] - dp[l+1][r-1]`（减去重复）。

## 适用特征（看到这些信号就选它）

- 状态天然是"区间 [l, r]"：回文、括号、划分、合并、涂色、博弈取两端；
- 大区间的答案由"两端 + 中间某点"拼出来；
- 字符串/数组长度在 500 以内（O(n³) 可接受）。

## 易错点

1. 填表顺序：`l` 从大到小、`r` 从小到大（保证依赖项已算）；
2. base case：`l == r` 与 `l + 1 == r` 要分开初始化；
3. "首尾相等"时**不能一律 `+1`**（涂色题、回文子序列题都有自己的正确形式）；
4. "最后打爆/最后进来"这类**反向定义**能救边界（戳气球、合唱队）；
5. 需要"前缀信息"时加第三维 k（移除盒子）；
6. 数值范围大但切点少 → **离散化**后再做区间 DP（切棍子）。

## 模板（可直接编译运行）

```cpp
// 区间 DP 模板：回文插入 / 预测赢家 / 三角剖分 / 切棍子 / 戳气球 / 合并石头 / 不同回文子序列
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= 1. 让字符串成为回文的最少插入次数 =================
int minInsertions(const string& s) {
    int n = (int)s.size();
    if (n < 2) return 0;
    vector<int> dp(n, 0);
    dp[n - 1] = (s[n - 2] == s[n - 1]) ? 0 : 1;
    for (int l = n - 3; l >= 0; l--) {
        int leftdown = 0, backup = 0;
        for (int r = l + 1; r < n; r++) {
            backup = dp[r];
            if (s[l] == s[r]) dp[r] = leftdown;
            else              dp[r] = min(dp[r - 1], dp[r]) + 1;
            leftdown = backup;
        }
    }
    return dp[n - 1];
}

// ================= 2. 预测赢家 =================
bool predictTheWinner(const vector<int>& nums) {
    int n = (int)nums.size(), sum = 0;
    for (int x : nums) sum += x;
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int i = 0; i < n; i++) dp[i][i] = nums[i];
    for (int i = 0; i + 1 < n; i++) dp[i][i + 1] = max(nums[i], nums[i + 1]);
    for (int l = n - 3; l >= 0; l--)
        for (int r = l + 2; r < n; r++) {
            int p1 = nums[l] + min(dp[l + 2][r], dp[l + 1][r - 1]);
            int p2 = nums[r] + min(dp[l + 1][r - 1], dp[l][r - 2]);
            dp[l][r] = max(p1, p2);
        }
    return dp[0][n - 1] >= sum - dp[0][n - 1];
}

// ================= 3. 多边形三角剖分的最低得分 =================
int minScoreTriangulation(const vector<int>& values) {
    int n = (int)values.size();
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int l = n - 3; l >= 0; l--)
        for (int r = l + 2; r < n; r++) {
            int best = INT_MAX;
            for (int k = l + 1; k < r; k++)
                best = min(best, values[l] * values[k] * values[r] + dp[l][k] + dp[k][r]);
            dp[l][r] = best;
        }
    return dp[0][n - 1];
}

// ================= 4. 切棍子的最小成本（离散化） =================
int minCostToCut(int n, vector<int> cuts) {
    sort(cuts.begin(), cuts.end());
    int m = (int)cuts.size();
    vector<int> pos(m + 2);
    pos[0] = 0;
    for (int i = 0; i < m; i++) pos[i + 1] = cuts[i];
    pos[m + 1] = n;
    vector<vector<int>> dp(m + 2, vector<int>(m + 2, 0));
    for (int i = 1; i <= m; i++) dp[i][i] = pos[i + 1] - pos[i - 1];
    for (int l = m - 1; l >= 1; l--)
        for (int r = l + 1; r <= m; r++) {
            dp[l][r] = INT_MAX;
            for (int k = l; k <= r; k++)
                dp[l][r] = min(dp[l][r], pos[r + 1] - pos[l - 1] + dp[l][k - 1] + dp[k + 1][r]);
        }
    return dp[1][m];
}

// ================= 5. 戳气球（k 最后打爆） =================
int maxCoins(const vector<int>& nums) {
    int n = (int)nums.size();
    vector<int> arr(n + 2, 1);
    for (int i = 0; i < n; i++) arr[i + 1] = nums[i];
    vector<vector<int>> dp(n + 2, vector<int>(n + 2, 0));
    for (int l = n; l >= 1; l--)
        for (int r = l; r <= n; r++)
            for (int k = l; k <= r; k++)
                dp[l][r] = max(dp[l][r],
                    arr[l - 1] * arr[k] * arr[r + 1] + dp[l][k - 1] + dp[k + 1][r]);
    return dp[1][n];
}

// ================= 6. 合并石头的最低成本 =================
int mergeStones(const vector<int>& stones, int k) {
    int n = (int)stones.size();
    if (k > 1 && (n - 1) % (k - 1) != 0) return -1;
    vector<int> pre(n + 1, 0);
    for (int i = 0; i < n; i++) pre[i + 1] = pre[i] + stones[i];
    vector<vector<int>> dp(n, vector<int>(n, INT_MAX));
    for (int i = 0; i < n; i++) dp[i][i] = 0;
    for (int l = n - 2; l >= 0; l--)
        for (int r = l + 1; r < n; r++) {
            for (int m = l; m < r; m += k - 1)         // ★每次跳 k-1
                dp[l][r] = min(dp[l][r], dp[l][m] + dp[m + 1][r]);
            if ((r - l) % (k - 1) == 0) dp[l][r] += pre[r + 1] - pre[l];
        }
    return dp[0][n - 1];
}

// ================= 7. 统计不同回文子序列 =================
int countPalindromicSubsequences(const string& s) {
    const long long MOD = 1000000007;
    int n = (int)s.size();
    vector<int> prevPos(n), nextPos(n), last(256, -1);
    for (int i = 0; i < n; i++) { prevPos[i] = last[(unsigned char)s[i]]; last[(unsigned char)s[i]] = i; }
    fill(last.begin(), last.end(), n);
    for (int i = n - 1; i >= 0; i--) { nextPos[i] = last[(unsigned char)s[i]]; last[(unsigned char)s[i]] = i; }
    vector<vector<long long>> dp(n, vector<long long>(n, 0));
    for (int i = 0; i < n; i++) dp[i][i] = 1;
    for (int i = n - 2; i >= 0; i--)
        for (int j = i + 1; j < n; j++) {
            if (s[i] != s[j]) {
                dp[i][j] = dp[i][j - 1] + dp[i + 1][j] - dp[i + 1][j - 1] + MOD;
            } else {
                int l = nextPos[i], r = prevPos[j];
                if (l > r)       dp[i][j] = 2 * dp[i + 1][j - 1] + 2;
                else if (l == r) dp[i][j] = 2 * dp[i + 1][j - 1] + 1;
                else             dp[i][j] = 2 * dp[i + 1][j - 1] - dp[l + 1][r - 1] + MOD;
            }
            dp[i][j] %= MOD;
        }
    return (int)dp[0][n - 1];
}

int main() {
    std::cout << "回文最少插入 = " << minInsertions("mbadm") << "\n";               // 2
    std::cout << "预测赢家 = " << (int)predictTheWinner({1,5,2}) << "\n";            // 0(输)
    std::cout << "三角剖分最低分 = " << minScoreTriangulation({1,3,1,4,1,5}) << "\n";// 13
    std::cout << "切棍最小成本 = " << minCostToCut(7, {1,3,4,5}) << "\n";            // 16
    std::cout << "戳气球最大 = " << maxCoins({3,1,5,8}) << "\n";                     // 167
    std::cout << "合并石头最低成本 = " << mergeStones({3,2,4,1}, 2) << "\n";         // 20
    std::cout << "不同回文子序列 = " << countPalindromicSubsequences("bccb") << "\n";// 6
    return 0;
}
```

## 为什么区间 DP 要按区间长度填表

设 `dp[left][right]` 只依赖严格更短的区间，例如 `dp[left+1][right]` 和 `dp[left][right-1]`。若先固定 `left` 从小到大扫 `right`，会读到尚未计算的长区间依赖；正确顺序是：

```text
len = 1, 2, ..., n
    枚举 left
        right = left + len - 1
```

也可以写成 `left` 从 `n-1` 到 0、`right` 从 `left` 到 `n-1`，但本质仍是先保证所有真子区间已经算出。填表顺序错了，常见症状是大量 `INF` 或答案偶然在小样例通过。

## 手算演练：戳气球 `[3,1,5,8]`

补边界后为 `[1,3,1,5,8,1]`。不要按“先打爆谁”思考，而要枚举区间 `[left,right]` 中**最后**打爆的 `mid`：

| 区间（原数组下标） | 最后打爆 | 本次得分 | 左右子区间最优 | 合计 |
| --- | --- | --- | --- | --- |
| [3,1] | 3 | 1×3×5=15 | 0+5 | 20 |
| [3,1] | 1 | 1×1×5=5 | 15+0 | 20 |
| [1,5] | 1 | 3×1×8=24 | 0+40 | 64 |
| [1,5] | 5 | 3×5×8=120 | 15+0 | 135 |
| [3,1,5] | 3 | 1×3×8=24 | 0+135 | 159 |
| [3,1,5,8] | 3 | 1×3×1=3 | 0+42 | 45 |
| [3,1,5,8] | 1 | 1×1×1=1 | 15+13 | 29 |
| [3,1,5,8] | 5 | 1×5×1=5 | 20+8 | 33 |
| [3,1,5,8] | 8 | 1×8×1=8 | 159+0 | 167 |

最优是最后打 8，总分 167，对应一种打爆顺序 `1,5,3,8`。关键不是这些算术，而是理解“最后打爆时，左右两个气球恰是当前补出的边界”；这样左右子问题才能彼此独立。

## 状态定义与边界对照

| 题 | 状态 | 为什么不能换一个更直观的定义 |
| --- | --- | --- |
| 回文最少插入 | `dp[l][r]` 变回文代价 | 首尾相等时可直接削去两端 |
| 预测赢家 | `dp[l][r]` 先手最优分 | 下一手会拿剩余区间的最大分，所以我要取较小的后继 |
| 戳气球 | `dp[l][r]` 清空区间最大分 | “先打爆”会改变后续边界，“最后打爆”边界固定 |
| 合并石头 | `dp[l][r]` 合并成一份/若干份代价 | 划分点必须满足每段最终可合成整数份 |
| 涂色 | `dp[l][r]` 最少刷色次数 | 首尾同色可一次顺带覆盖，不一定削去中间 |

## 进阶拓展

- 回文插入同时可转成 `n - LPS`，二者答案相同，但区间定义不同；
- 括号匹配可加 `match` 预处理，避免每次重复判断配对；
- 大区间不要求所有划分点合法时，可记录“最后一次操作”或“分界结构”而非枚举全部 `k`；
- 环形区间问题常复制数组后再限制区间长度，避免处理跨端点状态；
- 四边形不等式优化可把部分划分型 O(n³) 降为 O(n²)，但必须验证代价函数的单调性与凸性。
