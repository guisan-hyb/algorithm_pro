# 从递归入手三维动态规划

> 来源笔记：`0306从递归入手三维动态规划.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

尝试函数有几个可变参数，就对应几维 DP 表；三维只是因为"状态里多带了一个参数"（剩余容量、剩余步数、已用次数、当前余数……），套路仍是**递归 → 记忆化 → 迭代 → 空间压缩**。

## 解决什么问题

- **多维费用背包**：容量不止一个维度（如"0 的个数"和"1 的个数"）；
- **带次数限制的 DP**：还剩几步、已经用了几次；
- **带余数/模数状态的 DP**：路径和模 k；
- **区间 + 长度**的状态：扰乱字符串。

## 核心思想

### 三维从哪来

二维 DP 的两个下标描述"位置"；当题目还要求记住"某个量"（剩余容量 / 剩余步数 / 已用次数 / 当前余数）时，就把这个量作为第三维。

关键判断：**这个量会不会影响后续决策？** 会 → 必须进状态；不会 → 不进，否则白白多一维。

### 空间压缩的可行性

如果 `dp[i][...]` 只依赖 `dp[i-1][...]`（上一"层"），就可以把第一维滚掉；如果同一层内还需要"左前方"的值，就要注意遍历方向（通常是倒序）。

## 为什么这样做（以"一和零"为例）

`dp[i][z][o]` = 前 i 个字符串、0 的预算 z、1 的预算 o 时最多能选几个。

对第 i 个字符串只有两种决策：

- 不选：`dp[i][z][o] = dp[i-1][z][o]`；
- 选：若它的 0/1 数量不超过预算，`dp[i][z][o] = dp[i-1][z-zeros][o-ones] + 1`。

正确性：每个字符串选或不选，构成对"前 i 个"的完整划分；两种决策取最大，覆盖所有方案。

空间压缩成二维后，`z`、`o` 都必须**倒序**——否则同一个字符串会被重复选（那就变成完全背包了）。

## 手算演练（一和零）

`strs = ["10", "0001", "111001", "1", "0"]`，预算 m=5、n=3：

| 字符串 | 0 数 | 1 数 |
| --- | --- | --- |
| "10" | 1 | 1 |
| "0001" | 3 | 1 |
| "111001" | 2 | 4 |
| "1" | 0 | 1 |
| "0" | 1 | 0 |

可选的组合例如 `"10" + "0001"` 用 4 个 0、2 个 1（合法，2 个）；再加 `"0"` 用 5 个 0、2 个 1（合法，3 个）；再加 `"1"` 用 5 个 0、3 个 1（合法，4 个）。答案是 4。

## 五道题

### 题一：一和零（LeetCode 474）

多维费用背包，见上。压缩成二维时两个费用维度都倒序。

### 题二：盈利计划（LeetCode 879）

`f(i, n, sum)` = 前 i 个任务、还剩 n 个人、已赚 sum 的方案数；`sum` 超过 `minProfit` 时**截断成 minProfit**（超过之后只关心"达标"这一件事），这是省内存的关键观察。

### 题三：骑士在棋盘上的概率（LeetCode 688）

`dp[step][i][j]` = 走 step 步后仍在 (i,j) 的概率：

- 记忆化：越界返回 0，`step==0` 返回 1，八个方向各 `/8`；
- 迭代：把棋盘平移 2 格（`2..n+1`），数组开 `n+4`，八个方向的跳跃都不会越界。

### 题四：矩阵中和能被 K 整除的路径（LeetCode 2435）

用**同余**把"路径和"压缩成"余数"（否则第三维会爆内存）：

```
need = (r - grid[i][j] % k + k) % k
dp[i][j][r] = dp[i+1][j][need] + dp[i][j+1][need]
```

base：终点处 `grid[i][j] % k == r` 返回 1。

### 题五：扰乱字符串（LeetCode 87）

`f(l1, l2, len)` = s1 从 l1 起长 len 的子串 与 s2 从 l2 起长 len 的子串是否互为扰乱字符串：

- 不交错：`f(l1,l2,k) && f(l1+k,l2+k,len-k)`；
- 交错：`f(l1,l2+len-k,k) && f(l1+k,l2,len-k)`。

用 `len` 做第三维，把四维压成三维；迭代按 `len` 从 2 到 n 分层。

## 适用特征（看到这些信号就选它）

- 状态 = 位置 + 额外信息（预算 / 剩余步数 / 已用次数 / 余数 / 长度）；
- "多维费用背包"；
- 概率 / 方案数，且每步有多种等可能选择。

## 复杂度

| 题 | 状态数 | 单状态代价 |
| --- | --- | --- |
| 一和零 | O(n·m·n) | O(1) |
| 盈利计划 | O(任务数·人数·利润) | O(1) |
| 骑士概率 | O(k·n²) | O(8) |
| 整除路径 | O(m·n·k) | O(1) |
| 扰乱字符串 | O(n³) | O(n) |

## 与相似算法对比

- 三维 DP 与"多维背包"是同一件事：每一维容量都要满足，选/不选对应 01 背包；
- 当额外信息是"余数"时，本质是把大数值压缩成小状态（同余）；
- 当额外信息是"长度"时，本质是区间 DP 的变体。

## 易错点

1. 三维数组先想清楚**哪一维是"层"**（能当层的那一维适合做迭代外层）；
2. 空间压缩时，依赖"上一层同位置 + 上一层左前方" → 两个维度都倒序；
3. 状态截断（如 minProfit）要先分析"哪些信息不再重要"；
4. 用同余代替大数值参数，避免第三维爆炸；
5. 迭代前先做棋盘/数组平移，省掉越界判断；
6. 记忆化的哨兵值要和合法答案区分开。

## 模板（可直接编译运行）

```cpp
// 三维动态规划模板：一和零 / 盈利计划 / 骑士概率 / 同余路径计数
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <iomanip>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= 1. 一和零（多维费用背包，压缩成二维） =================
int findMaxForm(const vector<string>& strs, int m, int n) {
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (const string& s : strs) {
        int zeros = 0, ones = 0;
        for (char c : s) (c == '0' ? zeros : ones)++;
        for (int z = m; z >= zeros; z--)              // ★两个维度都倒序
            for (int o = n; o >= ones; o--)
                dp[z][o] = max(dp[z][o], 1 + dp[z - zeros][o - ones]);
    }
    return dp[m][n];
}

// ================= 2. 盈利计划（记忆化 + 超额截断） =================
class ProfitableSchemes {
    static const int MOD = 1000000007;
    vector<int> group, profit;
    int minProfit = 0;
    vector<vector<vector<long long>>> dp;
    int f(int i, int n, int sum) {
        if (i < 0 || n <= 0) return sum >= minProfit ? 1 : 0;
        if (sum > minProfit) sum = minProfit;         // 关键优化：超额部分不再区分
        if (dp[i][n][sum] != -1) return (int)dp[i][n][sum];
        long long ans = f(i - 1, n, sum);
        if (n >= group[i]) ans += f(i - 1, n - group[i], sum + profit[i]);
        return (int)(dp[i][n][sum] = ans % MOD);
    }
public:
    int profitableSchemes(int n, int mp, vector<int>& g, vector<int>& p) {
        group = g; profit = p; minProfit = mp;
        int m = (int)p.size();
        dp.assign(m, vector<vector<long long>>(n + 1, vector<long long>(mp + 1, -1)));
        return f(m - 1, n, 0);
    }
};

// ================= 3. 骑士在棋盘上的概率（平移 + 逐层迭代） =================
double knightProbability(int n, int k, int row, int column) {
    const std::vector<std::array<int, 2>> moves = {
        {-1, -2}, {-1, 2}, {-2, -1}, {-2, 1},
        {1, -2}, {1, 2}, {2, -1}, {2, 1}
    };
    vector<vector<vector<double>>> dp(k + 1,
        vector<vector<double>>(n + 4, vector<double>(n + 4, 0)));
    for (int i = 2; i <= n + 1; i++)
        for (int j = 2; j <= n + 1; j++) dp[0][i][j] = 1;
    for (int step = 1; step <= k; step++)
        for (int i = 2; i <= n + 1; i++)
            for (int j = 2; j <= n + 1; j++) {
                double tmp = 0;
                for (const auto& move : moves) {
                    tmp += dp[step - 1][i + move[0]][j + move[1]] / 8;
                }
                dp[step][i][j] = tmp;
            }
    return dp[k][row + 2][column + 2];
}

// ================= 4. 矩阵中和能被 K 整除的路径（同余做第三维） =================
int numberOfPaths(vector<vector<int>>& grid, int k) {
    const int MOD = 1000000007;
    int m = (int)grid.size(), n = (int)grid[0].size();
    vector<vector<vector<int>>> dp(m, vector<vector<int>>(n, vector<int>(k, 0)));
    dp[m - 1][n - 1][grid[m - 1][n - 1] % k] = 1;
    for (int i = m - 2; i >= 0; i--)
        for (int r = 0; r < k; r++)
            dp[i][n - 1][r] = dp[i + 1][n - 1][(r - grid[i][n - 1] % k + k) % k];
    for (int j = n - 2; j >= 0; j--)
        for (int r = 0; r < k; r++)
            dp[m - 1][j][r] = dp[m - 1][j + 1][(r - grid[m - 1][j] % k + k) % k];
    for (int i = m - 2; i >= 0; i--)
        for (int j = n - 2; j >= 0; j--)
            for (int r = 0; r < k; r++) {
                int need = (r - grid[i][j] % k + k) % k;
                dp[i][j][r] = (dp[i + 1][j][need] + dp[i][j + 1][need]) % MOD;
            }
    return dp[0][0][0];
}

int main() {
    vector<string> strs = {"10", "0001", "111001", "1", "0"};
    std::cout << "一和零 = " << findMaxForm(strs, 5, 3) << "\n";            // 4

    vector<int> g = {2,2,3,3}, p = {2,3,1,3};
    ProfitableSchemes ps;
    std::cout << "盈利计划 = " << ps.profitableSchemes(5, 3, g, p) << "\n";  // 3

    std::cout << "骑士概率 = " << std::fixed << std::setprecision(5) << knightProbability(3, 2, 0, 0) << std::defaultfloat << std::setprecision(6) << "\n";   // 0.0625

    vector<vector<int>> grid = {{5,2,4},{3,0,5},{0,7,2}};
    std::cout << "整除路径数 = " << numberOfPaths(grid, 3) << "\n";          // 2
    return 0;
}
```

## 进阶拓展

1. **多维背包**：第三维可以是任意"费用"，只要它能被枚举。
2. **状态截断**：超过阈值的信息可以合并（盈利计划），能大幅降维。
3. **同余压缩**：把"和"换成"和 mod k"，状态从 10^9 降到 k。
4. **滚动层**：只依赖上一层时，第一维可滚动；如果同层还要左值，注意倒序。
5. **记忆化 vs 迭代**：三维迭代在边界处理上容易错，记忆化搜索往往更好写。

## 面试追问

1. **什么时候需要第三维？** 当某个量会影响后续决策，且不能由前两维推出时。
2. **一和零为什么两个费用维度都倒序？** 每个物品只能用一次，倒序保证用的是"上一层"。
3. **骑士概率为什么要平移棋盘？** 八个方向的跳跃会越界，平移 2 格后所有访问都在数组内。
4. **整除路径为什么用余数而不是和？** 和的范围太大，余数只有 k 种。
5. **扰乱字符串为什么能压成三维？** 两个子串长度相等，长度可由起点推出一个维度。
