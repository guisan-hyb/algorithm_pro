# 动态规划专题总结（总纲回顾）

> 来源笔记：`0531动态规划专题总结.md`｜性质：DP 总纲（必读）｜分类：06 动态规划

## 一、什么是动态规划

一些递归**有重复计算**，可以用空间记录返回值来避免重复计算；动态规划是related的一整套原理和技巧的总和。

## 二、什么样的递归可以变成动态规划

- 设计的**可变参数类型简单**（不比 int 更复杂）的递归，可以改成动态规划；
- 如果递归过程中的**路径信息比较复杂（回溯）**，那么不能或没有必要改成动态规划；
- 虽然有路径信息，但**路径信息比较简单**时，也能改 → 这就是**状压 DP**。

## 三、三个经典名词

| 名词 | 含义 |
| --- | --- |
| **重叠子结构** | 除了数据量不同，剩下所有过程得到的逻辑大体相同 → **任何 DP 都一定来自某个递归** |
| **最优子问题** | **局部最优推导全局最优**：大问题的最优解一定来自若干子问题；子问题的最优解要么是决策出来的、要么是加工组合出来的 |
| **无后效性** | 之前做的决策对后续过程不产生影响 → **必须把参数带全** |

## 四、动态规划的大致过程（五步）

1. **想出设计优良的递归尝试**（一般用「**选或不选**」和「**枚举选哪个**」两种思路启发）；
2. **记忆化搜索**（从顶到底的 DP）；
3. **严格位置依赖的动态规划**（从底到顶的 DP）；
4. **进一步优化空间**（空间压缩）；
5. **进一步优化枚举行为**。

## 五、几条务实建议

- **推荐从尝试入手**，最符合自然智慧；
- 分析位置依赖时**多画图建立空间感**（这正是要写迭代版的重要原因）；
- 复杂度公式：`O(状态数量 × 每个状态的枚举代价)`；
- 尝试方法的优劣由**题目具体的数据量**决定：先确定靠谱的尝试，再做后续实现；
- DP 与其他专题、数据结构、算法技巧都有融合，**未完待续**。
