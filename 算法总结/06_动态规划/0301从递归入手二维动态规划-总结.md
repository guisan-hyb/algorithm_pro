# 从递归入手二维动态规划

> 来源笔记：`0301从递归入手二维动态规划.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

当尝试函数有**两个可变参数**才能决定返回值时，DP 表就是二维的；而"用长度定义状态"通常比"用下标定义状态"少一大堆边界讨论。

## 解决什么问题

- 两个字符串之间的匹配 / 转换 / 交错；
- 矩阵上的路径问题（只能向右、向下走）；
- 区间型问题（`dp[l][r]`）；
- 两个维度的"容量"问题（二维背包的雏形）。

## 核心思想

二维 DP 的三步：

1. **定状态**：`dp[i][j]` 的两个下标分别代表什么（s1 的前 i 个 / s2 的前 j 个；或矩阵的 (i,j)；或区间 [l,r]）；
2. **定转移**：当前格子由哪些格子推出来（上方、左方、左上、`i+1/j-1`……）；
3. **定顺序**：保证计算 `dp[i][j]` 时，它依赖的格子已经算过。

## 为什么这样做（以最小路径和为例）

`dp[i][j]` = 从 (0,0) 走到 (i,j) 的最小路径和。要走到 (i,j)，最后一步只能来自**上方 (i-1,j)** 或**左方 (i,j-1)**，所以

```
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
```

正确性来自"**最优子结构**"：任何一条到 (i,j) 的最优路径，去掉最后一步后，一定是到 (i-1,j)（或 (i,j-1)）的最优路径——否则把它替换成更优的那条，整体会更优，矛盾。

边界 `i=0` 或 `j=0` 时只有一个方向可走，所以要单独初始化首行、首列。

## 手算演练

矩阵：

```
1 3 1
1 5 1
4 2 1
```

`dp` 表（从 (0,0) 到每格的最小路径和）：

| | j=0 | j=1 | j=2 |
| --- | --- | --- | --- |
| i=0 | 1 | 4 | 5 |
| i=1 | 2 | 7 | 6 |
| i=2 | 6 | 8 | 7 |

填表过程：首行 1→4→5，首列 1→2→6；然后 `dp[1][1] = 5 + min(4,2) = 7`、`dp[1][2] = 1 + min(5,7) = 6`……最后答案是 7。

## 六道题

### 题一：最小路径和（LeetCode 64）

笔记给了**五种解法**，用来演示"同一题的多种尝试"：

1. Dijkstra（把网格当图，边权 = 格子值）；
2. 暴力递归（`f(i,j)`，超时）；
3. 记忆化搜索；
4. 二维 DP（首行首列单独初始化）；
5. **空间压缩成一维**（`dp[j] = min(dp[j-1], dp[j]) + grid[i][j]`，首列特殊处理）。

### 题二：单词搜索（LeetCode 79）——无法改成 DP 的反例

递归是 `f(i, j, k)`：从 (i,j) 出发能否匹配 `word[k..]`。它会**修改并恢复现场**（`board[i][j] = '0'` 再还原），路径依赖"已访问的格子集合"，**没有可复用的子问题结构**，所以只能 DFS + 回溯。

> 这个反例很重要：不是所有递归都能改成 DP，只有当"子问题解可复用"时才有必要。

### 题三：最长公共子序列（LeetCode 1143）

**核心：以结尾讨论可能性**。

- 用**下标**定义：`f(i1, i2)`，要讨论四种可能，边界要判 `i1 < 0 || i2 < 0`；
- 用**长度**定义（推荐）：`f(len1, len2)`，只剩两支：

```
s1[len1-1] == s2[len2-1] -> 1 + dp[len1-1][len2-1]
否则                      -> max(dp[len1-1][len2], dp[len1][len2-1])
```

- 空间压缩：一维 `dp[短串长度+1]`，用 `leftUp` 暂存左上角。

### 题四：最长回文子序列（LeetCode 516）

**区间型二维 DP**：

- `f(l, r)`：`s[l..r]` 的最长回文子序列长度；
- `s[l] == s[r]` → `2 + f(l+1, r-1)`；否则 `max(f(l, r-1), f(l+1, r))`；
- 迭代顺序：`l` 从大到小、`r` 从小到大；
- 空间压缩成一维时，用 `leftDown` 暂存左下角。

> 也可以用"原串与反转串做 LCS"来做。

### 题五：节点数为 n、高度不超过 m 的二叉树个数（牛客）

按"左右孩子如何分配节点数"划分子问题：

```
f(n, m) = Σ_{left=0}^{n-1} f(left, m-1) * f(n-1-left, m-1)
```

- `f(0, m) = 1`（空树算一种），`f(n, 0) = 0`；
- 记忆化 → 二维 DP → 空间压缩成"一列"（高度维从左往右、节点数维从下往上）。

### 题六：矩阵中的最长递增路径（LeetCode 329）——只能记忆化

`f(i,j)` = 从 (i,j) 出发的最长递增路径。因为**依赖关系（谁比谁大）整理起来很棘手**，笔记直接用记忆化搜索，不改成迭代。

## 适用特征（看到这些信号就选它）

- 两个可变参数决定返回值（两个下标 / 下标 + 剩余量 / 两个长度）；
- 出现"两个字符串""矩阵""区间 [l, r]""二维容量"；
- 区间型：`dp[l][r]`，依赖 `l+1`、`r-1`（所以 `l` 降序、`r` 升序填）。

## 复杂度

- 状态数：`O(m × n)`；
- 每个状态的转移代价：通常是 O(1)（LCS/编辑距离/最小路径和），区间型或枚举分割点是 O(n)；
- 总时间 = 状态数 × 转移代价；空间 = 状态数（可压缩到 O(n)）。

## 与相似算法对比

| 结构 | 状态 | 典型题 |
| --- | --- | --- |
| 一维 | `dp[i]` | 斐波那契、解码方法 |
| 二维（前缀对） | `dp[i][j]` | LCS、编辑距离、交错字符串 |
| 二维（区间） | `dp[l][r]` | 最长回文子序列、戳气球、合并石头 |
| 二维（网格） | `dp[i][j]` | 最小路径和、不同路径 |

## 易错点

1. **优先用长度定义状态**：`len` 最小为 0，能省掉下标越界讨论；
2. dp 表大小：用长度定义时是 `(m+1) × (n+1)`；
3. 首行/首列初始化不能漏；
4. 空间压缩时遍历方向由依赖方向决定；需要左上角值时用变量暂存；
5. 区间 DP 填表顺序：`l` 递减、`r` 递增；
6. 判断"能不能改 DP"：子问题是否可复用；带"已访问集合"的搜索类不能改。

## 模板（可直接编译运行）

```cpp
// 二维动态规划模板：最小路径和 / LCS / 最长回文子序列 / 二叉树结构数 / 矩阵最长递增路径
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= 1. 最小路径和（二维 DP + 空间压缩） =================
int minPathSum(const vector<vector<int>>& g) {
    int m = (int)g.size(), n = (int)g[0].size();
    vector<int> dp(n, 0);
    dp[0] = g[0][0];
    for (int j = 1; j < n; j++) dp[j] = dp[j - 1] + g[0][j];
    for (int i = 1; i < m; i++) {
        dp[0] += g[i][0];
        for (int j = 1; j < n; j++)
            dp[j] = min(dp[j - 1], dp[j]) + g[i][j];
    }
    return dp[n - 1];
}

// ================= 2. 最长公共子序列（长度定义 + 空间压缩） =================
int longestCommonSubsequence(string s1, string s2) {
    if (s1.size() > s2.size()) swap(s1, s2);       // 让 s1 更短
    int m = (int)s1.size(), n = (int)s2.size();
    vector<int> dp(m + 1, 0);
    for (int len2 = 1; len2 <= n; len2++) {         // 外层遍历长串
        int leftup = 0;                             // dp[i-1][j-1]
        for (int len1 = 1; len1 <= m; len1++) {
            int backup = dp[len1];
            if (s1[len1 - 1] == s2[len2 - 1]) dp[len1] = 1 + leftup;
            else                              dp[len1] = max(dp[len1], dp[len1 - 1]);
            leftup = backup;
        }
    }
    return dp[m];
}

// ================= 3. 最长回文子序列（区间 DP + 空间压缩） =================
int longestPalindromeSubseq(const string& s) {
    int n = (int)s.size();
    vector<int> dp(n, 0);
    for (int l = n - 1; l >= 0; l--) {
        int leftdown = 0, backup = 0;
        for (int r = l; r < n; r++) {
            backup = dp[r];
            if (l == r)            dp[r] = 1;
            else if (s[l] == s[r]) dp[r] = 2 + leftdown;
            else                   dp[r] = max(dp[r - 1], dp[r]);
            leftdown = backup;
        }
    }
    return dp[n - 1];
}

// ================= 4. 编辑距离（二维 DP + 空间压缩，三操作可不同代价） =================
int editDistance(const string& s1, const string& s2, int a, int b, int c) {
    int m = (int)s1.size(), n = (int)s2.size();
    vector<int> dp(n + 1, 0);
    for (int j = 0; j <= n; j++) dp[j] = j * a;      // s1 为空：全是插入
    for (int i = 1; i <= m; i++) {
        int leftup = dp[0];
        dp[0] = i * b;                               // s2 为空：全是删除
        for (int j = 1; j <= n; j++) {
            int backup = dp[j];
            if (s1[i - 1] == s2[j - 1]) dp[j] = leftup;
            else dp[j] = min(min(dp[j - 1] + a, dp[j] + b), leftup + c);
            leftup = backup;
        }
    }
    return dp[n];
}

// ================= 5. 矩阵中的最长递增路径（只能记忆化搜索） =================
class LongestIncreasingPath {
    int m, n;
    vector<vector<int>> dp;
    const std::array<int, 4> rowOffset = {1, -1, 0, 0};
    const std::array<int, 4> columnOffset = {0, 0, 1, -1};
    int f(const vector<vector<int>>& g, int i, int j) {
        if (dp[i][j] != -1) return dp[i][j];
        int nxt = 0;
        for (int d = 0; d < 4; d++) {
            int x = i + rowOffset[d], y = j + columnOffset[d];
            if (x >= 0 && x < m && y >= 0 && y < n && g[x][y] > g[i][j])
                nxt = max(nxt, f(g, x, y));
        }
        return dp[i][j] = 1 + nxt;
    }
public:
    int longestIncreasingPath(const vector<vector<int>>& g) {
        m = (int)g.size(); n = (int)g[0].size();
        dp.assign(m, vector<int>(n, -1));
        int ans = 0;
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                ans = max(ans, f(g, i, j));
        return ans;
    }
};

int main() {
    vector<vector<int>> g = {{1,3,1},{1,5,1},{4,2,1}};
    std::cout << "最小路径和 = " << minPathSum(g) << "\n";                        // 7
    std::cout << "LCS = " << longestCommonSubsequence("abcde", "ace") << "\n";    // 3
    std::cout << "最长回文子序列 = " << longestPalindromeSubseq("bbbab") << "\n"; // 4
    std::cout << "编辑距离 = " << editDistance("horse", "ros", 1, 1, 1) << "\n";  // 3
    LongestIncreasingPath lip;
    std::cout << "最长递增路径 = " << lip.longestIncreasingPath(g) << "\n";       // 4
    return 0;
}
```

## 进阶拓展

1. **滚动数组**：二维 DP 只依赖上一行时，压成一维；依赖上一行和当前行左侧时，注意保存左上角。
2. **状态设计升级**：LCS 的"前缀对"可以推广到编辑距离、交错字符串、正则匹配（见 `0322`）。
3. **区间 DP**：把 `dp[l][r]` 和"枚举分割点 k"结合，能解戳气球、合并石头等（见 `0326`）。
- **记忆化替代迭代**：依赖关系难以排序时（矩阵最长递增路径），记忆化搜索更直接。

## 面试追问

1. **为什么用长度而不是下标？** 长度从 0 开始，空串天然有定义，省掉 `i<0` 的边界讨论。
2. **二维 DP 的空间能压到多小？** 只依赖上一行时 O(n)；区间 DP 通常 O(n)。
3. **最小路径和为什么不能用贪心？** 局部选较小的邻居，可能把后面引到更大的格子，需要全局最优。
4. **什么题不能改 DP？** 子问题不可复用（如单词搜索的已访问集合）。
5. **LCS 与最长回文子序列的关系？** 回文子序列 = 原串与反转串的 LCS。
