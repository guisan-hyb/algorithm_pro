# 动态规划中"得到具体决策方案"的技巧

> 来源笔记：`0525动态规划中得到具体决策方案的技巧.cpp`｜核心程度：常见考点｜分类：06 动态规划

## 一句话

要求返回"具体方案"而不是一个数值时，两条路：**① 利用 DP 表反推决策路径**；**② 额外开一个路径收集结构**。找方案都从**递归入口（DP 表的终点）**开始往回走。

> 笔记原话："对这一类题目来说，动态规划是最重要的，得到具体方案只是一个比较简单的处理技巧。"

## 题目一：最长公共子序列的一个具体结果（牛客）

先正常求出 `dp[m][n]`，然后从 `(m, n)` 往回推：

```
if (a[i-1] == b[j-1])  ->  这个字符属于答案，i--, j--，从后往前填 ans
else                   ->  往 dp 值更大的方向走（dp[i-1][j] >= dp[i][j-1] 就 i--，否则 j--）
```

如果 `LCS == 0`，输出 -1。

## 题目二：最小的必要团队（LeetCode 1125，状压 + 反推）

- 把"需求技能"压成位，每个人会的技能也压成位；
- `dp[i][status]` = 从第 i 个人开始，把 status 补全所需的最少人数（`min(不要他, 1 + 要他)`）；
- **反推方案**：从 `i=0, s=0` 开始，若 `dp[i][s] != dp[i+1][s]`（说明选了他）或已到最后一人，就把他加入答案并 `s |= arr[i]`。

## 题目三：最长递增子序列字典序最小的结果（牛客 / 洛谷）

关键：**把 LIS 反着求**——从右往左、用"不上升"（`<=`）的二分，这样 `dp[i]` 的含义变成"以 i 为**开头**往右延伸的最长递增子序列长度"。

反推方案（贪心从前到后填）：

```
for i in 0..n-1:
    if (dp[i] == len)                  ans[0] = nums[i];        // 最后被覆盖的是最右且最小的，字典序最小
    else if (ans[len-1-dp[i]] < nums[i]) ans[len-dp[i]] = nums[i];
```

> 笔记提醒：正常求 LIS 时 `dp[i]` 的定义是"以 `nums[i]` 结尾"，本题要的是"以 `nums[i]` 开头"，所以必须倒着求并调整二分比较方向。

## 题目四：潜水的最大时间与方案（洛谷 P1759，路径收集结构）

二维费用背包（重量 m、阻力 v）+ **字典序最小的人员编号方案**：

- `dp[i][j][k]`：前 i 个工具、重量 ≤ j、阻力 ≤ k 的最大停留时间；
- 额外开 `path[i][j][k]` 存**字符串形式的编号序列**（如 `"1 3 5"`）；
- 转移时若"要第 i 个"更优就替换 path；**若相等就比较两个字符串的字典序，取小的**（本题字典序按字符串比较，"1 120" 比 "1 2" 小）；
- 有空间压缩版（三维压两维，`path` 同步压缩）。

## 适用特征（看到这些信号就选它）

- 题目要求输出"方案本身"（下标序列、选择的物品、具体路径、字符串）；
- 求"字典序最小/最大的方案"；
- 方案对应 DP 的每一次决策。

## 易错点

1. **一定要先把 DP 表算对**，方案只是反推的副产品；
2. 反推时的"等号分支"：`dp[i-1][j] >= dp[i][j-1]` 取哪边会影响得到的具体方案（要按题目要求的字典序选择）；
3. 路径用字符串拼接时，比较要用**字符串字典序**而不是"按数值比较"（题目定义可能很反直觉）；
4. 状压题反推方案时，判断条件是 `dp[i][s] != dp[i+1][s]`；
5. LIS 类题要注意 `dp` 的定义方向（以 i 开头还是结尾）；
6. 空间压缩后 `path` 也要同步压缩，且"旧值"必须先备份。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 由 DP 表反推 LCS 的具体方案 ----------
string lcsPath(const string& a, const string& b) {
    int m = (int)a.size(), n = (int)b.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = (a[i - 1] == b[j - 1])
                     ? dp[i - 1][j - 1] + 1
                     : max(dp[i - 1][j], dp[i][j - 1]);
    int len = dp[m][n];
    if (len == 0) return "";
    string ans(len, ' ');
    for (int i = m, j = n; len > 0; ) {
        if (a[i - 1] == b[j - 1]) { ans[--len] = a[i - 1]; i--; j--; }
        else if (dp[i - 1][j] >= dp[i][j - 1]) i--;
        else j--;
    }
    return ans;
}

// ---------- 2. 状压反推方案：最小的必要团队 ----------
vector<int> smallestSufficientTeam(vector<string>& req_skills,
                                   vector<vector<string>>& people) {
    unordered_map<string,int> id;
    for (auto& s : req_skills) id[s] = (int)id.size();
    int num = (int)req_skills.size(), n = (int)people.size();
    vector<int> arr(n, 0);
    for (int i = 0; i < n; i++)
        for (auto& s : people[i])
            if (id.count(s)) arr[i] |= 1 << id[s];

    vector<vector<int>> dp(n + 1, vector<int>(1 << num, INT_MAX / 2));
    for (int s = 0; s < (1 << num); s++) dp[n][s] = INT_MAX / 2;
    dp[n][(1 << num) - 1] = 0;
    for (int i = n - 1; i >= 0; i--)
        for (int s = 0; s < (1 << num); s++) {
            int p1 = dp[i + 1][s];
            int p2 = 1 + dp[i + 1][s | arr[i]];
            dp[i][s] = min(p1, p2);
        }

    vector<int> ans;                                   // 反推方案
    for (int i = 0, s = 0; s != (1 << num) - 1 && i < n; i++)
        if (i == n - 1 || dp[i][s] != dp[i + 1][s]) {
            ans.push_back(i);
            s |= arr[i];
        }
    return ans;
}

// ---------- 3. 路径收集结构：二维费用背包 + 字典序最小方案 ----------
// dp[j][k] = 最大价值；path[j][k] = 对应的编号字符串（字典序最小）
pair<int,string> knapsackWithPath(int m, int v,
                                  const vector<int>& a, const vector<int>& b,
                                  const vector<int>& c) {
    int n = (int)a.size();
    vector<vector<int>> dp(m + 1, vector<int>(v + 1, 0));
    vector<vector<string>> path(m + 1, vector<string>(v + 1, ""));
    for (int i = 1; i <= n; i++) {
        for (int j = m; j >= a[i - 1]; j--) {
            for (int k = v; k >= b[i - 1]; k--) {
                string p = path[j - a[i - 1]][k - b[i - 1]];
                p = p.empty() ? to_string(i) : p + " " + to_string(i);
                int val = dp[j - a[i - 1]][k - b[i - 1]] + c[i - 1];
                if (val > dp[j][k]) { dp[j][k] = val; path[j][k] = p; }
                else if (val == dp[j][k] && p < path[j][k]) path[j][k] = p;   // 字典序取小
            }
        }
    }
    return {dp[m][v], path[m][v]};
}

int main() {
    printf("LCS 方案 = %s\n", lcsPath("abcde", "ace").c_str());       // ace
    return 0;
}
