# 见识更多二维动态规划题目（字符串型）

> 来源笔记：`0303见识更多二维动态规划题目.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

字符串上的二维 DP 只有两种"状态定义"：**下标**（`dp[i][j]` = s1 到 i、s2 到 j）和**长度**（`dp[len1][len2]`）；后者能省掉越界讨论，但要看清"当前格子依赖哪些格子"来决定遍历方向。

## 五道题

### 题一：不同的子序列（LeetCode 115）

统计 s 的子序列中 t 出现的个数。

- 递归（下标版）：`if (i < j) return 0; if (j < 0) return 1;`；`dp[i][j] = f(i-1, j)`，若 `s[i] == t[j]` 再 `+ f(i-1, j-1)`；
- 迭代（长度版）：`dp[i][j] = dp[i-1][j]`，若 `s[i-1] == t[j-1]` 再 `+ dp[i-1][j-1]`；初始化 `dp[i][0] = 1`；
- 空间压缩成一维时，**从右往左**填（因为依赖"上方"和"左上"）；
- 结果很大 → 用 `unsigned long long`。

### 题二：编辑距离（LeetCode 72，完整版：三种操作代价可不同）

`dp[i][j]` = s1 前 i 个字符变成 s2 前 j 个字符的最小代价，插入/删除/替换代价分别为 `a / b / c`：

1. `s1[i-1] == s2[j-1]` 且让它俩对应 → `dp[i-1][j-1]`；不等且替换 → `dp[i-1][j-1] + c`；
2. `s1[i-1]` 不变成 `s2[j-1]` → `dp[i][j-1] + a`（插入）；
3. `s1[i-1]` 不参与 → `dp[i-1][j] + b`（删除）；

初始化：`dp[i][0] = i*b`（s2 空 → 全删）、`dp[0][j] = j*a`（s1 空 → 全插）。

三种代价都是 1 时就是 LeetCode 72；笔记也给了"贪心化简版"（相等直接 `dp[i-1][j-1]`，不等取三者最小）与空间压缩版。

### 题三：交错字符串（LeetCode 97）

`dp[i][j]` = s1 前 i 个 + s2 前 j 个能否交错组成 s3 前 i+j 个：

```
dp[i][j] = (s1[i-1] == s3[i+j-1] && dp[i-1][j])
        || (s2[j-1] == s3[i+j-1] && dp[i][j-1]);
```

初始化 `dp[0][0] = true`，首行/首列要"一直匹配才为 true"（一旦不匹配就 break）。
**前提判断**：`s1.size() + s2.size() == s3.size()`。

### 题四：有效涂色问题（n 个格子涂满 m 种颜色）

`dp[i][j]` = 前 i 个格子用了 j 种颜色的方案数：

```
dp[i][j] = dp[i-1][j] * j                     // 用已有颜色（j 种都行）
         + dp[i-1][j-1] * (m - (j-1));        // 开新颜色（前面用了 j-1 种）
```

初始化 `dp[i][1] = m`（前 i 个格子只用 1 种颜色，有 m 种选法）；答案对 1e9+7 取模。

### 题五：s1 至少删除多少字符能成为 s2 的子串

**把"子串"转化成"任意后缀"**：`dp[i][j]` = s1 前 i 个字符至少要删多少，才能变成 s2 前 j 个字符的**任意后缀**：

```
s1[i-1] != s2[j-1] -> dp[i][j] = 1 + dp[i-1][j]     // 删掉 s1[i-1]
s1[i-1] == s2[j-1] -> dp[i][j] = dp[i-1][j-1]       // 匹配上，不用删
```

初始化 `dp[i][0] = i`；最后答案是**最后一行 dp[m][0..n] 的最小值**（因为"子串"可以是 s2 的任意后缀）。

## 适用特征（看到这些信号就选它）

- 两个字符串/序列之间的"匹配、转换、交错、删除"；
- 状态是"前 i 个 / 前 j 个"这种**前缀对**；
- 要统计方案数或最小代价。

## 易错点

1. 用下标定义时 `i < 0`、`j < 0` 的 base case 要想清楚（如 `i < j` 时不可能匹配，直接 0）；
2. **改成迭代时优先换成"长度"定义**（笔记明说：下标定义改迭代不好改）；
3. 空间压缩的填表方向：依赖"上方 + 左上" → 从右往左；依赖"左 + 左上" → 从左往右；
4. 首行/首列的初始化往往是"连续匹配才为 true"（交错字符串），不能无脑全 true；
5. 方案数题要注意溢出（`unsigned long long` / 取模）；
6. "子串"题要转化成"后缀"再取行最小值，这是本题的关键转化。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 不同的子序列（空间压缩） ----------
int numDistinct(const string& s, const string& t) {
    int m = (int)s.size(), n = (int)t.size();
    vector<unsigned long long> dp(n + 1, 0);
    dp[0] = 1;
    for (int i = 1; i <= m; i++)
        for (int j = n; j >= 1; j--)                 // 从右往左
            if (s[i - 1] == t[j - 1]) dp[j] += dp[j - 1];
    return (int)dp[n];
}

// ---------- 2. 编辑距离（三种代价 + 空间压缩） ----------
int editDistance(const string& s1, const string& s2, int a, int b, int c) {
    int m = (int)s1.size(), n = (int)s2.size();
    vector<int> dp(n + 1, 0);
    for (int j = 0; j <= n; j++) dp[j] = j * a;
    for (int i = 1; i <= m; i++) {
        int leftup = dp[0];
        dp[0] = i * b;
        for (int j = 1; j <= n; j++) {
            int backup = dp[j];
            if (s1[i - 1] == s2[j - 1]) dp[j] = leftup;
            else dp[j] = min(min(dp[j - 1] + a, dp[j] + b), leftup + c);
            leftup = backup;
        }
    }
    return dp[n];
}

// ---------- 3. 交错字符串 ----------
bool isInterleave(const string& s1, const string& s2, const string& s3) {
    int len1 = (int)s1.size(), len2 = (int)s2.size();
    if (len1 + len2 != (int)s3.size()) return false;
    vector<vector<bool>> dp(len1 + 1, vector<bool>(len2 + 1, false));
    dp[0][0] = true;
    for (int i = 1; i <= len1; i++) {
        if (s1[i - 1] != s3[i - 1]) break;
        dp[i][0] = true;
    }
    for (int j = 1; j <= len2; j++) {
        if (s2[j - 1] != s3[j - 1]) break;
        dp[0][j] = true;
    }
    for (int i = 1; i <= len1; i++)
        for (int j = 1; j <= len2; j++)
            dp[i][j] = (s1[i - 1] == s3[i + j - 1] && dp[i - 1][j])
                    || (s2[j - 1] == s3[i + j - 1] && dp[i][j - 1]);
    return dp[len1][len2];
}
```
