# 见识更多二维动态规划题目（字符串型）

> 来源笔记：`0303见识更多二维动态规划题目.cpp`｜核心程度：必背｜分类：06 动态规划

## 一句话

字符串上的二维 DP 只有两种状态定义：**下标**（`dp[i][j]` = s1 到 i、s2 到 j）和**长度**（`dp[len1][len2]`）；后者能省掉越界讨论，但要看清"当前格子依赖哪些格子"来决定遍历方向。

## 解决什么问题

- 两个字符串之间的匹配 / 转换 / 交错 / 删除；
- 统计方案数（不同的子序列）；
- 求最小编辑代价（编辑距离）；
- 判断能否交错组成（交错字符串）。

## 核心思想

1. **定状态**：`dp[i][j]` = "s1 的前 i 个字符"与"s2 的前 j 个字符"之间某个量的最优值；
2. **定转移**：讨论 s1 的第 i 个字符 / s2 的第 j 个字符**参不参与**；
3. **定顺序**：`i` 从小到大、`j` 从小到大（依赖上方、左方、左上）。

## 为什么这样做（以 LCS 为例）

设 `dp[i][j]` 是 `s1[0..i-1]` 与 `s2[0..j-1]` 的 LCS 长度。看两个串的**最后一个字符**：

- 如果 `s1[i-1] == s2[j-1]`，这个字符一定可以放进公共子序列的末尾，于是 `dp[i][j] = dp[i-1][j-1] + 1`；
- 如果不等，至少有一个末尾字符不会出现在公共子序列里，于是 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。

正确性来自"**最优子结构 + 分类讨论**"：任何最优公共子序列，要么用了这两个末尾字符，要么至少舍弃其中一个。

## 手算演练（编辑距离）

`s1 = "horse"`、`s2 = "ros"`，插入/删除/替换代价都是 1。填表（行是 s1 前缀，列是 s2 前缀）：

| | "" | r | o | s |
| --- | --- | --- | --- | --- |
| "" | 0 | 1 | 2 | 3 |
| h | 1 | 1 | 2 | 3 |
| ho | 2 | 2 | 1 | 2 |
| hor | 3 | 2 | 2 | 2 |
| hors | 4 | 3 | 3 | 3 |
| horse | 5 | 4 | 4 | 3 |

最后一格 `dp[5][3] = 3`：horse → rorse（删 h）→ rose（删 r）→ ros（删 e），或 horse → rorse（删 h）→ rose（替换 o→o 不需要）……不同路径都得到 3。

## 五道题

### 题一：不同的子序列（LeetCode 115）

统计 s 的子序列中 t 出现的个数。

- 递归（下标版）：`if (i < j) return 0; if (j < 0) return 1;`；`f(i,j) = f(i-1,j)`，若 `s[i]==t[j]` 再 `+ f(i-1,j-1)`；
- 迭代（长度版）：`dp[i][j] = dp[i-1][j]`，若 `s[i-1]==t[j-1]` 再 `+ dp[i-1][j-1]`；初始化 `dp[i][0] = 1`；
- 空间压缩成一维时**从右往左**填；
- 结果很大 → `unsigned long long`。

### 题二：编辑距离（LeetCode 72，完整版）

`dp[i][j]` = s1 前 i 个字符变成 s2 前 j 个字符的最小代价，插入/删除/替换代价分别为 a/b/c：

1. 相等且对应 → `dp[i-1][j-1]`；不等且替换 → `dp[i-1][j-1] + c`；
2. 插入 → `dp[i][j-1] + a`；
3. 删除 → `dp[i-1][j] + b`。

初始化 `dp[i][0] = i*b`、`dp[0][j] = j*a`。三种代价都为 1 就是 LeetCode 72。

### 题三：交错字符串（LeetCode 97）

```
dp[i][j] = (s1[i-1] == s3[i+j-1] && dp[i-1][j])
        || (s2[j-1] == s3[i+j-1] && dp[i][j-1]);
```

初始化 `dp[0][0] = true`，首行/首列"连续匹配才为 true"（一旦不匹配就 break）。前提：`s1.size()+s2.size()==s3.size()`。

### 题四：有效涂色问题（n 个格子涂满 m 种颜色）

```
dp[i][j] = dp[i-1][j] * j                     // 用已有颜色
         + dp[i-1][j-1] * (m - (j-1));        // 开新颜色
```

初始化 `dp[i][1] = m`；答案对 1e9+7 取模。

### 题五：s1 至少删除多少字符能成为 s2 的子串

**把"子串"转化成"任意后缀"**：`dp[i][j]` = s1 前 i 个字符变成 s2 前 j 个字符的**任意后缀**所需的最少删除数：

```
s1[i-1] != s2[j-1] -> 1 + dp[i-1][j]
s1[i-1] == s2[j-1] -> dp[i-1][j-1]
```

初始化 `dp[i][0] = i`；答案是**最后一行 dp[m][0..n] 的最小值**。

## 适用特征（看到这些信号就选它）

- 两个字符串/序列之间的"匹配、转换、交错、删除"；
- 状态是"前 i 个 / 前 j 个"这种**前缀对**；
- 要统计方案数或最小代价。

## 复杂度

- 状态数 O(m×n)，转移 O(1)，总时间 O(m×n)；
- 空间 O(m×n)，可压缩到 O(min(m,n))。

## 与相似算法对比

| 题型 | 状态 | 初始化 |
| --- | --- | --- |
| LCS | `dp[i][j]` | 全 0 |
| 编辑距离 | `dp[i][j]` | 首行 i*a、首列 j*b |
| 交错字符串 | `dp[i][j]` bool | 首行/列连续匹配 |
| 不同子序列 | `dp[i][j]` 计数 | `dp[i][0]=1` |
| 删除成子串 | `dp[i][j]` | `dp[i][0]=i` |

## 易错点

1. 用下标定义时 `i<0`、`j<0` 的 base case 要想清楚（如 `i<j` 时不可能匹配，直接 0）；
2. **改成迭代时优先换成"长度"定义**；
3. 空间压缩方向：依赖"上方 + 左上" → 从右往左；依赖"左 + 左上" → 从左往右；
4. 首行/首列初始化往往是"连续匹配才为 true"；
5. 方案数题注意溢出（`unsigned long long` / 取模）；
6. "子串"题要转化成"后缀"再取行最小值。

## 模板（可直接编译运行）

```cpp
// 二维字符串 DP 模板：不同子序列 / 编辑距离 / 交错字符串 / 涂色方案 / 删除成子串
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= 1. 不同的子序列（空间压缩） =================
int numDistinct(const string& s, const string& t) {
    int m = (int)s.size(), n = (int)t.size();
    vector<unsigned long long> dp(n + 1, 0);
    dp[0] = 1;                                   // t 为空 → 一种方案
    for (int i = 1; i <= m; i++)
        for (int j = n; j >= 1; j--)             // 依赖上方与左上 → 从右往左
            if (s[i - 1] == t[j - 1]) dp[j] += dp[j - 1];
    return (int)dp[n];
}

// ================= 2. 编辑距离（三种代价可不同 + 空间压缩） =================
int editDistance(const string& s1, const string& s2, int a, int b, int c) {
    int m = (int)s1.size(), n = (int)s2.size();
    vector<int> dp(n + 1, 0);
    for (int j = 0; j <= n; j++) dp[j] = j * a;   // 插入
    for (int i = 1; i <= m; i++) {
        int leftup = dp[0];
        dp[0] = i * b;                            // 删除
        for (int j = 1; j <= n; j++) {
            int backup = dp[j];
            if (s1[i - 1] == s2[j - 1]) dp[j] = leftup;
            else dp[j] = min(min(dp[j - 1] + a, dp[j] + b), leftup + c);
            leftup = backup;
        }
    }
    return dp[n];
}

// ================= 3. 交错字符串 =================
bool isInterleave(const string& s1, const string& s2, const string& s3) {
    int len1 = (int)s1.size(), len2 = (int)s2.size();
    if (len1 + len2 != (int)s3.size()) return false;
    vector<vector<bool>> dp(len1 + 1, vector<bool>(len2 + 1, false));
    dp[0][0] = true;
    for (int i = 1; i <= len1; i++) {
        if (s1[i - 1] != s3[i - 1]) break;        // 首列：连续匹配才为真
        dp[i][0] = true;
    }
    for (int j = 1; j <= len2; j++) {
        if (s2[j - 1] != s3[j - 1]) break;
        dp[0][j] = true;
    }
    for (int i = 1; i <= len1; i++)
        for (int j = 1; j <= len2; j++)
            dp[i][j] = (s1[i - 1] == s3[i + j - 1] && dp[i - 1][j])
                    || (s2[j - 1] == s3[i + j - 1] && dp[i][j - 1]);
    return dp[len1][len2];
}

// ================= 4. 有效涂色（n 个格子涂满 m 种颜色的方案数） =================
int coloringWays(int n, int m) {
    const long long MOD = 1000000007;
    vector<vector<long long>> dp(n + 1, vector<long long>(m + 1, 0));
    for (int i = 1; i <= n; i++) dp[i][1] = m;    // 只用一种颜色
    for (int i = 2; i <= n; i++)
        for (int j = 2; j <= m; j++)
            dp[i][j] = (dp[i - 1][j] * j + dp[i - 1][j - 1] * (m - (j - 1))) % MOD;
    return (int)dp[n][m];
}

// ================= 5. s1 至少删除多少字符能变成 s2 的子串 =================
int minDeleteToSubstring(const string& s1, const string& s2) {
    int m = (int)s1.size(), n = (int)s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (int i = 0; i <= m; i++) dp[i][0] = i;    // 目标是空串 → 全删
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = (s1[i - 1] != s2[j - 1]) ? 1 + dp[i - 1][j] : dp[i - 1][j - 1];
    int ans = INT_MAX;
    for (int j = 0; j <= n; j++) ans = min(ans, dp[m][j]);   // 取最后一行最小值
    return ans;
}

int main() {
    std::cout << "不同子序列 = " << numDistinct("rabbbit", "rabbit") << "\n";        // 3
    std::cout << "编辑距离 = " << editDistance("horse", "ros", 1, 1, 1) << "\n";     // 3
    std::cout << "交错字符串 = " << (int)isInterleave("aab", "axy", "aaxaby") << "\n";// 1
    std::cout << "涂色方案 = " << coloringWays(3, 2) << "\n";                        // 6
    std::cout << "最少删除 = " << minDeleteToSubstring("abcde", "bcd") << "\n";      // 2
    return 0;
}
```

## 进阶拓展

1. **双序列 → 双数组**：把字符换成数字，就是"两个数组的最优匹配"。
2. **编辑距离的变体**：只允许插入/删除（= 最长公共子序列）、只允许交换、加权代价——都是改转移方程。
3. **正则 / 通配符匹配**：`*` 对应"完全背包式"的多选，见 `0322`。
4. **滚动数组**：只保留上一行 + 一个 `leftUp` 变量。

## 面试追问

1. **为什么编辑距离的转移有三种操作？** 对应"对齐（可能替换）、在 s2 插入、从 s1 删除"三种最后的动作。
2. **为什么先交换成短串？** 空间压缩时只开短串长度的数组，空间 O(min(m,n))。
3. **交错字符串的首行为什么是"连续匹配"？** 前缀必须由同一个串连续提供，一旦断掉后面都不行。
4. **不同的子序列为什么要 `unsigned long long`？** 结果可能超过 `int`。
5. **LCS 和编辑距离的关系？** 只允许插入/删除时，编辑距离 = n+m-2*LCS。
