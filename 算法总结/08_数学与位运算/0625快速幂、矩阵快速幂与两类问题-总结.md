# 快速幂、矩阵快速幂与两类问题

> 来源笔记：`0625快速幂、矩阵快速幂与两类问题.cpp`｜核心程度：必背模板｜分类：08 数学与位运算

## 一句话

快速幂把 `a^b` 从 O(b) 降到 O(log b)；**矩阵快速幂**则用来加速**固定关系的线性递推**——只要能把递推写成"向量 × 矩阵"，就能 O(log n · k³) 求出第 n 项。

## 一、乘法快速幂（模板）

```cpp
long long quickPower(long long a, long long b, long long p) {
    long long ans = 1;
    while (b > 0) {
        if (b & 1) ans = ans * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return ans;
}
```

## 二、矩阵乘法与矩阵快速幂

- 矩阵乘法：`ret[i][j] = Σ a[i][k] * b[k][j]`（a 的列数必须等于 b 的行数）；
- 矩阵快速幂：把底数矩阵反复平方，按二进制位乘到 `ans`（**单位矩阵**相当于"1"）：

```cpp
for (; p > 0; p >>= 1) {
    if (p & 1) ans = multiply(ans, m);
    m = multiply(m, m);
}
```

**关系矩阵怎么定**（笔记原文）："关系矩阵的**第 0 列**直接由递推表达式确定，剩下的项可以用前面的初始项代入求出。"

## 三、两类问题

> 笔记把矩阵快速幂能解决的问题分成两类：
> 1. **固定关系的一维 k 阶递推**：`f(n) = c1·f(n-1) + ... + ck·f(n-k)`，用 k×k 矩阵，O(log n · k³)；
> 2. **固定关系的 k 维一阶递推**：状态向量有 k 个分量，转移矩阵 k×k，同样 O(log n · k³)。

**限制**：矩阵快速幂只能解决**严格固定**的递推，**有条件转移的递推不行**。

## 四、七道题

| 题 | 递推 / 状态 | 矩阵 |
| --- | --- | --- |
| 斐波那契 | `f(n)=f(n-1)+f(n-2)` | `{{1,1},{1,0}}`，起始 `{1,0}` |
| 爬楼梯 | 同斐波那契 | 同上，起始 `{1,1}` |
| 泰波那契 | `t(n)=t(n-1)+t(n-2)+t(n-3)` | 3×3，起始 `{1,1,0}` |
| 多米诺和托米诺平铺 | **打表找规律**：`f(n) = 2f(n-1) + f(n-3)` | 3×3 |
| 统计元音字母序列 | 5 个字母的转移关系 | 5×5 转移矩阵 |
| 学生出勤记录 II | `dp[i][a][b]`（a≤1、b≤2），**三维压成 6 个状态** | 6×6 |

其中"多米诺"和"元音""出勤"三题笔记都给了**记忆化搜索版**作对照（矩阵快速幂的优势在 n 很大时）。

## 适用特征（看到这些信号就选它）

- 递推式固定、n 极大（10^9 以上）→ 矩阵快速幂；
- 状态是"若干个数的线性组合"→ 一维 k 阶递推；
- 状态向量各分量之间是固定线性关系 → k 维一阶递推；
- 需要打表看规律时，先写暴力/记忆化，再转矩阵。

## 易错点

1. 快速幂里 `a` 要在循环中自己平方，别写成 `a * a` 却不赋值；
2. 矩阵快速幂要**先取单位矩阵**作为 ans；
3. 乘法中要**用 long long 中间量**并逐项取模（笔记里都是 `(ret + 1LL*a*b) % MOD`）;
4. 关系矩阵的**第 0 列**是递推系数（笔记的关键提示），初始向量要与矩阵维度对齐；
5. 起始向量的定义（`{f(1), f(0)}` 还是别的）决定了指数是 `n-1` 还是 `n-2`；
6. 有条件转移（如带限制的 DP）**不能用矩阵快速幂**；
7. 三维状态转矩阵前，要先**压成一维编号**（如 `a*3+b`）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;
const long long MOD = 1000000007;

// ---------- 快速幂 ----------
long long quickPower(long long a, long long b, long long p) {
    long long ans = 1;
    a %= p;
    while (b > 0) {
        if (b & 1) ans = ans * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return ans;
}

// ---------- 矩阵乘法 + 矩阵快速幂 ----------
using Mat = vector<vector<long long>>;
Mat multiply(const Mat& a, const Mat& b, long long mod = MOD) {
    int ma = (int)a.size(), na = (int)a[0].size(), nb = (int)b[0].size();
    Mat ret(ma, vector<long long>(nb, 0));
    for (int i = 0; i < ma; i++)
        for (int k = 0; k < na; k++) {
            if (!a[i][k]) continue;
            for (int j = 0; j < nb; j++)
                ret[i][j] = (ret[i][j] + a[i][k] * b[k][j]) % mod;
        }
    return ret;
}
Mat quickPowerMat(Mat m, long long p, long long mod = MOD) {
    int n = (int)m.size();
    Mat ans(n, vector<long long>(n, 0));
    for (int i = 0; i < n; i++) ans[i][i] = 1;       // 单位矩阵
    for (; p > 0; p >>= 1) {
        if (p & 1) ans = multiply(ans, m, mod);
        m = multiply(m, m, mod);
    }
    return ans;
}

// ---------- 斐波那契第 n 项（矩阵快速幂） ----------
long long fib(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    Mat start = {{1, 0}};                            // {f(1), f(0)}
    Mat base = {{1, 1}, {1, 0}};
    Mat ret = multiply(start, quickPowerMat(base, n - 1));
    return ret[0][0];
}

// ---------- 多米诺和托米诺平铺：f(n) = 2f(n-1) + f(n-3) ----------
long long numTilings(long long n) {
    // 令 g(m) = f(m+1)，则 g(m) = 2g(m-1) + g(m-3)，g(0)=1, g(1)=2, g(2)=5
    auto g = [&](long long m) -> long long {
        if (m == 0) return 1;
        if (m == 1) return 2;
        if (m == 2) return 5;
        Mat start = {{5, 2, 1}};
        Mat base = {{2, 1, 0}, {0, 0, 1}, {1, 0, 0}};
        Mat ret = multiply(start, quickPowerMat(base, m - 2));
        return ret[0][0];
    };
    return g(n - 1);
}

int main() {
    printf("quickPower(3,10,1e9+7) = %lld\n", quickPower(3, 10, MOD));  // 59049
    printf("fib(10) = %lld\n", fib(10));                                // 55
    printf("numTilings(3) = %lld\n", numTilings(3));                    // 5
    return 0;
}
