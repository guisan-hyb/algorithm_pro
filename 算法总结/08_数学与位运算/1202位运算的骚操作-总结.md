# 位运算的骚操作

> 来源笔记：`1202位运算的骚操作.cpp`｜核心程度：必背模板（很多题直接套）｜分类：08 数学与位运算

## 一句话

六道题各自对应一个**可以当模板用**的位运算技巧：判 2 的幂、判 3 的幂、找最近的 2 的幂、区间按位与、翻转二进制、统计 1 的个数。

## 六道题

### 题一：判断是不是 2 的幂

2 的幂的二进制里**只有一个 1**，所以用 Brian Kernighan 提取最低位的 1，判断是否等于自身：

```cpp
return n > 0 && n == (n & -n);
```

### 题二：判断是不是 3 的幂

`int` 范围内最大的 3 的幂是 **1162261467**（3^19），它只含质因子 3：

```cpp
return n > 0 && 1162261467 % n == 0;
```

### 题三：返回 ≥ n 的最小的 2 的幂

**把最高位 1 右侧全部刷成 1，再 +1**：

```cpp
if (n <= 0) return 1;
n--;                                        // 减一防 n 本身是 2 的幂
n |= (unsigned)n >> 1;
n |= (unsigned)n >> 2;
n |= (unsigned)n >> 4;
n |= (unsigned)n >> 8;
n |= (unsigned)n >> 16;
return n + 1;
```

（笔记提醒：C++ 没有无符号右移运算符，要**强转 `(unsigned)`**。）

### 题四：区间 [left, right] 内所有数字按位与的结果

**公共前缀**思路：只要 `left < right`，`right` 最低位的 1 一定留不下来，不断减掉它：

```cpp
while (left < right) right -= right & -right;
return right;
```

### 题五：翻转二进制位（三种写法）

1. 逐位取 `n` 的最低位放到 `ans` 的 `31-i` 位；
2. 从高位往低位扫；
3. **Pro 版（分治交换，像归并的递归）**：

```cpp
n = ((n & 0xaaaaaaaa) >> 1) | ((n & 0x55555555) << 1);
n = ((n & 0xcccccccc) >> 2) | ((n & 0x33333333) << 2);
n = ((n & 0xf0f0f0f0) >> 4) | ((n & 0x0f0f0f0f) << 4);
n = ((n & 0xff00ff00) >> 8) | ((n & 0x00ff00ff) << 8);
n = (n >> 16) | (n << 16);
```

### 题六：统计二进制中 1 的个数（汉明权重）

- 朴素版：逐位判断；
- **Pro 版（分治累加）**：

```cpp
n = (n & 0x55555555) + (((unsigned)n >> 1) & 0x55555555);
n = (n & 0x33333333) + (((unsigned)n >> 2) & 0x33333333);
n = (n & 0x0f0f0f0f) + (((unsigned)n >> 4) & 0x0f0f0f0f);
n = (n & 0x00ff00ff) + (((unsigned)n >> 8) & 0x00ff00ff);
n = (n & 0x0000ffff) + ((unsigned)(n >> 16) & 0x0000ffff);
```

**汉明距离** = 两数异或后 1 的个数：`hammingDistance(x, y) = countOne_Pro(x ^ y)`。

> 笔记原话："条件判断比赋值、位运算、算术运算稍慢，所以 Pro 解法有现实意义——直接当模板用即可。"

## 适用特征（看到这些信号就选它）

| 需求 | 技巧 |
| --- | --- |
| 判 2/3 的幂 | `n & -n` / 最大幂取模 |
| 找最近的 2 的幂 | 右侧刷 1 再 +1 |
| 区间按位与 | 抹掉 right 的低位 1 |
| 翻转二进制 / 数 1 的个数 | 分治法（掩码移位） |
| 两数差异位数 | 异或 + 数 1 |

## 易错点

1. `near2Power` 别忘了 `n--`（否则 n 本身是 2 的幂时会返回 2n）；
2. 移位要用 `(unsigned)`（C++ 的 `>>` 对负数是算术右移）；
3. Pro 版代码里的掩码（`0xaaaa...`、`0x5555...`）必须写对；
4. `rangeBitwiseAnd` 的循环条件是 `left < right`（相等就不用动）；
5. `1162261467 % n` 之前要判 `n > 0`（除零）；
6. 这些技巧都建议**用对数器验证**（笔记给每个技巧都写了测试）。

## 模板（可直接编译运行）

```cpp
// 位运算骚操作模板：2/3 的幂 / 最近 2 的幂 / 区间按位与 / 翻转 / 数 1
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
using namespace std;

// ---------- 1. 2 的幂 ----------
bool isPowerOfTwo(int n) { return n > 0 && n == (n & -n); }

// ---------- 2. 3 的幂 ----------
bool isPowerOfThree(int n) { return n > 0 && 1162261467 % n == 0; }   // 3^19

// ---------- 3. ≥ n 的最小 2 的幂 ----------
int near2Power(int n) {
    if (n <= 0) return 1;
    n--;                                        // ★防 n 本身是 2 的幂
    n |= (unsigned)n >> 1;
    n |= (unsigned)n >> 2;
    n |= (unsigned)n >> 4;
    n |= (unsigned)n >> 8;
    n |= (unsigned)n >> 16;
    return n + 1;
}

// ---------- 4. 区间 [left, right] 按位与 ----------
int rangeBitwiseAnd(int left, int right) {
    while (left < right) right -= right & -right;
    return right;
}

// ---------- 5. 翻转二进制（分治） ----------
unsigned reverseBits(unsigned n) {
    n = ((n & 0xaaaaaaaau) >> 1) | ((n & 0x55555555u) << 1);
    n = ((n & 0xccccccccu) >> 2) | ((n & 0x33333333u) << 2);
    n = ((n & 0xf0f0f0f0u) >> 4) | ((n & 0x0f0f0f0fu) << 4);
    n = ((n & 0xff00ff00u) >> 8) | ((n & 0x00ff00ffu) << 8);
    n = (n >> 16) | (n << 16);
    return n;
}

// ---------- 6. 统计 1 的个数（分治） + 汉明距离 ----------
int countOne(unsigned n) {
    n = (n & 0x55555555u) + ((n >> 1) & 0x55555555u);
    n = (n & 0x33333333u) + ((n >> 2) & 0x33333333u);
    n = (n & 0x0f0f0f0fu) + ((n >> 4) & 0x0f0f0f0fu);
    n = (n & 0x00ff00ffu) + ((n >> 8) & 0x00ff00ffu);
    n = (n & 0x0000ffffu) + ((n >> 16) & 0x0000ffffu);
    return (int)n;
}
int hammingDistance(int x, int y) { return countOne((unsigned)(x ^ y)); }

int main() {
    std::cout << "isPowerOfTwo(16) = " << (int)isPowerOfTwo(16) << "\n";      // 1
    std::cout << "isPowerOfThree(27) = " << (int)isPowerOfThree(27) << "\n";  // 1
    std::cout << "near2Power(17) = " << near2Power(17) << "\n";               // 32
    std::cout << "rangeBitwiseAnd(5,7) = " << rangeBitwiseAnd(5, 7) << "\n";  // 4
    std::cout << "reverseBits(1) = " << reverseBits(1) << "\n";               // 2147483648
    std::cout << "countOne(0b1011) = " << countOne(0b1011) << "\n";           // 3
    std::cout << "hammingDistance(1,4) = " << hammingDistance(1, 4) << "\n";  // 2
    return 0;
}
```

## 专题深化：为什么成立

许多整数性质可以转化为位模式：2 的幂只有一个 1；区间按位与的公共前缀决定结果；反转位就是逐位搬运。位运算常把 O(log V) 循环压进常数次操作。

## 专题深化：手算与边界

`x=17` 的最近 2 的幂是 32；`rangeBitwiseAnd(5,7)` 的公共前缀为 `100₂=4`；汉明距离统计 `x^y` 的 1 的个数。

### 对照与取舍

位技巧适合固定宽度整数；字符串/大数需专用位集；不要为了炫技牺牲可读性，公式要有注释。

### 易错点与反例

1. 移位位数等于或超过位宽是 UB
2. 负数补码需明确语义
3. 2 的幂判断要排除 0
4. 浮点位模式与整数位运算不能混用
