# 异或运算的骚操作

> 来源笔记：`1201异或运算的骚操作.cpp`｜核心程度：必背（位运算第一课）｜分类：08 数学与位运算

## 一句话

异或的一切性质都来自一句话：**异或就是无进位相加**；由此推出"交换律、结合律、`0^n=n`、`n^n=0`、以及 `a^b=c ⇒ a=c^b`"。

## 一、四条性质

1. **异或 = 无进位相加**（最重要，其余都能推出来）；
2. 满足**交换律与结合律** ⇒ 同一批数字无论什么顺序异或，结果都一样；
3. `0 ^ n = n`，`n ^ n = 0`；
4. **整体异或和是 x、其中一部分是 y，则剩余部分就是 x ^ y**；等价地 `a ^ b = c ⇒ a = c ^ b, b = c ^ a`。

> 笔记原话：结论 4 相关的题目最多（利用区间异或和的性质）。

## 二、六道题

### 题一：不用临时变量交换两个数

```
a ^= b; b ^= a; a ^= b;
```

**前提（笔记特别提醒）**：两个变量必须各自有独立内存。若用数组 `arr[i]`、`arr[j]` 且 `i == j`，会得到 `n ^ n = 0`，把数据清成 0——所以这写法知道即可，不推荐。

### 题二：不用任何判断/比较返回两数最大值

- `sign(n)`：非负返回 1、负数返回 0（`flip((unsigned)n >> 31)`）；
- 朴素版 `c = a - b`，用 `sign(c)` 选 a 还是 b，**但有溢出风险**；
- **改进版（无溢出）**：先算 `sa = sign(a)`、`sb = sign(b)`、`sc = sign(c)`；
  - `diffAB = sa ^ sb`；`sameAB = flip(diffAB)`；
  - `returnA = sameAB * sc + diffAB * sa`（同号看 c，异号看 a）；
  - `returnB = flip(returnA)`；最后 `a * returnA + b * returnB`。

### 题三：找到缺失的数字（0~n 中缺一个）

把"0~n 的全部异或和"与"数组的异或和"再异或，就是缺失的那个数（性质 4）。

### 题四：只有一种数出现奇数次（其余偶数次）

全部异或，结果就是它。

### 题五：有两种数出现奇数次

1. 全部异或得到 `eor1 = a ^ b`；
2. 用 **Brian Kernighan** 取 `rightOne = eor1 & (-eor1)`（a、b 在这一位上必然不同）；
3. 按这一位把数组分成两组，分别异或 → 得到其中一个数；
4. 另一个 = `eor1 ^ 那个数`。

> 笔记提醒：取反时转 `long` 防溢出（`eor1 & (-(long)eor1)`）。

### 题六：只有一种数出现次数 < m 次，其余都恰好 m 次

**按位统计**：开一个 32 位桶，统计每一位上 1 的个数；

- 若某位上的计数 `% m == 0` → 目标数该位为 0；
- 否则目标数该位为 1。

## 适用特征（看到这些信号就选它）

- "其余数都出现偶数次 / 恰好 m 次" → 异或 / 按位统计；
- "缺了一个数""区间异或" → 前缀异或；
- 需要在没有比较/判断的情况下完成选择（面试趣味题）；
- 集合的对称差、标志位翻转。

## 易错点

1. 交换法在 `i == j`（同一块内存）时会把数据清零；
2. 取最低位 1 要写 `x & (-x)`，对 `int` 取 `-x` 可能溢出 → 用 `(long)`；
3. 求解"两种数出现奇数次"时，分组依据是 `rightOne` 那一位，别用错；
4. 按位统计题的桶是 32 位（`int`），`long` 要 64 位；
5. 笔记里原代码在"找目标数"的双层循环下标上写错过（`cnt[i] += (arr[i] >> i) & 1`），正确写法是 `cnt[j] += (arr[i] >> j) & 1`。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 交换（仅限独立内存；i==j 会清零，不推荐） ----------
void mySwap(int& a, int& b) { a ^= b; b ^= a; a ^= b; }

// ---------- 2. 不用判断求最大值（无溢出版） ----------
int flip(int n) { return n ^ 1; }                       // 只对 0/1 有意义
int sign(int n) { return flip((int)((unsigned)n >> 31)); }   // 非负 1，负 0
int getMax(int a, int b) {
    int c = a - b;
    int sa = sign(a), sb = sign(b), sc = sign(c);
    int diffAB = sa ^ sb, sameAB = flip(diffAB);
    int returnA = sameAB * sc + diffAB * sa;
    int returnB = flip(returnA);
    return a * returnA + b * returnB;
}

// ---------- 3. 缺失的数字 ----------
int missingNumber(const vector<int>& a) {
    int eorAll = 0, eorHas = 0;
    for (int i = 0; i < (int)a.size(); i++) { eorAll ^= i; eorHas ^= a[i]; }
    eorAll ^= (int)a.size();
    return eorAll ^ eorHas;
}

// ---------- 4. 唯一出现奇数次的数 ----------
int singleNumber(const vector<int>& a) {
    int eor = 0;
    for (int x : a) eor ^= x;
    return eor;
}

// ---------- 5. 两种数出现奇数次 ----------
pair<int,int> singleNumber2(const vector<int>& a) {
    int eor1 = 0;
    for (int x : a) eor1 ^= x;
    int rightOne = (int)(eor1 & (-(long long)eor1));
    int eor2 = 0;
    for (int x : a) if ((x & rightOne) == 0) eor2 ^= x;
    return {eor2, eor1 ^ eor2};
}

// ---------- 6. 只有一种数出现次数 < m ----------
int findLessThanM(const vector<int>& a, int m) {
    vector<int> cnt(32, 0);
    for (int x : a)
        for (int j = 0; j < 32; j++)
            cnt[j] += (x >> j) & 1;                     // 注意下标是 j
    int ans = 0;
    for (int j = 0; j < 32; j++)
        if (cnt[j] % m != 0) ans |= (1 << j);
    return ans;
}

int main() {
    printf("getMax(3,-5) = %d\n", getMax(3, -5));               // 3
    printf("缺失的数字 = %d\n", missingNumber({0,1,2,3,5}));     // 4
    pair<int,int> p = singleNumber2({1,2,1,3});
    printf("两种奇数次 = %d %d\n", p.first, p.second);           // 2 3
    printf("出现次数<m的数 = %d\n", findLessThanM({5,5,5,3}, 3)); // 3
    return 0;
}
