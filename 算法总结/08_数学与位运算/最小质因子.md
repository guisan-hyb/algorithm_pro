## **最小质因子**

```cpp
	int minPrimeFactor(int n) {
        if (n % 2 == 0) return 2;
        for (int i = 3; i <= n / i; i += 2) {
            if (n % i == 0) return i;
        }
        return n;
    }
```

这个方法求的是 **最小质因子**，思路是：

### 1. 偶数直接返回 2

```cpp
if (n % 2 == 0) return 2;
```

因为 2 是最小质数，任何偶数的最小质因子都是 2。

---

### 2. 奇数只检查奇数因子

如果 `n` 是奇数，那么它的质因子一定都是奇数，所以从 3 开始，每次加 2：

```cpp
for (int i = 3; i <= n / i; i += 2)
```

只检查：

```text
3, 5, 7, 9, 11, 13, ...
```

其中 9、15 这样的合数也会被检查，但不会影响正确性，原因见下面。

---

### 3. 为什么循环到 `n / i` 就够了？

条件是：

```cpp
i <= n / i
```

等价于：

```cpp
i * i <= n
```

也就是：

```cpp
i <= sqrt(n)
```

如果 `n` 是合数，那么一定可以写成：

```text
n = a * b
```

其中至少有一个因子 `a <= sqrt(n)`。

所以只需要检查到 `sqrt(n)`。如果这里都找不到因子，说明 `n` 是质数。

比如：

```text
n = 49
sqrt(49) = 7
```

检查到 7 就能发现 `49 % 7 == 0`。

又比如：

```text
n = 97
sqrt(97) ≈ 9.8
```

只需检查 3、5、7、9，都不整除，所以 97 是质数。

---

### 4. 为什么第一个整除的 `i` 就是最小质因子？

循环是从小到大检查的：

```text
3, 5, 7, 9, 11, ...
```

如果某个 `i` 整除 `n`，那么它是目前遇到的第一个因子。

可能你会问：如果 `i` 是合数怎么办？比如 9。

假设 `i = 9` 整除 `n`，那么 3 也整除 `n`。但 3 比 9 小，循环早就检查过 3 了。  
所以如果 9 会成为第一个整除 `n` 的数，这是不可能的，因为 3 会更早返回。

因此：

> 第一个整除 `n` 的 `i` 一定是质数，而且是最小质因子。

例如：

```text
n = 27
i = 3 时，27 % 3 == 0，直接返回 3
```

不会等到 9。

---

### 5. 如果没有找到因子，说明 `n` 是质数

```cpp
return n;
```

如果循环结束都没有找到任何因子，说明 `n` 没有小于等于 `sqrt(n)` 的因子，因此 `n` 是质数。  
质数的最小质因子就是它自己。

例如：

```text
n = 17
检查 i = 3，17 % 3 != 0
循环结束，返回 17
```

---

### 6. 举例验证

#### 例 1：`n = 9`

```text
n % 2 != 0
i = 3，i <= 9/3 = 3
9 % 3 == 0
返回 3
```

最小质因子是 3，正确。

#### 例 2：`n = 15`

```text
i = 3，i <= 15/3 = 5
15 % 3 == 0
返回 3
```

最小质因子是 3，正确。

#### 例 3：`n = 25`

```text
i = 3，25 % 3 != 0
i = 5，5 <= 25/5 = 5
25 % 5 == 0
返回 5
```

最小质因子是 5，正确。

#### 例 4：`n = 49`

```text
i = 3，不整除
i = 5，不整除
i = 7，7 <= 49/7 = 7
49 % 7 == 0
返回 7
```

最小质因子是 7，正确。

#### 例 5：`n = 17`

```text
i = 3，3 <= 17/3 = 5，不整除
i = 5，5 <= 17/5 = 3，不满足，循环结束
返回 17
```

17 是质数，最小质因子是 17，正确。

---

### 关键点总结

```cpp
int minPrimeFactor(int n) {
    if (n % 2 == 0) return 2;

    for (int i = 3; i <= n / i; i += 2) {
        if (n % i == 0) return i;
    }

    return n;
}
```

它正确的原因：

1. 偶数的最小质因子一定是 2；
2. 奇数只需检查奇数因子；
3. 合数一定有一个因子不超过 `sqrt(n)`，所以循环到 `n / i` 就够；
4. 从小到大检查，第一个整除 `n` 的数一定是最小质因子；
5. 如果循环结束都没找到因子，则 `n` 是质数，返回 `n`。

注意你原来的循环写成了：

```cpp
for(int i = 3; i < n / i; i += 2)
```

这会漏掉平方因子，比如 `n = 9` 时：

```text
i = 3，但 3 < 9 / 3 即 3 < 3 不成立
```

所以会错误地返回 9，而不是 3。应该用：

```cpp
i <= n / i
```
