# 质数判断、质因子分解与质数筛

> 来源笔记：`0624质数判断、质因子分解、质数筛.cpp`｜核心程度：必背模板（当原子技能）｜分类：08 数学与位运算

## 一句话

四件事：**小范围判质数**（O(√n)）、**大范围判质数**（Miller-Rabin）、**质因子分解**（试除到 √n）、**筛出 1~n 的质数**（埃氏筛就够）。

笔记原话："证明麻烦且没有扩展性，记住用法和模板即可，当作原子技能使用。"

## 一、判断小范围质数（O(√n)）

如果 n 不是质数，它必有一个 ≤ √n 的因子，所以只需试除到 √n：

```cpp
bool isPrime(long long n) {
    if (n <= 1) return false;
    for (long long i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
```

## 二、判断大范围质数（Miller-Rabin）

思路（笔记只要求会用）：

1. 每次选 1 ~ n-1 范围内的数（或用一批小质数）做测试；
2. 背后用到的原理：费马小定理、Carmichael 数、二次探测定理、乘法同余、快速幂；
3. 测 s 次，s 越大出错率越低、速度越慢，一般 20 次以内即可；
4. 复杂度 `O(s · (log n)³)`，很快。

两种实现：`long long` 版（配合快速幂，适用 10^9 量级）；`__int128` 版（GCC/Clang 扩展，比赛环境可用）。

## 三、质因子分解

最常用方法（试除到 √n）：

```cpp
for (long long j = 2; j * j <= x; j++) {
    if (x % j == 0) {
        // 用质因子 j 做合并（例如并查集）
        while (x % j == 0) x /= j;      // 把 j 除干净
    }
}
if (x > 1) { /* x 本身是剩下的质因子 */ }
```

典型应用（LeetCode 952 最大连通分量）：把"有公共质因子"的数用并查集合并（`factors[质因子]` 记录该质因子第一次出现在哪个下标），最后取最大的集合。

## 四、筛出 1~n 的所有质数

### 埃氏筛（够用）O(n log log n)

初始认为都是质数；从 2 开始，若 i 是质数，就把 `i*i, i*i+i, ...` 全部标记为合数（**从 i² 开始**是关键优化）。

### 欧拉筛（线性筛）O(n)

核心：**每个合数只被它的最小质因子筛掉**——遍历到一个数就放进质数表，再用质数表里的质数筛它的倍数，**当 `i % prime[j] == 0` 时立刻 break**。

### 只要计数时的埃氏筛优化

先把偶数处理掉（`cnt = n / 2`），再从 3 开始只遍历奇数、只筛奇数倍，能省一半时间。

## 适用特征（看到这些信号就选它）

| 需求 | 方法 |
| --- | --- |
| 单个数字判质数 | O(√n) 试除 |
| 单个大数判质数（10^18 量级） | Miller-Rabin |
| 分解某个数的质因子 | 试除到 √n |
| 统计/枚举 1~n 的质数 | 埃氏筛 / 欧拉筛 |
| "两数有公共质因子就相连" | 质因子分解 + 并查集 |

## 易错点

1. 试除边界用 `i * i <= n`，别写成 `i <= n / 2`（慢）；
2. `n <= 1` 不是质数；
3. 分解质因子时**必须把质因子除干净**（`while (x % j == 0) x /= j;`）；
4. 埃氏筛**从 `i*i` 开始标记**；
5. 欧拉筛的 `if (i % prime[j] == 0) break;` 不能省；
6. Miller-Rabin 要特判 `n <= 2` 与偶数；`__int128` 在 MSVC 下不可用。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 1) 小范围判质数
bool isPrime(long long n) {
    if (n <= 1) return false;
    for (long long i = 2; i * i <= n; i++) if (n % i == 0) return false;
    return true;
}

// 2) 埃氏筛
vector<int> primesUpTo(int n) {
    vector<char> composite(n + 1, 0);
    vector<int> primes;
    for (int i = 2; i <= n; i++)
        if (!composite[i]) {
            primes.push_back(i);
            if ((long long)i * i <= n)
                for (long long j = (long long)i * i; j <= n; j += i) composite[(int)j] = 1;
        }
    return primes;
}

// 3) 欧拉筛（线性）
vector<int> primesLinear(int n) {
    vector<char> composite(n + 1, 0);
    vector<int> primes;
    for (int i = 2; i <= n; i++) {
        if (!composite[i]) primes.push_back(i);
        for (int p : primes) {
            if ((long long)p * i > n) break;
            composite[p * i] = 1;
            if (i % p == 0) break;                 // ★
        }
    }
    return primes;
}

// 4) 质因子分解（不同的质因子）
vector<long long> primeFactors(long long x) {
    vector<long long> fac;
    for (long long j = 2; j * j <= x; j++)
        if (x % j == 0) {
            fac.push_back(j);
            while (x % j == 0) x /= j;             // 除干净
        }
    if (x > 1) fac.push_back(x);
    return fac;
}
```
