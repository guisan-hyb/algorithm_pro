# 最大公约数、最小公倍数与同余原理

> 来源笔记：`1220最大公约数、同余原理.cpp`｜核心程度：必背｜分类：08 数学与位运算

## 一句话

`gcd(a,b) = gcd(b, a%b)`（辗转相除法），`lcm = a / gcd * b`（**先除后乘**防溢出）；同余只要记住"加减乘可以边算边取模，除法要逆元"。

## 一、辗转相除法（欧几里得算法）

**要证**：`gcd(a, b) = gcd(b, a % b)`。设 `a % b = r`，即 `a = bq + r`：

1. 设 u 是 a、b 的公因子（`a = su, b = tu`），代入 `r = a - bq = (s - tq)u` ⇒ u 也是 r 的因子；
2. 设 v 是 b、r 的公因子（`b = xv, r = yv`），代入 `a = bq + r = (xq + y)v` ⇒ v 也是 a 的因子；
3. 两组公因子集合完全相同 ⇒ `gcd(a,b) = gcd(b,r)`，证毕。

**复杂度**：`gcd(a, b)`（a > b）约 O((log a)³)，足够快。比赛同学可继续学 **Stein 算法**与**裴蜀定理**；不比赛的同学**掌握一行代码即可**。

### 代码

```cpp
long long gcd(long long a, long long b) { return b == 0 ? a : gcd(b, a % b); }
long long lcm(long long a, long long b) { return a / gcd(a, b) * b; }   // 先除后乘
```

## 二、例题：第 N 个神奇数字（LeetCode 878）

定义：能被 a 或 b 整除的正整数叫神奇数字。

**二分答案 + 容斥计数**：

- `n * min(a,b)` 是答案的上界（粗略）；
- 计数函数：`f(m) = m/a + m/b - m/lcm(a,b)`（容斥，减去被重复计数的公倍数）；
- 二分的判定是 `f(m) >= n`。

## 三、同余原理

1. **加法、乘法可以每一步都取模**：

```
(a + b) % m = ((a % m) + (b % m)) % m
(a * b) % m = ((a % m) * (b % m)) % m
```

2. **减法**要防止负数：`(a - b + m) % m`；
3. 乘法时用 `long long` 做中间量**防溢出**；
4. **除法的同余需要求逆元**（`a / b ≡ a * inv(b) (mod m)`，要求 `gcd(b, m) = 1`）。

## 适用特征（看到这些信号就选它）

- 求最大公约数 / 最小公倍数；
- "能被 a 或 b 整除的第 n 个数""同时满足两个整除条件" → gcd/lcm + 二分或计数；
- 结果要取模、且过程中有加减乘 → 每步取模 + `long long` 中间量；
- 需要做除法取模 → 逆元（`0519数位dp` 之类的组合计数题常见）。

## 易错点

1. **`lcm` 必须先除后乘**（`a / gcd * b`），写成 `a * b / gcd` 容易溢出；
2. 递归 `gcd` 的写法是 `b == 0 ? a : gcd(b, a % b)`，base case 别写反；
3. 减法的同余：`(a - b + m) % m`，只写 `(a - b) % m` 在 C++ 里会得到负数；
4. 二分时边界要给足（`r = n * min(a, b)`）；
5. 取模的常数（如 1e9+7）要和题目一致；
6. 除法取模必须先确认逆元存在（`gcd(除数, 模数) == 1`）。

## 模板（可直接编译运行）

```cpp
// 数论基础模板：gcd/lcm / 神奇数字 / 同余工具 / 逆元
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <iostream>
#include <numeric>
using namespace std;

// ---------- gcd / lcm ----------
long long gcd_(long long a, long long b) { return b == 0 ? a : gcd_(b, a % b); }
long long lcm_(long long a, long long b) { return a / gcd_(a, b) * b; }     // 先除后乘

// ---------- 第 n 个能被 a 或 b 整除的数（二分 + 容斥） ----------
int nthMagicalNumber(long long n, long long a, long long b) {
    const long long MOD = 1000000007;
    long long L = lcm_(a, b);
    long long lo = 0, hi = n * min(a, b), ans = 0;
    while (lo <= hi) {
        long long m = lo + (hi - lo) / 2;
        if (m / a + m / b - m / L >= n) { ans = m; hi = m - 1; }
        else lo = m + 1;
    }
    return (int)(ans % MOD);
}

// ---------- 同余工具 ----------
long long addMod(long long a, long long b, long long m) { return ((a % m) + (b % m)) % m; }
long long subMod(long long a, long long b, long long m) { return ((a - b) % m + m) % m; }
long long mulMod(long long a, long long b, long long m) { return ((a % m) * (b % m)) % m; }

long long quickPowMod(long long a, long long b, long long m) {
    long long ans = 1;
    a %= m;
    while (b > 0) {
        if (b & 1) ans = ans * a % m;
        a = a * a % m;
        b >>= 1;
    }
    return ans;
}
// 费马小定理求逆元（p 必须是质数且 a % p != 0）
long long invModFermat(long long a, long long p) { return quickPowMod(a, p - 2, p); }

// 扩展欧几里得求逆元（模数不必是质数，但需 gcd(a, m) == 1）
long long invModExgcd(long long a, long long m) {
    long long old_r = a, r = m, old_s = 1, s = 0;
    while (r != 0) {
        long long q = old_r / r;
        long long tmp = old_r - q * r; old_r = r; r = tmp;
        tmp = old_s - q * s; old_s = s; s = tmp;
    }
    if (old_r != 1) return -1;                      // 逆元不存在
    return (old_s % m + m) % m;
}

int main() {
    std::cout << "gcd(12,18) = " << gcd_(12, 18) << "\n";                        // 6
    std::cout << "lcm(4,6) = " << lcm_(4, 6) << "\n";                            // 12
    std::cout << "第 3 个神奇数字(2,3) = " << nthMagicalNumber(3, 2, 3) << "\n";   // 6
    std::cout << "subMod(3,5,7) = " << subMod(3, 5, 7) << "\n";                  // 5
    std::cout << "invModFermat(2,1e9+7) = " << invModFermat(2, 1000000007) << "\n";  // 500000004
    std::cout << "invModExgcd(3,11) = " << invModExgcd(3, 11) << "\n";           // 4
    return 0;
}
```

## 专题深化：为什么成立

欧几里得算法用 `gcd(a,b)=gcd(b,a mod b)`，每次至少让一个数减半，所以 O(log min(a,b))。同余保持加减乘，除法必须乘模逆元；费马小定理只在模为质数且底数非零时给逆元。

## 专题深化：手算与边界

gcd(12,18)=gcd(18,6)=6；在 mod 7 下 3-5=-2≡5；2 的逆元是 4，因为 2×4=8≡1。

### 对照与取舍

扩展欧几里得适用于任意互质模数的逆元；费马只适用于质数模；组合数模质数可用阶乘逆元。

### 易错点与反例

1. lcm 先除后乘防溢出
2. 负数取模要归一化
3. 模数不质数时不能直接用 `a^(p-2)`
4. 逆元只在 gcd(a,m)=1 时存在
