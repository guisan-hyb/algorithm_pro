# 二进制与位运算基础

> 来源笔记：`1119二进制和位运算.cpp`｜核心程度：必背（一切位运算技巧的地基）｜分类：08 数学与位运算

## 一句话

计算机只有一套加法逻辑，所以负数用**补码**表示（取反加一）；六个位运算符的语义和两个"边界坑"（溢出、移位）必须先记牢。

## 一、二进制基础

- 1 个 bit = 一位（0/1）；1 字节 = 8 位；
- **最高位是符号位**：0 为正、1 为负；
- 正数：用"除 2 取余、倒序"转换；
- **负数**：先求绝对值的二进制，再**取反加一**（即 `~(s-1) = ~s + 1`）；
- 二进制负转十进制：同样取反加一；
- **整数最小值的特殊性**：`INT_MIN` 取绝对值还是自己；
- 十六进制：每 4 位二进制对应 1 个十六进制位；C++ 里可以写 `0b11`（二进制）、`0x7f`（十六进制）。

## 二、六个位运算符

| 运算符 | 含义 |
| --- | --- |
| `&` | 与：都为 1 才是 1 |
| `\|` | 或：有一个 1 就是 1 |
| `^` | 异或：相同为 0、相异为 1 |
| `~` | 取反 |
| `<<` | 左移：高位丢弃、低位补 0 |
| `>>` | 右移：`int` 时高位补符号位（算术右移） |

要点：

- **`>>>` 是 Java 的运算符，C++ 没有**；C++ 里想做无符号右移就强转 `(unsigned)`；
- 位运算符 `| &` **两侧都会计算**；逻辑运算符 `|| &&` 有短路（穿透）特性；
- 非负数：`<< i` 等于乘 `2^i`，`>> i` 等于除 `2^i`；**负数不适用**（要用无符号）；
- **溢出**：计算机不会替你检查，`(1 << 48)` 这种写法在 int 上早就溢出了，要用 `1L << 48`。

## 三、打印二进制（两种写法）

```cpp
cout << bitset<sizeof(int) * 8>(num) << endl;      // 推荐

for (int i = 31; i >= 0; i--)                      // 手写
    cout << ((num & (1 << i)) == 0 ? "0" : "1");
```

⚠️ 笔记特别提醒：判断某一位是否为 1 要写 `(num & (1 << i)) != 0`，**不能写 `== 1`**——因为 `num & (1 << i)` 的结果是 `2^i`（如 16），不是 1。

## 四、为什么用二进制

保证**只有一套加法运算逻辑**（算得快）；代价是负数的表示很别扭。位运算在实际题目里常用来做压缩、集合运算、快速判定（见 `1201异或运算的骚操作`、`1202位运算的骚操作`）。

## 适用特征（看到这些信号就选它）

- 需要按位处理（状态压缩、集合、标志位）；
- 需要"不用判断/比较"完成某种操作（如不借助 if 求最大值）；
- 位运算与其他算法结合（状压 DP、位图、树状数组的 lowbit）。

## 易错点

1. `(num & (1 << i)) == 1` 这种写法是错的（见上文）；
2. `1 << 31` 是有符号溢出（UB），要用 `1u << 31` 或 `1LL << 31`；
3. 负数右移是**算术右移**（补符号位），想逻辑右移要强转无符号；
4. `~n + 1` 即 `-n`（补码），`n & -n` 是提取最低位 1 的常用写法；
5. 位运算的优先级低于 `==`，比较时**记得加括号**。

## 模板（可直接编译运行）

```cpp
// 二进制与位运算基础模板
#define _CRT_SECURE_NO_WARNINGS
#include <bitset>
#include <climits>
#include <iostream>
using namespace std;

void printBinary(int num) { cout << bitset<sizeof(int) * 8>(num) << '\n'; }

int bitAt(long long num, int i) { return (int)((num >> i) & 1LL); }
long long setBit(long long x, int i)   { return x | (1LL << i); }
long long clearBit(long long x, int i) { return x & ~(1LL << i); }
long long flipBit(long long x, int i)  { return x ^ (1LL << i); }
long long lowBit(long long x)          { return x & (-x); }        // 提取最低位的 1
long long removeLowBit(long long x)    { return x & (x - 1); }     // 去掉最低位的 1
unsigned logicalShiftRight(int x, int k) { return (unsigned)x >> k; }

// 手写打印（注意用 != 0 而不是 == 1）
void printBinaryManual(int num) {
    for (int i = 31; i >= 0; i--) cout << ((num & (1 << i)) != 0 ? '1' : '0');
    cout << '\n';
}

int main() {
    int x = 0b0011010;
    printBinary(x);
    printBinaryManual(x << 1);
    std::cout << "第 4 位 = " << bitAt(x, 4) << "\n";                    // 1
    std::cout << "lowBit(12) = " << lowBit(12) << "\n";                // 4
    std::cout << "removeLowBit(12) = " << removeLowBit(12) << "\n";    // 8
    std::cout << "无符号右移 (-8) >> 2 = " << logicalShiftRight(-8, 2) << "\n";
    std::cout << "INT_MIN = " << INT_MIN << ", -INT_MIN = " << -INT_MIN << "\n";   // 取绝对值还是自己
    return 0;
}
```

## 专题深化：为什么成立

二进制每位权重是 2 的幂，位运算直接操作这些独立位。补码让加减统一成模 2^w 运算；有符号右移通常算术补符号位，无符号右移补 0。

## 专题深化：手算与边界

`12=1100₂`，第 3 位和第 2 位（从 0 计）为 1；`12 & -12 = 4` 取出最低位；`12 & (12-1)=8` 清除最低位。

### 对照与取舍

异或用于消除成对元素；与运算取掩码；或运算组合标志；移位乘除 2 的幂但负数与溢出要谨慎。

### 易错点与反例

1. 有符号左移溢出是 UB
2. `1<<31` 不能用 int 安全表示
3. 负数右移实现相关语义要避免依赖
4. 位宽和下标从 0/1 开始要统一

## 专题深化：进阶拓展

位集可做子集枚举、状态压缩、快速集合交并；GCC 的 `__builtin_popcount` 可统一种群计数。
