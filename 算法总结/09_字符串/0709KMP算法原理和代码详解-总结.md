# KMP 算法原理与代码详解

> 来源笔记：`0709KMP算法原理和代码详解.cpp`｜核心程度：必背｜分类：09 字符串

## 一句话

KMP 用 **next 数组**记录"前缀与后缀的最大匹配长度"，失配时**不回退主串指针**，只让模式串跳到 next 指示的位置，从而把匹配从 O(n·m) 降到 **O(n + m)**。

## next 数组的定义（笔记原文，定义是一切的关键）

`next[i]` = **不含当前字符**的前提下，`s2[0..i-1]` 的**前缀与后缀的最大匹配长度**（不能是整个串）。

它同时还有一个含义：**这个前缀的下一个字符所在的下标**。

两种约定（笔记用的是前一种）：

- 本题模板：`next[0] = -1`、`next[1] = 0`；
- 另一种常见约定：整体右移一位且 `next[0] = -1`。

## 主流程（匹配）

```cpp
int x = 0, y = 0;                 // x 是主串位置，y 是模式串位置
while (x < n && y < m) {
    if (s1[x] == s2[y]) { x++; y++; }
    else if (y == 0)    { x++; }        // 模式串第一个字符就失配，主串往前走
    else                { y = next[y]; }// 模式串跳到 next[y]，主串不动
}
return y == m ? x - y : -1;
```

**加速的两个理解核心**：

1. 失配时主串指针不倒退；
2. 模式串跳到的位置保证"跳过的部分已经匹配过"。

## next 数组的生成（O(m)）

```cpp
vector<int> getNext(const string& s2) {
    int m = (int)s2.size();
    if (m == 1) return {-1};
    vector<int> next(m, 0);
    next[0] = -1; next[1] = 0;
    int i = 2, cn = 0;                  // cn = 当前要和 i-1 位置比较的下标
    while (i < m) {
        if (s2[i - 1] == s2[cn])      next[i++] = ++cn;
        else if (cn > 0)              cn = next[cn];   // 不停跳跃
        else                          next[i++] = 0;
    }
    return next;
}
```

## 复杂度 O(n + m) 的直观解释

主流程里 `x` 单调不减、`y` 每次跳只会减小（减小幅度被之前的增加次数抵消），所以总的"跳跃次数"是 O(n + m)。

## 例题：另一棵树的子树（LeetCode 572）

两种做法：

1. **暴力递归**：对 root 的每个节点与 subRoot 做结构比较；
2. **序列化 + KMP**：先**先序遍历序列化**两棵树（空节点写 `_#_`，节点值两侧加 `_`），再用 KMP 判断子串。**必须带空节点占位**，否则不同结构可能序列化成同一个串。

## 适用特征（看到这些信号就选它）

- 单模式串匹配（`strStr`、找子串首次出现）；
- 需要 next 数组本身的信息（最长公共前后缀、字符串周期）；
- 树/图的**结构包含**判断（序列化后 KMP）；
- 比较对象是"完全相等的字符串"，不需要随机访问子串比较（那用字符串哈希更方便）。

## 易错点

1. **next 的含义必须记准**：是"不含当前字符"的前后缀匹配长度；
2. `m == 1` 时 `next = {-1}` 要特判；
3. 主流程里 `y == 0` 的分支不能漏（否则死循环）；
4. `cn = next[cn]` 是"跳跃"，不是 `cn--`；
5. 返回起始下标是 `x - y`（匹配完成时 y == m）；
6. 树序列化必须带**空节点占位符**，并加分隔符防止数值粘连（如 1 和 12）。

## 模板（可直接编译运行）

```cpp
// KMP 模板 + 例题（子树判断）
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <string>
#include <vector>
using namespace std;

// ================= next 数组 =================
// next[i]：不含 s2[i] 时，s2[0..i-1] 的前后缀最大匹配长度（不能是整体）
vector<int> getNext(const string& s2) {
    int m = (int)s2.size();
    if (m == 1) return {-1};
    vector<int> nxt(m, 0);
    nxt[0] = -1;
    nxt[1] = 0;
    int i = 2, cn = 0;                          // cn：要和 s2[i-1] 比较的下标
    while (i < m) {
        if (s2[i - 1] == s2[cn])      nxt[i++] = ++cn;
        else if (cn > 0)              cn = nxt[cn];   // 跳跃
        else                          nxt[i++] = 0;
    }
    return nxt;
}

// ================= KMP 主流程 =================
int kmp(const string& s1, const string& s2) {   // s2 在 s1 中最左出现的下标，没有返回 -1
    int n = (int)s1.size(), m = (int)s2.size();
    if (m == 0) return 0;
    vector<int> nxt = getNext(s2);
    int x = 0, y = 0;
    while (x < n && y < m) {
        if (s1[x] == s2[y])  { x++; y++; }
        else if (y == 0)     { x++; }           // 模式串首字符就失配
        else                 { y = nxt[y]; }    // 模式串跳，主串不动
    }
    return y == m ? x - y : -1;
}

// ================= 例题：另一棵树的子树 =================
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v = 0, TreeNode* l = nullptr, TreeNode* r = nullptr) : val(v), left(l), right(r) {}
};
void serialize(TreeNode* node, string& s) {     // 先序序列化，空节点占位
    if (!node) { s += "_#_"; return; }
    s += '_';
    s += to_string(node->val);
    s += '_';
    serialize(node->left, s);
    serialize(node->right, s);
}
bool isSubtree(TreeNode* root, TreeNode* subRoot) {
    string s1, s2;
    serialize(root, s1);
    serialize(subRoot, s2);
    return kmp(s1, s2) != -1;
}

int main() {
    std::cout << "kmp(abcabcabc, abc) = " << kmp("abcabcabc", "abc") << "\n";   // 0
    std::cout << "kmp(hello, ll) = " << kmp("hello", "ll") << "\n";             // 2
    std::cout << "kmp(hello, xyz) = " << kmp("hello", "xyz") << "\n";           // -1
    auto nxt = getNext("aabaab");
    std::cout << "next(aabaab) = ";
    for (int v : nxt) std::cout << v << " ";                             // -1 0 1 0 1 2
    std::cout << "\n";
    TreeNode* root = new TreeNode(3, new TreeNode(4, new TreeNode(1), new TreeNode(2)), new TreeNode(5));
    TreeNode* sub = new TreeNode(4, new TreeNode(1), new TreeNode(2));
    std::cout << "isSubtree = " << (int)isSubtree(root, sub) << "\n";           // 1
    return 0;
}
```

## 专题深化：为什么成立

KMP 的 next/前缀函数记录模式串每个前缀的最长真前后缀长度。失配时主串指针不退，只把模式串指针跳到“仍有可能匹配的最长前缀”，因此总比较次数线性。

## 专题深化：手算与边界

模式串 `aabaab` 的前缀函数为 `0,1,0,1,2,3`。匹配 `aabaa` 后失配，可跳到长度 2 的前缀 `aa`，不必从主串开头重来。

### 对照与取舍

暴力匹配最坏 O(nm)；KMP O(n+m) 且在线；Z 函数也可求所有前缀匹配；字符串哈希平均更快但要处理碰撞。

### 易错点与反例

1. next 下标 0-based/1-based 不能混
2. 空模式串按题意定义为 0 或匹配所有
3. 前缀函数不能等于当前长度
4. 构建 next 和匹配时都要在 fallback 循环中更新指针

## 专题深化：进阶拓展

KMP 可求最小循环节、所有出现位置、字符串周期；AC 自动机把多模式匹配合并到 Trie 的失败链。
