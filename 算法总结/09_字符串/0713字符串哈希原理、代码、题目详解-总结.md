# 字符串哈希（原理、代码与题目）

> 来源笔记：`0713字符串哈希原理、代码、题目详解.cpp`｜核心程度：必背（"赌狗的胜利"）｜分类：09 字符串

## 一句话

把字符串看作 **base 进制数**并让它**自然溢出**（等价于对 `2^64` 取模），就能用 `unsigned long long` 表示一个串；再配合前缀哈希，**任意子串的哈希都是 O(1)**，于是"子串比较"退化成"数字比较"。

## 一、哈希函数的四条性质

1. 输入可能性无限，输出值域有限；
2. 同样的输入一定得到同样的输出（**没有随机机制**）；
3. 不同的输入**可能**得到相同输出 → **哈希碰撞**；
4. 大量不同输入得到的输出值会**几乎均匀分布**在整个值域上（熵最大）—— **性质 4 最重要**。

## 二、字符串哈希的要点（笔记原文）

1. 理解 `long long`/`unsigned long long` 的**自然溢出**：等价于对 `2^64` 取模的状态；
2. 把字符串转成 **base 进制数**并自然溢出；
3. base 的选择：
   - 可用质数 `433、499、599、1000000007`；
   - 也可用经典值 `31、131、1313、13131、131313`；
   - **建议选质数而不是经典值**，因为经典值会被出题人刻意构造碰撞；
4. 每位字符的值**从 1 开始**（不用 0），避免前导零造成歧义；
5. 用数字比较代替字符串比较，**大幅降低复杂度**。

理论上会碰撞，但实际考察样本量小，出错概率极低；即使错了，**换个 base 再赌一次**。

## 三、核心：任意子串的哈希（O(1)）

```
pow[0] = 1;  pow[i] = pow[i-1] * base;
hash[0] = s[0] - 'a' + 1;
hash[i] = hash[i-1] * base + s[i] - 'a' + 1;
子串 s[l..r] 的哈希 = hash[r] - hash[l-1] * pow[r-l+1];     // l > 0 时
```

笔记用 `"c a b e f"` 举例完整推导了一遍，务必自己推一次。

## 四、六道题

| 题 | 做法 |
| --- | --- |
| 统计不同字符串个数（洛谷 P3370） | 每个串求哈希 → 排序去重 |
| 独特子串数量（LeetCode 2261） | 枚举子串，维护 `maxCnt / maxCntKind / allKind`，满足 `maxCntKind == allKind` 就把哈希丢进 set |
| 用字符串哈希替代 KMP（LeetCode 28） | 预处理 haystack 的哈希，滑动窗口比对 needle 哈希 |
| 重复叠加字符串匹配（LeetCode 686） | 把 a 叠加到 `k+1` 倍，再滑窗找 b 的哈希 |
| 串联所有单词的子串（LeetCode 30） | 按单词长度分组切块 + **滑窗 + 哈希计数表** |
| 匹配子串数量（洛谷 P3763） | **哈希 + 二分求最长公共前缀（LCP）**，跳过不同的位置，数不同字符数 ≤ k |

## 适用特征（看到这些信号就选它）

- 需要**频繁比较子串**（回文、重复、匹配）；
- 需要 O(1) 判断"两个子串是否相等"；
- 多模式串匹配（比 AC 自动机好写）；
- 替代 KMP / Z 函数 / 后缀数组的一部分场景。

## 易错点

1. 字符值**从 1 开始**（用 0 会产生前导零歧义）；
2. `pow` 数组要预处理到 `n`，`pow[0] = 1`；
3. 子串公式：`hash[r] - hash[l-1] * pow[r-l+1]`（**减号**，且 `l > 0` 才减）；
4. 用 `unsigned long long` 自然溢出（不要用有符号 `long long` 做减法）；
5. 多个字符串要**用同一个 base 与同一个 pow 数组**（或同一套预处理）；
6. 树/数组序列化时，元素之间要有分隔符（否则 `1` 和 `12` 会粘连）；
7. 哈希碰撞：必要时用双哈希（两组 base/mod）或换 base 重跑。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

const unsigned long long BASE = 499;                 // 建议用质数

struct StringHash {
    vector<unsigned long long> pw, hs;
    explicit StringHash(const string& s) {
        int n = (int)s.size();
        pw.assign(n, 1);
        hs.assign(n, 0);
        for (int i = 1; i < n; i++) pw[i] = pw[i - 1] * BASE;
        if (n > 0) {
            hs[0] = s[0] - 'a' + 1;                  // 值从 1 开始
            for (int i = 1; i < n; i++) hs[i] = hs[i - 1] * BASE + s[i] - 'a' + 1;
        }
    }
    // 子串 s[l..r] 的哈希（自然溢出）
    unsigned long long get(int l, int r) const {
        unsigned long long ans = hs[r];
        if (l > 0) ans -= hs[l - 1] * pw[r - l + 1];
        return ans;
    }
    static unsigned long long hashOf(const string& s) {   // 整串哈希
        unsigned long long h = 0;
        for (char c : s) h = h * BASE + (c - 'a' + 1);
        return h;
    }
};

// ---------- 用哈希替代 KMP ----------
int strStr(const string& haystack, const string& needle) {
    int n = (int)haystack.size(), m = (int)needle.size();
    if (m == 0) return 0;
    if (n < m) return -1;
    StringHash h(haystack);
    unsigned long long need = StringHash::hashOf(needle);
    for (int l = 0, r = m - 1; r < n; l++, r++)
        if (h.get(l, r) == need) return l;
    return -1;
}

// ---------- 统计不同字符串 ----------
int distinctStrings(vector<string> strs) {
    vector<unsigned long long> v;
    for (auto& s : strs) v.push_back(StringHash::hashOf(s));
    sort(v.begin(), v.end());
    return (int)(unique(v.begin(), v.end()) - v.begin());
}

int main() {
    printf("strStr(abcabcabc, abc) = %d\n", strStr("abcabcabc", "abc"));   // 0
    printf("不同字符串个数 = %d\n", distinctStrings({"ab","ab","ba"}));     // 2
    StringHash h("cabef");
    printf("子串 be 的哈希 = %llu\n", h.get(2, 3));
    return 0;
}
