# 前缀树（Trie / 字典树）

> 来源笔记：`1222前缀树原理和代码详解.cpp`｜核心程度：高频 + 竞赛必备｜分类：02 数据结构

## 一句话

每个样本都从根节点出发，按字符（或数字）走边建树：**没有路就新建节点，有路就复用**；节点上挂 `pass / end` 计数，就能 O(长度) 回答"前缀有多少词""这个词出现几次"。

## 解决什么问题

需要**按前缀信息查询**的场景：

- `insert(word)`：插入；
- `search(word)`：word 出现过几次（返回实例个数）；
- `prefixNumber(prefix)`：以 prefix 为前缀的字符串有多少个；
- `erase(word)`：删除一次。

## 核心思想

- 字符信息放在**边上**，节点只维护 `pass`（经过该节点的词数）和 `end`（以该节点结尾的词数）；
- 插入：路径上的每个节点 `pass++`，最后一个节点 `end++`；
- 查询"出现几次"：走到末尾节点返回 `end`，中途没路返回 0；
- 查询"前缀数"：走到节点返回 `pass`；
- 删除：沿路 `pass--`；**一旦某个子节点的 `pass` 减到 0，说明该子树没有任何词了，可以把这条路整段摘掉**（内存/静态数组都要处理）。

## 三种实现方式（笔记的核心考点）

| 方式 | 路的实现 | 评价 |
| --- | --- | --- |
| `Trie1` 类 + 固定数组 `nexts[26]` | 数组 | 最常用，但路上可能很多空指针；**析构要递归 delete，否则内存泄漏** |
| `Trie2` 类 + `unordered_map<int, TrieNode*>` | 哈希表 | 路的分支多（字符种类多）时用，省空间 |
| `Trie` 静态数组（`Tree[MAX][26]` + `pass[]` + `end[]`） | 数组 | **推荐**，笔试、比赛都稳；不 new/delete，无内存问题，常数小 |

静态数组版的关键点：

- 下标从 **1** 开始，`cnt = 1` 表示节点数量计数，`Tree[0]` 置空不用；
- `Tree[cur][path] != 0` 表示这条路已存在，值为子节点编号；
- `erase` 里 `if (--pass[Tree[cur][path]] == 0) { Tree[cur][path] = 0; return; }` —— **把父节点的这条路清空就等于整段剪枝**；
- 静态成员变量必须在类外初始化（`int Trie::cnt = 1;` 等）；
- 多组数据要调 `clear()`；
- 字符种类极多时，可以把 `path` **按位打散**依次下扎（见 `1224前缀树的相关题目`）。

## 适用特征（看到这些信号就选它）

- 题目出现"前缀""字典""单词集合""异或最大"等关键词；
- 需要在大规模字符串集合里做 O(长度) 查询（哈希只能查完整串，不能查前缀）；
- 需要按前缀统计或按字典序枚举；
- 数字也可以建树（二进制位建树 → 最大异或对，见 `1224前缀树的相关题目`）。

## 复杂度

- 时间：插入/查询/删除均为 O(字符串长度)；
- 空间：O(总字符数 × 分支数)；固定数组版最省心，哈希表版在分支多时省空间。

## 易错点

1. **`pass` 在根节点也要加**：`insert` 开头 `node->pass++;` 别漏（对应静态数组版 `pass[cur]++`，此时 `cur = 1`）；
2. `erase` 必须**先确认词存在**（否则会把不存在的词路径减成负数）；删除一次只减一次 `end`；
3. 删除时"`pass` 减到 0 就剪枝"要立即 `return`（后面的节点已经不存在了）；
4. 静态数组版忘记 `clear()`，多组数据必然错；
5. 类版本忘记写析构函数 → 内存泄漏（见 `内存安全的前缀树`）；
6. `path = word[i] - 'a'` 只适用小写字母；大写、数字、任意字符要相应调整（或按位打散）。

## 模板（可直接编译运行）

```cpp
// 前缀树模板：静态数组实现（竞赛/笔试推荐）
// 支持 insert / search(出现次数) / prefixNumber(前缀数) / erase / clear
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Trie {
    static constexpr int MAX_NODE = 200005;
    vector<array<int, 26>> nextNode;     // nextNode[cur][path] = 子节点编号，0 表示没有路
    vector<int> pass;                    // 经过该节点的词数
    vector<int> endCount;                // 以该节点结尾的词数
    int nodeCount = 1;                   // 节点数量，根节点是 1（下标从 1 开始）

    Trie() : nextNode(MAX_NODE), pass(MAX_NODE), endCount(MAX_NODE) {
        clear();
    }

    void clear() {
        for (int i = 0; i <= nodeCount; i++) {
            nextNode[i].fill(0);
            pass[i] = 0;
            endCount[i] = 0;
        }
        nodeCount = 1;
    }

    void insert(const string& w) {
        int cur = 1;
        pass[cur]++;
        for (char c : w) {
            int p = c - 'a';
            if (!nextNode[cur][p]) nextNode[cur][p] = ++nodeCount;
            cur = nextNode[cur][p];
            pass[cur]++;
        }
        endCount[cur]++;
    }

    int search(const string& w) {            // 单词出现次数
        int cur = 1;
        for (char c : w) {
            int p = c - 'a';
            if (!nextNode[cur][p]) return 0;
            cur = nextNode[cur][p];
        }
        return endCount[cur];
    }

    int prefixNumber(const string& pre) {    // 以 pre 为前缀的单词数
        int cur = 1;
        for (char c : pre) {
            int p = c - 'a';
            if (!nextNode[cur][p]) return 0;
            cur = nextNode[cur][p];
        }
        return pass[cur];
    }

    void erase(const string& w) {            // 删除一次
        if (search(w) == 0) return;          // 不存在则什么也不做
        int cur = 1;
        pass[cur]--;
        for (char c : w) {
            int p = c - 'a';
            if (--pass[nextNode[cur][p]] == 0) {
                nextNode[cur][p] = 0;
                return;
            }
            cur = nextNode[cur][p];
        }
        endCount[cur]--;
    }
};

int main() {
    int m;
    if (!(std::cin >> m)) return 0;
    Trie trie;
    for (int i = 0, op; i < m; i++) {
        string word;
        std::cin >> op >> word;
        if (op == 1) {
            trie.insert(word);
        } else if (op == 2) {
            trie.erase(word);
        } else if (op == 3) {
            std::cout << (trie.search(word) ? "YES" : "NO") << "\n";
        } else {
            std::cout << trie.prefixNumber(word) << "\n";
        }
    }
    return 0;
}
```

## 专题深化：为什么成立

前缀树把字符串的公共前缀合并到同一路径；每个节点有若干字符边和计数。插入沿字符走并在路径上加 pass，在终点加 end，因此查单词 O(L)、查前缀 O(L)，与存储词数无关。

## 专题深化：手算与边界

插入 `cat` 和 `car` 后，路径 `ca` 共享，末尾分叉 `t/r`。查询 `ca` 时 pass=2，查询 `cat` 时 endCount=1。

### 对照与取舍

哈希表查完整字符串平均 O(L)，但不能自然查前缀；前缀树查前缀 O(L)，代价是节点数乘分支空间。压缩/哈希表映射子节点可节省稀疏空间。

### 易错点与反例

1. 根节点通常从 1 开始，0 表示空路
2. 删除时递减 pass，计数到 0 才剪枝
3. 字符集大时不要固定开 26 分支
4. 多次测试要完整清零或用节点池
