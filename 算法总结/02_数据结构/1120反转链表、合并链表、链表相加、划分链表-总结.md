# 链表四件套：反转 / 合并 / 相加 / 划分

> 来源笔记：`1120反转链表、合并链表、链表相加、划分链表.cpp`｜核心程度：必背（链表题的四个原子操作）｜分类：02 数据结构

## 一句话

指针题的全部技巧可以压缩成两条：**先存 `next` 再改指向**，以及**用几个"头尾指针"把新链表串起来**。

## 解决什么问题

1. **反转链表**（单链表 / 双链表）：把 `next` 方向整体调头；
2. **合并两个有序链表**：把两条升序链升序归并成一条；
3. **两个链表相加**：链表版高精度加法（个位在链头）；
4. **划分链表**：把 `< x` 的节点放前面、`>= x` 的放后面，并保持各自内部相对顺序。

## 核心思想

### 反转（单链表）

三指针滚动：`prev / cur / nxt`。每轮：

```
nxt = cur->next;  cur->next = prev;  prev = cur;  cur = nxt;
```

双链表版多一步：`cur->prev = nxt`（把 prev 与 next 互换后再整体翻转），最后把头结点的 `next` 接到 `prev`，并把新首节点的 `prev` 指向头结点。

### 合并两个有序链表

- 先比两个首节点，选出小的那条作为**新链表头**（决定 `head`）；
- `prev` 指向新链表最后一个节点，谁小就把谁的节点接上并前移；
- 一条耗尽后，`prev->next` 直接挂另一条的剩余部分（不用再循环）。

### 链表相加

- 逐位相加，`sum = x + y + carry`，`val = sum % 10`，`carry = sum / 10`；
- 循环条件是 `h1 || h2`（短的用 0 补），缺位用三元表达式补 0；
- **循环结束后若 `carry == 1` 还要再挂一个节点**（最高位进位，最容易漏）。

### 划分链表

- 开两组 `head / tail`：`leftHead/leftTail` 存 `< x`，`rightHead/rightTail` 存 `>= x`；
- 遍历时先把当前节点断链（`realNode->next = NULL`），再接进对应组的尾部；
- 最后 `leftTail->next = rightHead` 拼起来；若 `leftHead == NULL` 直接返回 `rightHead`。

## 适用特征（看到这些信号就选它）

- 题目给的是单/双链表，要求在 O(1) 额外空间下原地操作；
- 需要"分段处理 + 保持相对顺序"（划分、奇偶重排、按位置分割）；
- 后面所有链表难题（K 个一组翻转、重排链表、合并 K 条）都由这四个操作拼出来。

## 复杂度

| 操作 | 时间 | 额外空间 |
| --- | --- | --- |
| 反转 | O(n) | O(1) |
| 合并 | O(n + m) | O(1) |
| 相加 | O(max(n, m)) | O(max(n, m))（新建结果链表） |
| 划分 | O(n) | O(1) |

## 易错点

1. 反转时**必须先存 `next`**，否则改完 `cur->next` 就找不到后继；
2. 带头结点与否要统一：笔记里所有函数都假设 `L` 是**带头结点的单链表**（`L->next` 才是第一个真实节点），写题时如果给的是无头链表要相应调整；
3. 合并时先判断 `L1/L2` 为空的情况（返回另一条），否则 `L1->next->data` 直接崩；
4. 相加时漏掉最高位的 `carry` 是最典型错误；
5. 划分时若忘了断链，会把两组串成环；
6. 划分的边界：`leftHead == NULL`（全都不小于 x）必须特判返回 `rightHead`。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v = 0) : val(v), next(nullptr) {}
};

// 1) 反转单链表（无头结点版）
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    while (head) {
        ListNode* nxt = head->next;
        head->next = prev;
        prev = head;
        head = nxt;
    }
    return prev;
}

// 2) 合并两个有序链表（无头结点版）
ListNode* mergeTwoLists(ListNode* a, ListNode* b) {
    ListNode dummy, *tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) { tail->next = a; a = a->next; }
        else                  { tail->next = b; b = b->next; }
        tail = tail->next;
    }
    tail->next = a ? a : b;          // 剩余部分整体挂上
    return dummy.next;
}

// 3) 两数相加（个位在链头）
ListNode* addTwoNumbers(ListNode* a, ListNode* b) {
    ListNode dummy, *tail = &dummy;
    int carry = 0;
    while (a || b || carry) {
        int sum = carry + (a ? a->val : 0) + (b ? b->val : 0);
        tail->next = new ListNode(sum % 10);
        tail = tail->next;
        carry = sum / 10;
        a = a ? a->next : nullptr;
        b = b ? b->next : nullptr;
    }
    return dummy.next;
}

// 4) 划分链表：< x 在前，>= x 在后
ListNode* partition(ListNode* head, int x) {
    ListNode lh, rh, *lt = &lh, *rt = &rh;     // 用哨兵省掉特判
    while (head) {
        ListNode* nxt = head->next;
        head->next = nullptr;                  // 先断链再挂
        if (head->val < x) { lt->next = head; lt = head; }
        else               { rt->next = head; rt = head; }
        head = nxt;
    }
    lt->next = rh.next;                        // 两段拼接
    return lh.next;
}
```
