# 数据结构设计高频题（7 道）

> 来源笔记：`1206数据结构设计高频题.cpp`｜核心程度：面试高频｜分类：02 数据结构

## 一句话

"设计一个 O(1) 的结构"这类题，答案几乎总是**哈希表 + 链表/堆/位图**的组合：哈希表负责定位，第二个结构负责顺序或极值。

## 题目一：带 setAll 的哈希表（MyMap）

**要求**：put / get / containKey / setAll 全部 O(1)（setAll 把当前所有 key 的值统一改成新值，且**之后新插入的 key 不受影响**）。

**做法**：`unordered_map<int, pair<int,int>> mp` 存 `(value, 写入时间)`；维护 `setAllValue` 与 `setAllTime`、全局自增时钟 `cnt`。

- `put(key, v)`：`mp[key] = {v, cnt++}`；
- `setAll(v)`：只更新 `setAllValue / setAllTime`（O(1)，不遍历）；
- `get(key)`：若 `mp[key].second < setAllTime` 说明这条记录在 setAll 之前写入，返回 `setAllValue`，否则返回自己的值。

**关键洞察**：用"时间戳比较"把批量修改变成 O(1) 的懒更新。

## 题目二：LRU 缓存

**要求**：get / put 均 O(1)，容量满时淘汰**最久未使用**的。

**做法**：`unordered_map<key, 节点位置>` + **双向链表**（头部最旧、尾部最新）。

- `get`：命中就 `moveToTail`；
- `put`：已存在 → 移到尾部并改值；不存在 → 满了先删头，再插尾。

两种写法（笔记都给了）：

1. **纯容器版**：`list<pair<int,int>>` + `unordered_map<int, list::iterator>`，靠 `erase / push_back / prev(end())` 完成；代码短；
2. **手写双向链表版**：`doubleNode{key,val,prev,next}` + `doubleList{pushBack, moveToTail, removeHead}` + `unordered_map<int, doubleNode*>`；面试想展示功底用这个。

## 题目三：O(1) 插入、删除、随机取（RandomizedSet）

**做法**：`vector<int> arr`（紧致的元素数组）+ `unordered_map<int,int> valToIndex`。

- 插入：不在表里就 `push_back` 并记下标；
- 删除（核心技巧）：**把要删的元素和数组末尾交换**，`pop_back`，再修正被换元素的下标；
- 随机：`arr[rand() % arr.size()]`。

**注意**：必须用 `unordered_map` 而不是 `map`（后者是 O(log n)）。

## 题目四：允许重复的随机集合（RandomizedCollection）

**与题目三的差别**：允许重复值。

**做法**：`unordered_map<int, unordered_set<int>> valToIndices`（一个值对应一组下标）。

- 插入：下标集合里加新下标，返回"之前是否存在"；
- 删除：取该值下标集合中的任意一个 `pos`；
  - 若 `pos` 是数组末尾：直接 `pop_back` + 从集合删下标；
  - 否则：把末尾元素换到 `pos`，修正末尾元素的下标集合（删旧下标、加新下标），再 `pop_back`；
  - 某值的下标集合空了就把这个 key 从 map 删掉。

## 题目五：数据流的中位数（MedianFinder）

**做法**：**对顶堆**——大根堆存较小的一半，小根堆存较大的一半，并保证两边规模差 ≤ 1（`balance`）。

- `addNum`：`num <= maxHeap.top()` 进大根堆，否则进小根堆，然后 `balance`；
- 奇数个 → 元素多的那堆的堆顶；偶数个 → 两个堆顶的平均值。

**为什么不用 vector 排序**：每次查询排序会超时（笔记原话）。

## 题目六：最大频率栈（FreqStack）

**要求**：push 正常入栈，pop 弹出**出现频率最高**的元素；频率相同时弹**最近入栈**的那个。

**做法**：`valToFre`（值 → 当前频率）+ `freqToVals`（频率 → **该频率下的元素栈**）+ `maxFreq`。

- `push(val)`：`freq = ++valToFre[val]`，把 val 压进 `freqToVals[freq]`，更新 `maxFreq`；
- `pop()`：从 `freqToVals[maxFreq]` 弹栈顶；该值频率 -1；若该频率的栈空了，`maxFreq--`。

**直觉**：每个元素第 k 次入栈时都进入"频率 k"这一层，弹栈自然满足"同频率取最近入栈"。

## 题目七：全 O(1) 的字符串计数结构（AllOne）

**要求**：inc / dec / getMaxKey / getMinKey 全部 O(1)。

**做法**：`unordered_map<string, list::iterator> mp` + **按频率升序的双向链表**，链表节点是 `pair<unordered_set<string>, int freq>`（一个"桶"里放所有频率相同的字符串）。

- `inc(key)`：找到 key 所在桶，频率 +1 → 若**下一个桶**的频率恰好是 `freq+1` 就把 key 挪过去，否则在两者之间新建一个桶；原桶空了就删掉；
- `dec(key)`：对称操作（频率 -1，往**前一个桶**找，频率 1 时直接删除 key）；
- `getMaxKey / getMinKey`：取链表尾/头桶里的任意一个字符串（`lst.back().first.begin()` / `lst.front()...`）。

面试里的加分做法（笔记提到但没写）：手搓双向链表，在头尾各放一个哨兵桶（头部频率 0、尾部频率 INT_MAX），head/tail 特判就全没了。

## 适用特征（看到这些信号就选它）

- 题目里出现 "get / put / insert / remove 都是 O(1)"；
- 需要"最近使用 / 最高频 / 中位数 / 随机取"这类顺序或统计需求；
- 需要在批量操作（setAll、flip）上偷懒 → 时间戳、懒标记。

## 复杂度总表

| 结构 | 各操作 | 额外空间 |
| --- | --- | --- |
| MyMap（setAll） | O(1) | O(n) |
| LRU | O(1) | O(capacity) |
| RandomizedSet | O(1) | O(n) |
| RandomizedCollection | O(1) | O(n) |
| MedianFinder | addNum O(log n)，findMedian O(1) | O(n) |
| FreqStack | push / pop O(1) | O(n) |
| AllOne | inc / dec O(1) | O(n) |

## 易错点

1. MyMap 的 `get` 判断条件是 `记录时间 < setAllTime`（**严格小于**），等于时应取自己的值；
2. LRU 的 `list::iterator` 在 `erase` 后立刻失效，必须先保存值再重新插入并更新 map；
3. RandomizedSet 删除时若"删的就是最后一个元素"，别再交换（会自己和自己换，逻辑仍对但多做一步），并注意 `mp.erase` 与 `arr.pop_back` 的先后；
4. RandomizedCollection 换位时要**先修正末尾元素的下标集合**，再改被删值的集合，顺序错了会留下脏下标；
5. 对顶堆的 `balance` 阈值用 `== 2`（差超过 1 就搬），并保证 `num <= maxHeap.top()` 归大根堆；
6. FreqStack 的 `maxFreq` 只在弹空最高层时才减 1；
7. AllOne 的桶插入位置：`inc` 要插在当前桶**之后**（`lst.insert(next(it), ...)`），`dec` 在**之前**；桶空了必须删。

## 模板（可直接编译运行）

```cpp
// 数据结构设计高频题模板：LRU / RandomizedSet / 中位数 / 最大频率栈 / setAll
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <cstdlib>
#include <functional>
#include <iomanip>
#include <iostream>
#include <list>
#include <queue>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

// ================= 1. LRU 缓存 =================
class LRUCache {
    int cap;
    list<pair<int,int>> lst;                    // 头 = 最久未使用，尾 = 最近使用
    unordered_map<int, list<pair<int,int>>::iterator> mp;
public:
    explicit LRUCache(int capacity) : cap(capacity) {}
    int get(int key) {
        auto it = mp.find(key);
        if (it == mp.end()) return -1;
        int v = it->second->second;
        lst.erase(it->second);
        lst.push_back({key, v});
        mp[key] = prev(lst.end());
        return v;
    }
    void put(int key, int value) {
        auto it = mp.find(key);
        if (it != mp.end()) {
            lst.erase(it->second);
        } else if ((int)lst.size() == cap) {
            mp.erase(lst.front().first);         // 淘汰最旧
            lst.pop_front();
        }
        lst.push_back({key, value});
        mp[key] = prev(lst.end());
    }
};

// ================= 2. O(1) 插入 / 删除 / 随机取 =================
class RandomizedSet {
    vector<int> arr;
    unordered_map<int,int> pos;
public:
    bool insert(int val) {
        if (pos.count(val)) return false;
        pos[val] = (int)arr.size();
        arr.push_back(val);
        return true;
    }
    bool remove(int val) {
        auto it = pos.find(val);
        if (it == pos.end()) return false;
        int p = it->second;
        int last = arr.back();
        arr[p] = last; pos[last] = p;            // 末尾元素补到被删位置
        arr.pop_back();
        pos.erase(val);
        return true;
    }
    int getRandom() { return arr[rand() % arr.size()]; }
};

// ================= 3. 数据流中位数（对顶堆） =================
class MedianFinder {
    priority_queue<int> big;
    priority_queue<int, vector<int>, greater<int>> small;
    void balance() {
        if ((int)big.size() - (int)small.size() == 2) { small.push(big.top()); big.pop(); }
        else if ((int)small.size() - (int)big.size() == 2) { big.push(small.top()); small.pop(); }
    }
public:
    void addNum(int num) {
        if (big.empty() || num <= big.top()) big.push(num);
        else small.push(num);
        balance();
    }
    double findMedian() {
        if (big.size() == small.size()) return (big.top() + small.top()) / 2.0;
        return big.size() > small.size() ? (double)big.top() : (double)small.top();
    }
};

// ================= 4. 最大频率栈 =================
class FreqStack {
    int maxFreq = 0;
    unordered_map<int,int> valToFre;
    unordered_map<int, vector<int>> freqToVals;
public:
    void push(int val) {
        int f = ++valToFre[val];
        freqToVals[f].push_back(val);
        maxFreq = max(maxFreq, f);
    }
    int pop() {
        int v = freqToVals[maxFreq].back();
        freqToVals[maxFreq].pop_back();
        if (--valToFre[v] == 0) valToFre.erase(v);
        if (freqToVals[maxFreq].empty()) { freqToVals.erase(maxFreq); --maxFreq; }
        return v;
    }
};

// ================= 5. 带 setAll 的哈希表 =================
class MyMap {
    unordered_map<int, pair<int,int>> mp;       // key -> (value, 写入时间)
    int setAllValue = 0, setAllTime = 0, cnt = 1;
public:
    void put(int key, int value) { mp[key] = {value, cnt++}; }
    bool containKey(int key) { return mp.count(key) > 0; }
    int get(int key) {
        if (!containKey(key)) return -1;
        if (mp[key].second < setAllTime) return setAllValue;   // 严格小于
        return mp[key].first;
    }
    void setAll(int value) { setAllValue = value; setAllTime = cnt++; }
};

int main() {
    LRUCache lru(2);
    lru.put(1, 1); lru.put(2, 2);
    std::cout << lru.get(1) << "\n";      // 1
    lru.put(3, 3);                   // 淘汰 key=2
    std::cout << lru.get(2) << "\n";      // -1

    MedianFinder mf;
    mf.addNum(1); mf.addNum(2); mf.addNum(3);
    std::cout << std::fixed << std::setprecision(1) << mf.findMedian() << std::defaultfloat << std::setprecision(6) << "\n";   // 2.0
    return 0;
}
```

## 专题深化：为什么成立

数据结构设计题应先列操作复杂度，再选能同时支持这些操作的组合结构。LRU 用哈希表 O(1) 定位节点、双向链表 O(1) 维护新旧顺序；随机集合用数组 O(1) 随机访问、哈希表记录下标完成 O(1) 删除。

## 专题深化：手算与边界

LRU 容量 2：访问 1 后 1 移到链尾；插入 3 时淘汰链头 2；再访问 2 返回 -1。随机集合删除 2 时把末尾元素换到 2 的下标，再删除末尾。

### 对照与取舍

| 设计 | 核心组合 | 难点 |
| --- | --- | --- |
| LRU | 哈希 + 双链表 | 同步移动节点 |
| LFU | 频率桶 + 双链表 | 最小频率 |
| 随机集合 | 数组 + 下标哈希 | O(1) 删除交换 |
| 中位数流 | 双堆 | 平衡大小 |

### 易错点与反例

1. 更新已有键时要先删除旧位置
2. 删除最后一个元素和空结构要特判
3. 随机集合交换时哈希下标同步更新
4. LFU 同频淘汰规则要精确
