# 位图（Bitmap）与 Bitset

> 来源笔记：`1203位图.cpp`｜核心程度：省空间利器｜分类：02 数据结构

## 一句话

用**每一个 bit** 记录一个数字"在不在"，于是 `n` 个数字只需要 `n/32` 个 int 的空间——这就是位图；`std::bitset` 就是它的现成实现。

## 解决什么问题

- 大规模数据、状态只有"存在/不存在"两种，判断某个数是否出现过；
- 需要 O(1) 增、删、改、查，并且极度在意空间（一个数字 1 bit）；
- 求集合运算（并、交、补）时用位运算批量处理 32 个元素；
- 进阶版 `Bitset`（笔记后半段）：还要求 `all()`、`one()`、`count()`、`toString()`、**整体翻转 `flip()`** —— 对应 LeetCode 2166「设计位集」。

## 核心思想

把位图看成一个 `int` 数组 `set[]`：

| 元素 | 覆盖的数字范围 |
| --- | --- |
| `set[0]` | 0 ~ 31 |
| `set[1]` | 32 ~ 63 |
| `set[2]` | 64 ~ 95 |

定位数字 `x` 的两步：

- `x / 32`：它在哪个 int 里；
- `x % 32`：它在这个 int 的第几位。

四个基本操作（位运算）：

| 操作 | 写法 |
| --- | --- |
| add | `set[x/32] |= 1 << (x%32)` |
| remove | `set[x/32] &= ~(1 << (x%32))` |
| flip | `set[x/32] ^= 1 << (x%32)` |
| contain | `((unsigned)set[x/32] >> (x%32)) & 1` |

**`Bitset` 的懒翻转技巧（重要）**：不真的翻转每一位，而是维护一个 `reverse` 标志位 + `ones / zeros` 计数：

- `flip()` 只做 `reverse = !reverse; swap(ones, zeros);` —— O(1)；
- `fix(i)` / `unfix(i)` 根据 `reverse` 决定"0 表示存在还是不存在"，同时维护 `ones / zeros`；
- 只有 `toString()` 才需要逐位按 `reverse` 还原——O(n)。

## 适用特征（看到这些信号就选它）

- 值域连续且不太大（笔记明确：**必须为连续范围且不能过大**）；
- 状态少（存在/不存在、正/负、访问过/没访问过）；
- 数据量 10^6 ~ 10^8 级，用 `bool` 数组会爆内存；
- 需要"整体翻转 + 统计 1 的个数"这类集合操作 → `Bitset` 的懒翻转。

## 复杂度

| 操作 | 复杂度 |
| --- | --- |
| add / remove / flip / contain | O(1) |
| `Bitset::flip()`（整体翻转） | O(1)（懒标记） |
| `Bitset::count() / all() / one()` | O(1)（维护计数） |
| `Bitset::toString()` | O(n) |
| 空间 | `(n + 31) / 32` 个 int，即 n/32 倍压缩 |

## 易错点

1. **开数组的向上取整**：`(n + 31) / 32`（`(a + b - 1) / b` 技巧），直接 `n / 32` 会少一格；
2. `1 << 31` 是 UB（有符号移位），`contain` 里笔记特意用了 `(unsigned int)set[...]` 先转无符号；
3. `remove` 用 `&= ~(1 << bit)`，别写成 `^=`（`^=` 是翻转，不是清除）；
4. `Bitset` 的 `reverse` 标志与 `ones / zeros` 计数必须**同步维护**，否则 `count()` 会和实际不符；
5. `toString()` 要按 `reverse` 反转状态输出，漏了就会输出"取反的位图"；
6. 值域不连续/过大时不要用位图（例如 `10^18` 的范围），改用哈希表。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 基础位图 ----------
class Bitmap {
    vector<unsigned> set;
public:
    explicit Bitmap(int n) : set((n + 31) / 32, 0) {}   // 向上取整
    void add(int x)    { set[x >> 5] |= 1u << (x & 31); }
    void remove(int x) { set[x >> 5] &= ~(1u << (x & 31)); }
    void flip(int x)   { set[x >> 5] ^= 1u << (x & 31); }
    bool contain(int x){ return (set[x >> 5] >> (x & 31)) & 1u; }
};

// ---------- 进阶位集：O(1) 整体翻转 ----------
class Bitset {
    vector<unsigned> set;
    int size, ones, zeros;
    bool rev;
public:
    explicit Bitset(int n) : set((n + 31) / 32, 0), size(n), ones(0), zeros(n), rev(false) {}
    void fix(int i) {                                   // 置为存在
        int idx = i >> 5, bit = i & 31;
        bool cur = (set[idx] >> bit) & 1u;              // 当前物理状态
        if (rev) cur = !cur;                            // 逻辑状态
        if (!cur) { ones++; zeros--; set[idx] ^= 1u << bit; }
    }
    void unfix(int i) {                                 // 置为不存在
        int idx = i >> 5, bit = i & 31;
        bool cur = (set[idx] >> bit) & 1u;
        if (rev) cur = !cur;
        if (cur) { ones--; zeros++; set[idx] ^= 1u << bit; }
    }
    void flip() { rev = !rev; swap(ones, zeros); }      // 懒翻转，O(1)
    bool all() const { return ones == size; }
    bool one() const { return ones > 0; }
    int count() const { return ones; }
    string toString() const {
        string s; s.reserve(size);
        for (int i = 0; i < size; i++) {
            int st = (set[i >> 5] >> (i & 31)) & 1u;
            s.push_back(char('0' + (rev ? !st : st)));
        }
        return s;
    }
};
```

## 延伸

- 位运算的更多技巧见 `1201异或运算的骚操作`、`1202位运算的骚操作`、`1119二进制和位运算`；
- 需要哈希而不是位图时（值域大/不连续）见 `1129哈希表、有序表的用法`；
- 位图也常用于"状压 DP"的状态表示（见 `0505状压dp`）。
