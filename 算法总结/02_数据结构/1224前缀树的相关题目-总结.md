# 前缀树相关题目（按位建树 / 剪枝 / 字符串化）

> 来源笔记：`1224前缀树的相关题目.cpp`｜核心程度：竞赛高频｜分类：02 数据结构

## 一句话

前缀树的三类进阶用法：**把数组差值转成字符串建树**（统计一致密匙）、**按二进制位建树**（最大异或值）、**在网格 DFS 上用前缀树剪枝**（单词搜索 II）。

## 题目一：一致密匙（差值序列 → 字符串 → 前缀树）

**题意**：密匙 b 与 a 一致 ⟺ `len(b) <= len(a)` 且所有相邻差相等。给定 m 个 b、n 个 a，求每个 b 有多少个一致的 a。

**关键技巧两条**（笔记原文）：

1. **加 `#` 做隔断**：`[3, 1, 4]` 的差值 `-2, 3` 转成 `"-2#3#"`，避免不同差值序列拼出同一个字符串；
2. **避免内存浪费**：差值可能很大（如 `1000-3 = 997`），不能按"一个数字一条边"建树，要**把差值按十进制拆成逐位字符**（`997 → 9→9→7→#`），于是树上只需要 12 条边（0-9、`-`、`#`）。

**做法**：把所有 a 的差值串插入前缀树；对每个 b 求 `prefixNumber(b的差值串)`——因为 b 是前缀就满足"每个差都相等"。

## 题目二：数组中两个数的最大异或值（按位建树）

**题意**：`nums[i] XOR nums[j]` 的最大值，n ≤ 2×10^5。

### 法一：前缀树（二进制 Trie）

- 只保留数组最大值 `maxs` 的最高位 `high`，从 `high` 位建到 0 位；
- 每个数按二进制位逐层插入，树最多 2 个分支；
- 查询时**贪心走相反位**（`want = status ^ 1`）：有相反位的路就走，否则只能走同位，累加 `ans |= (status ^ want) << i`；
- 复杂度 O(31n)，空间 O(31n)。

### 法二：哈希表 + 贪心（更好写）

> 笔记的贪心洞察："如果答案的第 i 位能是 1，那么这个 1 一定要，低位全是 1 也不如这个高位的 1 值钱。"

从高位往低位构造答案 `ans`：

1. `want = ans | (1 << i)`（希望这一位是 1）；
2. 把所有数的**高 i 位**存进 `unordered_set`：`(x >> i) << i`（先右移再左移 = 只保留高位）；
3. 若存在两个前缀互异或得到 `want`，即 `set` 中存在 `num ^ want`，则 `ans = want`；
4. 每轮清空 `set`（笔记特意指出：只用一个哈希表，空间更省）。

## 题目三：单词搜索 II（前缀树 + DFS 剪枝）

**题意**：m×n 网格（m,n ≤ 12）+ 至多 3×10^4 个长度 ≤ 10 的单词，返回所有能在网格中找到的词（相邻上下左右、格不能复用）。

**核心**：复杂度本质是 O(m·n·4^10)，前缀树的作用是**大量剪枝**（把常数压下来）：

- 用 `end_[t]` 存字符串（而不是 `bool`），走到就用 `end_[t]` 收集答案；
- 收集后把 `end_[t]` 清空，避免同一个词被重复加入；
- **`pass[t] == 0` 就返回**：说明这棵子树里的词已经被收集完了，后面没必要走；
- 回溯时 `board[i][j] = 0` 标记已访问，返回前还原；
- DFS 返回"本次收集到几个词"，上层用 `pass[t] -= fix` 更新剪枝信息。

注意笔记里的一个实现细节：类版本的 `Solution` 用**非静态成员数组**（每次实例化一份，避免多组数据互相污染），而 `WordSearchII` 用全局数组 + `clear()`。

## 适用特征（看到这些信号就选它）

- 要在"前缀"上比对（差值前缀、字符串前缀）；
- 要在**二进制位**上做大小比较/异或极值；
- 大量关键词在一个网格/图上搜索，需要剪枝降常数；
- 字符串集合规模大、需要按前缀统计。

## 复杂度

| 题目 | 时间 | 空间 |
| --- | --- | --- |
| 一致密匙 | O(总差值位数) | O(总差值位数 × 12) |
| 最大异或（Trie） | O(31n) | O(31n × 2) |
| 最大异或（哈希贪心） | O(31n) | O(n) |
| 单词搜索 II | O(m·n·4^10)（前缀树只优化常数） | O(所有词字符总数) |

## 易错点

1. 差值串**必须加 `#` 隔断**，否则 `[1, 2]` 的差值 `1` 和 `[1, 12]` 的差值 `11` 会被混在一起；
2. 差值按十进制拆位时别忘了**负号**也要占一条边（笔记用 `path('-') = 10`）；
3. 最大异或的 Trie 版**不需要 `pass/end`**，只需要两个孩子指针；`high` 要按数组最大值算，减少层数；
4. 哈希法里 `(x >> i) << i` 是保留高位、清低位的标准写法，写成 `x & (~0 << i)` 也可以（注意用无符号避免 UB）；
5. 单词搜索的 `pass[t] -= fix` 是剪枝的关键，漏掉会重复搜索、效率暴跌；
6. 网格 DFS 的越界判断要放在最前面，访问标记 `board[i][j] = 0` 与还原必须成对；
7. 静态数组成员要在类外初始化，多组数据记得 `clear()`。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ===== 1) 二进制 Trie 求最大异或 =====
struct XorTrie {
    static const int MAXN = 3000001;   // 31 * n
    int tree[MAXN][2];
    int cnt = 1, high = 0;

    void build(const vector<int>& nums) {
        int maxs = 0;
        for (int x : nums) maxs = max(maxs, x);
        high = 31; while (high > 0 && !((maxs >> high) & 1)) high--;
        for (int x : nums) {
            int cur = 1;
            for (int i = high; i >= 0; i--) {
                int p = (x >> i) & 1;
                if (!tree[cur][p]) tree[cur][p] = ++cnt;
                cur = tree[cur][p];
            }
        }
    }
    int query(int x) {                 // x 与树中某数的最大异或
        int ans = 0, cur = 1;
        for (int i = high; i >= 0; i--) {
            int st = (x >> i) & 1, want = st ^ 1;
            if (!tree[cur][want]) want ^= 1;    // 没有相反位只能走同一位
            ans |= (st ^ want) << i;
            cur = tree[cur][want];
        }
        return ans;
    }
};

// ===== 2) 哈希贪心求最大异或（更好写） =====
int findMaximumXOR(vector<int>& nums) {
    int ans = 0, high = 31;
    while (high > 0 && !((*max_element(nums.begin(), nums.end()) >> high) & 1)) high--;
    unordered_set<int> st;
    for (int i = high; i >= 0; i--) {
        int want = ans | (1 << i);
        st.clear();
        for (int x : nums) {
            int highBits = (x >> i) << i;        // 只保留高 i 位
            st.insert(highBits);
            if (st.count(highBits ^ want)) { ans = want; break; }
        }
    }
    return ans;
}
```
