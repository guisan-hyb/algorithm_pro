# 栈与队列相互实现 & 最小栈

> 来源笔记：`1123栈和队列相互成全、最小栈.cpp`｜核心程度：经典面试题｜分类：02 数据结构

## 一句话

两个栈可以凑出一个队列（一进一出），一个队列可以凑出一个栈（新元素入队后把前面的全转到它后面）；最小栈则用一个"同步记录历史最小值"的辅助栈实现 O(1) 取最小值。

## 解决什么问题

1. **用栈实现队列**：只允许 `push / pop / top / empty` 的情况下实现 FIFO 队列；
2. **用队列实现栈**：只允许 `push / pop / top / empty` 的情况下实现 LIFO 栈；
3. **最小栈**：要求 `push / pop / top / getMin` 全部 O(1)。

## 核心思想

### 栈 → 队列（两个栈 in / out）

- 入队：压入 `in`；
- 出队/取队头：把 `in` 全部倒入 `out`，再从 `out` 弹出；
- 倒数字的两条纪律（笔记原文）：
  1. **`out` 空了才能倒数据**；
  2. **一旦要倒，`in` 必须倒完**。

只要守住这两条，每个元素一生最多被倒一次，均摊 O(1)。

### 队列 → 栈（一个队列）

- 新元素先入队；
- 然后把队首的 `size - 1` 个元素依次"出队再入队"，让新来的元素跑到队首；
- 于是队首永远是最后进来的元素，出队即出栈。

### 最小栈（双栈同步）

- `data` 栈存全部数据，`min` 栈存"每一步的历史最小值"；
- 新值 `x <= min.top()` 时 `min` 压 `x`，否则 `min` 压 `min.top()`（重复压最小值）；
- 出栈时两个栈**同步弹出**；
- `min.empty()` ⟺ `data.empty()`，`getMin()` 就是 `min.top()`。

## 适用特征（看到这些信号就选它）

- 题目明确限制"只能用栈/只能用一个队列"实现另一种结构（面试高频）；
- 需要 O(1) 取栈内最小值 / 最大值（改为最大值只需反转比较）；
- 需要随时知道"当前状态下的极值"，而状态是后进先出的。

## 复杂度

| 结构 | 操作 | 复杂度 |
| --- | --- | --- |
| 栈实现队列 | push / pop / peek | 均摊 O(1) |
| 队列实现栈 | push | O(n)（转一圈） |
| 队列实现栈 | pop / top | O(1) |
| 最小栈 | push / pop / top / getMin | 全部 O(1)，额外空间 O(n) |

## 易错点

1. 倒数字时忘记"`out` 空才倒"或"倒必须倒完"，会导致顺序错乱（这是本题唯一的坑）；
2. 队列实现栈时循环次数是 `q.size() - 1`：入队后 size 已经 +1，所以转的是"老元素"个数；
3. 最小栈里 `x <= min.top()` 必须带等号，否则重复最小值在弹出时会提前丢失最小值；
4. 最小栈的另一种写法是存"差值"，但那会引入溢出问题，双栈同步写法更稳；
5. 最小栈的 `pop` 必须在两个栈上同时进行，漏一个就全错。

## 模板（可直接编译运行）

```cpp
// 栈与队列相互实现 + 最小栈：可直接使用的类模板
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <iostream>
#include <queue>
#include <stack>
using namespace std;

// ============ 1. 两个栈实现队列 ============
class MyQueue {
    stack<int> in, out;
    void inToOut() {
        if (!out.empty()) return;      // 纪律一：out 空才能倒
        while (!in.empty()) {          // 纪律二：倒就倒完
            out.push(in.top());
            in.pop();
        }
    }
public:
    void push(int x) { in.push(x); }
    int pop() { inToOut(); int v = out.top(); out.pop(); return v; }
    int peek() { inToOut(); return out.top(); }
    bool empty() { return in.empty() && out.empty(); }
};

// ============ 2. 一个队列实现栈 ============
class MyStack {
    queue<int> q;
public:
    void push(int x) {
        q.push(x);
        for (int i = 0; i < (int)q.size() - 1; i++) {   // 新元素转到队首
            q.push(q.front());
            q.pop();
        }
    }
    int pop() { int v = q.front(); q.pop(); return v; }
    int top() { return q.front(); }
    bool empty() { return q.empty(); }
};

// ============ 3. 最小栈 ============
class MinStack {
    stack<int> data, mn;
public:
    void push(int x) {
        data.push(x);
        mn.push(mn.empty() ? x : min(x, mn.top()));    // x <= 当前最小值都要记录
    }
    void pop() { data.pop(); mn.pop(); }               // 必须同步
    int top() { return data.top(); }
    int getMin() { return mn.top(); }
};

int main() {
    MinStack ms;
    int n;
    if (!(std::cin >> n)) return 0;
    for (int i = 0, x; i < n; i++) {
        (std::cin >> x);
        ms.push(x);
        std::cout << "push " << x << " -> min = " << ms.getMin() << "\n";
    }
    return 0;
}
```

## 专题深化：为什么成立

两个栈实现队列时，out 只在空时整体倒入 in，保证队头顺序；最小栈保存每个时刻的最小值，使 pop 后能恢复到前一个状态。每个元素最多被移动常数次，因此摊还 O(1)。

## 专题深化：手算与边界

push 1、2、3 后 in=`[1,2,3]`；首次 pop 时全部倒入 out，out 顶为 1。随后 push 4 不影响 out，继续pop 2、3，再倒一次得到 4。

### 对照与取舍

最小栈可用同步辅助栈、差值编码或栈元素结构体实现。同步栈最稳；差值法节省空间但对数值范围敏感。

### 易错点与反例

1. out 非空时不能倒入
2. push 到最小栈要包含等号以支持重复最小值
3. 空栈调用 top/pop 是非法操作
4. 摊还复杂度不是每次操作最坏 O(1)

## 专题深化：进阶拓展

单调队列可维护滑动窗口最值；两个队列也能模拟栈，但每次 push 代价可能 O(n)。
