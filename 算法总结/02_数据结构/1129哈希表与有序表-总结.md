# 哈希表、有序表与比较器的用法（STL 容器手册）

> 来源笔记：`1129哈希表、有序表的用法.md`｜性质：STL 使用手册 + 选型对照｜分类：02 数据结构

## 一句话

要"有序 + 范围查询"就用红黑树容器（`set / map / multiset / multimap`），要"只要查得快"就用哈希容器（`unordered_set / unordered_map`）；能自定义比较规则（仿函数）是它们的关键能力。

## 一、核心对照表（选型看这张就够）

| 集合 | 底层实现 | 是否有序 | 数值可否重复 | 查询/增删 |
| --- | --- | --- | --- | --- |
| `std::set` | 红黑树 | 有序 | 否 | O(log n) |
| `std::multiset` | 红黑树 | 有序 | 是 | O(log n) |
| `std::unordered_set` | 哈希表 | 无序 | 否 | 平均 O(1)，最坏 O(n) |

| 映射 | 底层实现 | 是否有序 | key 可否重复 | 查询/增删 |
| --- | --- | --- | --- | --- |
| `std::map` | 红黑树 | key 有序 | 否 | O(log n) |
| `std::multimap` | 红黑树 | key 有序 | 是 | O(log n) |
| `std::unordered_map` | 哈希表 | key 无序 | 否 | 平均 O(1)，最坏 O(n) |

**选型口诀（笔记结论）**：用集合解哈希类问题时**优先 `unordered_set`**（查询/增删最优）；需要有序用 `set`；既要有序又要重复用 `multiset`。`map` 系列同理。

## 二、常用 API（set / map 通用记忆）

### 构造与赋值

```cpp
set<int> st;                    // 默认构造（升序）
set<int> st2(st);               // 拷贝构造
st2 = st;                       // 重载 =
```

### 插入与删除

```cpp
s.insert(10);                   // set 返回 pair<iterator, bool>，bool 表示是否插入成功
s.erase(s.begin());             // 按迭代器删，返回下一个迭代器
s.erase(s.begin(), s.end());    // 按区间删 [beg, end)
s.erase(30);                    // 按值删（set 返回删除个数，map 按 key 删）
s.clear();                      // 清空
```

### 大小、交换、查找、统计

```cpp
s.size(); s.empty(); s.swap(s2);
s.find(30);     // 找到返回迭代器，找不到返回 s.end()
s.count(30);    // 统计个数（set 是 0/1，multiset 可 >1）
```

### `set` 与 `multiset` 的区别

- `set` 不允许重复，且 `insert` 返回 `pair<iterator, bool>` 能告诉你"插入是否成功"；
- `multiset` 不检测重复，可以插多个相同值。
- 注意：`multiset` 的 `erase(value)` 会**删掉所有等于 value 的元素**，只想删一个要 `s.erase(s.find(value))`。

### `map` 的四种插入方式

```cpp
m.insert(pair<int,int>(1, 10));
m.insert(make_pair(2, 20));
m.insert(map<int,int>::value_type(3, 30));
m[4] = 40;                      // 最常用，但 key 不存在时会"凭空创建"默认值
```

> `operator[]` 的陷阱：`m[key]` 会对不存在的 key 插入一个默认值；只想查询时用 `find` / `count` / `at`。这个特性在 `1203链表高频题`（复制随机链表）里被巧妙地利用了。

## 三、自定义比较规则（仿函数）

```cpp
class MyCompare {
public:
    bool operator()(int v1, int v2) { return v1 > v2; }   // 从大到小
};
set<int, MyCompare> s;          // 降序集合
map<int, int, MyCompare> m;     // key 降序的 map
```

要点：比较器必须满足**严格弱序**（`cmp(a,a)` 必须为 false），否则容器行为未定义。

## 四、`pair` 对组

```cpp
pair<string, int> p("Tom", 20);            // 直接构造
pair<string, int> p2 = make_pair("Jerry", 10);
// 访问：p.first / p.second
```

`pair` 是 `map` 的元素类型，也是"函数返回两个值"的常用手段。

## 五、适用特征（看到这些信号就选它）

| 需求 | 选 |
| --- | --- |
| 只查存在性、要最快 | `unordered_set` |
| 需要有序遍历 / 找前驱后继 / 范围查询（`lower_bound`） | `set` |
| 键值映射、key 唯一 | `unordered_map`（快）/ `map`（有序） |
| key 可以重复 | `multiset` / `multimap` |
| 需要"按第 k 小查询" | 红黑树容器做不到（要树状数组/平衡树/有序表模板） |

## 六、易错点

1. `map` 的 `operator[]` 会插入默认值，遍历时容易凭空多出键；
2. `unordered_map` 的**最坏**是 O(n)（哈希被卡）；比赛里可用自定义哈希或改用 `map`；
3. `set` / `map` 的 key **不可修改**（改动会破坏红黑树），要改就先删再插；
4. `multiset::erase(value)` 删除所有等值元素，别误用；
5. `hash_set / hash_map` 是 C++11 之前的民间轮子，标准里请用 `unordered_*`；
6. `set` 的迭代器是双向迭代器，不支持随机访问（不能 `s[i]`）。
