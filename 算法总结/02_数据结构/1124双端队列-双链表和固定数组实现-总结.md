# 双端队列（固定数组实现 + 双链表实现）

> 来源笔记：`1124双端队列-双链表和固定数组实现.cpp`｜核心程度：工程基础｜分类：02 数据结构

## 一句话

两端都能进出，所以只要维护"环形的 `left / right` 下标 + 一个独立的 `size`"，数组就能 O(1) 支持四种操作。

## 解决什么问题

- 需要同时从两端插入/删除的场景：滑动窗口（单调队列）、0-1 BFS、双向广搜的队列；
- 手写结构题（"请你设计一个双端队列"）；
- 理解 C++ `deque` 的底层（分段数组 + 索引映射）。

## 核心思想

### 固定数组实现（环形缓冲区）

维护三个量：

- `left`：队头下标；`right`：队尾下标；`size`：当前元素个数；
- `insertFront`：`left = (left == 0 ? limit - 1 : left - 1)`，再写值；
- `insertRear`：`right = (right == limit - 1 ? 0 : right + 1)`，再写值；
- `deleteFront`：`left = (left == limit - 1 ? 0 : left + 1)`，`size--`；
- `deleteRear`：`right = (right == 0 ? limit - 1 : right - 1)`，`size--`；
- `isEmpty`: `size == 0`；`isFull`: `size == limit`；
- 空队列插入第一个元素时，`left = right = 0` 是唯一的特判点。

**为什么必须单独存 size**：环形数组里 `left`/`right` 会绕圈，无法像普通数组那样用下标差判断空与满（`left == right` 既可能是空也可能是满）。

### 双链表实现

带头结点的双向链表：`insertFront` = 在头结点之后插入；`insertRear` = 在尾结点之后插入；删除同理。O(1) 且不受容量限制，代价是每个节点多一个 `prev` 指针。

## 适用特征（看到这些信号就选它）

- 需要在两端做 O(1) 增删；
- 数据是"窗口"式的（左端淘汰、右端进入）；
- C++ 里直接 `#include <deque>` 用现成的（`push_front / push_back / pop_front / pop_back / front / back`）。

## 复杂度

| 实现 | 四种操作 | 空间 |
| --- | --- | --- |
| 固定数组（环形） | O(1) | O(limit) 预先分配，不能扩容 |
| 双链表 | O(1) | O(n) 动态，每节点多一个指针 |

## 易错点

1. **不存 size 是最高频错误**：用 `left == right` 判空/判满必然出错；
2. 边界判断的两种写法（`limit - 1` 回绕 / `+1` 回绕）容易写反，建议照抄模板；
3. 空队列插入必须特判 `left = right = 0`，否则会凭空多走一格；
4. 删除操作只动下标和 `size`，**不需要**真的把数据清零（写不写无所谓，别依赖旧值）；
5. 固定数组版取元素前必须先 `isEmpty()` 判断，越界访问是未定义行为。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

class MyDeque {
    vector<int> arr;
    int limit, left = 0, right = 0, sz = 0;
public:
    MyDeque(int capacity) : arr(capacity), limit(capacity) {}
    bool isEmpty() const { return sz == 0; }
    bool isFull()  const { return sz == limit; }

    bool insertFront(int val) {
        if (isFull()) return false;
        if (isEmpty()) { left = right = 0; }
        else left = (left == 0) ? limit - 1 : left - 1;
        arr[left] = val;
        sz++;
        return true;
    }
    bool insertRear(int val) {
        if (isFull()) return false;
        if (isEmpty()) { left = right = 0; }
        else right = (right == limit - 1) ? 0 : right + 1;
        arr[right] = val;
        sz++;
        return true;
    }
    bool deleteFront() {
        if (isEmpty()) return false;
        left = (left == limit - 1) ? 0 : left + 1;
        sz--;
        return true;
    }
    bool deleteRear() {
        if (isEmpty()) return false;
        right = (right == 0) ? limit - 1 : right - 1;
        sz--;
        return true;
    }
    int getFront() const { return isEmpty() ? -1 : arr[left]; }
    int getRear()  const { return isEmpty() ? -1 : arr[right]; }
};
```
