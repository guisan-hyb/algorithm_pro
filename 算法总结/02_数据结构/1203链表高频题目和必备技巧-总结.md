# 链表高频题目与必备技巧

> 来源笔记：`1203链表高频题目和必备技巧.cpp`｜核心程度：面试高频｜分类：02 数据结构

## 一句话

链表题考的不是算法设计，而是 **coding 能力**；每个高频题都有"容器版（好写）"和"O(1) 空间版（够硬）"两条路，快慢指针是最常用的杠杆。

## 笔记开篇的四条原则

1. 笔试空间要求不严格 → **直接用容器**（vector / stack / set / map）解决；
2. 笔试空间严格、或面试官强调空间优化 → 用**额外空间 O(1)** 的方法；
3. 最常用的技巧是**快慢指针**；
4. 链表题没有捷径，**除了多写多练**没有别的方法；练习时不要用容器讨巧。

> 笔记原文的忠告："我们是用**栈区的临时变量**操作**堆区的链表**，不要被变量名迷惑"、"参数是指针类型，注意不要破坏传入的参数，用临时变量解决"。

## 六个高频题

### 题一：两个无环链表的第一个相交结点

- 容器版：`set` 记录第一条链的所有节点，再走第二条，第一个命中即交点；
- O(1) 空间版：分别走到尾，`diff` 记录长度差；**尾节点不同则不相交**；长的先走 `|diff|` 步，再同步走，第一次相遇即交点。

### 题二：每 K 个结点一组翻转链表

- 容器版：把节点指针装进 `vector`，按组 `reverse`，再重新串 `next`；
- O(1) 空间版：`getEnd(start, k)` 找每组的尾；`reverseList(start, end)` 反转 `[start, end]` 这一段（注意反转后要 `start->next` 指回下一组头）;
- **第一组特殊**：它决定整条链的新头（`head = end`），后续组用 `lastTeamEnd` 串接。

### 题三：复制带随机指针的链表

- 容器版：`map<Node*, Node*> mp`；第一遍建节点，第二遍用 `mp[curr]->next = mp[curr->next]` 复制指针（`map` 的 `operator[]` 对不存在的 key 会插入 `NULL`，正好利用这点）；
- O(1) 空间版（"白绝结点"法）：把副本插到原节点后面（`1 -> 1' -> 2 -> 2' ...`），再修 `random`（`cur->next->random = cur->random ? cur->random->next : NULL`），最后**分离新旧链表**。

### 题四：判断链表是否回文

- 容器版：全部压栈再逐一出栈比对；
- O(1) 空间版（考研常考流程）：快慢指针找中点（`fast` 一次两步）→ 反转右半 → 左右比对 → **把右半反转回去恢复原链表**。

### 题五：返回链表第一个入环节点（LeetCode 142）

- 容器版：`set` 存走过的节点，第一次重复即入环点；
- O(1) 空间版（Floyd 判圈）：
  1. 快指针一次两步、慢指针一次一步，直到相遇（快指针走到空则无环）；
  2. **慢指针原地不动，快指针回到链表头**，两指针每次各走一步，再次相遇处就是入环点。

### 题六：链表排序（O(n log n) + O(1) 额外空间 + 稳定）

- 容器版：节点指针装进 `vector`，按 `val` 排序（`sort` + 比较器），再重连；
- 真解：**非递归归并排序**（递归版需要 O(log n) 栈空间，不满足 O(1)）：
  - `for (step = 1; step < n; step <<= 1)` 自底向上；
  - 找到 `l1..r1`、`l2..r2` 两段，断链（`r1->next = r2->next = nullptr`）；
  - `mergeList` 归并两段，用全局 `start / end` 带回整段的新头与新尾；
  - 第一组特殊（决定新头），后续组用 `lastTeamEnd->next = start` 串起来。

## 适用特征（看到这些信号就选它）

- 题目在链表上做"定位 / 重组 / 判环 / 复制"；
- 要求 O(1) 额外空间 → 快慢指针 + 原地反转 + 断链重连；
- 面试考察实现细节 → 主动给出"容器版"和"O(1) 空间版"两个方案。

## 复杂度

| 题目 | 容器版 | O(1) 空间版 |
| --- | --- | --- |
| 相交结点 | O(n) 时间 / O(n) 空间 | O(n + m) / O(1) |
| K 个一组翻转 | O(n) / O(n) | O(n) / O(1) |
| 复制随机链表 | O(n) / O(n) | O(n) / O(1) |
| 回文判断 | O(n) / O(n) | O(n) / O(1) |
| 入环节点 | O(n) / O(n) | O(n) / O(1) |
| 链表排序 | O(n log n) / O(n) | O(n log n) / O(1)（非递归归并） |

## 易错点

1. 快慢指针的循环条件要同时保护 `fast` 和 `fast->next`（见 `浅谈链表哨兵节点与循环条件.md`）；
2. K 个一组翻转里，`reverseList` 结束后要 `start->next = nextGroupStart`——`start` 已经是这一段的**尾**；
3. 复制随机链表时，`mp[curr->random]` 在 `random == NULL` 时要用 `map` 的行为（插入 NULL）或显式判断，否则越界；
4. 回文题若要求"恢复原链表"，比对完必须把右半再反转回去；
5. 判圈第二步是"快指针回到头部再同速走"，不是"慢指针回到头部"；
6. 链表排序：非递归归并必须**先断链**再 merge，否则会串成环或死循环。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v = 0, ListNode* n = nullptr) : val(v), next(n) {}
};

// 相交结点：先求长度差，长的先走
ListNode* getIntersectionNode(ListNode* a, ListNode* b) {
    if (!a || !b) return nullptr;
    int diff = 0;
    ListNode* pa = a; ListNode* pb = b;
    while (pa->next) { pa = pa->next; diff++; }
    while (pb->next) { pb = pb->next; diff--; }
    if (pa != pb) return nullptr;              // 尾不同 -> 不相交
    ListNode *fast = diff >= 0 ? a : b, *slow = diff >= 0 ? b : a;
    for (int i = 0; i < abs(diff); i++) fast = fast->next;
    while (fast != slow) { fast = fast->next; slow = slow->next; }
    return fast;
}

// 入环节点：Floyd 判圈
ListNode* detectCycle(ListNode* head) {
    ListNode *slow = head, *fast = head;
    do {
        if (!fast || !fast->next) return nullptr;
        fast = fast->next->next;
        slow = slow->next;
    } while (fast != slow);
    fast = head;                                // 快指针回到头部
    while (fast != slow) { fast = fast->next; slow = slow->next; }
    return fast;
}

// 回文：快慢找中点 + 反转右半 + 比对 + 还原
bool isPalindrome(ListNode* head) {
    if (!head || !head->next) return true;
    ListNode *fast = head, *slow = head;
    while (fast->next && fast->next->next) { fast = fast->next->next; slow = slow->next; }
    ListNode* prev = nullptr;                    // 反转 slow->next 开始
    ListNode* cur = slow->next;
    while (cur) { ListNode* nxt = cur->next; cur->next = prev; prev = cur; cur = nxt; }
    bool ok = true;
    ListNode *l = head, *r = prev;
    while (r) { if (l->val != r->val) { ok = false; break; } l = l->next; r = r->next; }
    cur = prev; prev = nullptr;                  // 还原右半
    while (cur) { ListNode* nxt = cur->next; cur->next = prev; prev = cur; cur = nxt; }
    slow->next = prev;
    return ok;
}
```
