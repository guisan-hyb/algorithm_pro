# 树状数组（BIT）

> 来源笔记：`1002树状数组.cpp`｜核心程度：必背（竞赛主力数据结构）｜分类：02 数据结构

## 一句话

用 `lowbit` 把数组按二进制分块：`add` 往上跳 `i += i & -i`，`query` 往下跳 `i -= i & -i`，于是单点/区间操作全部 O(log n)，而代码只有十行。

## 解决什么问题

维护**可差分的信息**（前缀和能相减得到区间结果的信息）：累加和、累乘积等。

| 场景 | 做法 |
| --- | --- |
| 单点增加 + 范围查询 | 直接维护原数组（笔记题目一） |
| 范围增加 + 单点查询 | 维护**差分**数组（笔记题目二） |
| 范围增加 + 范围查询 | 维护**两个**差分数组 `D[i]` 和 `(i-1)·D[i]`（笔记题目三） |
| 二维：单点增加 + 范围查询 | 二维 BIT，双重 lowbit 循环 + 容斥（笔记题目四） |
| 二维：范围增加 + 范围查询 | 维护**四个**二维 BIT（笔记题目五，较难） |

## 核心思想

### lowbit 的两条路线

```
add(idx, v)     : for (i = idx; i <= n; i += i & -i)  tree[i] += v;
query(idx)      : for (i = idx; i >   0; i -= i & -i)  ans += tree[i];
range(l, r)     : query(r) - query(l - 1)
```

含义：树状数组的每个下标 `i` 管理 `[i - lowbit(i) + 1, i]` 这一段的合并信息（右端点是 `i` 的最长管辖区间）。

**下标必须从 1 开始**（0 的 lowbit 是 0，会死循环）。

### 范围修改 + 单点查询

树状数组维护**差分数组** `D`：`range_add(l, r, k)` 就是 `add(l, k); add(r+1, -k)`；单点查询 `query(x)` 得到 `a[x]`。

### 范围修改 + 范围查询（关键推导）

前缀和 `sum(1..x) = Σ(x - i + 1)·D[i] = (x+1)·ΣD[i] - Σ i·D[i]`，所以维护两个数组：

```cpp
add(info1, l, v);        add(info1, r + 1, -v);          // ΣD
add(info2, l, v*(l-1));  add(info2, r + 1, -v*r);        // Σ(i-1)·D
range(l, r) = (query(info1,r)*r - query(info2,r))
            - (query(info1,l-1)*(l-1) - query(info2,l-1));
```

笔记里 `info2` 存的是 `(i-1)·D[i]`，与上面的推导只差一个下标偏移，形式等价。

### 二维 BIT

把两层 lowbit 循环套起来即可；矩形查询用二维容斥：

```
sum(a,b,c,d) = query(c,d) - query(c,b-1) - query(a-1,d) + query(a-1,b-1)
```

二维范围修改 + 范围查询要维护 4 个 BIT（`d[i][j]`、`d·i`、`d·j`、`d·i·j`），笔记给了完整代码，重推导不建议现场推，按模板抄。

## 树状数组 vs 线段树（笔记结论）

| | 树状数组 | 线段树 |
| --- | --- | --- |
| 时间复杂度 | 单次 O(log n) | 单次 O(log n) |
| 代码量 | 少 | 多 |
| 空间 | 少 | 大 |
| 常数 | 优异 | 较差 |
| 维护信息类型 | **只能维护可差分信息**（和、积） | 可差分 + 不可差分（最值等） |

绝大多数情况下线段树可以替代树状数组；但当信息可差分、又想要短代码和好常数时，用树状数组。

## 适用特征（看到这些信号就选它）

- 出现"单点修改 + 区间求和""区间加 + 区间求和""动态前缀和"；
- 需要动态维护逆序对、第 k 小（配合值域）；
- n 在 10^5 ~ 10^6，需要 O(log n) 且常数小；
- 维护的信息**可差分**（能由 `query(r) - query(l-1)` 得到区间结果）。

## 复杂度

- 单次 `add` / `query`：O(log n)；
- 建树：O(n)（也可以用 `add` 逐个插入，O(n log n)）；
- 空间：O(n)（二维 O(n·m)）。

## 易错点

1. **下标从 1 开始**，读入后 `add(i, v)` 而不是 `add(i-1, v)`；数组开 `n + 2` 防止 `r + 1` 越界；
2. 前缀和型问题时 `query(idx)` 返回 `[1..idx]` 的和，区间和别忘了减 `query(l-1)`；
3. 范围修改 + 单点查询时，初始化要写 `add(i, v); add(i+1, -v);`（构造差分）；
4. 结果可能溢出：和、乘积用 `long long`；
5. 二维容斥的四个符号别写错（正、负、负、正）；
6. 多组数据要清空 tree（`fill` 或重新 `resize`）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ===== 1) 单点增加 + 范围查询 =====
template <class T>
struct BIT {
    int n;
    vector<T> tree;
    explicit BIT(int n = 0) { init(n); }
    void init(int n_) { n = n_; tree.assign(n + 2, 0); }
    static int lowbit(int x) { return x & -x; }
    void add(int idx, T v) {                    // 下标从 1 开始
        for (int i = idx; i <= n; i += lowbit(i)) tree[i] += v;
    }
    T query(int idx) const {
        T ans{};
        for (int i = idx; i > 0; i -= lowbit(i)) ans += tree[i];
        return ans;
    }
    T range(int l, int r) const { return query(r) - query(l - 1); }
};

// ===== 2) 范围增加 + 单点查询（维护差分） =====
// add(l, k); add(r + 1, -k);  然后 query(x) 就是 a[x]

// ===== 3) 范围增加 + 范围查询（维护两个差分数组） =====
struct BITRange {
    BIT<long long> b1, b2;                      // b1: D, b2: (i-1)*D
    explicit BITRange(int n = 0) : b1(n), b2(n) {}
    void add(int l, int r, long long v) {
        b1.add(l, v);          b1.add(r + 1, -v);
        b2.add(l, v * (l - 1)); b2.add(r + 1, -v * r);
    }
    long long prefix(int x) {                   // sum(1..x)
        return b1.query(x) * x - b2.query(x);
    }
    long long range(int l, int r) { return prefix(r) - prefix(l - 1); }
};

// ===== 4) 二维单点增加 + 范围查询 =====
struct BIT2D {
    int n, m;
    vector<vector<long long>> tree;
    BIT2D(int n_, int m_) : n(n_), m(m_), tree(n_ + 2, vector<long long>(m_ + 2, 0)) {}
    static int lowbit(int x) { return x & -x; }
    void add(int x, int y, long long v) {
        for (int i = x; i <= n; i += lowbit(i))
            for (int j = y; j <= m; j += lowbit(j))
                tree[i][j] += v;
    }
    long long query(int x, int y) const {
        long long ans = 0;
        for (int i = x; i > 0; i -= lowbit(i))
            for (int j = y; j > 0; j -= lowbit(j))
                ans += tree[i][j];
        return ans;
    }
    long long sum(int a, int b, int c, int d) const {   // 矩形 [a..c] x [b..d]
        return query(c, d) - query(c, b - 1) - query(a - 1, d) + query(a - 1, b - 1);
    }
};
```
