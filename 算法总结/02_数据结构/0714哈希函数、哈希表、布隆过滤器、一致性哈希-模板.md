## 一、MD5 手写实现的结构（理解用，工程直接调库）

```text
初始状态：A=0x67452301, B=0xefcdab89, C=0x98badcfe, D=0x10325476
四轮，每轮 16 步，共 64 步：
  第 1 轮用 F(x,y,z) = (x & y) | (~x & z)
  第 2 轮用 G(x,y,z) = (x & z) | (y & ~z)
  第 3 轮用 H(x,y,z) = x ^ y ^ z
  第 4 轮用 I(x,y,z) = y ^ (x | ~z)
每步：a = rotl(a + f(b,c,d) + x[k] + T[i], s) + b   （逐变量轮转）

填充：先补 0x80，再补 0 到 56 (mod 64)，最后 8 字节写原始长度（小端）
输出：把 4 个 32 位状态按小端拼成 16 字节摘要

取模技巧（大整数哈希值 % m）：
  result = 0
  for each hex digit d: result = (result * 16 + d) % m
```

## 二、哈希表扩容

```text
均摊复杂度 O(k)（k = 平均样本长度）；int / long long 时为 O(1)
可定制项：
  初始桶数 / 扩容阈值（链表多长触发）/ 扩容因子（翻倍或 1.5 倍）/ 哈希函数 / 桶结构
结论：所有定制只影响常数，时间复杂度无法再优化
```

## 三、布隆过滤器（重点公式）

```text
已知：样本数量 n、期望失误率 p

1. 需要的 bit 数            m = ceil( -(n * ln p) / (ln 2)^2 )
   需要的字节数             m / 8
2. 需要的哈希函数个数        k = ceil( ln 2 * m / n )
3. 取整后真实失误率          p_true = (1 - e^(-n*k/m))^k

插入：用 k 个哈希函数算出 k 个下标，全部置 1
查询：k 个下标全是 1 -> "可能存在"；有一个是 0 -> "一定不存在"
特性：只有误报、没有漏报；不支持删除；空间与样本长度无关
```

**示例套用（笔记的题）**：n = 100 亿，p = 万分之一（0.0001），代入求 m（bit）→ 转字节检查是否 < 30G，再求 k，再算真实失误率。

## 四、一致性哈希

```text
1. 朴素分片：机器 = hash(key) % N  ->  增删机器时几乎全量迁移
2. 一致性哈希：
   - 哈希空间 [0, 2^32) 首尾相接成环
   - 机器按标识哈希落到环上，数据顺时针找到第一台机器
   - 增删机器只影响环上相邻的一段 -> 迁移量约 1/N
3. 数据倾斜的解决：虚拟节点
   - 每台物理机在环上放多个虚拟节点（如 1000 个）
   - 虚拟节点让各机器负责的弧长趋于均匀 -> 负载均衡
   - 还可以按机器性能分配虚拟节点数量 -> 负载管理
```

## 五、海量数据 top-k 的通用流程

```text
输入：超大文件（内存装不下），求出现次数最多的元素

1. 逐行读，计算 hash(line) % K，写到第 K 个小文件（K 取到每个小文件能进内存）
   —— 同一个 key 一定落在同一个文件（哈希确定性）
2. 对每个小文件：读进内存，用哈希表统计词频，记录局部最大值
3. 汇总所有小文件的局部最大值，得到全局答案

变体：求 top-100 -> 每个小文件维护一个大小为 100 的小根堆，最后合并
```
