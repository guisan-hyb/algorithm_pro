# 算法总结 · 目录索引

本目录由仓库根目录的原始笔记（76 个 `.cpp` + 17 个 `.md`，以及 `.assert` 中的配图）**逐篇精读后重写**而成：

- 每个专题一份 **`XXX-总结.md`**：在原始结论之外补充不变量与正确性、手算过程、反例、相近算法对比、进阶变体、面试追问和闭卷自测；
- 配套一份 **`XXX-模板.cpp`**：可直接编译运行的 ACM 模式模板（核心函数完整实现 + 复杂度注释 + 极简自测 `main`）；
- 纯方法论/对照表类专题以决策表、反例和自测为主；带代码的树专题也已补齐独立模板。

> 所有模板与总结均为 UTF-8 编码。模板统一使用 `#define _CRT_SECURE_NO_WARNINGS`、显式 STL 头文件、`iostream`、`vector/array/string` 等 STL 容器和 `lowerCamelCase` 命名；不再使用 `bits/stdc++.h`、C 风格数组或 `printf/scanf`。

## 怎么用这份总结

1. **先读"一句话 / 适用特征 / 对照表"**：先形成选型直觉；
2. **再读"为什么成立 / 手算 / 反例"**：把结论还原成可证明、可手推的过程；
3. **闭卷默写模板并用对数器对拍**：不要抄代码；
4. **最后做"面试追问 / 自测"**：能解释边界，才算真正掌握。

本地根目录的 `算法训练计划.md` 与 `CSP大模拟训练清单.md` 仅作为整理时的参考，不会加入本目录或提交到仓库。
