# 洪水填充（Flood Fill）

> 来源笔记：`0127洪水填充.cpp`｜核心程度：必背｜分类：05 图论

## 一句话

在网格（或图）上"从一个点向四周感染"，**路径信息不撤销**，每一片连通区域只会被统计一次；看起来是暴力递归，实际遍历次数与样本量同阶。

## 核心思想

- 递归边界写成一行：越界 或 不满足条件就 `return`；
- 进入时**立刻标记**（改成 `'0'`、`'F'`、编号 ID 等），标记**不撤销**——这是把"感染过程"区分开的关键；
- 向四个方向递归；
- 外层遍历每个格子，遇到未标记的起点就计数并开始一次完整填充。

**与并查集的关系**：笔记明确说"这节课用并查集也能解决"（见 `0122并查集`）；洪水填充是 DFS 版连通块，并查集是离线合并版。

## 四道题的套路

| 题目 | 填充方式 | 关键点 |
| --- | --- | --- |
| 岛屿数量（LC 200） | 把 `'1'` 染成 `'0'` | 每个岛屿只被外层遍历命中一次 |
| 被围绕的区域（LC 130） | 从**边界**的 `'O'` 出发染成 `'F'` | 剩余 `O` 改 `X`；最后 `F` 还原为 `O` |
| 最大人工岛（LC 827） | 给每个岛屿染**编号 ID**（从 2 开始） | 统计各岛面积；枚举每个 `0` 把上下左右不同岛屿的面积相加（用 isCollect 去重并还原） |
| 打砖块（LC 803） | **时光倒流**：先按最终状态染色，再逆序复原砖块并统计新掉落数 | "便于合并、不便于删除"时，倒着处理 |

## 适用特征（看到这些信号就选它）

- 二维网格连通块：岛屿、区域、染色、迷宫；
- 需要每个连通块的编号或大小；
- 需要"从边界向内传播"（被围绕的区域）；
- 只有删除、没有新增的操作 → 时光倒流（打砖块）。

## 复杂度

- 时间 O(n·m)（每格最多被访问常数次）；
- 空间 O(n·m)（递归栈最坏情况）。

## 易错点

1. **递归深度**：网格很大（如一条 10^5 长的链）时会爆栈，要改成显式栈或 BFS；
2. 标记必须**在进入时立刻做**，否则会重复递归（死循环）；
3. 越界判断放在最前面，并用 `||` 短路；
4. 最大人工岛的"面积去重"必须用临时标记 + 用完还原，不能直接累加（同一个岛会被上下左右各算一次）；
5. 打砖块的 `worth()` 判断不能省，否则会误判"打掉一块必然导致其他砖块掉落"；
6. 洪水填充会**修改原数组**，后续还要用原图就先备份。

## 模板（可直接编译运行）

```cpp
// 洪水填充模板：岛屿数量 / 被围绕的区域 / 最大人工岛 / 打砖块（时光倒流）
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <functional>
#include <iostream>
#include <vector>
using namespace std;

std::array<int, 4> dx= {1, -1, 0, 0};
std::array<int, 4> dy= {0, 0, 1, -1};
// ================= 1. 通用染色骨架 =================
void dfsFill(vector<vector<char>>& g, int i, int j, char from, char to) {
    if (i < 0 || i >= (int)g.size() || j < 0 || j >= (int)g[0].size() || g[i][j] != from)
        return;
    g[i][j] = to;                                  // 标记，不撤销
    for (int d = 0; d < 4; d++) dfsFill(g, i + dx[d], j + dy[d], from, to);
}

// ================= 2. 岛屿数量 =================
int numIslands(vector<vector<char>> g) {
    int ans = 0;
    for (int i = 0; i < (int)g.size(); i++)
        for (int j = 0; j < (int)g[0].size(); j++)
            if (g[i][j] == '1') { ans++; dfsFill(g, i, j, '1', '0'); }
    return ans;
}

// ================= 3. 被围绕的区域 =================
void solveSurrounded(vector<vector<char>>& board) {
    int n = (int)board.size(), m = (int)board[0].size();
    for (int i = 0; i < n; i++) {
        if (board[i][0] == 'O') dfsFill(board, i, 0, 'O', 'F');
        if (board[i][m - 1] == 'O') dfsFill(board, i, m - 1, 'O', 'F');
    }
    for (int j = 0; j < m; j++) {
        if (board[0][j] == 'O') dfsFill(board, 0, j, 'O', 'F');
        if (board[n - 1][j] == 'O') dfsFill(board, n - 1, j, 'O', 'F');
    }
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            if (board[i][j] == 'O') board[i][j] = 'X';
            else if (board[i][j] == 'F') board[i][j] = 'O';
        }
}

// ================= 4. 最大人工岛 =================
int largestIsland(vector<vector<int>> grid) {
    int n = (int)grid.size(), m = (int)grid[0].size(), id = 2;
    function<void(int,int,int)> dfsId = [&](int i, int j, int ID) {
        if (i < 0 || i >= n || j < 0 || j >= m || grid[i][j] != 1) return;
        grid[i][j] = ID;
        for (int d = 0; d < 4; d++) dfsId(i + dx[d], j + dy[d], ID);
    };
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            if (grid[i][j] == 1) dfsId(i, j, id++);

    vector<int> sizeOf(id, 0);
    int ans = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            if (grid[i][j] > 1) ans = max(ans, ++sizeOf[grid[i][j]]);

    vector<bool> used(id, false);
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            if (grid[i][j] != 0) continue;
            int cur = 1;
            for (int d = 0; d < 4; d++) {
                int x = i + dx[d], y = j + dy[d];
                if (x < 0 || x >= n || y < 0 || y >= m) continue;
                int ID = grid[x][y];
                if (ID > 1 && !used[ID]) { used[ID] = true; cur += sizeOf[ID]; }
            }
            for (int d = 0; d < 4; d++) {          // 还原临时标记
                int x = i + dx[d], y = j + dy[d];
                if (x >= 0 && x < n && y >= 0 && y < m && grid[x][y] > 1)
                    used[grid[x][y]] = false;
            }
            ans = max(ans, cur);
        }
    return ans;
}

// ================= 5. 打砖块（时光倒流） =================
class Bricks {
    int m, n;
    vector<vector<int>> g;
    int dfs(int i, int j) {                        // 返回新增的"坚固(2)"砖块数
        if (i < 0 || i >= m || j < 0 || j >= n || g[i][j] != 1) return 0;
        g[i][j] = 2;
        return 1 + dfs(i + 1, j) + dfs(i - 1, j) + dfs(i, j + 1) + dfs(i, j - 1);
    }
    bool worth(int i, int j) {
        return g[i][j] == 1 &&
               (i == 0 || (i > 0 && g[i - 1][j] == 2) || (i < m - 1 && g[i + 1][j] == 2) ||
                (j > 0 && g[i][j - 1] == 2) || (j < n - 1 && g[i][j + 1] == 2));
    }
public:
    vector<int> hitBricks(vector<vector<int>> grid, vector<vector<int>> hits) {
        g = grid; m = (int)g.size(); n = (int)g[0].size();
        vector<int> ans(hits.size(), 0);
        for (auto& h : hits) g[h[0]][h[1]]--;              // 先变成最终状态
        for (int j = 0; j < n; j++) dfs(0, j);             // 顶部坚固砖块染 2
        for (int i = (int)hits.size() - 1; i >= 0; i--) {  // 时光倒流
            int r = hits[i][0], c = hits[i][1];
            g[r][c]++;
            if (worth(r, c)) ans[i] = dfs(r, c) - 1;
        }
        return ans;
    }
};

int main() {
    vector<vector<char>> g = {{'1','1','0'},{'0','1','0'},{'0','0','1'}};
    std::cout << "岛屿数量 = " << numIslands(g) << "\n";                 // 2
    vector<vector<int>> grid = {{1,0},{0,1}};
    std::cout << "最大人工岛 = " << largestIsland(grid) << "\n";          // 3
    return 0;
}
```

## 笔记里的题目

LeetCode 200 岛屿数量、130 被围绕的区域、827 最大人工岛、803 打砖块（时光倒流）。

## 延伸

- 并查集解法见 `0122并查集`；
- 网格最短路（BFS）见 `0207宽度优先遍历及其扩展`；
- "时光倒流"也常用于其他"只有删除"的题目。

## 专题深化：为什么成立

洪水填充从种子格子出发，沿四/八方向访问同类型连通块。DFS 表达递归扩散，BFS 保证层数最短；visited 或原地染色防止回头。

## 专题深化：手算与边界

网格中的岛屿若按四连通，`11/01` 为一个岛；按八连通可能把对角也接上，答案会变。填充时访问过的 1 改成 0 可省 visited。

### 对照与取舍

DFS 代码短但深图可能爆栈；BFS 适合求最短距离；并查集适合动态合并但需先枚举边。

### 易错点与反例

1. 四/八方向必须按题意选
2. 边界检查先于访问
3. 原地修改会改变输入
4. 大量格子用队列要注意内存

## 专题深化：进阶拓展

多源 BFS 可求每格到最近源距离；最大人工岛用连通分量编号+边界计数。
