# 最小生成树（Kruskal / Prim）

> 来源笔记：`0205最小生成树.cpp`｜核心程度：必背｜分类：05 图论

## 一句话

在**无向带权图**中选出 n-1 条边把 n 个点连通，且总权值最小；最常用的是 Kruskal（排序 + 并查集），只需考虑边、连图都不用建。

## 核心性质

- n 个点 ⇒ 最小生成树恰有 **n-1 条边**；
- 最小生成树可能不唯一，但总权值唯一；
- **最小生成树一定是最小瓶颈树**（改造类题目的理论依据，见题目五）。

## 两种算法

### Kruskal（最常用）

1. 所有边按权值从小到大排序；
2. 依次考虑每条边：两端点不在同一集合就选它（并查集判断是否成环）；
3. 选够 n-1 条就得到最小生成树。

- 复杂度 O(m log m) + O(n + m)；
- 只需要边集合 + 并查集，**不用建图**；
- 判连通：`edgeCnt == n - 1` 才说明图连通。

### Prim（不常用）

1. "解锁的点集合" `set` + "解锁的边的小根堆" `heap`；
2. 任取一点入 set，把它的边全部入 heap；
3. 弹出权值最小的边 e，看它的另一端点 x：
   - x 已在 set → 丢弃 e；
   - x 不在 set → e 属于最小生成树，把 x 加入 set，并把 x 的边入 heap；
4. heap 空即结束。

- 需要建图；复杂度 O(n + m) + O(m log n)；
- 判连通：统计访问到的点数是否等于 n。

## 五类题目

| 题目 | 关键转化 |
| --- | --- |
| Kruskal 模板（洛谷 P3366） | 排序 + 并查集；`edgeCnt != n-1` 输出 orz |
| Prim 模板（洛谷 P3366） | 小根堆 + `set` 标记；注意 `vector<int> set(n+1)` 要在读到 n 之后再建 |
| 水资源分配优化（LC 1168） | **建虚拟节点**：虚拟点到房子 i 的边权 = `wells[i]`；房子之间是管道 |
| 检查边长度限制的路径是否存在（LC 1697） | **边和查询都按 limit 排序 + 双指针 + 并查集**（本质是并查集题） |
| 繁忙的都市（洛谷 P2330） | 最小生成树 = 最小瓶颈树，答案是"边数 + 最大边权" |

## 适用特征（看到这些信号就选它）

- 无向图 + 要求"连通所有点且总代价最小"；
- 要求"改造的道路数最少、且最贵的那条尽量便宜" → 最小瓶颈树；
- 题目有"自建 / 借用"这类二选一的花费 → 考虑**虚拟节点**建模。

## 易错点

1. Kruskal 只在两个端点不在同一集合时才 `ans += w` 并 `edgeCnt++`；
2. 并查集合并前先 `find`；
3. 输出"连通/不连通"两种结果时注意输出类型一致（`to_string(ans) : "orz"`）；
4. Prim 里 `set` 与 `pq` 的同步：只把"目标点还没进 set"的边入堆；
5. **动态创建的 `vector` 要在读到 n 之后再创建**（笔记特别提醒：`vector<int> set(n+1)` 放在 main 开头，此时 n 还是 0）；
6. 最小生成树的前提是**连通**，不连通时答案是"无解"而不是"部分和"。

## 模板（可直接编译运行）

```cpp
// 最小生成树模板：Kruskal + Prim
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <functional>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

struct DSU {
    vector<int> fa;
    explicit DSU(int n) : fa(n) { for (int i = 0; i < n; i++) fa[i] = i; }
    int find(int i) { return i == fa[i] ? i : fa[i] = find(fa[i]); }
    bool unite(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        fa[rb] = ra;
        return true;
    }
};

// ================= Kruskal（最常用，不用建图） =================
long long kruskal(int n, vector<array<int,3>> edges) {
    sort(edges.begin(), edges.end(),
         [](const array<int,3>& a, const array<int,3>& b) { return a[2] < b[2]; });
    DSU dsu(n + 1);
    long long ans = 0;
    int cnt = 0;
    for (auto& e : edges) {
        if (dsu.unite(e[0], e[1])) { ans += e[2]; cnt++; }
        if (cnt == n - 1) break;
    }
    return cnt == n - 1 ? ans : -1;              // -1 表示图不连通
}

// ================= Prim（需要建图） =================
long long prim(int n, vector<vector<pair<int,int>>>& adj) {
    vector<char> inSet(n + 1, 0);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;   // {w, v}
    inSet[1] = 1;
    int cnt = 1;
    long long ans = 0;
    for (auto& e : adj[1]) pq.push({e.second, e.first});
    while (!pq.empty()) {
        auto pr = pq.top(); pq.pop();
        int w = pr.first, v = pr.second;
        if (inSet[v]) continue;                  // 已在集合里，丢弃这条边
        inSet[v] = 1;
        ans += w;
        cnt++;
        for (auto& e : adj[v])
            if (!inSet[e.first]) pq.push({e.second, e.first});
    }
    return cnt == n ? ans : -1;
}

// ================= 应用：水资源分配优化（虚拟节点） =================
int minCostToSupplyWater(int n, vector<int>& wells, vector<vector<int>>& pipes) {
    vector<array<int,3>> edges;
    for (int i = 1; i <= n; i++) edges.push_back({0, i, wells[i - 1]});  // 虚拟水源点 0
    for (auto& p : pipes) edges.push_back({p[0], p[1], p[2]});
    return (int)kruskal(n + 1, edges);           // 注意节点数是 n+1
}

int main() {
    // 洛谷 P3366 样例：4 个点 5 条边
    vector<array<int,3>> edges = {{1,2,2},{1,3,2},{1,4,3},{2,3,4},{3,4,3}};
    std::cout << "Kruskal 最小总权 = " << kruskal(4, edges) << "\n";      // 7

    vector<vector<pair<int,int>>> adj(5);
    for (auto& e : edges) {
        adj[e[0]].push_back({e[1], e[2]});
        adj[e[1]].push_back({e[0], e[2]});
    }
    std::cout << "Prim 最小总权 = " << prim(4, adj) << "\n";              // 7

    vector<int> wells = {1, 2, 2};
    vector<vector<int>> pipes = {{1,2,1},{2,3,1}};
    std::cout << "供水最低成本 = " << minCostToSupplyWater(3, wells, pipes) << "\n";   // 3
    return 0;
}
```

## 专题深化：为什么成立

Kruskal 按边权从小到大加边，若两端未连通则加入，并查集保证无环。割性质说明横跨任意割的最小边一定可被某棵 MST 采用，因此贪心正确。Prim 维护已选集合到外部的最近点。

## 专题深化：手算与边界

三条边权 1、2、5 的三角形：先取 1、2，5 会成环不加，总权 3。

### 对照与取舍

| 算法 | 适合 | 依赖 |
| --- | --- | --- |
| Kruskal | 稀疏图 | 排序+并查集 |
| Prim | 稠密图 | 优先队列/扫描 |
| Boruvka | 并行 | 分量最小边 |

### 易错点与反例

1. 图不连通时得到最小生成森林
2. 重边无影响
3. 负边仍可处理
4. 只求最小树时不需要去重所有边
