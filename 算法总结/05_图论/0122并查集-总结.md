# 并查集（DSU）

> 来源笔记：`0122并查集.cpp`｜核心程度：必背｜分类：05 图论

## 一句话

用森林管理"不相交集合"：`find` 找代表元素、`union` 合并两个集合；加上**路径压缩**（必做）和**小挂大**（可选）后，单次操作均摊 **O(α(n))**，可以当成 O(1)。

## 解决什么问题

1. 一开始每个元素自成一个集合；
2. `find(i)`：i 所在集合的代表元素；
3. `isSameSet(a,b)`：a、b 是否同集合；
4. `union(a,b)`：合并两个集合。

## 核心思想

- **路径压缩（扁平化）**：`find` 沿路上的所有节点直接挂到根上（笔记用显式栈，或递归写 `father[i] = find(father[i])`）；
- **小挂大**：按集合大小（或秩）把小的挂到大的上；
- 两个优化**都发生在 find 里**；路径压缩一定要做，小挂大可以省（洛谷模板题就省了）；
- 复杂度证明极难，记住结论即可（α(n) ≤ 6，即使 n 到宇宙原子量级）。

## 进阶：给集合打标签

并查集可以定制信息（类似 size 数组）：

- **集合数量** `sets`：合并成功时 `sets--`；
- **集合属性**：例如 `secret[代表元素]` 表示"该集合是否知道秘密"，合并时 `secret[fb] |= secret[fa]`。

笔记提示：带权并查集、可持久化并查集、可撤销并查集是竞赛必学内容（本文未展开）。

## 六类题目的套路

| 题目 | 建模方式 | 关键等式 |
| --- | --- | --- |
| 情侣牵手（LC 765） | 每对情侣是一个集合，相邻座位上的两人所在情侣对 union | 答案 = `n/2 - sets` |
| 相似字符串组（LC 839） | 相似（不同字符数为 0 或 2）就 union | 答案 = `sets` |
| 岛屿数量（LC 200） | 二维点编号 `i*m+j`，与上/左邻居 union | 答案 = 陆地的集合数 |
| 移除最多同行同列石头（LC 947） | 同一行/同一列的石头 union（Row/Col 记录"该行/列上一个石头"） | 答案 = `m - sets` |
| 知晓秘密的专家（LC 2092） | 按时间分组，同时间的会议 union，再撤销不含秘密的集合 | 逐组处理 + 撤销 |
| 好路径数目（LC 2421） | 边按两端最大值排序，集合并时最大值相等才计数 | `ans += cnt[fa]*cnt[fb]` |
| 恶意软件传播 II（LC 928） | 未感染的连通块 union，并记录每个块相邻的感染源个数 | 只救"仅邻接 1 个感染源"的块 |

## 适用特征（看到这些信号就选它）

- 动态连通性：不断加边，问是否连通 / 集合个数；
- 需要把"等价关系"传递下去（相似、同列、同祖先）；
- Kruskal 最小生成树；
- 二维网格连通块的另一种解法（与洪水填充等价）。

## 复杂度

单次操作均摊 O(α(n))，可视为 O(1)；空间 O(n)。

## 易错点

1. 递归 find 一定要写 `return father[i] = find(father[i]);`（漏 `return` 就不是路径压缩）；
2. 合并前先 `find`，并且是"根挂根"，不要节点挂节点；
3. `sets` 只在两个根不同时减；
4. 二维网格要把 `(i,j)` 映射成 `i * m + j`；
5. 撤销类题目（如 LC 2092）只能针对"没有秘密的集合"，思路是"按时间分组处理 + 撤销不合法的合并"；
6. `sort` 的比较器要写成类内静态函数或 lambda（非静态成员函数不能直接当比较器）。

## 模板（可直接编译运行）

```cpp
// 并查集模板：路径压缩 + 小挂大 + 集合计数
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct DSU {
    vector<int> fa, sz;
    int sets;
    explicit DSU(int n) : fa(n), sz(n, 1), sets(n) {
        for (int i = 0; i < n; i++) fa[i] = i;
    }
    int find(int i) { return i == fa[i] ? i : fa[i] = find(fa[i]); }
    bool same(int a, int b) { return find(a) == find(b); }
    bool unite(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (sz[ra] < sz[rb]) swap(ra, rb);    // 小挂大
        fa[rb] = ra;
        sz[ra] += sz[rb];
        sets--;
        return true;
    }
};

// ---------- 例题 1：岛屿数量（二维点编号 + 只查上/左邻居） ----------
int numIslands(vector<vector<char>>& grid) {
    int n = (int)grid.size(), m = n ? (int)grid[0].size() : 0;
    DSU dsu(n * m);
    auto idx = [&](int i, int j) { return i * m + j; };
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (grid[i][j] != '1') continue;
            if (i > 0 && grid[i - 1][j] == '1') dsu.unite(idx(i - 1, j), idx(i, j));
            if (j > 0 && grid[i][j - 1] == '1') dsu.unite(idx(i, j - 1), idx(i, j));
        }
    }
    int blocks = 0;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            if (grid[i][j] == '1' && dsu.find(idx(i, j)) == idx(i, j)) blocks++;
    return blocks;
}

// ---------- 例题 2：情侣牵手（答案 = n/2 - 集合数） ----------
int minSwapsCouples(vector<int>& row) {
    int n = (int)row.size() / 2;
    DSU dsu(n);
    for (int i = 0; i + 1 < (int)row.size(); i += 2)
        dsu.unite(row[i] / 2, row[i + 1] / 2);   // 情侣编号 = 人编号 / 2
    return n - dsu.sets;
}

// ---------- 例题 3：相似字符串组 ----------
bool isSimilar(const string& a, const string& b) {
    int diff = 0;
    for (size_t i = 0; i < a.size(); i++)
        if (a[i] != b[i] && ++diff > 2) return false;
    return diff == 0 || diff == 2;
}
int numSimilarGroups(vector<string>& strs) {
    int n = (int)strs.size();
    DSU dsu(n);
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (!dsu.same(i, j) && isSimilar(strs[i], strs[j])) dsu.unite(i, j);
    return dsu.sets;
}

int main() {
    vector<vector<char>> g = {{'1','1','0'},{'0','1','0'},{'0','0','1'}};
    std::cout << "岛屿数量 = " << numIslands(g) << "\n";                  // 2
    vector<int> row = {0, 2, 1, 3};
    std::cout << "情侣牵手最少交换 = " << minSwapsCouples(row) << "\n";    // 1
    vector<string> strs = {"tars", "rats", "arts", "star"};
    std::cout << "相似字符串组 = " << numSimilarGroups(strs) << "\n";      // 2
    return 0;
}
```

## 专题深化：为什么成立

并查集维护等价关系。每个集合用一棵代表树表示，find 返回根，union 合并根。只关注连通性时无需保存完整边，路径压缩与按大小合并使摊还复杂度接近 O(1)。

## 专题深化：手算与边界

边 `(1,2),(2,3),(4,5)` 后，`find(1)==find(3)`，但 `find(1)!=find(4)`。再加 `(3,4)` 后全部连通，岛屿/朋友圈数量减一。

### 对照与取舍

| 需求 | 结构 |
| --- | --- |
| 动态连通性 | 并查集 |
| 最短路径 | BFS/Dijkstra |
| 带删除连通 | 动态树/离线逆序 |

### 易错点与反例

1. find 递归可能栈深
2. 路径压缩后父指针不再表达原树结构
3. 带权并查集要同时维护到根的距离
4. 不能直接处理在线删边

## 专题深化：进阶拓展

带权并查集、可撤销并查集、按时间分治可处理更复杂约束；Kruskal 用它判断环。
