# 并查集（DSU）

> 来源笔记：`0122并查集.cpp`｜核心程度：必背｜分类：05 图论

## 一句话

用森林管理"不相交集合"：`find` 找代表元素、`union` 合并两个集合；加上**路径压缩**（必做）和**小挂大**（可选）后，单次操作均摊 **O(α(n))**，可以当成 O(1)。

## 解决什么问题

1. 一开始每个元素自成一个集合；
2. `find(i)`：i 所在集合的代表元素；
3. `isSameSet(a,b)`：a、b 是否同集合；
4. `union(a,b)`：合并两个集合。

## 核心思想

- **路径压缩（扁平化）**：`find` 沿路上的所有节点直接挂到根上（笔记用显式栈，或递归写 `father[i] = find(father[i])`）；
- **小挂大**：按集合大小（或秩）把小的挂到大的上；
- 两个优化**都发生在 find 里**；路径压缩一定要做，小挂大可以省（洛谷模板题就省了）；
- 复杂度证明极难，记住结论即可（α(n) ≤ 6，即使 n 到宇宙原子量级）。

## 进阶：给集合打标签

并查集可以定制信息（类似 size 数组）：

- **集合数量** `sets`：合并成功时 `sets--`；
- **集合属性**：例如 `secret[代表元素]` 表示"该集合是否知道秘密"，合并时 `secret[fb] |= secret[fa]`。

笔记提示：带权并查集、可持久化并查集、可撤销并查集是竞赛必学内容（本文未展开）。

## 六类题目的套路

| 题目 | 建模方式 | 关键等式 |
| --- | --- | --- |
| 情侣牵手（LC 765） | 每对情侣是一个集合，相邻座位上的两人所在情侣对 union | 答案 = `n/2 - sets` |
| 相似字符串组（LC 839） | 相似（不同字符数为 0 或 2）就 union | 答案 = `sets` |
| 岛屿数量（LC 200） | 二维点编号 `i*m+j`，与上/左邻居 union | 答案 = 陆地的集合数 |
| 移除最多同行同列石头（LC 947） | 同一行/同一列的石头 union（Row/Col 记录"该行/列上一个石头"） | 答案 = `m - sets` |
| 知晓秘密的专家（LC 2092） | 按时间分组，同时间的会议 union，再撤销不含秘密的集合 | 逐组处理 + 撤销 |
| 好路径数目（LC 2421） | 边按两端最大值排序，集合并时最大值相等才计数 | `ans += cnt[fa]*cnt[fb]` |
| 恶意软件传播 II（LC 928） | 未感染的连通块 union，并记录每个块相邻的感染源个数 | 只救"仅邻接 1 个感染源"的块 |

## 适用特征（看到这些信号就选它）

- 动态连通性：不断加边，问是否连通 / 集合个数；
- 需要把"等价关系"传递下去（相似、同列、同祖先）；
- Kruskal 最小生成树；
- 二维网格连通块的另一种解法（与洪水填充等价）。

## 复杂度

单次操作均摊 O(α(n))，可视为 O(1)；空间 O(n)。

## 易错点

1. 递归 find 一定要写 `return father[i] = find(father[i]);`（漏 `return` 就不是路径压缩）；
2. 合并前先 `find`，并且是"根挂根"，不要节点挂节点；
3. `sets` 只在两个根不同时减；
4. 二维网格要把 `(i,j)` 映射成 `i * m + j`；
5. 撤销类题目（如 LC 2092）只能针对"没有秘密的集合"，思路是"按时间分组处理 + 撤销不合法的合并"；
6. `sort` 的比较器要写成类内静态函数或 lambda（非静态成员函数不能直接当比较器）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
    vector<int> fa, sz;
    int sets;
    explicit DSU(int n) : fa(n), sz(n, 1), sets(n) {
        for (int i = 0; i < n; i++) fa[i] = i;
    }
    int find(int i) {                       // 递归 + 路径压缩
        return i == fa[i] ? i : fa[i] = find(fa[i]);
    }
    bool same(int a, int b) { return find(a) == find(b); }
    bool unite(int a, int b) {               // 小挂大
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (sz[ra] < sz[rb]) swap(ra, rb);
        fa[rb] = ra;
        sz[ra] += sz[rb];
        sets--;
        return true;
    }
};

// 迭代版 find（防递归爆栈，对应笔记里"显式栈"的写法）
int stk[1000005];
int findIter(int i, vector<int>& fa) {
    int top = 0;
    while (i != fa[i]) { stk[top++] = i; i = fa[i]; }
    while (top > 0) fa[stk[--top]] = i;      // 扁平化
    return i;
}
```
