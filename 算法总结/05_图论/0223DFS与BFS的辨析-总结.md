# DFS 与 BFS 的辨析

> 来源笔记：`0223DFS与BFS的辨析.md`｜性质：选型指南 + 思维方式对比｜分类：05 图论

## 一句话

DFS 是**探险者**（钻进洞穴深处），BFS 是**雷达**（扫描周围一圈）；选谁取决于你要的是"所有方案/存在性"还是"最短/最少/最近"。

## 一、图论/树结构场景

### 1. 遍历逻辑与路径性质

| | DFS | BFS |
| --- | --- | --- |
| 行为 | 不撞南墙不回头 | 由近及远、波纹式扩散 |
| 路径 | **任意路径**，不保证最短 | 无权图中**首次到达即最短** |
| 擅长 | 连通性判断、树中找特定深度的节点、先序/中序/后序遍历 | 无权图最短路、最少操作次数 |

### 2. 空间复杂度（竞赛/大数据的关键抉择）

| 场景 | DFS 空间 | BFS 空间 | 结论 |
| --- | --- | --- | --- |
| 树很深很窄 | 低（与深度成正比） | 低（每层节点少） | 都可，DFS 递归更简洁 |
| 树很宽很矮 | **低**（只存路径） | **极高**（要存整层） | **优选 DFS**，BFS 可能内存溢出 |
| 图节点极多且带环 | 取决于递归深度 | 取决于最大宽度 | 可能栈溢出或内存溢出，按数据形态选 |

### 3. 特殊功能

- **拓扑排序**：DFS 天然适合（回溯退出的逆序即拓扑序）；BFS 需配合入度表（Kahn 算法），更直观、也便于检测环；
- **连通分量**：两者都能统计，DFS 代码更简短。

## 二、思维模型层面

### 1. 回溯与穷举（DFS 主场）

- 场景：八皇后、数独、排列组合、子集问题；
- 特点：需要**试错**，DFS + 回溯能在发现选择错误时撤销并换一条路；BFS 难以追踪单一决策路径，实现"回退"很别扭；
- 结论：涉及**路径记录、试错、所有解枚举** → 选 DFS。

### 2. 状态空间搜索与"最近/最少"（BFS 主场）

- 场景：游戏 AI 寻路、社交网络六度人脉、魔方求解；
- 特点：需要"最少步骤"或"最近关系"；
- 结论：涉及**最优解、层级关系、最近邻居** → 选 BFS。

### 3. 网络爬虫与系统设计

- **BFS 用于爬虫**：网站很"宽"，DFS 容易陷入无限深的链接陷阱（如日历 `2024/01/01 -> 2024/01/02 ...`），永远爬不完一个站；
- **DFS 用于文件系统遍历**（如 `find`）：目录树深度有限，递归结构与目录天然匹配，内存更可控。

## 三、总对比表

| 维度 | DFS | BFS |
| --- | --- | --- |
| 核心隐喻 | 探险者（钻进洞穴深处） | 雷达（扫描周围一圈） |
| 数据结构 | 栈 | 队列 |
| 代码风格 | 递归，简洁 | 迭代，需维护队列 |
| 空间瓶颈 | 栈溢出（深度过大） | 内存溢出（宽度过大） |
| 路径特征 | 任意路径（不保证最短） | 无权图最短路径 |
| 解决问题 | 连通性、存在性、全解枚举、回溯 | 最优解、最短步数、层级遍历、最小操作数 |
| 典型应用 | 八皇后、数独、连通块、拓扑排序 | 迷宫最短路、社交网络关系、爬虫、层序遍历 |

## 四、一句话决策指南

- 题目要求"**最短 / 最少 / 最近**"，或数据呈**扁平状**（宽而浅）→ 选 **BFS**；
- 题目要求"**所有方案 / 是否存在 / 路径记录**"，或数据呈**长条状**（深而窄），或涉及回溯剪枝 → 选 **DFS**。

## 专题深化：为什么成立

DFS 优先深入，适合枚举/回溯/连通块；BFS 优先扫层，适合最短步数/层序。二者都需 visited，但 DFS 的栈隐式保存路径，BFS 的队列保存边界。

## 专题深化：手算与边界

在迷宫中 DFS 可能先走到一个很远的死路，BFS 则按步数逐层扩展，第一次到终点即最短；如果只问是否连通，两者都可。

### 对照与取舍

| 维度 | DFS | BFS |
| --- | --- | --- |
| 数据结构 | 栈/递归 | 队列 |
| 最短路 | 不保证 | 等权保证 |
| 空间 | O(h)~O(V) | O(width) |
| 适用 | 枚举、连通 | 层数、最短 |

### 易错点与反例

1. 递归 DFS 深图可能爆栈
2. BFS 入队即标记避免重复
3. 路径恢复需 parent 或递归栈
4. 多状态图按状态数算空间

## 专题深化：进阶拓展

双向 BFS、迭代加深、A* 是两者折中；DFS 低内存适合极深但状态简单图。
