# 拓扑排序的扩展技巧（上游向下游推送消息）

> 来源笔记：`0202拓扑排序的扩展技巧.cpp`｜核心程度：高频（已是树形 DP 的雏形）｜分类：05 图论

## 一句话

拓扑排序不只用来排顺序：在"删掉入度 0 的点"的过程中，可以让**上游节点把消息逐步推送给下游节点**，出队时就能顺手完成统计/更新——这是树形 DP 的入门形态。

## 拓扑排序复习（笔记原文）

- 以 BFS 为基础，把入度为 0 的点入队；每遇到一个节点就把邻居入度减一，减到 0 就入队，如此往复，像"抽丝剥茧"；
- 复杂度 O(n + m)；
- 因为是单向图，**不需要 visited 数组**——入度数组已经替我们完成了这件事；
- 用"出队节点数 < 总节点数"判断有环。

## 四道题的套路

### 题一：最大食物链计数（洛谷 P4017）

- `lines[i]` 表示"以 i 结尾的食物链条数"，所有入度为 0 的点 `lines[i] = 1`（自己算一条链的起点）；
- 出队时把 `lines[cur]` **推给下游**：`lines[to] = (lines[to] + lines[cur]) % MOD`；
- `head[cur] == 0`（没有出边）说明到了最顶端，把 `lines[cur]` 累加进答案；
- 结果对 80112002 取模。

### 题二：喧闹和富有（LeetCode 851）

- `richer` 关系建图：**让有钱的指向没钱的**（这样有钱的入度低、先出队、早点把答案传下去）；
- `ans[i]` 初始化为 i（自己）；出队时向下游传播：如果 `quiet[ans[cur]] < quiet[ans[nxt]]`，就更新 `ans[nxt] = ans[cur]`；
- "每次都要尝试更新"是关键（只要更安静就覆盖）。

### 题三：并行课程 III（LeetCode 2050）

- `timeCost[i]` 表示"完成 i 及其全部先修课需要的最少月数"；
- 入度为 0 的点 `timeCost = time[i]`；
- 下游节点：`timeCost[nxt] = max(timeCost[nxt], timeCost[cur])`；当 `indegree[nxt]` 减到 0 时再 `timeCost[nxt] += time[nxt]`（等所有先修课都完成才累加自己的耗时）；
- 答案是所有 `timeCost` 的最大值。

### 题四：参加会议的最多员工数（LeetCode 2127）

每个员工指向自己喜欢的人，形成"基环树"森林。先用拓扑排序**剥掉所有不在环上的点**，同时算出每个点往前的**最长链长度** `deep[]`：

- `deep[nxt] = max(deep[nxt], deep[cur] + 1)`；

剥完之后，剩下的入度 > 0 的点就是环。分两种情况：

1. **二元环（环长 2）**：两个人互指，各自可以再拖一条最长链 → 贡献 `deep[a] + deep[b] + 2`，**所有二元环的贡献可以累加**；
2. **大环（环长 > 2）**：只能坐下这一个环上的人 → 取最大环长。

答案 = `max(所有二元环贡献之和, 最大环长)`。

> 笔记的点评很生动："两个互相暗恋的人能各自吊着一群舔狗不崩盘；三个及以上火药味就没法隐藏。"

## 适用特征（看到这些信号就选它）

- DAG 上需要"从源点向汇点传播信息"（计数、最值、路径长度）；
- 需要"剥掉非环节点"来找环、算环外最长链（基环树）；
- 依赖关系上的最优化（最少时间、最安静的人、最多人数）。

## 复杂度

O(n + m)，空间 O(n + m)。

## 易错点

1. **建图方向**要按题目语义选（851 要"有钱 -> 没钱"，让信息顺着拓扑序流动）；
2. 只有 `--indegree[v] == 0` 时才把 v 入队；
3. 2050 的 `timeCost[nxt] += time[nxt-1]` 必须在入度减到 0 **之后**做（先取所有先修课的最大完成时间，再加自己的耗时）；
4. 2127 的 `deep[]` 含义是"不含自己、朝向自己这边的最长链长度"，最后二元环要 `+2`（环上两人）；
5. 取模题的取模位置：先加后模，避免溢出；
6. 用 `deque` 数组模拟时注意容量与下标从 0/1 开始的一致性。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 通用骨架：拓扑排序 + 向下游推送信息 ----------
// vector<int> indegree(n), val(n);
// 初始化入度为 0 的点的 val
// while (队列非空) {
//     cur = 出队;
//     结算 cur 的答案（如果是终点，累加进全局答案）
//     for (v : adj[cur]) {
//         val[v] = merge(val[v], val[cur]);     // 向下游推送
//         if (--indegree[v] == 0) 入队;
//     }
// }

// ---------- 最大食物链计数 ----------
long long countFoodChains(int n, vector<vector<int>>& adj) {
    const long long MOD = 80112002;
    vector<int> indegree(n + 1, 0);
    for (int u = 1; u <= n; u++)
        for (int v : adj[u]) indegree[v]++;

    vector<long long> lines(n + 1, 0);
    vector<int> q(n + 1);
    int l = 0, r = 0;
    for (int i = 1; i <= n; i++) if (!indegree[i]) { q[r++] = i; lines[i] = 1; }

    long long ans = 0;
    while (l < r) {
        int cur = q[l++];
        if (adj[cur].empty()) {                     // 食物链顶端
            ans = (ans + lines[cur]) % MOD;
        } else {
            for (int nxt : adj[cur]) {
                lines[nxt] = (lines[nxt] + lines[cur]) % MOD;   // 推送
                if (--indegree[nxt] == 0) q[r++] = nxt;
            }
        }
    }
    return ans;
}

// ---------- 并行课程 III ----------
int minimumTime(int n, vector<vector<int>>& relations, vector<int>& time) {
    vector<vector<int>> adj(n + 1);
    vector<int> indegree(n + 1, 0);
    for (auto& e : relations) { adj[e[0]].push_back(e[1]); indegree[e[1]]++; }
    vector<int> cost(n + 1, 0), q(n + 1);
    int l = 0, r = 0, ans = 0;
    for (int i = 1; i <= n; i++)
        if (!indegree[i]) { q[r++] = i; cost[i] = time[i - 1]; }
    while (l < r) {
        int cur = q[l++];
        ans = max(ans, cost[cur]);
        for (int nxt : adj[cur]) {
            cost[nxt] = max(cost[nxt], cost[cur]);
            if (--indegree[nxt] == 0) { cost[nxt] += time[nxt - 1]; q[r++] = nxt; }
        }
    }
    return ans;
}
```
