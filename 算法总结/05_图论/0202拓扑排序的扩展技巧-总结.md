# 拓扑排序的扩展技巧（上游向下游推送消息）

> 来源笔记：`0202拓扑排序的扩展技巧.cpp`｜核心程度：高频（已是树形 DP 的雏形）｜分类：05 图论

## 一句话

拓扑排序不只用来排顺序：在"删掉入度 0 的点"的过程中，可以让**上游节点把消息逐步推送给下游节点**，出队时就能顺手完成统计/更新——这是树形 DP 的入门形态。

## 拓扑排序复习（笔记原文）

- 以 BFS 为基础，把入度为 0 的点入队；每遇到一个节点就把邻居入度减一，减到 0 就入队，如此往复，像"抽丝剥茧"；
- 复杂度 O(n + m)；
- 因为是单向图，**不需要 visited 数组**——入度数组已经替我们完成了这件事；
- 用"出队节点数 < 总节点数"判断有环。

## 四道题的套路

### 题一：最大食物链计数（洛谷 P4017）

- `lines[i]` 表示"以 i 结尾的食物链条数"，所有入度为 0 的点 `lines[i] = 1`（自己算一条链的起点）；
- 出队时把 `lines[cur]` **推给下游**：`lines[to] = (lines[to] + lines[cur]) % MOD`；
- `head[cur] == 0`（没有出边）说明到了最顶端，把 `lines[cur]` 累加进答案；
- 结果对 80112002 取模。

### 题二：喧闹和富有（LeetCode 851）

- `richer` 关系建图：**让有钱的指向没钱的**（这样有钱的入度低、先出队、早点把答案传下去）；
- `ans[i]` 初始化为 i（自己）；出队时向下游传播：如果 `quiet[ans[cur]] < quiet[ans[nxt]]`，就更新 `ans[nxt] = ans[cur]`；
- "每次都要尝试更新"是关键（只要更安静就覆盖）。

### 题三：并行课程 III（LeetCode 2050）

- `timeCost[i]` 表示"完成 i 及其全部先修课需要的最少月数"；
- 入度为 0 的点 `timeCost = time[i]`；
- 下游节点：`timeCost[nxt] = max(timeCost[nxt], timeCost[cur])`；当 `indegree[nxt]` 减到 0 时再 `timeCost[nxt] += time[nxt]`（等所有先修课都完成才累加自己的耗时）；
- 答案是所有 `timeCost` 的最大值。

### 题四：参加会议的最多员工数（LeetCode 2127）

每个员工指向自己喜欢的人，形成"基环树"森林。先用拓扑排序**剥掉所有不在环上的点**，同时算出每个点往前的**最长链长度** `deep[]`：

- `deep[nxt] = max(deep[nxt], deep[cur] + 1)`；

剥完之后，剩下的入度 > 0 的点就是环。分两种情况：

1. **二元环（环长 2）**：两个人互指，各自可以再拖一条最长链 → 贡献 `deep[a] + deep[b] + 2`，**所有二元环的贡献可以累加**；
2. **大环（环长 > 2）**：只能坐下这一个环上的人 → 取最大环长。

答案 = `max(所有二元环贡献之和, 最大环长)`。

> 笔记的点评很生动："两个互相暗恋的人能各自吊着一群舔狗不崩盘；三个及以上火药味就没法隐藏。"

## 适用特征（看到这些信号就选它）

- DAG 上需要"从源点向汇点传播信息"（计数、最值、路径长度）；
- 需要"剥掉非环节点"来找环、算环外最长链（基环树）；
- 依赖关系上的最优化（最少时间、最安静的人、最多人数）。

## 复杂度

O(n + m)，空间 O(n + m)。

## 易错点

1. **建图方向**要按题目语义选（851 要"有钱 -> 没钱"，让信息顺着拓扑序流动）；
2. 只有 `--indegree[v] == 0` 时才把 v 入队；
3. 2050 的 `timeCost[nxt] += time[nxt-1]` 必须在入度减到 0 **之后**做（先取所有先修课的最大完成时间，再加自己的耗时）；
4. 2127 的 `deep[]` 含义是"不含自己、朝向自己这边的最长链长度"，最后二元环要 `+2`（环上两人）；
5. 取模题的取模位置：先加后模，避免溢出；
6. 用 `deque` 数组模拟时注意容量与下标从 0/1 开始的一致性。

## 模板（可直接编译运行）

```cpp
// 拓扑排序扩展模板：食物链计数 / 并行课程 / 喧闹和富有 / 参加会议的最多员工
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

// ================= 1. 最大食物链计数 =================
long long countFoodChains(int n, vector<vector<int>>& adj) {
    const long long MOD = 80112002;
    vector<int> indegree(n + 1, 0);
    for (int u = 1; u <= n; u++)
        for (int v : adj[u]) indegree[v]++;

    vector<long long> lines(n + 1, 0);
    vector<int> q(n + 1);
    int l = 0, r = 0;
    for (int i = 1; i <= n; i++)
        if (!indegree[i]) { q[r++] = i; lines[i] = 1; }   // 入度为 0 的是链的起点

    long long ans = 0;
    while (l < r) {
        int cur = q[l++];
        if (adj[cur].empty()) {                            // 到达最顶端
            ans = (ans + lines[cur]) % MOD;
        } else {
            for (int nxt : adj[cur]) {
                lines[nxt] = (lines[nxt] + lines[cur]) % MOD;   // 上游推给下游
                if (--indegree[nxt] == 0) q[r++] = nxt;
            }
        }
    }
    return ans;
}

// ================= 2. 并行课程 III =================
int parallelCoursesIII(int n, vector<vector<int>>& relations, vector<int>& time) {
    vector<vector<int>> adj(n + 1);
    vector<int> indegree(n + 1, 0);
    for (auto& e : relations) { adj[e[0]].push_back(e[1]); indegree[e[1]]++; }

    vector<int> cost(n + 1, 0), q(n + 1);
    int l = 0, r = 0, ans = 0;
    for (int i = 1; i <= n; i++)
        if (!indegree[i]) { q[r++] = i; cost[i] = time[i - 1]; }
    while (l < r) {
        int cur = q[l++];
        ans = max(ans, cost[cur]);
        for (int nxt : adj[cur]) {
            cost[nxt] = max(cost[nxt], cost[cur]);        // 等所有先修课完成
            if (--indegree[nxt] == 0) {
                cost[nxt] += time[nxt - 1];               // 入度清零后才加自己的耗时
                q[r++] = nxt;
            }
        }
    }
    return ans;
}

// ================= 3. 喧闹和富有 =================
vector<int> loudAndRich(vector<vector<int>>& richer, vector<int>& quiet) {
    int n = (int)quiet.size();
    vector<vector<int>> adj(n);
    vector<int> indegree(n, 0), ans(n);
    for (int i = 0; i < n; i++) ans[i] = i;                // 初始认为自己是答案
    for (auto& e : richer) {                               // 有钱 -> 没钱
        adj[e[0]].push_back(e[1]);
        indegree[e[1]]++;
    }
    vector<int> q(n);
    int l = 0, r = 0;
    for (int i = 0; i < n; i++) if (!indegree[i]) q[r++] = i;
    while (l < r) {
        int cur = q[l++];
        for (int nxt : adj[cur]) {
            if (quiet[ans[nxt]] > quiet[ans[cur]]) ans[nxt] = ans[cur];   // 传播更安静的人
            if (--indegree[nxt] == 0) q[r++] = nxt;
        }
    }
    return ans;
}

// ================= 4. 参加会议的最多员工数（基环树） =================
int maximumInvitations(vector<int>& favorite) {
    int n = (int)favorite.size();
    vector<int> indegree(n, 0);
    for (int i = 0; i < n; i++) indegree[favorite[i]]++;

    vector<int> deep(n, 0), q(n);
    int l = 0, r = 0;
    for (int i = 0; i < n; i++) if (!indegree[i]) q[r++] = i;
    while (l < r) {                                        // 剥掉所有非环节点
        int cur = q[l++];
        int nxt = favorite[cur];
        deep[nxt] = max(deep[nxt], deep[cur] + 1);         // 记录朝向环的最长链
        if (--indegree[nxt] == 0) q[r++] = nxt;
    }

    int sumSmallRings = 0, bigRings = 0;
    for (int i = 0; i < n; i++) {
        if (indegree[i] > 0) {                             // 只在环上
            int ringSize = 1;
            indegree[i] = 0;
            for (int e = favorite[i]; e != i; e = favorite[e]) {
                ringSize++;
                indegree[e] = 0;
            }
            if (ringSize == 2) sumSmallRings += deep[i] + deep[favorite[i]] + 2;
            else               bigRings = max(bigRings, ringSize);
        }
    }
    return max(sumSmallRings, bigRings);
}

int main() {
    // 食物链：1->2, 2->3
    vector<vector<int>> adj(4);
    adj[1].push_back(2); adj[2].push_back(3);
    std::cout << "食物链条数 = " << countFoodChains(3, adj) << "\n";   // 1

    vector<vector<int>> rel = {{1,3},{2,3}};
    vector<int> t = {3, 2, 5};
    std::cout << "并行课程最少月数 = " << parallelCoursesIII(3, rel, t) << "\n";  // 8

    vector<int> fav = {2, 2, 1, 2};
    std::cout << "会议最多员工数 = " << maximumInvitations(fav) << "\n";  // 3
    return 0;
}
```

## 专题深化：为什么成立

拓扑序描述依赖关系。把节点状态扩展为时间、颜色、集合大小等 DP 值，就可以在删边过程中动态合并：拓扑保证所有前置信息已经算完。

## 专题深化：手算与边界

食物链题中每个节点记录“以它结尾的路径数”，删除入度为 0 节点时把计数加到后继；所有初值 1 的源点贡献最终汇合。

### 对照与取舍

普通拓扑只求一个顺序；带权拓扑在入度清零时合并贡献；DAG 最长路只需按拓扑序一次松弛。

### 易错点与反例

1. DP 初值要区分源点和普通点
2. 环路节点永远无法入队
3. 多源/多汇要明确贡献边界
4. 计数可能溢出需取模

## 专题深化：进阶拓展

缩点后 DAG 上可做最长链、路径计数、依赖传播；树上拓扑可处理外向依赖。
