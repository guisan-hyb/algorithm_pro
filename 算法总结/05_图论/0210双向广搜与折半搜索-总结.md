# 双向广搜 / 折半搜索（Meet in the Middle）

> 来源笔记：`0210双向广搜.cpp`｜核心程度：高频技巧｜分类：05 图论

## 一句话

两种用法：① **小优化**——从起点和终点同时 BFS，每次扩展"规模较小"的那一侧；② **重要**——全量样本展不开、但半量能展开时，把样本**折半**，两侧各自展开，再设计整合逻辑。

## 用法一：双向 BFS（单词接龙）

**核心思路**（LC 127）：

- 维护 `smallLevel`（较小层）与 `bigLevel`（较大层）两个集合；
- 每轮只扩展 `smallLevel`，生成 `nextLevel`；
- **如果生成的单词出现在 `bigLevel` 里，说明两侧相遇，返回层数**；
- 每轮结束后把较小的那层作为下一轮的 `smallLevel`（保证每次都扩小的一侧）；
- 扩展时用"把每个字母换成 a~z"的方式查词典，而不是遍历整个词典（哈希表查 O(1)）。

**要点**：每轮开始先把 `smallLevel` 里的单词从词典里**删掉**，避免重复入层。

## 用法二：折半搜索（Meet in the Middle）

**特征**（笔记原文）：**全量样本不允许递归完全展开，但是半量样本可以完全展开**。

**过程**：

1. 把数据分成两半；
2. 每半点分别完全展开，得到两组结果；
3. 设计"两部分结果的整合逻辑"。

> 笔记的比喻：思想类似归并分治，但归并分治是对多次折半做整合，折半搜索只需整合一次；"与其说是双向广搜，不如说是折半 DFS"。

### 折半搜索的三个例子

| 题目 | 折半后的整合 |
| --- | --- |
| 牛牛的背包 / 世界冰球锦标赛（洛谷 P4799，n ≤ 40） | 两半分别 DFS 出所有可行体积和 → 排序 → **双指针**统计 `lsum + rsum <= w` 的方案数 |
| 最接近目标值的子序列和（LC 1755，n ≤ 40） | 两半分别 DFS 出所有子序列和 → 排序 → 双指针找最接近 goal 的组合 |
| 单词接龙 II（LC 126） | BFS 建反向图 + DFS 生成所有最短路径（属于"BFS 与 DFS 结合"） |

### 复杂度

- 朴素 DFS：O(2^n)（n = 40 时爆炸）；
- 折半后：O(2^(n/2)) × 整合（通常是排序 O(2^(n/2) log) 或双指针 O(2^(n/2))）。

## 适用特征（看到这些信号就选它）

- **n ≤ 40 左右**，枚举 2^n 会超时但 2^(n/2) 可以接受；
- 求"方案数 / 最接近的值 / 能否凑出"这类可以两半合并的问题；
- 起点和终点都明确、图很大但分支不多 → 双向 BFS；
- 求"所有最短路径"→ BFS 建图 + DFS 生成（LC 126）。

## 易错点

1. 双向 BFS 每轮必须**扩展较小的一侧**，否则退化成单向 BFS；
2. 扩展出的新词要同时检查"是否在对面层里"（相遇）与"是否还在词典里"（可继续）；
3. 折半 DFS 的两半要**分别记录所有可行结果**（含空集），再排序后双指针；
4. 折半题的剪枝很关键：例如 LC 1755 先判断 `maxs < goal` / `mins > goal` 直接返回；
5. 双指针在"找最接近"时，**相等时指针也要移动**（笔记特别提醒），否则会漏情况；
6. 两半的结果数组要开够：`1 << 20` 量级。

## 模板（可直接编译运行）

```cpp
// 双向 BFS + 折半搜索模板
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <cstdlib>
#include <functional>
#include <iostream>
#include <string>
#include <unordered_set>
#include <vector>
using namespace std;

// ================= 1. 双向 BFS：单词接龙（最短转换序列长度） =================
int ladderLength(string beginWord, string endWord, vector<string> wordList) {
    unordered_set<string> dict(wordList.begin(), wordList.end());
    if (!dict.count(endWord)) return 0;

    unordered_set<string> small{beginWord}, big{endWord}, next;
    int level = 2;
    while (!small.empty()) {
        for (auto& w : small) dict.erase(w);       // 已处理的串从词典删除
        next.clear();
        for (auto& w : small) {
            for (size_t i = 0; i < w.size(); i++) {
                string nw = w;
                for (char c = 'a'; c <= 'z'; c++) {
                    nw[i] = c;
                    if (nw == w) continue;
                    if (big.count(nw)) return level;      // 两侧相遇
                    if (dict.count(nw)) next.insert(nw);
                }
            }
        }
        if (next.size() >= big.size()) { small = big; big = next; }  // 总是扩小的一侧
        else                            { small = next; }
        level++;
    }
    return 0;
}

// ================= 2. 折半搜索：背包方案数（n <= 40） =================
vector<long long> lsum, rsum;

void dfsHalf(vector<long long>& out, const vector<long long>& a, int i, int end, long long sum, long long limit) {
    if (sum > limit) return;
    if (i == end) { out.push_back(sum); return; }
    dfsHalf(out, a, i + 1, end, sum, limit);              // 不要 i
    dfsHalf(out, a, i + 1, end, sum + a[i], limit);       // 要 i
}

long long countWays(const vector<long long>& a, long long limit) {
    lsum.clear(); rsum.clear();
    int n = (int)a.size();
    dfsHalf(lsum, a, 0, n / 2, 0, limit);
    dfsHalf(rsum, a, n / 2, n, 0, limit);
    sort(lsum.begin(), lsum.end());
    sort(rsum.begin(), rsum.end());

    long long ans = 0;
    for (int i = (int)lsum.size() - 1, j = 0; i >= 0; i--) {
        while (j < (int)rsum.size() && lsum[i] + rsum[j] <= limit) j++;
        ans += j;
    }
    return ans;
}

// ================= 3. 折半搜索：最接近目标值的子序列和 =================
int minAbsDifference(vector<int>& nums, int goal) {
    lsum.clear(); rsum.clear();
    int n = (int)nums.size();

    long long maxs = 0, mins = 0;                      // 剪枝
    for (int x : nums) { if (x > 0) maxs += x; if (x < 0) mins += x; }
    if (maxs < goal) return (int)abs(goal - maxs);
    if (mins > goal) return (int)abs(goal - mins);

    function<void(vector<long long>&, int, int, long long)> dfs =
        [&](vector<long long>& out, int i, int end, long long sum) {
            if (i == end) { out.push_back(sum); return; }
            dfs(out, i + 1, end, sum);
            dfs(out, i + 1, end, sum + nums[i]);
        };
    dfs(lsum, 0, n / 2, 0);
    dfs(rsum, n / 2, n, 0);
    sort(lsum.begin(), lsum.end());
    sort(rsum.begin(), rsum.end());

    long long ans = llabs(goal);
    for (int i = 0, j = (int)rsum.size() - 1; i < (int)lsum.size(); i++) {
        while (j > 0 && llabs(goal - lsum[i] - rsum[j]) >= llabs(goal - lsum[i] - rsum[j - 1]))
            j--;                                        // 相等时也要移动
        ans = min(ans, llabs(goal - lsum[i] - rsum[j]));
    }
    return (int)ans;
}

int main() {
    vector<string> dict = {"hot", "dot", "dog", "lot", "log", "cog"};
    std::cout << "单词接龙最短长度 = " << ladderLength("hit", "cog", dict) << "\n";   // 5

    vector<long long> a = {1, 2, 3, 4};
    std::cout << "体积不超过 5 的方案数 = " << countWays(a, 5) << "\n";              // 5

    vector<int> nums = {5, -7, 3, 5};
    std::cout << "最接近 6 的子序列和差 = " << minAbsDifference(nums, 6) << "\n";      // 0
    return 0;
}
```

## 专题深化：为什么成立

双向 BFS 从起点和终点同时扩展，每次扩展较小 frontier，会面后合并路径；折半搜索把 n 个元素分成两半，分别枚举所有子集，再用排序/二分/哈希组合答案。

## 专题深化：手算与边界

单词接龙从 `hit` 与 `cog` 两端各走两步，在中间单词相遇，合并距离得到最短长度。折半背包把 40 个物品拆成两组 2^20 子集。

### 对照与取舍

双向 BFS 适合已知终端、状态分支大；折半搜索适合 n≤40 的选取问题；普通搜索适合单端状态小。

### 易错点与反例

1. 两边距离合并要避免重复计中心点
2. 交换扩展较小 frontier 可降常数
3. 折半枚举要注意空集
4. 二分组合要避免同一元素两半边重复选择

## 专题深化：进阶拓展

双向 A*、Meet-in-the-middle 的子集和/异或、生日攻击式碰撞都可视为折半思想。
