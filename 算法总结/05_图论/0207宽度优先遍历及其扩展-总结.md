# 宽度优先遍历（BFS）及其扩展

> 来源笔记：`0207宽度优先遍历及其扩展.cpp`｜核心程度：必背｜分类：05 图论

## 一句话

BFS 逐层扩散，**扩散到第几层，最短距离就是几**；难点从来不在"怎么写队列"，而在**节点如何找到路、路怎么展开、剪枝怎么设计**。

## 基础要点（笔记原文）

- 适用特征：任意两个节点之间的相互距离相同（无权图 / 边权全相等）；
- 起点可以是**单源**（第 0 层 1 个），也可以是**多源**（第 0 层多个，同时扩散，标记过的不重复访问）；
- 队列有两种用法：**单点弹出**（把每个点附带的信息也放进队列）或**整层弹出**（一次处理一层，信息用队列外的变量维护）；
- 入队时必须**标记状态**，防止同一节点重复进出队列；
- BFS 常配合**剪枝策略**。

## 五个扩展方向

### 一、多源 BFS：地图分析（LC 1162）

把所有陆地作为第 0 层同时入队，做按层 BFS，层数就是"到最近陆地的距离"；最后一个被扩散到的海洋格子的层数即为答案（返回 `level - 1`）。特判：全是陆地或全是海洋返回 -1。

### 二、隐式图 BFS：贴纸拼词（LC 691）

- **节点** = 当前还剩下的目标字符串；
- **路** = 用某张贴纸消掉若干字符后的剩余串；
- 层数 = 用掉的贴纸数；变成空串时的层数就是答案；
- 技巧：target 与贴纸都**按字典序排序**，用两指针 `eliminate` 消字符；`unordered_set<string>` 去重；按首字母建图（只试含该字母的贴纸）。

### 三、0-1 BFS（边权只有 0/1）

- 用**双端队列**代替普通队列：
  - `w == 0` 从**队头**入队；`w == 1` 从**队尾**入队；
- 复杂度 O(n + m)，比 Dijkstra 更优；
- 不需要 visited（`distance` 已起去重作用）；
- 例题：到达角落的最小障碍移除数（LC 2290）、使网格至少有一条有效路径的最小代价（LC 1368）。

> 笔记原话："0-1 BFS 就是 Dijkstra 的简化版——因为只有 0/1，把堆优化成了双端队列。"

### 四、BFS + 优先队列（堆）

把队列换成小根堆就进入 Dijkstra 的世界（见 `0212Dijkstra算法、分层图最短路`）。典型题：二维接雨水（LC 407）——从边界最弱的点开始往里"涨水"，堆顶就是当前水线。

### 五、BFS 建图 + DFS 生成路径：单词接龙 II（LC 126）

- BFS 从 beginWord 出发**反向建图**（记录每个单词由哪些单词转换而来）；
- 一旦发现 endWord 立刻停止（只保留最短路上的边）；
- DFS 从 endWord 往回走，每走到 beginWord 收集一条路径，最后反转。

笔记的说明："BFS 正向是为了尽快找到 end 且把路找全；DFS 反向是因为从 end 出发的每一步都是必经之路，没有冤枉路。"

## 适用特征（看到这些信号就选它）

- "最少步数 / 最短距离 / 最少操作数"，且每步代价相同 → BFS；
- 边权只有 0 和 1 → 0-1 BFS；
- 多个起点同时扩散 → 多源 BFS；
- 状态是字符串/局面而不是网格 → 隐式图 BFS（配哈希表去重）；
- 要**所有**最短路径 → BFS 建图 + DFS 生成。

## 复杂度

- 普通 BFS / 0-1 BFS：O(n + m)；
- 与堆结合（Dijkstra）：O(m log n)。

## 易错点

1. 入队立即标记（或出队判 visited），不要重复入队；
2. **越界判断放在最前面**（笔记多次强调，否则后续判断可能越界）；
3. 0-1 BFS 的入队方向写反会得到错误答案；
4. 按层 BFS 时"当前层大小"要在循环前固定；
5. 隐式图必须把状态做哈希去重，否则会无限扩展；
6. 单词接龙类题目每轮要把当前层的单词从词典里删掉。

## 模板（可直接编译运行）

```cpp
// BFS 扩展模板：多源 BFS / 0-1 BFS / BFS + 小根堆
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <climits>
#include <deque>
#include <functional>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

const std::array<int, 4> DX= {1, -1, 0, 0};
const std::array<int, 4> DY= {0, 0, 1, -1};
// ================= 1. 多源 BFS：地图分析 =================
int maxDistance(vector<vector<int>> grid) {
    int n = (int)grid.size(), m = (int)grid[0].size(), seas = 0;
    queue<pair<int,int>> q;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++) {
            if (grid[i][j] == 1) q.push({i, j});
            else seas++;
        }
    if (seas == 0 || seas == n * m) return -1;
    int level = 0;
    while (!q.empty()) {
        int sz = q.size();
        level++;
        while (sz--) {
            auto pr = q.front(); q.pop();
            int x = pr.first, y = pr.second;
            for (int d = 0; d < 4; d++) {
                int nx = x + DX[d], ny = y + DY[d];
                if (nx < 0 || nx >= n || ny < 0 || ny >= m || grid[nx][ny] != 0) continue;
                grid[nx][ny] = 1;                 // 入队即标记
                q.push({nx, ny});
            }
        }
    }
    return level - 1;
}

// ================= 2. 0-1 BFS：移除最少障碍物 =================
int minimumObstacles(vector<vector<int>> grid) {
    int n = (int)grid.size(), m = (int)grid[0].size();
    vector<vector<int>> dist(n, vector<int>(m, INT_MAX));
    deque<pair<int,int>> dq;
    dist[0][0] = 0;
    dq.push_front({0, 0});
    while (!dq.empty()) {
        auto pr = dq.front(); dq.pop_front();
        int x = pr.first, y = pr.second;
        if (x == n - 1 && y == m - 1) return dist[x][y];
        for (int d = 0; d < 4; d++) {
            int nx = x + DX[d], ny = y + DY[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
            int w = grid[nx][ny];                 // 0 或 1
            if (dist[x][y] + w < dist[nx][ny]) {
                dist[nx][ny] = dist[x][y] + w;
                if (w == 0) dq.push_front({nx, ny});
                else        dq.push_back({nx, ny});
            }
        }
    }
    return -1;
}

// ================= 3. BFS + 小根堆：二维接雨水 =================
int trapRainWater(vector<vector<int>>& h) {
    int n = (int)h.size(), m = (int)h[0].size();
    if (n < 3 || m < 3) return 0;
    using State = array<int,3>;                   // {水线高度, x, y}
    priority_queue<State, vector<State>, greater<State>> pq;
    vector<vector<char>> vis(n, vector<char>(m, 0));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            if (i == 0 || i == n - 1 || j == 0 || j == m - 1) {
                pq.push({h[i][j], i, j});
                vis[i][j] = 1;
            }
    int ans = 0;
    while (!pq.empty()) {
        State cur = pq.top(); pq.pop();
        int water = cur[0], x = cur[1], y = cur[2];
        for (int d = 0; d < 4; d++) {
            int nx = x + DX[d], ny = y + DY[d];
            if (nx < 0 || nx >= n || ny < 0 || ny >= m || vis[nx][ny]) continue;
            vis[nx][ny] = 1;
            ans += max(0, water - h[nx][ny]);
            pq.push({max(water, h[nx][ny]), nx, ny});
        }
    }
    return ans;
}

int main() {
    vector<vector<int>> g = {{1,0,1},{0,0,0},{1,0,1}};
    std::cout << "地图分析 = " << maxDistance(g) << "\n";              // 2

    vector<vector<int>> grid = {{0,1,1},{1,1,0},{1,1,0}};
    std::cout << "最少移除障碍 = " << minimumObstacles(grid) << "\n";   // 2

    vector<vector<int>> height = {{1,4,3,1,3,2},{3,2,1,3,2,4},{2,3,3,2,3,1}};
    std::cout << "二维接雨水 = " << trapRainWater(height) << "\n";      // 4
    return 0;
}
```

## 专题深化：为什么成立

BFS 按层扩展，第一次到达某状态时层数最少，适用于所有边权相同的最短路。多源 BFS 把多个起点同时入队，相当于添加一个超级源点；01 BFS 用双端队列处理 0/1 边。

## 专题深化：手算与边界

网格最短路中，起点入队 dist=0；每步向四方向扩散，第一次碰到终点时的 dist 就是最短步数。

### 对照与取舍

DFS 适合连通性/枚举路径；BFS 适合无权最短路/层序；Dijkstra 适合非负权。

### 易错点与反例

1. 入队时标记访问，避免重复入队
2. 多源初值所有源点 dist=0
3. 01 BFS 的 0 边从队头、1 边从队尾
4. 网格方向按四/八连通确定

## 专题深化：进阶拓展

双向 BFS 从两端同时扩展；A* 加入启发函数；状态图 BFS 可解决最短操作次数。
