# 宽度优先遍历（BFS）及其扩展

> 来源笔记：`0207宽度优先遍历及其扩展.cpp`｜核心程度：必背｜分类：05 图论

## 一句话

BFS 的本质是“按距离从近到远处理状态”。**答案依赖距离时，必须显式保存层号或 `dist`；需要按层分组、多源逐轮扩散时用分层 BFS；只问连通性时用单点弹出即可。**

## 基础要点（笔记原文）

- 适用特征：任意两个节点之间的相互距离相同（无权图 / 边权全相等）；
- 起点可以是**单源**（第 0 层 1 个），也可以是**多源**（第 0 层多个，同时扩散，标记过的不重复访问）；
- 队列有两种用法：**单点弹出**（把每个点附带的信息也放进队列）或**整层弹出**（一次处理一层，信息用队列外的变量维护）；
- 入队时必须**标记状态**，防止同一节点重复进出队列；
- BFS 常配合**剪枝策略**。

## 先选语义：单点弹出、距离数组还是按层遍历

不要从“队列怎么写”开始，而要先看答案需要什么信息。

> **判断标准：答案是否依赖“层数 / 距离 / 步数”？**
>
> - 不依赖，只问连通块、可达性、能否染色：**单点弹出（不维护层）**；
> - 依赖距离，但没有“按整层输出/整轮扩散”的需求：**单点弹出 + `dist` 数组或队列携带距离**；
> - 要逐层统计、模拟一轮扩散、在层末统一计数：**按层遍历**；
> - 第一次到目标就返回最短路：两种写法都可，分层写法通常语义最直观。

| 场景 | 是否需要距离 | 推荐写法 | 原因 |
| --- | --- | --- | --- |
| 岛屿数量、朋友圈、服务器通信 | 否 | 单点弹出 | 只累计连通块大小 |
| 能否从 A 到 B | 否 | 单点弹出 | 遇到目标即可结束，不需要步数 |
| 无权图最短距离 | 是 | 单点弹出 + `dist` | 每个状态保存到源点的距离 |
| 二叉树层序、每层最大值 | 是 | 按层遍历 | 必须把同一深度的节点分成一组 |
| 腐烂橘子、多源最近距离 | 是 | 按层或 `dist` | 多源扩散，需要每轮同步推进 |
| 0/1 边权最短路 | 是 | 双端队列 + `dist` | 0 边走队头、1 边走队尾 |

### 单点弹出：只关心访问集合

```cpp
queue<int> pending;
visited[source] = true;
pending.push(source);

while (!pending.empty()) {
    int current = pending.front();
    pending.pop();
    ++componentSize;

    for (int next : graph[current]) {
        if (!visited[next]) {
            visited[next] = true;
            pending.push(next);
        }
    }
}
```

这里没有 `size` 快照，也没有 `distance`。如果服务器之间只问“能不能通信”，把一个连通块完整弹出后一次性累计 `componentSize` 即可。强行加一层 `for (k < layerSize)` 不会产生任何额外信息。

### 单点弹出 + 距离数组：最短路

```cpp
vector<int> distance(vertexCount, -1);
queue<int> pending;
distance[source] = 0;
pending.push(source);

while (!pending.empty()) {
    int current = pending.front();
    pending.pop();

    for (int next : graph[current]) {
        if (distance[next] == -1) {
            distance[next] = distance[current] + 1;
            pending.push(next);
        }
    }
}
```

这仍然是“每次弹一个点”，但每个点携带了由 `distance` 表示的距离。它和分层 BFS 求出的距离完全一致。

### 按层遍历：层本身有意义

```cpp
int level = 0;
while (!pending.empty()) {
    int layerSize = static_cast<int>(pending.size());
    for (int index = 0; index < layerSize; ++index) {
        int current = pending.front();
        pending.pop();
        // 处理当前层
    }
    ++level;
}
```

`layerSize` 必须在处理前固定，因为内层循环会向队列加入下一层节点。层次含义可能是距离、扩散轮数、树的深度，或题目要求的“每层统计”。

## 为什么 BFS 第一次到达就是最短

设所有边权均为 1，队列中状态按距离非递减排列。初始时源点的距离为 0，成立。每次弹出距离为 `d` 的节点时，它加入的未访问邻居距离都是 `d+1`；队列中不可能已经存在距离更大的节点排在更前面，因此新层仍保持非递减。

若第一次到达状态 `v` 时距离为 `d`，那么任何更短路径的倒数第二个状态距离会小于 `d`，应在 `v` 之前被处理并发现 `v`，矛盾。因此第一次发现的距离就是最短距离。

**前提是“入队即标记”或至少“入队后不再重复扩展同一距离”**。如果只在出队时标记，同一节点可能被多个同层前驱重复入队；不仅浪费空间，也会让“队列长度”和层语义变得复杂。

## 手算演练：连通、距离与分层

无向图有边 `0-1、0-2、1-3、4-5`：

| 问题 | 推荐写法 | 结果 |
| --- | --- | --- |
| 0 能到多少个点 | 单点弹出 | 4 个：`{0,1,2,3}` |
| 0 到 3 最少几步 | `dist` 或分层 | 2 步 |
| 4 与 0 是否连通 | 单点弹出 | 不连通 |
| 每层有哪些点 | 分层 | 第 0 层 `{0}`，第 1 层 `{1,2}`，第 2 层 `{3}` |

同一个队列可以承担三类任务，区别只在于是否维护距离以及是否需要在层末统一处理。

## 服务器通信：典型的单点弹出连通块

服务器网格中，如果两台服务器在同一行或同一列，就认为有直接通信关系；关系可传递，因此问题等价于统计大小大于 1 的连通块。

每个服务器只需保留“同一行相邻服务器”和“同一列相邻服务器”两条无向边，就可以把整行/整列串成一个连通块，无需真的构造完全图。

```cpp
for (每个尚未访问的服务器 server) {
    int componentSize = 0;
    queue<GridPosition> pending;
    visited[server.row][server.column] = true;
    pending.push(server);

    while (!pending.empty()) {
        GridPosition current = pending.front();
        pending.pop();
        ++componentSize;

        for (GridPosition next : adjacentServers[current]) {
            if (!visited[next.row][next.column]) {
                visited[next.row][next.column] = true;
                pending.push(next);
            }
        }
    }

    if (componentSize > 1) {
        answer += componentSize;
    }
}
```

这里若套一层 `layerSize` 循环，层次既不是距离也不是扩散轮数，完全没有业务含义。真正需要在“整个连通块结束后”做的是 `if (componentSize > 1)`，而不是在层循环中重复累计。

## 都用队列，但不一定是 BFS 最短路

下面几种写法都可能在代码里出现 `queue`，但语义不同：

| 算法 | 队列中的对象 | 队列层数表示什么 |
| --- | --- | --- |
| 无权图 BFS | 当前距离的状态 | 到源点的最短边数 |
| 洪水填充 | 同一连通块中的待访问格子 | 通常没有业务意义 |
| Kahn 拓扑排序 | 当前入度为 0 的节点 | 没有统一距离，只表示“可处理集合” |
| 多源 BFS | 当前扩散距离的全部状态 | 到最近源点的距离或扩散轮数 |

因此，看到 `queue` 不要立即断言“这是最短路”。只有当前处理顺序对距离具有单调保证时，才能用它推导最短距离。

## `dist` 版与分层版怎么选

| 维度 | 单点弹出 + `dist` | 按层遍历 |
| --- | --- | --- |
| 每层快照 | 不需要 | `layerSize = queue.size()` |
| 距离来源 | `dist[next] = dist[current] + 1` | 当前 `level` |
| 多源最远距离 | 最后取 `max(dist)` | 每完成一轮更新层数 |
| 每层统计 | 按 `dist` 分组 | 天然按层处理 |
| 提前停止 | 弹出目标时返回 `dist[target]` | 弹出目标时返回当前 `level` |
| 常见风险 | 忘记初始化或更新距离 | 混淆“刚入队的下一层”和“当前层” |

二者不是互斥关系：可以“按层处理”，同时维护 `dist` 增强可读性；也可以单点弹出并通过 `dist` 得出所有距离。

## 多源 BFS：超级源点与扩散轮数

把所有源点的距离都初始化为 0，并同时加入队列。这等价于在原图外增加一个超级源点，超级源点到每个源点的边权为 0，再把超级源点作为唯一源点做 BFS。

因此，每个普通节点第一次被访问时的层数，就是它到**最近源点**的距离。腐烂橘子题中，每处理完一层，代表病毒同步向外扩散一分钟，层末增加时间；最后一层没有新的节点时不要多加一分钟。

如果使用 `dist` 数组，则不需要额外维护 `level`：

```cpp
distance[nextRow][nextColumn] = distance[currentRow][currentColumn] + 1;
answer = max(answer, distance[nextRow][nextColumn]);
```

## 0-1 BFS：不是普通队列

边权只有 0 和 1 时，用双端队列维护距离顺序：

- 0 边产生同一距离的新状态，放队头；
- 1 边产生距离加一的新状态，放队尾。

这样队列前部始终是当前最小距离的候选。`dist` 数组负责记录最短距离，也承担“是否已有更优到达”的判断。若新距离没有变小，就不应再次入队。

普通 BFS 把所有边默认成权 1；若题目中 0 边和 1 边混用却仍用普通 `queue`，层数不再是真实代价，答案会偏大。

## 必须能解释的边界

1. **源点就是目标**：最短距离通常应为 0；分层模板中若先增加层号再判断，可能返回 1。
2. **多源图的最后一层**：如果循环每轮无条件 `minutes++`，最后会多算一轮；应在扩展出新节点时才增加时间，或最后返回 `max(dist)`。
3. **无向图双向边**：没有 `visited/dist` 会导致两个端点反复入队。
4. **状态 BFS**：状态应包含影响后续转移的全部信息，例如位置、钥匙集合、剩余次数；只按坐标去重可能合并不同状态。
5. **提前终止**：多源“最远距离”不能遇到第一个目标就停止，必须等所有状态处理完。

## 五个扩展方向

### 一、多源 BFS：地图分析（LC 1162）

把所有陆地作为第 0 层同时入队，做按层 BFS，层数就是"到最近陆地的距离"；最后一个被扩散到的海洋格子的层数即为答案（返回 `level - 1`）。特判：全是陆地或全是海洋返回 -1。

### 二、隐式图 BFS：贴纸拼词（LC 691）

- **节点** = 当前还剩下的目标字符串；
- **路** = 用某张贴纸消掉若干字符后的剩余串；
- 层数 = 用掉的贴纸数；变成空串时的层数就是答案；
- 技巧：target 与贴纸都**按字典序排序**，用两指针 `eliminate` 消字符；`unordered_set<string>` 去重；按首字母建图（只试含该字母的贴纸）。

### 三、0-1 BFS（边权只有 0/1）

- 用**双端队列**代替普通队列：
  - `w == 0` 从**队头**入队；`w == 1` 从**队尾**入队；
- 复杂度 O(n + m)，比 Dijkstra 更优；
- 不需要 visited（`distance` 已起去重作用）；
- 例题：到达角落的最小障碍移除数（LC 2290）、使网格至少有一条有效路径的最小代价（LC 1368）。

> 笔记原话："0-1 BFS 就是 Dijkstra 的简化版——因为只有 0/1，把堆优化成了双端队列。"

### 四、BFS + 优先队列（堆）

把队列换成小根堆就进入 Dijkstra 的世界（见 `0212Dijkstra算法、分层图最短路`）。典型题：二维接雨水（LC 407）——从边界最弱的点开始往里"涨水"，堆顶就是当前水线。

### 五、BFS 建图 + DFS 生成路径：单词接龙 II（LC 126）

- BFS 从 beginWord 出发**反向建图**（记录每个单词由哪些单词转换而来）；
- 一旦发现 endWord 立刻停止（只保留最短路上的边）；
- DFS 从 endWord 往回走，每走到 beginWord 收集一条路径，最后反转。

笔记的说明："BFS 正向是为了尽快找到 end 且把路找全；DFS 反向是因为从 end 出发的每一步都是必经之路，没有冤枉路。"

## 适用特征（看到这些信号就选它）

- "最少步数 / 最短距离 / 最少操作数"，且每步代价相同 → BFS；
- 边权只有 0 和 1 → 0-1 BFS；
- 多个起点同时扩散 → 多源 BFS；
- 状态是字符串/局面而不是网格 → 隐式图 BFS（配哈希表去重）；
- 要**所有**最短路径 → BFS 建图 + DFS 生成。

## 复杂度

- 普通 BFS / 0-1 BFS：O(n + m)；
- 与堆结合（Dijkstra）：O(m log n)。

## 易错点

1. 入队立即标记（或出队判 visited），不要重复入队；
2. **越界判断放在最前面**（笔记多次强调，否则后续判断可能越界）；
3. 0-1 BFS 的入队方向写反会得到错误答案；
4. 按层 BFS 时"当前层大小"要在循环前固定；
5. 隐式图必须把状态做哈希去重，否则会无限扩展；
6. 单词接龙类题目每轮要把当前层的单词从词典里删掉。

## 模板（可直接编译运行）

`cpp
// BFS 选型模板：连通块 / 单点弹出距离 / 分层 / 多源 / 0-1 BFS / 优先队列
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <climits>
#include <deque>
#include <functional>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;

constexpr array<int, 4> ROW_OFFSET = {1, -1, 0, 0};
constexpr array<int, 4> COLUMN_OFFSET = {0, 0, 1, -1};

struct GridPosition {
    int row;
    int column;
};

struct WeightedState {
    int row;
    int column;
    int distance;
};

struct WaterState {
    int waterLevel;
    int row;
    int column;
};

struct WaterStateGreater {
    bool operator()(const WaterState& left, const WaterState& right) const {
        return left.waterLevel > right.waterLevel;
    }
};

bool isInside(int row, int column, int rowCount, int columnCount) {
    return 0 <= row && row < rowCount &&
           0 <= column && column < columnCount;
}

// 只问连通性：单点弹出，不需要 layerSize 或 distance。
int countReachableVertices(const vector<vector<int>>& graph, int source) {
    if (source < 0 || source >= static_cast<int>(graph.size())) {
        return 0;
    }

    vector<char> visited(graph.size(), false);
    queue<int> pending;
    visited[source] = true;
    pending.push(source);

    int reachedCount = 0;
    while (!pending.empty()) {
        int current = pending.front();
        pending.pop();
        ++reachedCount;

        for (int next : graph[current]) {
            if (visited[next]) {
                continue;
            }
            visited[next] = true;
            pending.push(next);
        }
    }
    return reachedCount;
}

// 需要距离但不需要按层分组：仍然是单点弹出，用 dist 保存距离。
vector<int> shortestDistanceFrom(const vector<vector<int>>& graph,
                                 int source) {
    vector<int> distance(graph.size(), -1);
    if (source < 0 || source >= static_cast<int>(graph.size())) {
        return distance;
    }

    queue<int> pending;
    distance[source] = 0;
    pending.push(source);

    while (!pending.empty()) {
        int current = pending.front();
        pending.pop();

        for (int next : graph[current]) {
            if (distance[next] != -1) {
                continue;
            }
            distance[next] = distance[current] + 1;
            pending.push(next);
        }
    }
    return distance;
}

// 服务器通信：同一行/列串成连通块，最后统计大小大于 1 的块。
int countCommunicatingServers(const vector<vector<int>>& grid) {
    if (grid.empty() || grid[0].empty()) {
        return 0;
    }

    int rowCount = static_cast<int>(grid.size());
    int columnCount = static_cast<int>(grid[0].size());
    int cellCount = rowCount * columnCount;
    vector<vector<int>> adjacency(cellCount);

    for (int row = 0; row < rowCount; ++row) {
        int previousServer = -1;
        for (int column = 0; column < columnCount; ++column) {
            if (grid[row][column] == 0) {
                continue;
            }
            int currentServer = row * columnCount + column;
            if (previousServer != -1) {
                adjacency[previousServer].push_back(currentServer);
                adjacency[currentServer].push_back(previousServer);
            }
            previousServer = currentServer;
        }
    }

    for (int column = 0; column < columnCount; ++column) {
        int previousServer = -1;
        for (int row = 0; row < rowCount; ++row) {
            if (grid[row][column] == 0) {
                continue;
            }
            int currentServer = row * columnCount + column;
            if (previousServer != -1) {
                adjacency[previousServer].push_back(currentServer);
                adjacency[currentServer].push_back(previousServer);
            }
            previousServer = currentServer;
        }
    }

    vector<char> visited(cellCount, false);
    int communicatingCount = 0;
    for (int row = 0; row < rowCount; ++row) {
        for (int column = 0; column < columnCount; ++column) {
            int source = row * columnCount + column;
            if (grid[row][column] == 0 || visited[source]) {
                continue;
            }

            int componentSize = 0;
            queue<int> pending;
            visited[source] = true;
            pending.push(source);

            while (!pending.empty()) {
                int current = pending.front();
                pending.pop();
                ++componentSize;

                for (int next : adjacency[current]) {
                    if (visited[next]) {
                        continue;
                    }
                    visited[next] = true;
                    pending.push(next);
                }
            }

            if (componentSize > 1) {
                communicatingCount += componentSize;
            }
        }
    }
    return communicatingCount;
}

// 需要明确的层次语义：固定当前层大小，第一次弹出目标时返回层号。
int shortestDistanceLayered(const vector<vector<int>>& graph,
                            int source,
                            int target) {
    int vertexCount = static_cast<int>(graph.size());
    if (source < 0 || source >= vertexCount ||
        target < 0 || target >= vertexCount) {
        return -1;
    }
    if (source == target) {
        return 0;
    }

    vector<char> visited(vertexCount, false);
    queue<int> pending;
    visited[source] = true;
    pending.push(source);

    int level = 0;
    while (!pending.empty()) {
        int layerSize = static_cast<int>(pending.size());
        for (int index = 0; index < layerSize; ++index) {
            int current = pending.front();
            pending.pop();
            if (current == target) {
                return level;
            }

            for (int next : graph[current]) {
                if (visited[next]) {
                    continue;
                }
                visited[next] = true;
                pending.push(next);
            }
        }
        ++level;
    }
    return -1;
}

// 多源 BFS：所有陆地距离为 0，静止时已入队；每成功扩展一轮，距离加一。
int maxDistanceToNearestLand(vector<vector<int>> grid) {
    if (grid.empty() || grid[0].empty()) {
        return -1;
    }

    int rowCount = static_cast<int>(grid.size());
    int columnCount = static_cast<int>(grid[0].size());
    int seaCount = 0;
    queue<GridPosition> pending;

    for (int row = 0; row < rowCount; ++row) {
        for (int column = 0; column < columnCount; ++column) {
            if (grid[row][column] == 1) {
                pending.push({row, column});
            } else {
                ++seaCount;
            }
        }
    }
    if (seaCount == 0 || seaCount == rowCount * columnCount) {
        return -1;
    }

    int maximumDistance = 0;
    while (!pending.empty()) {
        int layerSize = static_cast<int>(pending.size());
        bool expanded = false;

        for (int index = 0; index < layerSize; ++index) {
            GridPosition current = pending.front();
            pending.pop();

            for (int direction = 0; direction < 4; ++direction) {
                int nextRow = current.row + ROW_OFFSET[direction];
                int nextColumn = current.column + COLUMN_OFFSET[direction];
                if (!isInside(nextRow, nextColumn, rowCount, columnCount) ||
                    grid[nextRow][nextColumn] != 0) {
                    continue;
                }

                grid[nextRow][nextColumn] = 1;
                pending.push({nextRow, nextColumn});
                expanded = true;
            }
        }

        if (expanded) {
            ++maximumDistance;
        }
    }
    return maximumDistance;
}

// 0-1 BFS：0 边放队头，1 边放队尾。
int minimumObstacles(const vector<vector<int>>& grid) {
    if (grid.empty() || grid[0].empty()) {
        return -1;
    }

    int rowCount = static_cast<int>(grid.size());
    int columnCount = static_cast<int>(grid[0].size());
    vector<vector<int>> distance(
        rowCount, vector<int>(columnCount, INT_MAX));
    deque<WeightedState> pending;

    distance[0][0] = 0;
    pending.push_front({0, 0, 0});

    while (!pending.empty()) {
        WeightedState current = pending.front();
        pending.pop_front();
        if (current.distance != distance[current.row][current.column]) {
            continue;
        }

        for (int direction = 0; direction < 4; ++direction) {
            int nextRow = current.row + ROW_OFFSET[direction];
            int nextColumn = current.column + COLUMN_OFFSET[direction];
            if (!isInside(nextRow, nextColumn, rowCount, columnCount)) {
                continue;
            }

            int edgeCost = grid[nextRow][nextColumn];
            int nextDistance = current.distance + edgeCost;
            if (nextDistance >= distance[nextRow][nextColumn]) {
                continue;
            }

            distance[nextRow][nextColumn] = nextDistance;
            WeightedState nextState = {
                nextRow, nextColumn, nextDistance
            };
            if (edgeCost == 0) {
                pending.push_front(nextState);
            } else {
                pending.push_back(nextState);
            }
        }
    }
    return distance[rowCount - 1][columnCount - 1];
}

// 非负权时需要小根堆，这时是 Dijkstra 思路，不再属于普通 BFS。
int trapRainWater(const vector<vector<int>>& heights) {
    if (heights.size() < 3 || heights[0].size() < 3) {
        return 0;
    }

    int rowCount = static_cast<int>(heights.size());
    int columnCount = static_cast<int>(heights[0].size());
    vector<vector<char>> visited(
        rowCount, vector<char>(columnCount, false));
    priority_queue<
        WaterState,
        vector<WaterState>,
        WaterStateGreater
    > pending;

    for (int row = 0; row < rowCount; ++row) {
        for (int column = 0; column < columnCount; ++column) {
            bool isBoundary =
                row == 0 || row == rowCount - 1 ||
                column == 0 || column == columnCount - 1;
            if (!isBoundary) {
                continue;
            }
            pending.push({heights[row][column], row, column});
            visited[row][column] = true;
        }
    }

    int trappedWater = 0;
    while (!pending.empty()) {
        WaterState current = pending.top();
        pending.pop();

        for (int direction = 0; direction < 4; ++direction) {
            int nextRow = current.row + ROW_OFFSET[direction];
            int nextColumn = current.column + COLUMN_OFFSET[direction];
            if (!isInside(nextRow, nextColumn, rowCount, columnCount) ||
                visited[nextRow][nextColumn]) {
                continue;
            }

            visited[nextRow][nextColumn] = true;
            trappedWater += max(
                0, current.waterLevel - heights[nextRow][nextColumn]);
            pending.push({
                max(current.waterLevel, heights[nextRow][nextColumn]),
                nextRow,
                nextColumn
            });
        }
    }
    return trappedWater;
}

## 专题深化：为什么成立

BFS 按层扩展，第一次到达某状态时层数最少，适用于所有边权相同的最短路。多源 BFS 把多个起点同时入队，相当于添加一个超级源点；01 BFS 用双端队列处理 0/1 边。

## 专题深化：手算与边界

网格最短路中，起点入队 dist=0；每步向四方向扩散，第一次碰到终点时的 dist 就是最短步数。

### 对照与取舍

DFS 适合连通性/枚举路径；BFS 适合无权最短路/层序；Dijkstra 适合非负权。

### 易错点与反例

1. 入队时标记访问，避免重复入队
2. 多源初值所有源点 dist=0
3. 01 BFS 的 0 边从队头、1 边从队尾
4. 网格方向按四/八连通确定

## 专题深化：进阶拓展

双向 BFS 从两端同时扩展；A* 加入启发函数；状态图 BFS 可解决最短操作次数。
