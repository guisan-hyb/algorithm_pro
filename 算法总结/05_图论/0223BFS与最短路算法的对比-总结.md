# BFS 与最短路算法的对比

> 来源笔记：`0223BFS与最短路算法的对比.md`｜性质：选型指南｜分类：05 图论

## 一句话

**BFS 是最短路算法在"无权图（或边权相等）"下的特例**；选谁，先看图的两个属性：**边权情况**和**状态空间**。

## 一、核心判断标准：边权

| 边权情况 | 首选算法 | 原因 |
| --- | --- | --- |
| 无权 / 所有边权相等 | **BFS** | 层层扩散保证"首次到达即最短"；O(V+E)，代码极简 |
| 非负且不相等 | **Dijkstra** | BFS 的"层数"不再代表距离；Dijkstra 用优先队列保证每次取出的是当前最近的点；O(E log V) |
| 有负数（无负环） | **Bellman-Ford / SPFA** | Dijkstra 的贪心在负权下失效（一旦定稿不再更新）；Bellman-Ford O(VE) |

> **注意**：无权图但每步代价是同一个常数 k（如每步 5），BFS 依然适用，最后把层数乘以 k 即可。

## 二、进阶判断标准：状态空间

- **隐式图搜索**（八数码、华容道、翻转矩阵、最少操作次数）：
  - 没有显式给出点和边，只给初始状态与目标状态；
  - 操作代价均等 → **BFS**；需要启发式加速 → **A***；
  - 状态空间大，要用哈希表记录是否访问过（而不是邻接表）。
- **多源最短路**：要求任意两点之间的距离，且 n 较小（< 400）、图较稠密 → **Floyd**（O(N³)）最省事。

## 三、总结对照表

| 图的特征 | 适用算法 | 时间复杂度 | 典型场景 |
| --- | --- | --- | --- |
| 无权图 / 边权相等 | BFS | O(V+E) | 走迷宫、单词接龙、层序遍历 |
| 正权图（边权不等） | Dijkstra | O(E log V) | 地图导航、带权最短路 |
| 负权图（无负环） | Bellman-Ford / SPFA | O(VE) / 最坏 O(VE) | 带负花费的最优路径 |
| 多源最短路（N 小） | Floyd | O(N³) | 传递闭包、任意两点距离 |
| 矩阵/棋盘（步数最少） | BFS | O(R×C) | 马走日、逃离迷宫 |
| 矩阵（带权移动代价） | Dijkstra / 0-1 BFS | O(RC log(RC)) / O(RC) | 代价不同的地形移动 |

## 四、特殊的交集：0-1 BFS

- 边权只有 0 和 1；
- 用 Dijkstra 可以，但"杀鸡用牛刀"；
- 用普通 BFS 不行，因为权值 0 不增加层数；
- **解法**：双端队列——权值 1 入**队尾**，权值 0 入**队头**；复杂度 O(V+E)，优于 Dijkstra。

## 五、一句话决策

- 求"最少操作次数、最少步数"，每一步代价相同 → **BFS**；
- 求"最小代价、最短距离"，每一步代价不同 → **最短路算法（先看边权）**。
