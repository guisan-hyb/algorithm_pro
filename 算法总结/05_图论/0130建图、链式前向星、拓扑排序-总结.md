# 建图（邻接矩阵 / 邻接表 / 链式前向星）与拓扑排序

> 来源笔记：`0130建图、链式前向星、拓扑排序.cpp`｜核心程度：必背｜分类：05 图论

## 一句话

建图三种方式按"点多少、空间多紧"来选；拓扑排序就是不断删掉"入度为 0"的点（连它的出边一起删），删完所有点说明无环，删不完说明有环。

## 一、三种建图方式

| 方式 | 结构 | 适用 | 复杂度 |
| --- | --- | --- | --- |
| **邻接矩阵** | `matrix[u][v] = w` | 点少（n ≤ 1000 左右）、稠密图、需要 O(1) 查边 | 空间 O(n²) |
| **邻接表** | `vector<vector<pair<int,int>>> adj` | 最常用 | 空间 O(n + m) |
| **链式前向星** | `head[] / to[] / next[] / weight[]` | 空间苛刻、比赛必用 | 空间 O(n + m)，常数小 |

要点：

- 无向图的边数要**准备 2 倍**（一条无向边加两条有向边）；
- 邻接表带权用 `pair<to, weight>`；不带权用 `vector<vector<int>>`；
- 链式前向星的 `addEdge(u, v, w)` 四步（笔记原文）：

```
to[edgeCnt] = v;
next[edgeCnt] = head[u];
weight[edgeCnt] = w;
head[u] = edgeCnt++;
```

- 遍历某点的出边：`for (int ei = head[u]; ei > 0; ei = next[ei])`（**边的编号从 1 开始**，0 表示空）。

## 二、拓扑排序

**前提**：有向图、无环（DAG）。

**流程**（笔记原文）：

1. 找到所有入度为 0 的点；
2. 把它们从图中删掉，**重点是删掉它们造成的影响**（把邻居的入度减 1）；
3. 继续找入度为 0 的点并删掉影响；
4. 所有点都被删掉 → 删除顺序就是拓扑序；**删不完 → 有环**。

实现要点：用队列（`l, r` 两个下标的数组模拟）维护入度为 0 的点；`cnt` 记录出队点数，最后 `cnt == n` 才算无环。

## 三、拓扑排序的四个应用

| 题目 | 做法 |
| --- | --- |
| 课程表 II（LC 210） | 模板题，返回拓扑序，无解返回空 |
| 字典序最小的拓扑排序（洛谷 U107394） | 把队列换成**小根堆**（链式前向星建图防卡空间） |
| 火星词典（LC 269/剑指 114） | 相邻单词第一个不同字符构成一条边；**特判** `["abc","ab"]` 这种前缀更长却排前面的非法情况 |
| 戳印序列（LC 936） | **反向拓扑**：把"盖章"倒过来看成"擦章"；入度 = 该位置与 stamp 不匹配的字符数 |

### 火星词典的两个细节

- 只把出现过的字母的入度初始化为 0，其余保持 -1（区分"没出现"与"入度为 0"）；
- 最后 `ans.size() == kind` 才合法（否则有环或信息不全）。

### 戳印序列的两个细节

- 入度数组长度为 `n - stampLen + 1`（所有可盖章的位置），初始入度是 `stampLen`（全部不匹配）；
- `visited` 数组防止同一位置重复消除影响（**不写会导致重复统计**），最后要检查所有位置都被访问过。

## 适用特征（看到这些信号就选它）

- 有明显的先后依赖（先修课、编译顺序、任务调度）；
- 需要判断"有没有环"（能否完成所有任务）；
- 需要"字典序最小/最大的合法顺序" → 队列换小根堆/大根堆；
- "后一步覆盖前一步" → 反向拓扑。

## 复杂度

- 建图 O(n + m)；
- 拓扑排序 O(n + m)；
- 字典序最小版多一个 O(n log n) 的堆开销。

## 易错点

1. 无向图边数要开 **2 倍**；
2. 链式前向星的边编号从 1 开始，`head` 初值 0 表示空；
3. 拓扑排序里只有 `--indegree[邻居] == 0` 时才入队；
4. 用 `cnt` 与 n 比较判断有没有环；
5. 火星词典前缀更长的非法情况要专门判（`pos == next.size()-1 && cur.size() > next.size()` 时返回 ""）；
6. 戳印序列的 `visited` 去重不能省；
7. 类内 `sort` 比较器必须是静态函数/lambda。

## 模板（可直接编译运行）

```cpp
// 建图 + 拓扑排序模板：邻接表 / 链式前向星 / 拓扑排序 / 字典序最小 / 火星词典
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <functional>
#include <iostream>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

// ================= 1. 邻接表建图（带权） =================
vector<vector<pair<int,int>>> adj;
void buildAdjList(int n, const vector<array<int,3>>& edges, bool directed) {
    adj.assign(n + 1, {});
    for (auto& e : edges) {
        adj[e[0]].push_back({e[1], e[2]});
        if (!directed) adj[e[1]].push_back({e[0], e[2]});
    }
}

// ================= 2. 链式前向星 =================
const int MAX_NODE = 100005;
const int MAX_EDGE = 200005;
vector<int> head(MAX_NODE, 0);
vector<int> nextEdge(MAX_EDGE);
vector<int> to(MAX_EDGE);
vector<int> weightEdge(MAX_EDGE);
int edgeCount = 1;
void addEdge(int u, int v, int w = 0) {
    to[edgeCount] = v;
    nextEdge[edgeCount] = head[u];
    weightEdge[edgeCount] = w;
    head[u] = edgeCount++;
}
void traverse(int u) {
    for (int edgeIndex = head[u]; edgeIndex > 0; edgeIndex = nextEdge[edgeIndex]) {
        int v = to[edgeIndex];
        (void)v;                // 处理边 u -> v
    }
}

// ================= 3. 拓扑排序（无环返回拓扑序，有环返回空） =================
vector<int> topoSort(int n, vector<vector<int>>& g) {
    vector<int> indegree(n, 0);
    for (int u = 0; u < n; u++)
        for (int v : g[u]) indegree[v]++;

    vector<int> q(n), ans;
    int l = 0, r = 0;
    for (int i = 0; i < n; i++) if (!indegree[i]) q[r++] = i;
    while (l < r) {
        int u = q[l++];
        ans.push_back(u);
        for (int v : g[u]) if (--indegree[v] == 0) q[r++] = v;
    }
    return (int)ans.size() == n ? ans : vector<int>{};
}

// ================= 4. 字典序最小的拓扑排序（小根堆） =================
vector<int> topoSortSmallest(int n, vector<vector<int>>& g) {
    vector<int> indegree(n, 0);
    for (int u = 0; u < n; u++)
        for (int v : g[u]) indegree[v]++;
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int i = 0; i < n; i++) if (!indegree[i]) pq.push(i);
    vector<int> ans;
    while (!pq.empty()) {
        int u = pq.top(); pq.pop();
        ans.push_back(u);
        for (int v : g[u]) if (--indegree[v] == 0) pq.push(v);
    }
    return (int)ans.size() == n ? ans : vector<int>{};
}

// ================= 5. 火星词典 =================
string alienOrder(vector<string>& words) {
    vector<int> indegree(26, -1);
    for (auto& w : words) for (char c : w) indegree[c - 'a'] = 0;

    vector<vector<int>> g(26);
    for (size_t i = 0; i + 1 < words.size(); i++) {
        const string& a = words[i];
        const string& b = words[i + 1];
        size_t len = min(a.size(), b.size()), p = 0;
        for (; p < len; p++) {
            if (a[p] != b[p]) {
                g[a[p] - 'a'].push_back(b[p] - 'a');
                indegree[b[p] - 'a']++;
                break;
            }
            if (p + 1 == b.size() && a.size() > b.size()) return "";   // 非法前缀
        }
    }

    int kind = 0;
    for (int i = 0; i < 26; i++) if (indegree[i] != -1) kind++;

    queue<int> q;
    for (int i = 0; i < 26; i++) if (indegree[i] == 0) q.push(i);
    string ans;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        ans.push_back(char(u + 'a'));
        for (int v : g[u]) if (--indegree[v] == 0) q.push(v);
    }
    return (int)ans.size() == kind ? ans : "";
}

int main() {
    // 课程表 II：0 -> 1，0 -> 2，1 -> 3
    vector<vector<int>> g(4);
    g[0].push_back(1); g[0].push_back(2); g[1].push_back(3);
    for (int x : topoSort(4, g)) std::cout << x << " ";
    std::cout << "\n";

    vector<string> words = {"wrt", "wrf", "er", "ett", "rftt"};
    std::cout << "火星词典：" << alienOrder(words) << "\n";   // wertf
    return 0;
}
```

## 专题深化：为什么成立

邻接表按点存出边，空间 O(V+E)；链式前向星用 head/next 把边串成链表；拓扑排序维护入度 0 的队列，删除节点时减少后继入度。若最终处理数小于 V，则存在环。

## 专题深化：手算与边界

边 `0->1,0->2,1->3`：初始入度 0 只有 0；删除 0 后 1、2 入度变 0；删除 1 后 3 入度变 0，得到合法序。

### 对照与取舍

| 建图 | 空间 | 遍历 | 优点 |
| --- | --- | --- | --- |
| 邻接矩阵 | O(V²) | O(1) 判边 | 稠密图直观 |
| 邻接表 | O(V+E) | O(deg) | 通用 |
| 前向星 | O(V+E) | O(deg) | 连续边存 |

### 易错点与反例

1. 自环和重边会影响入度判断
2. 拓扑序不唯一
3. 字典序最小需用小根堆
4. 无向图不能用普通拓扑排序
