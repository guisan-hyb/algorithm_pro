# 贪心经典题目专题 5

> 来源笔记：`0616贪心经典题目专题5.cpp`｜核心程度：必看（区间覆盖两题）｜分类：07 贪心与博弈

## 五道题

### 题一：跳跃游戏 II（LeetCode 45）——区间覆盖的标准形态

`curEnd` = 当前步数内能到的最右位置，`nextEnd` = 再多走一步能到的最右位置：

```
for i in 0..n-1:
    if (curEnd < i) { ans++; curEnd = nextEnd; }     // 需要多一步
    nextEnd = max(nextEnd, i + nums[i]);
```

笔记也给了 DP 版（`f(i)` = 从 i 跳到终点的最少步数）作对照。

### 题二：灌溉花园的最少水龙头数目（LeetCode 1326）

**先转化，再用跳跃游戏的模板**：

1. 对每个水龙头算灌溉区间 `[i-ranges[i], i+ranges[i]]`（截断到 `[0, n]`）；
2. 记 `right[l]` = 所有左端点为 l 的水龙头里能覆盖的最右边界；
3. 问题变成"从 0 跳到 n 的最少步数"，套跳跃游戏 II 的贪心，**跳不过去就返回 -1**。

### 题三：字符串转化（LeetCode 1153）

每次可以把 str1 中**出现的所有相同字母**一次性换成任意字母，问能否变成 str2。

- 特判 `str1 == str2` → true；
- 若 `str2` 用到 **26 种字母** → 一定失败（换任何一个字母都会连锁反应）；
- 否则检查"str1 里同一个字母出现的位置上，str2 对应的字母是否一致"，不一致就 false。

笔记还给了 BFS / DFS 暴力版（枚举 26×25 种替换）作对照，并指出 DFS 里 **visited 不需要回溯**（从同一状态出发找不到解，走别的路再来也一样）。

### 题四：过河问题（洛谷 P1809）

n 个人过河，船最多坐两人，时间取两人中的最大值，求最少总时间。

**排序后的递推**（先按时间升序）：

```
dp[0] = t[0]; dp[1] = t[1]; dp[2] = t[0] + t[1] + t[2];
dp[i] = min( t[i] + t[0] + dp[i-1],                    // 最快的来回接一个人
             t[1] + t[0] + t[i] + t[1] + dp[i-2] );    // 最快的两个当"摆渡人"
```

### 题五：超级洗衣机（LeetCode 517）

每步可以把任意多台洗衣机的各一件衣服送到相邻位置，求最少步数使所有洗衣机衣服数相等。

**瓶颈法**：先算平均值（不能整除返回 -1）；对每个位置 i，算**左边需要多少（lneed）、右边需要多少（rneed）**：

```
if (lneed > 0 && rneed > 0) ans = max(ans, lneed + rneed);     // 两边都向 i 要，必须同时满足
else                        ans = max(ans, max(|lneed|, |rneed|));
```

笔记的水坝比喻："只看水坝放水的时间，不用管洼地之间的水怎么传——水坝不动时水就静止了。"

## 适用特征（看到这些信号就选它）

| 题面特征 | 贪心方式 |
| --- | --- |
| "最少跳几步覆盖到终点" | curEnd / nextEnd 双指针贪心 |
| "最少几个区间覆盖整段" | 先预处理 right[]，再套跳跃游戏 |
| "整体替换同一类元素" | 分类讨论 + 冲突检测 |
| "船最多载两人、时间取较大者" | 排序后固定两种接法取 min |
| "同步搬运使各处相等" | 左右需求 + 取瓶颈 |

## 易错点

1. 跳跃游戏：`curEnd < i` 才加步数（相等不加），`nextEnd` 在判断**之后**更新；
2. 水龙头题的区间要**截断到 [0, n]**，且 `right` 数组长度为 `n+1`；
3. 字符串转化题：26 种字母全用到必失败；同一字母的映射必须唯一；
4. 过河问题的初始三项要单独写好（`dp[0]`、`dp[1]`、`dp[2]`）；
5. 超级洗衣机：两边都要时**相加**，只有一边要时取绝对值最大；
6. 这些题都建议对拍验证（笔记里大多配了暴力版）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 1) 跳跃游戏 II
int jump(vector<int>& nums) {
    int ans = 0, curEnd = 0, nextEnd = 0;
    for (int i = 0; i < (int)nums.size(); i++) {
        if (curEnd < i) { ans++; curEnd = nextEnd; }
        nextEnd = max(nextEnd, i + nums[i]);
    }
    return ans;
}

// 2) 灌溉花园的最少水龙头数目
int minTaps(int n, vector<int>& ranges) {
    vector<int> right(n + 1, 0);
    for (int i = 0; i <= n; i++) {
        int l = max(0, i - ranges[i]);
        int r = min(n, i + ranges[i]);
        right[l] = max(right[l], r);
    }
    int ans = 0, curEnd = 0, nextEnd = 0;
    for (int i = 0; i < n; i++) {
        nextEnd = max(nextEnd, right[i]);
        if (curEnd == i) {
            if (i < nextEnd) { ans++; curEnd = nextEnd; }
            else return -1;
        }
    }
    return ans;
}

// 3) 字符串转化
bool canConvert(const string& s1, const string& s2) {
    if (s1 == s2) return true;
    vector<int> cnt(26, 0);
    int kind = 0;
    for (char c : s2) if (cnt[c - 'a']++ == 0) kind++;
    if (kind == 26) return false;                 // 26 种全用到必失败
    vector<int> pos(26, -1);
    for (int i = 0; i < (int)s1.size(); i++) {
        int c = s1[i] - 'a';
        if (pos[c] != -1 && s2[pos[c]] != s2[i]) return false;
        pos[c] = i;
    }
    return true;
}

// 4) 过河问题
long long crossRiver(vector<int> t) {
    sort(t.begin(), t.end());
    int n = (int)t.size();
    if (n == 1) return t[0];
    if (n == 2) return t[1];
    vector<long long> dp(n, 0);
    dp[0] = t[0];
    dp[1] = t[1];
    dp[2] = t[0] + t[1] + t[2];
    for (int i = 3; i < n; i++)
        dp[i] = min(t[i] + t[0] + dp[i - 1],
                    t[1] + t[0] + t[i] + t[1] + dp[i - 2]);
    return dp[n - 1];
}

// 5) 超级洗衣机
int findMinMoves(vector<int>& m) {
    int n = (int)m.size(), sum = 0;
    for (int x : m) sum += x;
    if (sum % n) return -1;
    int avg = sum / n, ans = 0, lSum = 0, rSum = sum;
    for (int i = 0; i < n; i++) {
        rSum -= m[i];
        int lneed = i * avg - lSum;
        int rneed = (n - i - 1) * avg - rSum;
        if (lneed > 0 && rneed > 0) ans = max(ans, lneed + rneed);
        else ans = max(ans, max(abs(lneed), abs(rneed)));
        lSum += m[i];
    }
    return ans;
}
```
