# 贪心经典题目专题 3

> 来源笔记：`0607贪心经典题目专题3.cpp`｜核心程度：必看｜分类：07 贪心与博弈

## 六道题

### 题一：最短无序连续子数组（LeetCode 581）

- 朴素版：复制一份排序，双指针从两端向中间收缩（相同就跳过），剩下的长度就是答案；
- **O(n) 版（值得记）**：
  - 从左往右扫，维护 max，若 `max > nums[i]` 说明 i 位置"不达标"，记下**最右**不达标位置 `r`；
  - 从右往左扫，维护 min，若 `min < nums[i]` 记下**最左**不达标位置 `l`；
  - 答案 = `max(0, r - l + 1)`。

### 题二：最小区间（LeetCode 632）

有 k 个有序列表，找一个区间使每个列表至少有一个数落在其中，且区间长度最小。

**做法：有序集合（set）+ 每次推进最小值**：

1. 每个列表的当前元素放进 `set`（按值排序）；
2. 每次取 `set` 的最小值 `mins` 与最大值 `maxs`，用 `maxs - mins` 更新答案；
3. 把 `mins` 换成它所在列表的**下一个元素**（用它来缩小范围）；
4. 直到某个列表耗尽（`set.size() < k`）为止。

### 题三：组团买票（洛谷 P12331）

题意：每个项目有 `Ki`（折扣系数）、`Bi`（原价）；若已有 `p` 人买过，第 p+1 个人带来的**净收益**是

```
singleProfit = max(0, Bi - Ki*(p+1) - Ki*p)
             = max(0, Bi - Ki*(2p+1))
```

**做法：优先队列（大根堆）**——每次取当前 `singleProfit` 最大的项目，累加收益并让它的人数 +1 后放回堆，直到堆顶收益 ≤ 0 或人数用完。

笔记给了暴力递归版作对数器（两版随机对拍通过）。

### 题四：平均值最小累加和（大厂笔试）

把 n 个数分成 k 个集合（每个数只能进一个集合），使**各集合平均值（向下取整）之和最小**。

**贪心结论**：让**最小的 k-1 个数各自单独成一个集合**，剩下的所有数放进第 k 个集合：

```
ans = 前 k-1 个最小的数之和 + (剩余数的和) / (剩余数的个数)
```

（单元素集合的平均值就是它自己；把最大的那些数混在一起摊薄平均值。）

### 题五：执行所有任务的最少初始电量（LeetCode 1665）

每个任务 `(消耗 a0, 至少需要 a1)`，求完成所有任务所需的最小初始电量。

**排序依据的推导（笔记原文，很重要）**：

比较两个任务 a、b 谁先做：

- 先做 a 要求 `T >= a0 + b1`；
- 先做 b 要求 `T >= a1 + b0`；
- 若先做 a 更好，则 `a0 + b1 < a1 + b0`，即 **`a0 - a1 < b0 - b1`**。

所以按 `消耗 - 至少` **降序**排序，然后依次 `ans = max(ans + 消耗, 至少)`。

### 题六：两个 0 和 1 数量相等区间的最大长度（大厂笔试）

找两个（可相交、不完全重叠）区间，使它们 0 的个数相等且 1 的个数也相等，返回最大长度。

**贪心结论**：只需找**最左边第一个 0、最右边最后一个 0** 的距离，以及**最左边第一个 1、最右边最后一个 1** 的距离，取较大者。

直觉：两个区间共用中间部分，所以只要端点字符相同，两段的 01 计数就必然相等。

## 适用特征（看到这些信号就选它）

| 题面特征 | 贪心方式 |
| --- | --- |
| "最短需要排序的子数组" | 两次单向扫描记录最左/最右的"不达标"位置 |
| "k 个有序列表的最小覆盖区间" | 有序集合 + 每次推进最小值 |
| "收益随人数递减" | 大根堆贪心：每次取当前边际收益最大的 |
| "分成 k 组使平均值之和最小" | 最小的 k-1 个各自成组 |
| "任务顺序影响所需初始资源" | 按 `消耗 - 需求` 排序（推导比较器） |
| "两区间计数相等" | 找同字符的最左与最右位置 |

## 易错点

1. 最短无序子数组题：两遍扫描的"不达标"判定条件不同（左扫用 max，右扫用 min）；
2. 最小区间题：`set` 只放"各列表当前指针"的元素，取完一个要立刻补下一个；
3. 组团买票的 `singleProfit` 公式：`Bi - Ki*(2p+1)`，注意 p 是"之前的人数"；
4. 平均值题的除法是**向下取整**的整数除法；剩余集合不能为空（k ≤ n 保证）；
5. 电量题的排序方向是**降序**（`a0 - a1` 大的先做）；
6. 01 区间题只要"端点字符相同"，不要试图枚举所有区间；
7. 所有贪心结论都要**对数器验证**。

## 模板（可直接编译运行）

```cpp
// 贪心专题3模板：最短无序子数组 / 最小区间 / 组团买票 / 平均值和 / 初始电量 / 01区间
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <climits>
#include <iostream>
#include <queue>
#include <set>
#include <vector>
using namespace std;

// ---------- 1. 最短无序连续子数组（O(n) 两遍扫描） ----------
int findUnsortedSubarray(const vector<int>& nums) {
    int n = (int)nums.size();
    int l = n, r = -1, maxs = INT_MIN;
    for (int i = 0; i < n; i++) {                 // 从左往右找最右的"不达标"
        if (maxs > nums[i]) r = i;
        maxs = max(maxs, nums[i]);
    }
    int mins = INT_MAX;
    for (int i = n - 1; i >= 0; i--) {            // 从右往左找最左的"不达标"
        if (mins < nums[i]) l = i;
        mins = min(mins, nums[i]);
    }
    return max(0, r - l + 1);
}

// ---------- 2. 最小区间（k 个有序列表，有序集合 + 推进最小值） ----------
vector<int> smallestRange(vector<vector<int>>& nums) {
    int k = (int)nums.size();
    struct Node { int v, i, j; };
    auto cmp = [](const Node& a, const Node& b) {
        return a.v != b.v ? a.v < b.v : (a.i != b.i ? a.i < b.i : a.j < b.j);
    };
    set<Node, decltype(cmp)> s(cmp);
    for (int i = 0; i < k; i++) s.insert({nums[i][0], i, 0});
    int bestL = 0, bestR = INT_MAX;
    while ((int)s.size() == k) {
        Node lo = *s.begin(), hi = *s.rbegin();
        if (hi.v - lo.v < bestR - bestL) { bestL = lo.v; bestR = hi.v; }
        s.erase(s.begin());
        if (lo.j + 1 < (int)nums[lo.i].size())
            s.insert({nums[lo.i][lo.j + 1], lo.i, lo.j + 1});
    }
    return {bestL, bestR};
}

// ---------- 3. 组团买票（大根堆取边际收益） ----------
long long groupTickets(int n, vector<vector<int>>& games) {   // games[i] = {Ki, Bi}
    struct Info { long long bi, ki, people; };
    auto profit = [](const Info& x) { return max(0LL, x.bi - x.ki * (2 * x.people + 1)); };
    auto cmp = [&](const Info& a, const Info& b) { return profit(a) < profit(b); };
    priority_queue<Info, vector<Info>, decltype(cmp)> heap(cmp);
    for (auto& g : games) heap.push({g[1], g[0], 0});
    long long ans = 0;
    for (int i = 0; i < n && !heap.empty(); i++) {
        Info cur = heap.top();
        long long p = profit(cur);
        if (p <= 0) break;
        heap.pop();
        ans += p;
        cur.people++;
        heap.push(cur);
    }
    return ans;
}

// ---------- 4. 平均值最小累加和 ----------
int minAverageSum(vector<int> arr, int k) {
    sort(arr.begin(), arr.end());
    int ans = 0;
    for (int i = 0; i <= k - 2; i++) ans += arr[i];       // 最小的 k-1 个各自成组
    int sum = 0;
    for (int i = k - 1; i < (int)arr.size(); i++) sum += arr[i];
    ans += sum / ((int)arr.size() - k + 1);
    return ans;
}

// ---------- 5. 执行所有任务的最少初始电量（按 消耗-需求 降序） ----------
int minimumEffort(vector<vector<int>> tasks) {
    sort(tasks.begin(), tasks.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[0] - a[1] > b[0] - b[1]; });
    int ans = 0;
    for (auto& t : tasks) ans = max(ans + t[0], t[1]);
    return ans;
}

// ---------- 6. 两个 0/1 数量相等区间的最大长度 ----------
int maxEqualZerosOnes(const vector<int>& arr) {
    int n = (int)arr.size();
    int lz = -1, lo = -1, rz = -1, ro = -1;
    for (int i = 0; i < n; i++) {
        if (arr[i] == 0 && lz == -1) lz = i;
        if (arr[i] == 1 && lo == -1) lo = i;
    }
    for (int i = n - 1; i >= 0; i--) {
        if (arr[i] == 0 && rz == -1) rz = i;
        if (arr[i] == 1 && ro == -1) ro = i;
    }
    return max(rz - lz, ro - lo);
}

int main() {
    std::cout << "最短无序子数组 = " << findUnsortedSubarray({2,6,4,8,10,9,15}) << "\n";   // 5
    vector<vector<int>> lists = {{4,10,15,24,26},{0,9,12,20},{5,18,22,30}};
    auto r = smallestRange(lists);
    std::cout << "最小区间 = [" << r[0] << ", " << r[1] << "]\n";                                 // [20,24]
    std::cout << "最小初始电量 = " << minimumEffort({{1,2},{2,4},{4,8}}) << "\n";           // 8
    std::cout << "平均值和 = " << minAverageSum({1,2,3,4,5}, 2) << "\n";                    // 4
    std::cout << "01 最大长度 = " << maxEqualZerosOnes({0,1,1,0,0,1}) << "\n";              // 5
    return 0;
}
```

## 专题深化：为什么成立

最短无序子数组通过从左记录最大值、从右记录最小值确定第一个逆序边界；最小初始电量按“先满足最低需求”排序；平均段/01 最大长度依赖前缀计数或排序后的可交换选择。

## 专题深化：手算与边界

`[2,6,4,8,10,9,15]` 中，从左到 9 时最大值 10 超过 9，右边界扩展；从右看到 6 时最小值 4 小于 6，左边界确定，结果是 `[6,4,8,10,9]`。

### 对照与取舍

双指针/单调信息适合找无序边界；排序后相邻选择适合平均/配对约束；前缀状态适合 01 差值。

### 易错点与反例

1. 已经有序时返回 0
2. 相等元素不算无序
3. 平均值比较避免浮点可用交叉乘法
4. 01 问题把 0 映射为 -1 后找平衡点

## 专题深化：进阶拓展

无序边界可用栈匹配；最小代价调度可转成排序不等式；前缀和+哈希适合最长子数组。
