# 贪心经典题目专题 1

> 来源笔记：`0601贪心经典题目专题1.cpp`｜核心程度：必看（贪心总纲 + 6 题）｜分类：07 贪心与博弈

## 贪心的总纲（笔记原文，值得整段记住）

- **狭义贪心**：每一步都做当前状态下最好/最优的选择，希望最终最好；
- **广义贪心**：只要发现能让求解过程**加速的结论**，都算广义贪心；
- 贪心最符合自然智慧、分析门槛不高，但**题目千题千面，极难把握**；难点在于证明"局部最优 → 全局最优"；
- 七条务实提醒：
  1. **不要纠结严格证明**（浪费时间、收益低）；
  2. **一定要掌握用对数器验证**——这是解决贪心问题的关键；
  3. 纯贪心题代码量都不大；
  4. 积累的重点是**题目特征 + 贪心方式特征**，不是证明；
  5. 关注数据量：能不用贪心就别用（DP 更稳）；
  6. 笔试常考、面试较少（淘汰率 vs 区分度）；
  7. 广义贪心无处不在，常与别的思路结合。

## 六道题

### 题一：最大数（LeetCode 179）

**比较器贪心**：把所有数转成字符串排序，比较规则是 `a + b > b + a`（拼接后谁大谁在前）；若最大的是 "0" 就返回 "0"。

### 题二：两地调度（LeetCode 1029）

**排序差值**：先假设所有人都去 A（`sum += a[i]`），然后按 `b[i] - a[i]` 升序排序，选**前 n/2 个**改成去 B（它们的"改签收益"最大）。

笔记也给了两个 DP 版本（三维 `f(i,a,b)` → 二维 `f(i,a)`，因为 `b = i - a`）作对照，说明"贪心题往往也能 DP，但 DP 更慢"。

### 题三：吃掉 N 个橘子的最少天数（LeetCode 1553）

贪心 + 记忆化：能按比例吃（吃一半 / 吃三分之二）一定比一个个吃快，所以

```
ans = min( n % 2 + 1 + minDays(n / 2),      // 先吃掉余数，再吃一半
           n % 3 + 1 + minDays(n / 3) )     // 先吃掉余数，再吃三分之二
```

### 题四：会议室 II（LeetCode 253 / 2406）

**按开始时间排序 + 小根堆存结束时间**：每次开会前把"已经结束的会议"弹出堆；堆的大小就是当前同时进行的会议数，取最大值即为所需会议室数。

> 笔记的洞察："互相重叠的区间一定不能分到同一组，所以**最大重叠数**就是所需的组数/会议室数。"

### 题五：课程表 III（LeetCode 630）

**按截止时间排序 + 大根堆存已选课程的时长**：

- 时间够（`time + duration <= lastDay`）→ 直接选，入堆；
- 时间不够 → 若堆顶（已选里最长的课）比当前课还长，就**用它换掉**（`time = time - heap.top() + duration`）；
- 答案 = 堆的大小。

### 题六：连接棒材的最低费用（LeetCode 1167 / 洛谷 P1090，哈夫曼编码）

**每次合并最短的两根**：小根堆取出两个最小元素，合并后放回，累加合并代价。这就是哈夫曼树。

## 适用特征（看到这些信号就选它）

| 题面特征 | 贪心方式 |
| --- | --- |
| "排列后拼出最大/最小" | 自定义比较器（`a+b` vs `b+a`） |
| "每个人二选一、两边数量固定" | 排序**差值**，选收益最大的若干个 |
| "按比例削减/倍增" | 优先用比例操作（贪心）+ 记忆化 |
| "区间重叠/分组/最少资源" | 按开始时间排序 + 小根堆 |
| "截止时间 + 最多任务" | 按截止时间排序 + 大根堆替换 |
| "合并代价最小" | 每次取最小的两个（哈夫曼） |

## 易错点

1. 自定义比较器必须**满足严格弱序**（`a+b > b+a` 满足，可放心用）；
2. 最大数题要特判前导 0（全 0 时输出 "0"）；
3. 会议室题是"弹出 `arr[i][0] >= heap.top()`"（**>=**，会议结束即刻可用）；
4. 课程表 III 的替换条件别写反（是"堆顶时长 > 当前课"才换）；
5. 哈夫曼题每次必须取**最小**的两个（小根堆），取大根堆就错了；
6. **贪心写完必须对数器验证**（笔记反复强调）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 最大数（比较器贪心） ----------
string largestNumber(vector<int> nums) {
    vector<string> arr;
    for (int x : nums) arr.push_back(to_string(x));
    sort(arr.begin(), arr.end(), [](const string& a, const string& b) { return a + b > b + a; });
    if (arr[0] == "0") return "0";
    string ans;
    for (auto& s : arr) ans += s;
    return ans;
}

// ---------- 2. 两地调度（排序差值） ----------
int twoCitySchedCost(vector<vector<int>>& costs) {
    int n = (int)costs.size(), sum = 0;
    vector<int> diff;
    for (auto& c : costs) { sum += c[0]; diff.push_back(c[1] - c[0]); }
    sort(diff.begin(), diff.end());
    for (int i = 0; i < n / 2; i++) sum += diff[i];
    return sum;
}

// ---------- 3. 会议室 II（按开始排序 + 小根堆） ----------
int minMeetingRooms(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[0] < b[0]; });
    priority_queue<int, vector<int>, greater<>> heap;
    int ans = 0;
    for (auto& it : intervals) {
        while (!heap.empty() && it[0] >= heap.top()) heap.pop();   // 已结束的会议
        heap.push(it[1]);
        ans = max(ans, (int)heap.size());
    }
    return ans;
}

// ---------- 4. 课程表 III ----------
int scheduleCourse(vector<vector<int>> courses) {
    sort(courses.begin(), courses.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
    priority_queue<int> heap;                                  // 已选课程的时长（大根堆）
    int time = 0;
    for (auto& c : courses) {
        if (time + c[0] <= c[1]) {
            time += c[0];
            heap.push(c[0]);
        } else if (!heap.empty() && heap.top() > c[0]) {
            time = time - heap.top() + c[0];
            heap.pop();
            heap.push(c[0]);
        }
    }
    return (int)heap.size();
}

// ---------- 5. 连接棒材的最低费用（哈夫曼） ----------
long long connectSticks(vector<int> sticks) {
    priority_queue<int, vector<int>, greater<>> heap(sticks.begin(), sticks.end());
    long long cost = 0;
    while (heap.size() > 1) {
        int a = heap.top(); heap.pop();
        int b = heap.top(); heap.pop();
        cost += a + b;
        heap.push(a + b);
    }
    return cost;
}

// ---------- 6. 吃掉 N 个橘子（贪心 + 记忆化） ----------
unordered_map<int,int> memoEat;
int minDays(int n) {
    if (n <= 1) return n;
    if (memoEat.count(n)) return memoEat[n];
    return memoEat[n] = min(n % 2 + 1 + minDays(n / 2), n % 3 + 1 + minDays(n / 3));
}

int main() {
    printf("最大数 = %s\n", largestNumber({10, 2}).c_str());           // 210
    vector<vector<int>> costs = {{10,20},{30,200},{400,50},{30,20}};
    printf("两地调度 = %d\n", twoCitySchedCost(costs));                 // 110
    printf("最少会议室 = %d\n", minMeetingRooms({{0,30},{5,10},{15,20}}));  // 2
    printf("最多课程 = %d\n", scheduleCourse({{100,200},{200,1300},{1000,1250},{2000,3200}}));  // 3
    printf("连接棒材费用 = %lld\n", connectSticks({2,4,3}));            // 14
    printf("吃橘子天数 = %d\n", minDays(10));                           // 4
    return 0;
}
