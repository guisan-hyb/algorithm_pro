# 博弈类问题必备内容详解（SG 函数与经典博弈）

> 来源笔记：`0621博弈类问题必备内容详解.cpp`｜核心程度：必背（SG 定理是通用武器）｜分类：07 贪心与博弈

## 一句话

经典博弈（巴什/尼姆/威佐夫/斐波那契）可以记结论，但**真正通用的是 SG 函数 + SG 定理**：任何公平组合游戏都能算出 SG 值，非 0 先手必胜。

## 博弈问题的分类与前提

- 分三类：**公平组合游戏（ICG）**、非公平组合游戏（多数棋类）、反常游戏；
- 只关注 **ICG**，四个条件：
  1. 两个玩家轮流行动且游戏方式一致；
  2. 双方对局面完全了解；
  3. 游戏一定在有限步内分出胜负；
  4. 无法行动者输。
- 双方都是"神之个体"（绝对理性、全知），所以**局面一旦确定，结果就注定**，只有**必胜态 / 必败态**两种，没有任何随机成分——这个结论是反直觉的；
- 常用手段：**对数器打表找规律**。

## 上篇：经典博弈结论

| 博弈 | 结论 |
| --- | --- |
| **巴什博弈**（拿 1~m 颗，拿最后者胜） | `n % (m+1) != 0` → 先手赢，否则后手 |
| **质数次方版**（可拿 p^k 颗，p 为质数） | 只有 6 的倍数拿不到 → `n % 6 != 0` 先手赢 |
| **尼姆博弈**（n 堆，任取一堆任意颗） | **异或和 != 0 → 先手赢**；== 0 → 后手 |
| **反尼姆**（拿最后者输） | 全是 1 时看 1 的个数奇偶；否则同尼姆（异或判定） |
| **斐波那契博弈**（先手任意取，之后最多取上一次的 2 倍） | 与 Zeckendorf 定理（齐肯多夫分解）有关 |
| **威佐夫博弈**（两堆，可取一堆任意颗或两堆同数） | 与黄金分割比 `1.618`（Beatty 序列）有关 |

尼姆的正确性直觉（笔记原文）：必败态是所有堆为 0（异或为 0）；先手面对异或 ≠ 0 的局面，总能一步把异或变成 0 交给对手；对手无论怎么动，都会把异或变回非 0。

## 下篇：SG 函数与 SG 定理（重点）

### 图游戏模型

把每个局面看成图上的一个点，一次行动就是走到一个后继点；**必败局面没有后继点**。

### SG 函数（mex 过程）

- 规定必败点 `SG = 0`；
- 一般点：`SG(x) = mex({ SG(y) : y 是 x 的后继 })`，其中 mex = **不属于该集合的最小非负整数**：
  - `mex({0,1,2}) = 3`、`mex({0,2}) = 1`、`mex({1,2}) = 0`；
- `SG(x) != 0` → 必胜态；`SG(x) == 0` → 必败态。

**求 SG 表本质上就是一个标准 DP**：`sg[i] = mex{sg[j] | j 是 i 的后继}`，边界 `sg[0] = 0`。

### SG 定理（Bouton 定理）

若一个 ICG 由若干**独立子游戏**组成：

```
SG(总) = SG(分1) ^ SG(分2) ^ ...      // 异或和
SG(总) != 0 → 先手必胜
```

**数据量大时**：先打 SG 表，观察是否有简洁规律（如尼姆中 `sg[x] = x`），再用规律写出 O(1)/O(n) 的解。

## 六道进阶题

1. **巴什博弈（SG 版）**：打表验证 `n % (m+1)` 的结论；
2. **尼姆博弈（SG 版）**：打表发现 `sg[x] = x`，于是 `SG(总) = 各堆异或`；
3. **两堆石头的巴什博弈**：贪心版直接给结论 `a % (m+1) != b % (m+1)` 先手赢（SG 版与暴搜版对拍验证）；
4. **三堆石头、可取斐波那契数**：`sg` 表前段有规律、`sg(138)` 后出现异常波动 → **数据量允许就老老实实 build，不必强行找 O(1) 规律**；
5. **E&D 游戏（洛谷 P2148）**：打表发现 `sg(a,b) = lowZero((a-1) | (b-1))`（lowZero = 最低的 0 在第几位），整局 SG = 各组异或；
6. **分裂游戏（洛谷 P3185）**：**不能把瓶子当独立游戏**，要把**每颗糖豆**当独立游戏（一次操作会把一颗分裂成两颗，对应两个子游戏的 SG 异或）。

## 适用特征（看到这些信号就选它）

- 双人轮流、无随机、无法行动者输 → ICG；
- 局面能表示成"若干堆/若干组" → 想 SG 定理（异或）；
- 数据量大但规律不明显 → 打表看 SG 的周期/规律；
- 单次操作会"分裂成多个子游戏" → 子游戏 SG 异或后再 mex。

## 易错点

1. **mex 是不属于集合的最小非负整数**（不是"最小的缺失正整数"）；
2. SG 定理的前提是**子游戏相互独立**（分裂游戏就是反例：不能按瓶子分，要按糖豆分）；
3. 反尼姆要**先特判全是 1**的情况；
4. 打表发现规律前不要急着写结论；数据量允许时就老老实实算 SG；
5. 取 SG 值时下标边界（如 `appear` 数组大小）容易越界；
6. 结论类博弈（威佐夫、斐波那契）建议直接背结论 + 对数器验证。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 经典结论 ----------
bool bashWin(long long n, long long m) { return n % (m + 1) != 0; }          // 巴什
bool nimWin(const vector<int>& a) {                                          // 尼姆
    int eor = 0;
    for (int x : a) eor ^= x;
    return eor != 0;
}
bool antiNimWin(const vector<int>& a) {                                      // 反尼姆
    int eor = 0, sum = 0;
    for (int x : a) { eor ^= x; sum += x; }
    if (sum == (int)a.size()) return (sum & 1) == 0;   // 全是 1：偶数个 1 → 先手赢
    return eor != 0;
}

// ---------- 2. SG 函数（打表，O(n * 后继数)） ----------
vector<int> buildSG(int n, const vector<int>& moves) {   // moves = 每次可取的步数集合
    vector<int> sg(n + 1, 0), appear(n + 2, 0);
    for (int i = 1; i <= n; i++) {
        for (int m : moves) if (i - m >= 0) appear[sg[i - m]] = 1;
        int s = 0;
        while (appear[s]) s++;
        sg[i] = s;
        for (int m : moves) if (i - m >= 0) appear[sg[i - m]] = 0;   // 清空
    }
    return sg;
}

// ---------- 3. lowZero：status 最低的 0 在第几位 ----------
int lowZero(unsigned status) {
    int cnt = 0;
    while (status & 1) { status >>= 1; cnt++; }
    return cnt;
}

// ---------- 4. E&D 游戏：每组 (a,b) 的 sg = lowZero((a-1)|(b-1)) ----------
bool eAndDWin(const vector<pair<int,int>>& groups) {
    int sg = 0;
    for (auto& g : groups) sg ^= lowZero((unsigned)((g.first - 1) | (g.second - 1)));
    return sg != 0;
}

// ---------- 5. 分裂游戏（洛谷 P3185）：按"糖豆"建 SG ----------
// sg[i]：第 i 号瓶里一颗糖豆的 SG 值
// sg[i] = mex{ sg[j] ^ sg[k] | 0 <= k <= j < i }
vector<int> buildSplitSG(int n) {
    vector<int> sg(n, 0);
    vector<char> appear(300, 0);
    for (int i = 1; i < n; i++) {
        fill(appear.begin(), appear.end(), 0);
        for (int j = i - 1; j >= 0; j--)
            for (int k = j; k >= 0; k--)
                appear[sg[j] ^ sg[k]] = 1;
        int s = 0;
        while (appear[s]) s++;
        sg[i] = s;
    }
    return sg;
}

int main() {
    printf("巴什(10,3) = %d\n", (int)bashWin(10, 3));           // 1
    printf("尼姆(1,2,3) = %d\n", (int)nimWin({1,2,3}));          // 0
    printf("反尼姆(1,1) = %d\n", (int)antiNimWin({1,1}));         // 1
    auto sg = buildSG(10, {1, 2, 3});
    printf("sg[10] = %d\n", sg[10]);
    printf("lowZero(0b1011) = %d\n", lowZero(0b1011));           // 2
    return 0;
}
