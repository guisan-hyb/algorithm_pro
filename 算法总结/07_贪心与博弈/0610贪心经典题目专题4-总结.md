# 贪心经典题目专题 4

> 来源笔记：`0610贪心经典题目专题4.cpp`｜核心程度：必看｜分类：07 贪心与博弈

## 六道题

### 题一：数组的最小偏移量（LeetCode 1675）

操作：偶数可以 ÷2（任意次）、奇数可以 ×2（任意次，之后就变偶数了），求操作后"最大值 - 最小值"的最小值。

**贪心**：所有奇数**先乘一次 2**（这是它们唯一能变大的机会），放进有序集合；然后不断把**当前最大值**（若为偶数）÷2 放回，每次用 `max - min` 更新答案，直到最大值为奇数（不能再变小）为止。

### 题二：森林中的兔子（LeetCode 781）

`answers[i] = v` 表示"还有 v 只兔子与我同色"，所以每种颜色共有 `v+1` 只。

**分组贪心**：统计每个答案 v 的频次 `freq`，它至少需要 `ceil(freq / (v+1)) * (v+1)` 只兔子：

```
ans += (freq + v) / (v + 1) * (v + 1);
```

排序版 O(n log n)，哈希版 O(n)。

### 题三：使数组相似的最少操作次数（LeetCode 2449）

操作是"一个数 +2、另一个数 -2"，所以**奇偶性不变**：

1. 把 `nums` 和 `target` 都按奇偶分开（奇数放前面）；
2. 各自段内排序；
3. 答案 = `Σ|nums[i] - target[i]| / 4`（每次操作让总绝对差减少 4）。

### 题四：知识竞赛（牛客）

选两人使 `min(两人推理均值, 两人阅读均值)` 最大。

**贪心**：按 `|a - b|` **从小到大排序**，用 `maxA / maxB` 维护前缀最大值，枚举右端点：若 `a[i] < b[i]` 就用 `a[i] + maxA` 更新答案，否则用 `b[i] + maxB` 更新；最后答案 `/2`。

### 题五：将数组分成几个递增序列（LeetCode 1121）

把一个有序正整数数组分成若干**长度至少为 K 的不相交递增子序列**（所有元素都要用到）。

**结论**：对出现次数最多的那个数，必须把它分派到不同的子序列里，所以

```
每组长度（下界）= n / 出现次数最多的次数
答案 = (该下界 >= k)
```

笔记还给了回溯暴力版作对数器，并踩过一个坑：**在递归中遍历 `vector` 时用范围 for 取引用，`push_back` 会导致引用失效**——要用下标循环。

### 题六：最低加油次数（LeetCode 871）

**贪心视角（笔记的比喻很妙）**："路上的不是加油站，而是一桶桶油——经过时就带上，油不够时再取身上最大的一桶。"

做法：小/大根堆（这里用大根堆）存"路过的加油站的油量"；当前油量不足以到下一站/终点时，反复取最大的一桶加上并计数，取不出就返回 -1。

笔记同时给了 DP 版：`dp[i][j]` = 0~i 个加油站、恰好加 j 次油能跑的最远距离。

## 适用特征（看到这些信号就选它）

| 题面特征 | 贪心方式 |
| --- | --- |
| "偶数可除 2、奇数可乘 2，最小化极差" | 奇数先 ×2，反复把最大值 ÷2 |
| "回答同色兔子数量" | 按 v+1 分组，向上取整 |
| "±2 操作使两数组相似" | 按奇偶分离 + 排序 + 绝对差 /4 |
| "两两配对使较差能力最大" | 按 \|a-b\| 排序 + 前缀最值 |
| "分成若干长度 ≥ k 的递增子序列" | 看最高频次的数 |
| "无限油箱、最少加油次数" | 大根堆存路过的油量，缺油时取最大 |

## 易错点

1. 偏移量题：**奇数必须先 ×2**（否则没有变大机会）；
2. 兔子题别把它当成 `unique`——相同答案的人可以共享一种颜色，但**超过 v+1 个就要再开一组**；
3. 相似数组题除以 4（不是 2）；
4. 知识竞赛题最后要 `/2.0`（题目要的是平均值），中间用整数和比较；
5. 递增序列题别漏"最后一次统计"（循环外的 `maxcnt = max(maxcnt, curcnt)`）；
6. 加油题的边界："到达加油站时油量为 0 也能加"、"到达终点时油量为 0 也算到达"。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;

// ---------- 1. 数组的最小偏移量 ----------
int minimumDeviation(vector<int> nums) {
    set<int> s;
    for (int x : nums) s.insert(x % 2 == 0 ? x : x * 2);   // 奇数先翻倍
    int ans = *s.rbegin() - *s.begin();
    while (ans > 0 && *s.rbegin() % 2 == 0) {
        int mx = *s.rbegin();
        s.erase(mx);
        s.insert(mx / 2);
        ans = min(ans, *s.rbegin() - *s.begin());
    }
    return ans;
}

// ---------- 2. 森林中的兔子 ----------
int numRabbits(vector<int> answers) {
    unordered_map<int,int> cnt;
    for (int v : answers) cnt[v]++;
    int ans = 0;
    for (auto& [v, f] : cnt) ans += (f + v) / (v + 1) * (v + 1);   // 向上取整 * (v+1)
    return ans;
}

// ---------- 3. 使数组相似的最少操作次数 ----------
long long makeSimilar(vector<int> nums, vector<int> target) {
    auto splitAndSort = [](vector<int>& a) {
        int odd = 0;
        for (int i = 0; i < (int)a.size(); i++)
            if (a[i] & 1) swap(a[odd++], a[i]);
        sort(a.begin(), a.begin() + odd);
        sort(a.begin() + odd, a.end());
        return odd;
    };
    int odd = splitAndSort(nums);
    splitAndSort(target);
    long long sum = 0;
    for (int i = 0; i < (int)nums.size(); i++) sum += abs(nums[i] - target[i]);
    return sum / 4;
}

// ---------- 4. 最低加油次数 ----------
int minRefuelStops(int target, int startFuel, vector<vector<int>>& stations) {
    if (startFuel >= target) return 0;
    priority_queue<int> heap;                              // 路过的油量
    long long cur = startFuel;
    int cnt = 0;
    for (auto& st : stations) {
        while (!heap.empty() && cur < st[0]) { cur += heap.top(); heap.pop(); cnt++; }
        if (cur < st[0]) return -1;
        heap.push(st[1]);
    }
    while (!heap.empty()) {
        cur += heap.top(); heap.pop(); cnt++;
        if (cur >= target) return cnt;
    }
    return cur >= target ? cnt : -1;
}

int main() {
    printf("最小偏移量 = %d\n", minimumDeviation({1,2,3,4}));       // 1
    printf("最少兔子数 = %d\n", numRabbits({1,1,2}));                // 5
    printf("相似最少操作 = %lld\n", makeSimilar({1,2,3}, {2,1,3}));  // 0
    vector<vector<int>> st = {{10,60},{20,30},{30,30},{60,40}};
    printf("最少加油次数 = %d\n", minRefuelStops(100, 10, st));      // 2
    return 0;
}
