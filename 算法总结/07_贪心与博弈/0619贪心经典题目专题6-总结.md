# 贪心经典题目专题 6

> 来源笔记：`0619贪心经典题目专题6.cpp`｜核心程度：必看｜分类：07 贪心与博弈

## 五道题

### 题一：消灭怪物的最大数量（LeetCode 1921）

武器每 1 分钟充能一次、开局满电；怪物按 `dist/speed` 到达城市。**谁先到就先消灭谁**：算出每只怪物的到达时间（向上取整），排序后逐分钟检查

```
if (time[i] <= i) return i;      // 第 i 分钟时已有怪物到达（含"恰好在整分钟到达"也算输）
```

### 题二：最大回文数字（LeetCode 2383）

**计数贪心**：统计每个数字出现次数，

- 从 9 到 1，每对相同数字各放一半到答案两端；同时记录**出现奇数次的数字里最大的**当中间位；
- 处理 0 时要小心：**不能有前导零**（若前半段为空，只能返回单个非 0 数字，或 "0"）；
- 最后把前半段反转拼在后面。

### 题三：最大平均通过率（LeetCode 1792）

给每个班加 1 名必过学生，使平均通过率最大。

**大根堆按"边际收益"排序**：

```
收益 = (pass+1)/(total+1) - pass/total
```

每次取收益最大的班，`pass+1, total+1` 后放回，重复 `extraStudents` 次；最后求平均。

### 题四：雇佣 K 名工人的最低成本（LeetCode 857）

规则：组内按质量比例发工资，且每人不得低于期望 `wage[i]`。

**结论**：只要确定组内"性价比" `ratio = wage/quality` 的**最大值**，总成本 = `ratio * 总质量`。所以要**选择总质量最小的 k 个人**：

1. 所有人按 ratio 升序排序；
2. 依次把当前人放进**按质量的大根堆**，维护"当前 k 个人的总质量"；
3. 每凑够 k 人，就用 `总质量 * 当前 ratio` 更新答案（当前 ratio 是组内最大值，因为已按 ratio 排序）。

### 题五：砍树（PAT 平台题）

每棵树有"初始重量 + 每天增长量"，每天只能砍一棵，共 m 天，求最大收益。

**排序 + DP**：

- 先按**增长率升序**排序；
- `dp[i][j]` = 前 i 棵树、还剩 j 天的最大收益：

```
不砍第 i 棵：dp[i-1][j]
砍第 i 棵  ：dp[i-1][j-1] + 初始重量[i] + 增长[i] * (j-1)
```

（越晚砍，增长大的树收益越高，所以增长率小的先砍。）

## 适用特征（看到这些信号就选它）

| 题面特征 | 贪心方式 |
| --- | --- |
| "按到达时间先后处理" | 算时间、排序、逐分钟检查 |
| "拼出最大回文数" | 数字计数 + 中间位取最大奇数频次 |
| "逐个分配资源使平均收益最大" | 大根堆按边际收益 |
| "比例计费 + 不低于期望" | 按 ratio 排序 + 质量大根堆 |
| "每天做一件事、收益随时间增长" | 按增长率排序 + DP |

## 易错点

1. 消灭怪物题：到达时间是**向上取整**（`(dist + speed - 1) / speed`），且 `time[i] <= i` 就失败（含相等）；
2. 回文数字题：0 的前导零处理最麻烦（前半段为空时不能以 0 开头）；
3. 通过率题用 `double` 计算收益，堆的比较器要用**当前**的 pass/total；
4. 雇佣工人题：排序键是 ratio，堆里存的是**质量**（用来淘汰质量最大的）；
5. 砍树题：DP 的 `*(j-1)` 表示"还能用 j 天、今天砍则前面过了 (j-1) 天增长"；
6. 贪心结论都要对拍验证（本题集里砍树题就配了暴力对拍）。

## 模板（可直接编译运行）

```cpp
// 贪心专题6模板：消灭怪物 / 最大回文数字 / 最大平均通过率 / 雇佣工人 / 砍树
#define _CRT_SECURE_NO_WARNINGS
#include <algorithm>
#include <array>
#include <functional>
#include <iomanip>
#include <iostream>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

// ---------- 1. 消灭怪物的最大数量 ----------
int eliminateMaximum(vector<int>& dist, vector<int>& speed) {
    int n = (int)dist.size();
    vector<int> t(n);
    for (int i = 0; i < n; i++) t[i] = (dist[i] + speed[i] - 1) / speed[i];   // 向上取整
    sort(t.begin(), t.end());
    for (int i = 0; i < n; i++) if (t[i] <= i) return i;
    return n;
}

// ---------- 2. 最大回文数字 ----------
string largestPalindromic(const string& num) {
    std::array<int, 10> cnt= {0};
    for (char c : num) cnt[c - '0']++;
    string half;
    char mid = 0;
    for (int d = 9; d >= 1; d--) {
        if (mid == 0 && (cnt[d] & 1)) mid = char('0' + d);
        half.append(cnt[d] / 2, char('0' + d));
    }
    if (half.empty() && mid == 0) return "0";
    if (half.empty()) return string(1, mid);
    half.append(cnt[0] / 2, '0');
    if (mid == 0 && (cnt[0] & 1)) mid = '0';
    string ans = half;
    if (mid) ans += mid;
    for (int i = (int)half.size() - 1; i >= 0; i--) ans += half[i];
    return ans;
}

// ---------- 3. 最大平均通过率（大根堆按边际收益） ----------
double maxAverageRatio(vector<vector<int>>& classes, int extra) {
    auto gain = [](double p, double t) { return (p + 1) / (t + 1) - p / t; };
    auto cmp = [&](const vector<double>& a, const vector<double>& b) {
        return gain(a[0], a[1]) < gain(b[0], b[1]);
    };
    priority_queue<vector<double>, vector<vector<double>>, decltype(cmp)> heap(cmp);
    for (auto& c : classes) heap.push({(double)c[0], (double)c[1]});
    while (extra--) {
        vector<double> cur = heap.top(); heap.pop();
        cur[0] += 1; cur[1] += 1;
        heap.push(cur);
    }
    double sum = 0;
    while (!heap.empty()) { sum += heap.top()[0] / heap.top()[1]; heap.pop(); }
    return sum / classes.size();
}

// ---------- 4. 雇佣 K 名工人的最低成本 ----------
double mincostToHireWorkers(vector<int>& quality, vector<int>& wage, int k) {
    int n = (int)quality.size();
    vector<pair<double,int>> arr(n);                    // {ratio, quality}
    for (int i = 0; i < n; i++) arr[i] = {(double)wage[i] / quality[i], quality[i]};
    sort(arr.begin(), arr.end());
    priority_queue<int> heap;                           // 质量大根堆
    long long sumQ = 0;
    double ans = 1e18;                                  // 用大数代替 DBL_MAX，避免依赖 <cfloat>
    for (auto& pr : arr) {
        double ratio = pr.first;
        int q = pr.second;
        heap.push(q);
        sumQ += q;
        if ((int)heap.size() > k) { sumQ -= heap.top(); heap.pop(); }
        if ((int)heap.size() == k) ans = min(ans, sumQ * ratio);
    }
    return ans;
}

// ---------- 5. 砍树（按增长率排序 + DP） ----------
long long cutTrees(vector<vector<int>> tree, int day) {  // tree[i] = {初始重量, 每日增长}
    sort(tree.begin(), tree.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
    int n = (int)tree.size();
    vector<vector<long long>> dp(n + 1, vector<long long>(day + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= day; j++)
            dp[i][j] = max(dp[i - 1][j],
                           dp[i - 1][j - 1] + tree[i - 1][0] + (long long)tree[i - 1][1] * (j - 1));
    return dp[n][day];
}
// 暴力版（作对数器）：枚举每天的砍树选择
long long cutTreesBrute(vector<vector<int>> tree, int day) {
    int n = (int)tree.size();
    vector<char> used(n, 0);
    function<long long(int)> f = [&](int remaining) -> long long {
        if (remaining == 0) return 0;
        long long ans = f(remaining - 1);                       // 今天不砍
        for (int i = 0; i < n; i++)
            if (!used[i]) {
                used[i] = 1;
                ans = max(ans, f(remaining - 1) + tree[i][0] + (long long)tree[i][1] * (day - remaining));
                used[i] = 0;
            }
        return ans;
    };
    return f(day);
}

int main() {
    vector<int> dist = {1,3,4}, speed = {1,1,1};
    std::cout << "消灭怪物 = " << eliminateMaximum(dist, speed) << "\n";       // 3
    std::cout << "最大回文数字 = " << largestPalindromic("444947137") << "\n";
    vector<vector<int>> cls = {{1,2},{3,5},{2,2}};
    std::cout << "最大平均通过率 = " << std::fixed << std::setprecision(5) << maxAverageRatio(cls, 2) << std::defaultfloat << std::setprecision(6) << "\n";
    vector<int> q = {10,20,5}, w = {70,50,30};
    std::cout << "雇佣最低成本 = " << std::fixed << std::setprecision(5) << mincostToHireWorkers(q, w, 2) << std::defaultfloat << std::setprecision(6) << "\n";  // 105.00000
    vector<vector<int>> tree = {{1,2},{2,1}};
    std::cout << "砍树最大收益 = " << cutTrees(tree, 2) << " (暴力 = " << cutTreesBrute(tree, 2) << ")\n";
    return 0;
}
```

## 专题深化：为什么成立

消灭怪物按到达时间排序，因为越早到越先构成威胁；最大回文数按频率构造，中心最多一个奇数计数；平均通过率用增量最大堆，每次提升收益最大的班级。

## 专题深化：手算与边界

距离 1、3 的车与速度相同，按到达时间排序可在时间 0、1、2 依次消灭；若先打远处会错过近处。

### 对照与取舍

排序贪心处理全局顺序；堆贪心处理动态边际收益；字符串频率构造先固定高位再放中心。

### 易错点与反例

1. 到达时间用交叉相乘避免浮点
2. 平均通过率是边际递减，堆需动态更新
3. 回文首位不能为 0
4. 频率奇偶决定中心
