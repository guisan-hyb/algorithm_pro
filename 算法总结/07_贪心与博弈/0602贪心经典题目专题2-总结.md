# 贪心经典题目专题 2

> 来源笔记：`0602贪心经典题目专题2.cpp`｜核心程度：必看｜分类：07 贪心与博弈

## 六道题

### 题一：砍竹子 II（LeetCode 剑指 Offer 14- II）

把 n 分成若干段使乘积最大：**尽量多分 3**，余数 1 时改成 `3*3*...*4`（即少用一个 3 换 4），余数 2 时补一个 2：

```
tail   = n%3 == 0 ? 1 : (n%3 == 1 ? 4 : 2);
power  = (tail == 1 ? n : n - tail) / 3;
answer = 3^power * tail (mod 1e9+7)        // 用快速幂
```

> **为什么不能用 DP**（笔记的思考）：数据太大，不取模 `long long` 会溢出；取模又会让"最大值"的大小关系失真。

### 题二：分成 k 份的最大乘积（大厂笔试，n、k 到 10^12）

**基本不等式 ⇒ 均分最大**：令 `a = n/k`、`b = n%k`，答案是 `(a+1)^b * a^(k-b) (mod 1e9+7)`，用快速幂。

### 题三：会议必须独占时间段的最大会议数量（LeetCode 435 变体）

**按结束时间升序**，`cur` 记录上一个选中会议的结束时间，`start >= cur` 就选它。答案 = `n - 能参加的数量`（原题是求"最少移除几个"，两者互补）。

### 题四：会议只占一天的最大会议数量（LeetCode 1353）

**优先开最紧急（最快要过期）的会议**：

- 按开始时间排序；
- 按天遍历（从最早开始日到最晚结束日）；
- 当天开始的会议入**小根堆**（按结束时间）；
- 弹出已经过期的（`heap.top() < day`）；
- 堆非空就参加一个（`ans++` 并 pop）。

### 题五：IPO（LeetCode 502）

**选力所能及里利润最大的**：两个堆配合——

1. `minCap`：按**启动资金**升序的小根堆；
2. `maxPro`：按**利润**降序的大根堆；

每轮把 `w >= cap` 的项目从 minCap 搬到 maxPro，然后取 maxPro 堆顶（利润最大）累加到 `w`，重复 k 次。

### 题六：加入差值绝对值直到长度固定（大厂笔试）

反复把"任意两数差的绝对值"加入数组（每个新值只加一份），直到长度固定，问最终长度。

**结论（数论解法）**：由**裴蜀定理**，最终生成的元素恰好是"从 0 到 maxs、步长为 gcd"的等差数列：

```
answer = 原数组长度 + (欧氏序列元素个数 - 原数组中已有的不同元素个数)
其中欧氏序列元素个数 = maxs / gcd + (是否含 0 ? 1 : 0)
```

笔记还给了暴力模拟版作对数器，两版随机对拍通过。

## 适用特征（看到这些信号就选它）

| 题面特征 | 贪心方式 |
| --- | --- |
| "拆分使乘积最大" | 尽量拆 3（余数 1 换 4） |
| "分成 k 份使乘积最大" | 均分（基本不等式） |
| "最多能参加几个会议（独占整段时间）" | 按结束时间排序 |
| "会议只需抽一天" | 按开始时间排序 + 小根堆（最紧急优先） |
| "资本做项目、利润再投入" | 双堆（门槛小根堆 + 利润大根堆） |
| "不断取差值直到稳定" | 数论结论（gcd + 裴蜀定理） |

## 易错点

1. 砍竹子题 `n ≤ 3` 要特判（n=2、3 直接返回 1、2）；
2. 快速幂的底层写法：`ans = ans * x % MOD; x = x * x % MOD; power >>= 1;`
3. "会议独占"用 **`>=`**（结束即可开始下一场），"只占一天"用 **`>`**（当天不能再用）；
4. IPO 的两个堆方向别搞反（一个按 cap 升序、一个按 profit 降序）；
5. 差值题要处理"全是 0"（gcd = 0）与"有重复元素 ⇒ 一定会产生 0"的边界；
6. 贪心题**必须对数器验证**（本文件里每题都配了暴力对拍）。

## 模板（默写骨架）

```cpp
#include <bits/stdc++.h>
using namespace std;
const long long MOD = 1000000007;

// ---------- 快速幂 ----------
long long quickPow(long long x, long long power) {
    long long ans = 1;
    x %= MOD;
    while (power > 0) {
        if (power & 1) ans = ans * x % MOD;
        x = x * x % MOD;
        power >>= 1;
    }
    return ans;
}

// ---------- 1. 砍竹子 II ----------
int cuttingBamboo(int n) {
    if (n <= 2) return 1;
    if (n == 3) return 2;
    int tail = n % 3 == 0 ? 1 : (n % 3 == 1 ? 4 : 2);
    int power = (tail == 1 ? n : n - tail) / 3;
    return (int)(quickPow(3, power) * tail % MOD);
}

// ---------- 2. 分成 k 份的最大乘积 ----------
int maxProductOfKParts(long long n, long long k) {
    long long a = n / k, b = n % k;
    return (int)(quickPow(a + 1, b) * quickPow(a, k - b) % MOD);
}

// ---------- 3. 最多参加的会议（独占时间） ----------
int maxEventsExclusive(vector<vector<int>> intervals) {
    sort(intervals.begin(), intervals.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });
    int ans = 0, cur = INT_MIN;
    for (auto& it : intervals)
        if (it[0] >= cur) { ans++; cur = it[1]; }        // ★>
    return ans;
}

// ---------- 4. 会议只占一天的最大数量 ----------
int maxEvents(vector<vector<int>> events) {
    sort(events.begin(), events.end(),
         [](const vector<int>& a, const vector<int>& b) { return a[0] < b[0]; });
    int minDay = events[0][0], maxDay = 0;
    for (auto& e : events) maxDay = max(maxDay, e[1]);
    priority_queue<int, vector<int>, greater<>> heap;    // 结束时间
    int ans = 0, idx = 0;
    for (int day = minDay; day <= maxDay; day++) {
        while (idx < (int)events.size() && events[idx][0] == day)
            heap.push(events[idx++][1]);
        while (!heap.empty() && heap.top() < day) heap.pop();   // 过期的丢掉
        if (!heap.empty()) { ans++; heap.pop(); }
    }
    return ans;
}

// ---------- 5. IPO（双堆） ----------
int findMaximizedCapital(int k, int w, vector<int> profits, vector<int> capital) {
    int n = (int)profits.size();
    vector<int> idx(n);
    iota(idx.begin(), idx.end(), 0);
    sort(idx.begin(), idx.end(), [&](int a, int b) { return capital[a] < capital[b]; });
    priority_queue<int> maxPro;
    int i = 0;
    while (k-- > 0) {
        while (i < n && capital[idx[i]] <= w) { maxPro.push(profits[idx[i]]); i++; }
        if (maxPro.empty()) break;
        w += maxPro.top(); maxPro.pop();
    }
    return w;
}

// ---------- 6. 差值绝对值直到长度固定（裴蜀定理） ----------
int finalLength(vector<int> arr) {
    if (arr.size() < 2) return (int)arr.size();
    unordered_map<int,int> cnt;
    int g = 0, maxs = 0;
    for (int x : arr) { maxs = max(maxs, x); g = std::gcd(g, x); cnt[x]++; }
    if (g == 0) return (int)arr.size();
    int distinct = (int)cnt.size();
    bool hasZero = cnt.count(0) > 0 || distinct < (int)arr.size();   // 有重复必产生 0
    int seqLen = maxs / g + (hasZero ? 1 : 0);
    return (int)arr.size() + (seqLen - distinct);
}

int main() {
    printf("砍竹子(10) = %d\n", cuttingBamboo(10));                  // 36
    printf("分k份最大乘积(n=6,k=3) = %d\n", maxProductOfKParts(6, 3));// 8
    printf("独占会议数 = %d\n", maxEventsExclusive({{1,2},{2,3},{3,4}}));  // 3
    printf("只占一天会议数 = %d\n", maxEvents({{1,2},{2,3},{3,4}}));       // 3
    printf("IPO = %d\n", findMaximizedCapital(2, 0, {1,2,3}, {0,1,1}));    // 4
    printf("最终长度 = %d\n", finalLength({6, 10}));                 // 4 (0,2,4,6,10)
    return 0;
}
